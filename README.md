# MathStart

Образовательный сайт по математике для 5–10 классов: Django, SQLite, серверные HTML-шаблоны. В каталоге 281 опубликованная страница: 263 урока и 18 страниц сайта.

## Где редактировать материалы

**Все 263 урока, включая старые и версии 2.0, находятся в `curriculum/`.** Найдите тему в [указателе уроков](curriculum/INDEX.md). В каждой папке обязательны только `lesson.json` и `body.html`. Файлы `page.css` и `page.js` добавляются, когда уроку нужны собственные стили или скрипт; пустые файлы не требуются.

- Учебный текст, формулы, рисунки и интерактивные блоки: `body.html` нужной темы.
- Название, порядок, SEO и статус публикации: `lesson.json`.
- Особое оформление и поведение конкретной темы: её необязательные `page.css` и `page.js`.
- Общая оболочка сайта: `templates/page_detail.html` и `templates/includes/`.
- Чтение и публикация исходников: `content/services/`.
- Обычные страницы сайта (контакты, главная и т. п.): Django Admin.

Все уроки и остальные страницы сайта используют единое оформление на основе темы «Свойства степенных функций и их графики 2.0». Заголовки, примеры, таблицы, карточки и самопроверка получают стиль из общих файлов `static/mathstart/css/`. Старых локальных вариантов этих компонентов больше нет; `page.css` нужен только для особенностей конкретного материала. Общая тема действует при любой ширине экрана. Отдельная переработка мобильного интерфейса в этот этап не входила.

Основной стиль находится в `lesson.css`, дополнительные общие компоненты, математическое оформление и диаграммы — в отдельных именованных файлах той же папки. Оболочка сайта использует `site.css`. Компоненты содержания, раздела и задания находятся в `templates/lessons/components/`, код общего графика степенных функций — в `static/mathstart/js/widgets/`. Подробнее: [карта общих стилей и ресурсов](docs/lesson-theme.md).

Изменение файлов урока появляется на сайте после публикации. Для уроков, связанных с исходниками, админка показывает путь к файлам и доступна для просмотра содержимого. Исторические генераторы больше не заменяют такие страницы.

Читайте [правила редактирования](docs/editing-lessons.md) и [архитектуру](docs/architecture.md).

## Запуск на Windows

Требуются Python 3.10 или новее и зависимости из `requirements.txt`. Для нового окружения:

```powershell
py -m venv .venv
.venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
```

Если старое `.venv` ссылается на удалённый Python, создайте рабочее окружение с установленным интерпретатором. Команды ниже выполняются из корня проекта в активированном окружении.

Если `.env` отсутствует, скопируйте `.env.example` и задайте `DJANGO_SECRET_KEY`; для разработки включите `DJANGO_DEBUG=1`. Существующий `.env` не заменяйте.

```powershell
python manage.py migrate
python manage.py collectstatic --noinput
python manage.py runserver
```

Откройте [локальный сайт](http://127.0.0.1:8000/). Рабочая база `db.sqlite3` уже содержит материалы. Для новой пустой базы после миграций:

```powershell
python manage.py loaddata var/exports/mathstart-content-unified.json.gz
python manage.py check_lesson_sources --all
```

Это актуальный переносимый экспорт после объединения оформления. Файл `data/mathstart_content.json.gz` оставлен как предыдущий снимок; его не следует использовать для восстановления текущей версии. При переносе проекта сохраняйте `curriculum/`, `media/`, шаблоны и код вместе с базой или актуальным экспортом. Каталог `var/` исключён из контроля версий, поэтому экспорт нужно включить в перенос отдельно. В production каталог `media/` обслуживает веб-сервер; исходники `curriculum/` публично не раздаются.

## Публикация одного урока

Например, после редактирования темы 6.6:

```powershell
python manage.py publish_lessons --slug kvadratichnaya-funkcziya-y-ax2-bx-c --dry-run
python manage.py publish_lessons --slug kvadratichnaya-funkcziya-y-ax2-bx-c
python manage.py check_lesson_sources --slug kvadratichnaya-funkcziya-y-ax2-bx-c
```

Весь каталог выбирается явно через `--all`. Публикация проверяет конфликты, сохраняет резервную копию SQLite в `var/backups/` и записывает выбранные изменения одной транзакцией. Повторный запуск без изменений не обновляет страницы и даты.

## Проверки

```powershell
python manage.py check
python manage.py test
python manage.py check_lesson_sources --all
python manage.py check_site_integrity
python manage.py check_content_quality
```

`check_lesson_sources` сравнивает файлы с базой. Два следующих аудита проверяют внутренние ссылки, изображения, ответы страниц, SVG и служебные заглушки. Тесты `content/test_shared_styles.py` проверяют, что в локальные стили не возвращаются общие темы и встроенные таблицы стилей. Эти проверки не заменяют редакторскую проверку математики и графиков.

## История переноса

Проект перенесён с WordPress. Первоначальные исходники сохранены в `source/`, прежние генераторы — в `content/lessons/`, исторические резервные копии, отчёты и предыдущий экспорт — в `data/`. Папка `data/` при объединении оформления не изменялась. Её резервные копии и отчёты не загружаются при обычном открытии сайта, но нужны для истории и восстановления прежних состояний; на часть файлов ссылаются старые инструменты.

[Исторические инструкции](docs/migration-history.md) описывают прежнюю структуру. Новые исходники — `curriculum/`, новые резервные копии — `var/backups/`. Содержимое прежних уроков, адреса и версии 2.0 сохранены.
