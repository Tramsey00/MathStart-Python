# Главная MathStart — локальный React-прототип

Проба выбранного пользователем направления, не внедрение в публичный сайт и не
закрытие полной задачи MS-N001. Ветка `ui/ux`, исходный main `1a015f7`.

- Структура: [Math Learning Website UI](https://www.figma.com/community/file/1652599323840288360/math-learning-website-ui),
  Ayush Kumbhar’s team, CC BY 4.0. Адаптация: русский язык, классы/предметы/разделы
  MathStart, поиск и мобильная навигация; исходные иллюстрации/код не копировались.
- Тема: [Professional Theme](https://tweakcn.com/themes/cmluajfgz000004l5afke7znm),
  Rachel Hong. Полный исходный экспорт сохранён в `theme.registry.json`;
  `theme.css` — его light/dark/theme cssVars без ручной подмены цветов.
- React/Vite берутся из существующего lock. shadcn, Tailwind и Next.js не установлены:
  для пробы используются CSS-переменные темы и обычные React-компоненты.
- Inter (Latin/Cyrillic) хранится локально с OFL. Моноширинный шрифт объявлен
  экспортом, но в этом макете не используется и не загружается.

## Запуск

Из `frontend/` после установки существующих locked dependencies:

```powershell
node node_modules/vite/bin/vite.js --config prototypes/home/vite.config.mjs
```

Открыть http://127.0.0.1:5173/. Порт отдельный, БД/контейнеры не запускаются.
Нужен Node из диапазона `frontend/package.json`. Остановка: Ctrl+C.

Проверки из `frontend/`:

```powershell
node node_modules/typescript/bin/tsc -p prototypes/home/tsconfig.json
node node_modules/vite/bin/vite.js build --config prototypes/home/vite.config.mjs
node node_modules/@playwright/test/cli.js test --config prototypes/home/playwright.config.ts
```

Browser checks используют установленный Chrome; сервер запускается автоматически,
если порт свободен. Результаты, build и screenshots — в игнорируемом `frontend/.cache/`.
Этот отдельный конфиг не входит в существующий product CI и не заменяет его.

## Границы

Каталог строится из опубликованных `lesson.json` и `site_content/catalog.json`.
Тексты уроков и HTML для верхней иллюстрации не извлекаются.
Исходники читаются при запуске/build; после правок контента перезапустить сервер.
Проба не является authoritative publication и не обходит gateway основного сайта.
Тексты, счётчики тем и ссылки настоящие; процент освоения, XP, тесты, рейтинг и
персональный прогресс не имитируются. Тема/класс/поиск в памяти до обновления.
По умолчанию 7 класс / алгебра для сравнения с выбранным образцом.

Вход, все темы и уроки ведут на существующий локальный сайт :8121. Если он не
запущен, эти переходы недоступны. Новая форма входа в этот прототип не входит.
Прототип адаптирован под 360/768/1440/1920; desktop sidebar превращается в native
modal dialog с Escape и восстановлением фокуса. 60/30/10 — ориентир баланса:
белая основа, вспомогательные поверхности, синий акцент. Это не измеренные доли
пикселей. Доступность и человеческая визуальная приёмка ещё требуют оценки.

После просмотра отдельно решить: сохраняем ли выбранную структуру, начальный
экран/класс, плотность карточек, цвета и меню. Перенос на `/`, библиотека компонентов,
SSG/no-JS, поисковые URL, auth и rollout требуют следующего явного поручения.

## Управление меню

Повторное нажатие на выбранный предмет сворачивает список разделов, сохраняя
выбранный предмет. Все шесть классов видны открытым рядом без выпадающей панели.
На компьютере выбор расположен в sidebar, на мобильном — также над заголовком.
Tab перемещает фокус, Enter/Space выбирает класс; фокус остаётся на выбранной
кнопке. Escape закрывает мобильное меню.

Фон и поверхности используют те же tokens Professional Theme. Экспорт темы
сохранён. Декоративные и финальные точки в коротких UI-подписях убраны;
пунктуация авторских названий и учебных материалов сохранена.

Разделы показаны открытым списком в две колонки (на телефоне — в одну): без
рамок-карточек и теней. Горизонтальные линии и центральная вертикальная линия
образуют общую сетку; у последнего непарного раздела вертикальной линии нет.
Отступы внутри разделов сокращены. Hero не обёрнут в панель.
Удалены служебная отметка дизайна, мотивационная карточка sidebar, блок других
предметов и весь прежний footer. Источники и атрибуция дизайна сохранены в этом
README. Вместо шрифтового ± используется выровненный SVG-знак математики.

Верхняя область содержит расширенное описание предмета и общую SVG-иллюстрацию:
дроби с полосой долей, решение уравнения, последовательность квадратных чисел
и небольшой график. Рисунок декоративный, использует цвета/шрифты темы и не
содержит ответов на упражнения. Убраны первая тема курса, верхние счётчики, подпись «Открыть раздел»
и точка навигации. Раздел открывается нажатием на всю область, стрелка остаётся.
На телефоне у каталога остаются только горизонтальные разделители.
Hover разделов не меняет фон/границу/тень; keyboard focus сохраняется.

Повторяющий класс breadcrumb и блок «Твоё обучение / Учебные материалы» удалены.
Класс над названием предмета и соседний значок увеличены. У heading каталога
нет счётчика. Поле «Найти раздел» увеличено и имеет постоянную тонкую рамку;
при фокусе рамка темнеет, без синей обводки.

Пустой поиск — компактная строка со значком, пояснением области поиска и кнопкой
сброса. Сброс возвращает фокус в соответствующее поле. Номера разделов сохраняют
место в полном списке при фильтрации. Окно раздела расширено до 800 px: заголовок
на secondary surface, нумерованный список настоящих тем, прокрутка длинных
списков. Escape и кнопка закрытия возвращают фокус к открывшему окно элементу.
Окно тем также закрывается нажатием на затемнённый фон. Нажатие внутри окна
и перетаскивание из окна на фон не закрывают его.

Выбранная тема принята пользователем как основа последующих страниц:
[theme-baseline](../../../docs/ux/theme-baseline.md). Исходный export проверен
повторно; применение общей темы во всём продукте — отдельное будущее внедрение.
