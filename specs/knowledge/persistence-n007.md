# MS-N007 — хранение графа и привязок тем

[R03](R03-knowledge-graph.md) задаёт `pilot-v1` из 10 навыков и 13 рёбер.
Отдельный [пакет Content](fixtures/pilot-topic-skills-v1.json) содержит две
утверждённые Русланом привязки 6 класса. «Упрощение выражений, раскрытие скобок»
связано с `expand_parentheses`, «Решение линейных уравнений» — с `linear_one_step`.
Роль обеих связей PRIMARY, importance 1, позиция 0. Content сверяет класс,
предмет, раздел, slug и статус публикации, затем сохраняет FK на существующий
`content_contentpage.id`. При снятии темы с публикации связь сохраняется для
истории и скрывается при чтении.

## Чтение

`backend.knowledge.repository.read_pilot_graph(database)` возвращает
неизменяемый DTO графа или `None` до импорта. `ancestors(code, max_depth=2)`
возвращает пары `(skill_code, depth)` в порядке глубины и кода. Внешняя
предпосылка `basic_arithmetic` представлена отдельным полем графа.

`backend.content.topic_skills.read_topic_skills(database, content_page_id)`
возвращает связи с активными навыками в порядке позиции и кода, пустой кортеж
для опубликованной темы без связей или `None` для недоступной темы. DTO содержит
код и имя навыка, роль, вес, позицию и версию привязки. Будущий HTTP-адаптер
учтёт видимость темы в активной редакции Content.

## Миграция и импорт

Ревизия `v01_0004` добавляет три таблицы и FK с защитой от удаления. Для
установленного `v01_0003` используйте `backend.release_migrate preview --profile
TARGET_0003` с новым plan-file, затем обычные `apply` и `check` по
[регламенту](../../deploy/RELEASE.md). Для локальной установки используйте
[host-dev](../../docs/local-development-host.md#4-ежедневный-старт-и-остановка)
или [Compose](../../docs/local-development.md#обновление-установленной-compose-базы-до-v01_0004).
Роли приложения нужен `SELECT` на
`knowledge_skill`, `knowledge_skill_dependency` и `content_topic_skill`.
Локальный проверяющий ACL учитывает эти права.

После установки схемы и публикации обеих тем оператор с правом записи в новые
таблицы и блокировки строк каталога запускает явный импорт с конфигурацией
целевого PostgreSQL:

```text
python -m backend.content.import_pilot_knowledge --apply
```

Команда печатает JSON со статусом `IMPORTED` или `UNCHANGED`, количеством
навыков, рёбер и привязок, а также ID обеих тем в выбранной базе. Повтор
сохраняет ID. При отказе транзакция откатывается. При неопределённом результате
commit оператор сверяет сохранённые данные. Для отката приложения нужна версия,
совместимая с расширенной схемой. Исправления схемы вносятся следующей
аддитивной миграцией.
