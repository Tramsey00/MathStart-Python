# Общий стиль уроков MathStart

Используйте [общий UI-контракт](ux/shared-ui-contract.md) и
[стандарт учебных страниц](frontend/lesson-migration.md).
Шапка, подвал, структура урока, раскрытие ответа и работа с иллюстрациями
принадлежат `frontend/src/shared/lesson/`. Токены и общие шрифты находятся
в `frontend/src/shared/styles/`. Для авторских блоков используйте описанный
в стандарте формат `content.json`. Новый интерактив добавляйте в общую React
систему только по отдельному поручению.

Описание старого HTML renderer сохранено в
[редакции до MS-T011](https://github.com/Tramsey00/MathStart-Python/blob/618075d9a6b8d5a8bc2f84b15386556a6acac8ca/docs/lesson-theme.md).
