# Адрес React-пилота, 2026-10-23

Пользователь согласовал формат /materials/<класс>-<предмет>-<номер> и разрешил
подключить его только к пробной странице квадратичной функции.

Присвоен /materials/8-algebra-32. На дату назначения урок занимает 32-е место
среди 39 опубликованных тем алгебры 8-го класса при сортировке по порядку раздела,
затем порядку темы и slug. Это первоначальное назначение, не runtime-алгоритм URL.
Запись зафиксирована в frontend/prototypes/home/lesson-routes.mjs и не должна
перенумеровываться при изменении порядка или добавлении тем. Slug canonical
curriculum, содержимое и опубликованный runtime 8121 не изменяются.

Vite dev/preview обслуживают чистый адрес через прежний HTML entry, который
остаётся внутренним build input. Старый /quadratic.html, прежний длинный slug
и новый адрес с завершающим / перенаправляются на выбранный путь (302 в
экспериментальном прототипе). Query и browser fragment сохраняются. Поиск и
список тем каталога используют общую запись маршрута. Это не миграция адресов
основного FastAPI/SSG runtime и не статическая публикация без rewrite-сервера.

Целевой Chrome-просмотр на dev 5173 подтвердил прямое открытие (200), reload,
redirect всех трёх aliases, сохранение query/fragment и переход из поиска
каталога. Pageerror отсутствует. Результаты и screenshot в
frontend/.cache/lesson-url-preview/. Первый вспомогательный просмотр остановился
на неверном селекторе поиска; после чтения реального input выбран #topic-search,
повтор завершён. Не засчитывается первоначальный timeout как успешная проверка.
Build, preview server, полный Playwright suite и target gate не запускались.
