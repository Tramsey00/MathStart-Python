# Общие компоненты и оформление MathStart

## Действующее состояние MS-T011

Принятая система MathStart сохраняет общую навигацию, обе темы и локальные шрифты. Текущие поведение и оформление описаны ниже. [История UI-решений](shared-ui-history.md) сохраняет первоначальные сценарии, отклонённые макеты, receipts и даты.

| Поверхность | Действующий интерфейс и владелец |
| --- | --- |
| Главная `/` | Принятая «Орбита» в [HomePage](../../frontend/src/features/public-pages/home-page.tsx). Спираль из 11 витков задаёт один путь для линии и бегущей точки. Пауза на рисунке, клавиатурный фокус, сохранение фазы, остановка вне видимости и reduced motion. |
| Каталог `/materials` | [MaterialsPage](../../frontend/src/features/public-pages/materials-page.tsx) сохраняет предметное вступление, общий рисунок, список разделов и диалог тем. Глобальный поиск открывается в строке шапки, на мобильном экране поле разворачивается под ней. Escape закрывает поиск или диалог, фокус возвращается к вызвавшему элементу. Ссылки каталога используют canonical URL из Content. Для отключённого JavaScript сохраняется читаемый список. |
| Уроки | [LessonPageShell](../../frontend/src/shared/lesson/lesson-shell.tsx) использует тот же [OrbitHeader](../../frontend/src/shared/ui/orbit-header.tsx), что главная. В оболочке остаются учебное оглавление, якоря, общие блоки и ссылки на соседние темы. Данные и порядок тем приходят из Content. |
| Авторизация и кабинет | [Identity](../../frontend/src/features/identity/account-page.tsx) обслуживает самостоятельную страницу входа со своим Brand, локальными ошибками и защищёнными сценариями восстановления. Личный кабинет использует общую шапку, выбор класса и разделы аккаунта и безопасности. Состояния формы и ошибок привязаны к конкретному действию. |
| 404 | [PageStatus](../../frontend/src/features/public-pages/page-status.tsx) использует общие шапку и подвал, текст ошибки и прямые действия «К материалам» и «На главную». [MongeArtwork](../../frontend/src/features/public-pages/monge-artwork.tsx) размещён в увеличенной desktop-колонке. На узком экране рисунок идёт после текста. В композиции три одноцветные окружности, шесть общих внешних касательных, ось и три центра гомотетии. |

## Темы, шрифты и компоненты

- Базовые назначения идут из [theme.css](../../frontend/src/shared/styles/theme.css) и [base.css](../../frontend/src/shared/styles/base.css). Outfit используется для Brand и базового sans stack, Merriweather Italic — для serif-акцентов, STIX Two Math — для математической нотации урока. Golos Text подключён локально для Orbit-поверхностей и форм авторизации. JetBrains Mono указан в базовом fallback-стеке. Шрифты и лицензии хранятся в [fonts](../../frontend/src/shared/styles/fonts).
- [Orbit CSS](../../frontend/src/features/public-pages/orbit.css) задаёт локальные light/dark поверхности. Шапка использует `#f1f3fc` / `#141a31`, цвет текста `#252943` / `#eef0ff` и primary `#4655c6` / `#b5bfff`. Главная и 404 используют hero-primary `#4f22f1` / `#b5bfff`; светлая поверхность hero `#e7f0f8c4` дополняется локальным фоном. Каталог задаёт собственные токены поверх Orbit, а формы входа — [auth-appearance.css](../../frontend/src/features/identity/auth-appearance.css). Binding цветов остаётся в CSS.
- [theme-baseline.md](theme-baseline.md) описывает происхождение Professional Theme и QraftHive. [theme.registry.json](theme.registry.json) сохраняет исходный registry. Границы реализации задаёт каскад действующего CSS.
- Общая шапка владеет Brand, навигацией, состоянием аккаунта и переключателем темы. Общий подвал и оболочка урока находятся в [lesson-shell.tsx](../../frontend/src/shared/lesson/lesson-shell.tsx). У каждого экрана один главный заголовок и доступная навигация с клавиатуры. Состояние ошибки показано текстом рядом с соответствующим действием. Клиентский UI не подменяет серверную авторизацию и проверки.

## Движение на 404

SVG отрисован целиком в исходном HTML. Касание или клик по рисунку, Enter и Space управляют паузой через нативную кнопку. При продолжении сохраняется фаза. Один [модуль движения](../../frontend/src/features/public-pages/monge-motion.js) обслуживает React и автономный 404-документ. Скрытая вкладка и рисунок вне экрана останавливают кадры, reduced motion оставляет статичное построение. Цвет окружностей берётся из `--primary`, касательные и ось различаются контрастом и толщиной.

## Маршруты и статус

Номера 263 тем закреплены в [карте маршрутов](../../site_content/material-routes.json). Каталог, поиск и навигация ведут прямо на действующий URL. Выведенные учебные адреса возвращают HTTP 404 на исходном URL с `noindex`. Технические HTTPS/auth redirects сохраняются. Содержание урока, учебные якоря и формулы меняются по [стандарту переноса](../frontend/lesson-migration.md) и действующим контрактам.

Код MS-T011 находится в [PR #85](https://github.com/Tramsey00/MathStart-Python/pull/85). На момент передачи активен локальный immutable выпуск `ms-t011-81b6994-20261118`. Кандидат с итоговой 404 `ms-t011-6709507-20261118` подготовлен для своего SHA и ожидает утверждения. Host-dev показывает исходники через HMR. Ручной отзыв о локальном выпуске и итоговая приёмка всей MS-T011 учитываются отдельно в [карточке](../../skills/tasks/t011-rollout-finalization/SKILL.md).
