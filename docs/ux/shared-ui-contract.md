# Общие компоненты и оформление MathStart

Статус: пользователь согласовал структуру учебной страницы, шапку, подвал,
управление и анимации 23.10.2026. Этот документ закрепляет основу для следующих
страниц. Реализация пока подключена к самостоятельному Vite-прототипу;
основной FastAPI/React SSG runtime не переведён на неё автоматически.

## Владение и переиспользование

Новую страницу собирают из существующих компонентов и данных. Не копируют
их JSX/CSS в новую папку урока. Общая правка компонента применяется ко всем
его потребителям; частный вариант задаётся параметрами или локальным классом,
без изменения глобальной темы ради одного экрана.

| Общая часть | Источник | Что передаёт страница |
| --- | --- | --- |
| Professional Theme light/dark | frontend/src/shared/styles/theme.css | data-theme на html |
| Шрифты, reset, focus, skip link | frontend/src/shared/styles/base.css и fonts/ | Подключение базового CSS один раз |
| Логотип | frontend/src/shared/ui/brand.tsx, brand.css | Контекстный размер через CSS оболочки |
| Тема интерфейса | frontend/src/shared/ui/use-site-theme.ts | Состояние/обработчик в оболочку; один владелец на страницу |
| Оболочка урока | frontend/src/shared/lesson/lesson-shell.tsx | brand, contents, children, dark/onTheme, адреса и gradeLinks |
| Стиль урока и анимации | frontend/src/shared/lesson/lesson.css, lesson-shell.css | Класс lesson-page на body |
| Заголовок и breadcrumbs | LessonHeading | breadcrumbs, title, subtitle |
| Содержание | LessonContents | sections, title, catalogueHref |
| Самопроверка | SelfCheck / LessonDisclosure | question, kind, children с ответом |
| Примеры и примечания | WorkedExample / LessonNote | children |
| Соседние темы | LessonNavigation | previous/next, href(topic), catalogueHref |
| Статичная схема | LessonDiagram | Исходный SVG и подпись по существующим props |
| Материал из узлов | LessonSource | nodes с сохранённым учебным содержимым |
| График квадратичной функции | QuadraticGraph / quadratic-math.ts | Отдельный предметный виджет, не общий график всех тем |
| URL материалов | frontend/src/shared/routing/material-routes.mjs | Явно назначенные slug/grade/subject/number |

Экспорт компонентов: frontend/src/shared/lesson/index.ts. Стили подключаются
явно: theme.css, base.css, lesson.css. lesson-shell.css подключает LessonPageShell.
Прототип использует style.css с импортом общего base.css и сохраняет свои стили
главной/каталога. Их уже утверждённая композиция отличается от оболочки урока.
Не нужно применять lesson shell к формам кабинета или каталогу буквально:
повторно используются подходящие общие части, а не весь экран.

В frontend/src/shared/ui/components.tsx уже есть Button/Field и другие примитивы
действующего runtime. Они не удалены и не переоформлены. При будущей интеграции
нужно согласованно расширить их вариантами нового оформления, не создавать
параллельную копию для каждой страницы и не менять формы без проверки.

## Подключение урока

```tsx
import { Brand } from '../shared/ui/brand';
import { useSiteTheme } from '../shared/ui/use-site-theme';
import { LessonPageShell, LessonContents, LessonHeading,
  LessonNavigation, LessonSource } from '../shared/lesson';
import '../shared/styles/theme.css';
import '../shared/styles/base.css';
import '../shared/lesson/lesson.css';
```

Пути в примере относительные: зависят от расположения route-файла.
Контейнер страницы задаёт body.lesson-page. lesson-preview-page оставлен
совместимым алиасом для существующих browser checks. Оболочка содержит один
main#lesson-content; её экземпляр на странице должен быть один.
Владельцем URL, данных каталога, контента, brand и theme state остаётся адаптер
страницы; общая оболочка не импортирует Vite virtual modules, prototype или API.

LessonHeader может использоваться отдельно с brand/catalogueHref/loginHref и
темой. LessonFooter принимает brand, homeHref/catalogueHref/accountHref и
массив {title,href} для классов; данные не зашиты в компонент.
LessonHeading принимает произвольный ReactNode для формулы в заголовке и
массив {label,href?}; отсутствие href означает обычный текст, не пустую ссылку.
LessonNavigation не выводит отсутствующего соседа на границе раздела.
Наличие кнопки/ссылки определяется действительным действием, а не декорацией.

## Кнопки и состояния

Общие действия уже инкапсулированы в соответствующих компонентах:

| Действие | Вид и поведение |
| --- | --- |
| Ответ и решение | Справа от задания, 33 px, 12.5 px, pill; normal нейтральный, hover синий, open тёмный. Только кнопка раскрывает ответ. На телефоне под текстом справа. |
| Предыдущая / следующая тема | Ссылки 44 px со стрелками; previous нейтральная рамка, next синий контур. Названия тем только в доступных aria-label, не под кнопками. |
| Все темы раздела | Нейтральная ссылка-кнопка 44 px, без подчёркивания. |
| Сбросить коэффициенты | Нейтральная поверхность, тонкая рамка, синий текст. Кнопка принадлежит графику. |
| Материалы в шапке | Книга + текст, без рамки/фона, weight 500. |
| Вход | Синий квадрат со скруглением и контурной стрелкой; aria-label/title, настоящий href. |
| Тема / закрыть содержание | Иконки с доступным именем, focus-visible и нейтральным hover. |

Общий вид задают CSS-классы компонентов, а не копии inline styles. Не заменять
ссылки на span/button, если это навигация; не делать submit-кнопки без намерения.
Focus-visible сохраняется. На кнопках/навигации user-select:none; текст заданий,
ответов и формул копируется. В lab copy/cut/drag отменены по решению пользователя.
Согласованный размер answer-кнопки не увеличивать по вкусовой рекомендации.

## Палитра и типографика

Professional Theme и QraftHive закреплены в theme-baseline.md. Файлы темы и
шрифтов перенесены без изменения bytes; OFL сохранены рядом. Outfit не содержит
кириллицы: работает согласованный системный fallback. Merriweather Italic — формулы.
Зелёный дополнительный акцент разрешён только главной, не урокам.

Для уроков используются семантические --lesson-* поверхности и действия.
--lesson-accent отвечает за линии/исходный брендовый синий;
--lesson-accent-text — за читаемый синий текст, особенно в dark;
--lesson-action-accent/foreground — контрастная пара кнопки ответа;
--lesson-footer-muted/accent-text — текст на фоне подвала.
Нельзя подменять все четыре роли одной переменной: проверка уже выявляла
недостаточный контраст. Мелкий текст normal/hover/open должен иметь ≥4.5:1,
нетекстовые значки и границы важных контролов — ≥3:1.

## Компоновка и движение

Белая светлая шапка, отдельное боковое содержание на desktop, отдельная строка
на телефоне. В статье нет повторяющихся карточек и вертикальных акцентных полос.
Подвал выделен фоном, классы симметрично сгруппированы, кнопки Наверх нет.
Содержание: номера с точками, маленький промежуток, активный пункт выделен
только фоном. Escape/backdrop, focus trap/return, scroll lock обязательны.

CSS motion: fast 160 ms; drawer 280 ms вход/220 ms выход, backdrop согласован;
ответ 240 ms с natural height/opacity, hidden content inert/aria-hidden;
reset графика rAF 360 ms с синхронными значениями и остановкой от ручного ввода.
Reduced motion отключает переходы и делает reset мгновенным. Hover не выбирает
точку; tap подтверждается только после исключения движения/cancel. Прокрутка
через график сохраняется. Формулы и абзацы не получают scroll-reveal/parallax.

## Постоянные URL

Формат: /materials/<класс>-<предмет>-<номер>, без .html и завершающего /.
Примеры формата: /materials/5-math-1, /materials/8-algebra-32.
Это не обещание, что все примерные адреса уже обслуживаются.

buildMaterialPath проверяет положительные целые grade/number и латинский
lowercase subject code. В materialRoutes регистрируются уникальные slug/path.
materialPathForSlug возвращает только назначенный путь либо undefined.
Сейчас назначен только пилот: 8/algebra/32. Номер 32 один раз выбран по текущему
каталогу и больше не зависит от порядка. Новая тема получает свободный номер;
вставка в раздел меняет display order, но не URL соседей. Номера не переиспользовать.
Если меняется класс/предмет существующего урока, старый адрес сохраняют как alias,
а судьбу canonical решают явно: не пересчитывают автоматически.

Прототип обслуживает этот маршрут через Vite middleware, а старые HTML/slug
адреса перенаправляет (302, с query/fragment). Для остальных уроков сохраняются
существующие ссылки. При интеграции в SSG требуется отдельно подключить реестр
к генерации страниц и redirects веб-сервера, проверить direct/reload/старые ссылки.
Одно добавление записи в реестр пока не публикует новый урок автоматически.

## Сохранность и следующие этапы

curriculum и его body.html/lesson.json/page.css/page.js остаются каноническими.
lesson-source.mjs — действующий build adapter пилота, не мусор. quadratic.html,
virtual modules и Vite entry пока нужны для просмотра; удалять их можно после
проверенной интеграции в основной route. Math и authored SVG не переписываются.
Legacy self-check не становится серверной проверкой попыток или mastery.
Главная, каталог и урок пока показываются отдельным прототипом на 5173.

Изменение общих компонентов требует затронутых проверок, включая другие
потребляющие страницы. Прошлый аудит подтверждает прежний fingerprint, не новую
ревизию после рефакторинга. Итоговые отчёты и evidence сохраняются; черновые
скриншоты, временные профили и кеши можно удалить по scoped manifest.
AGENTS.md/скилы, слияние main и новая рабочая ветка — отдельный следующий этап.
