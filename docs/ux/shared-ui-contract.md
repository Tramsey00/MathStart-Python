# Общие компоненты и оформление MathStart

Статус: пользователь согласовал структуру учебной страницы, шапку, подвал,
управление и анимации 23.10.2026. Этот документ закрепляет основу для следующих
страниц. Описание раннего Vite-прототипа ниже — историческое; текущие правила
интеграции и preview указаны в действующих решениях ниже и стандарте миграции.

## Владение и переиспользование

Требования к переносу главной и каталога, 23.10.2026:

- Все страницы используют LessonHeader и LessonFooter из общего модуля
  lesson-shell, включая одинаковые light/dark поверхности и состояния кнопок.
  Каталог передаёт в шапку кнопку мобильной навигации и лупу справа как слоты.
  Поле поиска плавно расширяется влево внутри самой строки шапки, без панели
  под ней. На узком экране открытое поле временно заменяет логотип.
  Ссылка «Материалы» в самом каталоге скрыта;
  на главной и в уроках остаётся. При открытии лупа остаётся, выделяясь мягким акцентным фоном,
  фокус переходит в поле. Закрытие — кнопкой в шапке, Escape или нажатием вне
  панели. В поле только один крестик очистки; закрытие не стирает запрос.
  Кнопка и Escape возвращают фокус на переключатель, нажатие вне панели
  сохраняет обычное взаимодействие с выбранным элементом страницы.
- Ссылки классов в подвале формируются из canonical catalogue; авторизация
  использует существующий согласованный маршрут, без новой логики сессий.
- В нумерованных списках разделов и тем после номера стоит точка;
  отступ до названия компактный, переносы не смещают колонку номера.
- Список разделов под предметом раскрывается и сворачивается плавно.
  Скрытый список недоступен для фокуса; prefers-reduced-motion отключает движение.

Текущий вид каталога визуально одобрен пользователем 23.10.2026: общая шапка
и подвал, компактная нумерация, плавное меню слева, расширяемый поиск в шапке
и hover кнопки темы. Это зафиксированный baseline для переноса; дальнейшие
изменения оформления — по отдельному поручению. Тесты и прогоны этих быстрых
корректировок не запускались по просьбе пользователя. Интеграция в основной
SSG runtime выполнена позднее в MS-T002 по отдельному поручению; согласованный
дизайн при этом остаётся исходным образцом.

Новую страницу собирают из существующих компонентов и данных. Не копируют
их JSX/CSS в новую папку урока. Общая правка компонента применяется ко всем
его потребителям; частный вариант задаётся параметрами или локальным классом,
без изменения глобальной темы ради одного экрана.

нужно согласованно расширить их вариантами нового оформления, не создавать
параллельную копию для каждой страницы и не менять формы без проверки.

## Подключение урока

```tsx
import { Brand } from '../shared/ui/brand';
import { useSiteTheme } from '../shared/ui/use-site-theme';
import { LessonPageShell, LessonContents, LessonHeading,
  LessonNavigation, LessonSource } from '../shared/lesson';
import '../shared/styles/theme.css';
import '../shared/styles/base.css';
import '../shared/lesson/lesson.css';
```

Пути в примере относительные: зависят от расположения route-файла.
Контейнер страницы задаёт body.lesson-page. lesson-preview-page оставлен
совместимым алиасом для существующих browser checks. Оболочка содержит один
main#lesson-content; её экземпляр на странице должен быть один.
Владельцем URL, данных каталога, контента, brand и theme state остаётся адаптер
страницы; общая оболочка не импортирует Vite virtual modules, prototype или API.

LessonHeader может использоваться отдельно с brand/catalogueHref/loginHref и
темой. LessonFooter принимает brand, homeHref/catalogueHref/accountHref и
массив {title,href} для классов; данные не зашиты в компонент.
LessonHeading принимает произвольный ReactNode для формулы в заголовке и
массив {label,href?}; отсутствие href означает обычный текст, не пустую ссылку.
LessonNavigation получает соседей всего предмета текущего класса, включая
переходы между разделами; отсутствующий край предмета не выводится.
Наличие кнопки/ссылки определяется действительным действием, а не декорацией.

## Кнопки и состояния

Общие действия уже инкапсулированы в соответствующих компонентах:

| Действие | Вид и поведение |
| --- | --- |
| Ответ и решение | Справа от задания, 33 px, 12.5 px, pill; normal нейтральный, hover синий, open тёмный. Только кнопка раскрывает ответ. На телефоне под текстом справа. |
| Предыдущая / следующая тема | Ссылки 44 px со стрелками; previous нейтральная рамка, next синий контур. Названия тем только в доступных aria-label, не под кнопками. |
| Все темы раздела | Нейтральная ссылка-кнопка 44 px, без подчёркивания. |
| Сбросить коэффициенты | Нейтральная поверхность, тонкая рамка, синий текст. Кнопка принадлежит графику. |
| Материалы в шапке | Книга + текст, без рамки/фона, weight 500. |
| Вход | Синий квадрат со скруглением и контурной стрелкой; aria-label/title, настоящий href. |
| Тема / закрыть содержание | Иконки с доступным именем, focus-visible и нейтральным hover. |

Общий вид задают CSS-классы компонентов, а не копии inline styles. Не заменять
ссылки на span/button, если это навигация; не делать submit-кнопки без намерения.
Focus-visible сохраняется. На кнопках/навигации user-select:none; текст заданий,
ответов и формул копируется. В lab copy/cut/drag отменены по решению пользователя.
Согласованный размер answer-кнопки не увеличивать по вкусовой рекомендации.

## Палитра и типографика

Professional Theme и QraftHive закреплены в theme-baseline.md. Файлы темы и
шрифтов перенесены без изменения bytes; OFL сохранены рядом. Outfit не содержит
кириллицы: работает согласованный системный fallback. Merriweather Italic — формулы.
Зелёный дополнительный акцент разрешён только главной, не урокам.

Для уроков используются семантические --lesson-* поверхности и действия.
--lesson-accent отвечает за линии/исходный брендовый синий;
--lesson-accent-text — за читаемый синий текст, особенно в dark;
--lesson-action-accent/foreground — контрастная пара кнопки ответа;
--lesson-footer-muted/accent-text — текст на фоне подвала.
Нельзя подменять все четыре роли одной переменной: проверка уже выявляла
недостаточный контраст. Мелкий текст normal/hover/open должен иметь ≥4.5:1,
нетекстовые значки и границы важных контролов — ≥3:1.

## Компоновка и движение

Уточнение 25.10.2026: обычные абзацы разделяются 12 px, последовательные строки
решения — небольшим отступом 4 px. Пустые абзацы и лишние br не образуют пустых
строк; смысловые интервалы, anchors и учебный текст сохраняются. Рамка примера
включает заголовок, условие, решение и ответ, а рамка SVG — его название и подпись.
Самостоятельные схемы на desktop могут быть шире колонки текста на 48 px с каждой
стороны; на телефоне и внутри узких блоков расширения нет. Точные правила —
«Отступы, примеры и SVG» в стандарте. Цвета рамок/поверхностей берутся из текущих
lesson tokens Professional Theme, без замены палитры или шрифтов QraftHive.

Единый формат дробей и корней пока PROPOSED / WAITING_USER_APPROVAL в стандарте:
сохранить текущие формулы до отдельного согласования. Новую математическую
типографику не считать принятой из-за наличия этого предложения.

Белая светлая шапка, отдельное боковое содержание на desktop, отдельная строка
на телефоне. Теория остаётся на плоской поверхности без вертикальных акцентных
полос. Настоящие примеры целиком оформляются одной рамкой WorkedExample;
авторский SVG с названием и подписью — одной рамкой LessonDiagram. Существующие
рамки сохраняются без вложенного дублирования. Не оборачивать обычную теорию
в карточки только из-за legacy-класса ms-math-box.
Подвал выделен фоном, классы симметрично сгруппированы, кнопки Наверх нет.
Шесть ссылок классов 5–10 расположены в три колонки и две строки на desktop.
Содержание — общий LessonContents для обоих пилотов и следующих уроков.
Сверху «К темам раздела», затем полное название и просторный список с номерами
и точками. Панель до 650 px; desktop: заголовок 22 px, пункты 17 px, строки
до 56 px. При нехватке высоты сокращаются свободное место и отступы, без
внутреннего scroll, обрезки или уменьшения текста списка. Активный пункт
выделен только фоном. Маленький крестик — в боковой полосе. Точные mobile/
короткие состояния и расстояния закреплены в разделе «Содержание: принятый
образец» [стандарта переноса](../frontend/lesson-migration.md).
Escape/backdrop, focus trap/return, scroll lock обязательны.

CSS motion: fast 160 ms; drawer 280 ms вход/220 ms выход, backdrop согласован;
ответ 240 ms с natural height/opacity, hidden content inert/aria-hidden;
reset графика rAF 360 ms с синхронными значениями и остановкой от ручного ввода.
Reduced motion отключает переходы и делает reset мгновенным. Hover не выбирает
точку; x изменяется только отдельным ползунком, tap по графику также ничего не выбирает. Прокрутка
через график сохраняется. Формулы и абзацы не получают scroll-reveal/parallax.

## Постоянные URL

Формат: /materials/<класс>-<предмет>-<номер>, без .html и завершающего /.
Примеры формата: /materials/5-math-1, /materials/8-algebra-32.
Это не обещание, что все примерные адреса уже обслуживаются.
Публичный предмет — `algebra`, `geometry`, `statistics` или `math`.
`site_content/material-subjects.json` задаёт общее сопоставление с внутренними
Content subject. Предметный пункт breadcrumbs использует русскую подпись через
общий materialSubjectLabel: «Алгебра», «Геометрия», «Вероятность и статистика»,
«Математика». Внутренние slug и контентная identity сохраняются.

buildMaterialPath проверяет положительные целые grade/number и один из четырёх
утверждённых subject codes. В materialRoutes регистрируются уникальные slug/path.
materialPathForSlug возвращает только назначенный путь либо undefined.
Действующий реестр — `site_content/material-routes.json`. Назначены как минимум
оба пилота: `/materials/7-algebra-8` и `/materials/8-algebra-32`. Начальный номер
назначается один раз по полному curriculum класса и предмета, а не по очереди
переноса; после назначения не зависит от display order. Номера не переиспользовать.
Если меняется класс/предмет существующего урока, старый адрес сохраняют как alias,
а судьбу canonical решают явно: не пересчитывают автоматически.

Оба урока подключены к основному SSG/Content/FastAPI. Старые адреса, включая
`/materials/7-algebra-1`, получают прямой server-side 301 на canonical с query;
fragment обрабатывает браузер. Каталог — `/materials`; прежние адреса каталога
также ведут прямым 301. Ссылки same-origin, без портов отдельных прототипов.
Одно добавление записи в реестр не публикует новый урок автоматически:
сохраняется явный Content prepare/build/publication.

## Сохранность и следующие этапы

Для legacy уроков canonical остаются lesson.json/body.html/page.css/page.js.
Для перенесённых уроков canonical новой редакции — lesson.json + content.json;
старые HTML/CSS/JS сохраняются замороженными до приёмки и проверки потребителей.
lesson-source.mjs — действующий build adapter пилота, не мусор. quadratic.html,
virtual modules и Vite entry пока нужны для просмотра; удалять их можно после
проверенной интеграции в основной route. Math и authored SVG не переписываются.
Legacy self-check не становится серверной проверкой попыток или mastery.
Ранний прототип на 5173 не является способом запуска текущих уроков. Обычная
разработка — `npm --prefix frontend run dev`, один browser origin 8131 с HMR
и внутренним FastAPI proxy; готовая версия обслуживается FastAPI. Пересборка
и перезапуск не нужны после каждой CSS/React правки.

Решение пользователя 25.10.2026: автоматические прогоны при правках выключены,
включая изменения общих компонентов. Не запускать тесты, typecheck, browser/
smoke, source/docs gates или сборку ради проверки UI без отдельного поручения.
Для просмотра применяется HMR; результат — NOT_RUN_BY_USER_REQUEST, не PASS.
Будущая техническая приёмка учитывает все затронутые страницы; прошлые результаты
не подтверждают новую ревизию. См. [политику проверок](../frontend/testing-policy.md).
Локальные результаты, снимки и кеши временные: их хранят в игнорируемом
frontend/.cache/, а не рядом с исходниками. Запуск из frontend не должен
создавать frontend/frontend; пути результатов задают относительно конфигурации.

23.10.2026 по поручению пользователя удалены завершённые дизайн-аудиты
docs/audits/{lesson-*,quadratic-lesson-*,shared-ui-finalization*,ui-ux-*},
.impeccable/critique, прежние lesson-{motion,shell,url}-pilot заметки,
временные видеоразборы и captures в var/, frontend/frontend и результаты
прогонов из frontend/.cache/. Их история доступна в Git. Этот контракт и
theme-baseline.md остаются актуальными источниками решений. Исходники,
тесты, учебный контент, шрифты/лицензии и активный кеш Vite сохранены.


## Подключение линейного пилота MS-T001

### Действующие уточнения пользователя от 24.10.2026

Для всех уроков breadcrumbs имеют порядок класс > предмет > раздел; названия
разделов и заголовки секций материала не имеют цифровых префиксов, содержание
показывает одну автоматическую нумерацию с точкой. Последний пункт breadcrumbs
над названием урока — обычный текст без ссылки, hover-фона и акцентного состояния.
Предмет в breadcrumbs показывается по-русски, например
«5 класс > Математика > Обыкновенные дроби»; адрес остаётся `/materials/5-math-12`.
Самопроверка называется ровно «Самопроверка», с компактной
кнопкой справа и тонкими разделителями/интервалами по эталону квадратичного
preview. Кнопки увеличения схем и изображений и соответствующая функциональность
удалены из общего UI. Иллюстрации упражнений получают неброскую рамку.
После секции самопроверки нет учебных блоков: удаляются все последующие
материалы, независимо от названия. Сама секция сохраняется полностью, включая
все задания и раскрываемые решения. Далее идут только общая навигация и footer.

Внутри страницы нет legacy UI navigation. Общая навигация ведёт к соседним
разделам того же класса и предмета; на границе подписи «Предыдущий раздел» /
«Следующий раздел», внутри раздела — «Предыдущая тема» / «Следующая тема».
У первого урока первого раздела остаётся только «Следующая тема», у последнего
урока последнего раздела — только «Предыдущая тема». «Все темы раздела»
отображается всегда. Footer — один общий компонент с шестью ссылками
«5 класс»–«10 класс» без placeholder-названий.

Все содержимое умещается в viewport без горизонтальной прокрутки страницы или
внутренних областей (кроме необходимых широких таблиц); длинные заголовки
переносятся. Интерактивный график выбирает x только slider-ом; указатель не
создаёт probe/crosshair. Координатная сетка статична, подписи осей и деления
остаются внутри её области. Все страницы обслуживаются через общий FastAPI
origin/port; отдельные Vite/static lesson servers не используются.

Актуальные назначения URL и состава страниц см. в действующих решениях

основному SSG для react-v1. Текст и блоки приходят из verified lesson_document;
файлы `body.html/page.css/page.js` пилота сохраняются как замороженный источник
сравнения до человеческой приёмки. Остальные уроки остаются legacy. По дополнительному поручению
24.10.2026 главная, каталог и квадратичная страница подключены к одному
FastAPI origin с линейной в MS-T002, без отдельных Vite servers.
Проверки этого подключения отложены пользователем; приёмка учитывается отдельно.

Единственный registry адресов теперь `site_content/material-routes.json`;
`shared/routing/material-routes.mjs` импортирует его, Content публикует canonical
и permanent redirects. `runtime.css` подключает существующие theme/base/lesson
стили для новой страницы без legacy site.css. Внешний вид компонентов сохранён.
