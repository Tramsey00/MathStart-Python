# Выбор плана для миграции

Для переноса на FastAPI/React действует только [MIGRATION.md](../../../MIGRATION.md).
[migration-execution.md](migration-execution.md) — короткая ссылка на то же задание.

Остальные планы в этом каталоге сохраняют исторические задачи и provenance.
Их старые владельцы, календарь, карточки и ограничения запусков не управляют текущей
миграцией. Пути сохранены для ссылок и проверок исходных артефактов. Не выполнять
планы будущих продуктовых функций в рамках переноса. Читать необходимые технические
критерии по затрагиваемой области, не весь каталог при каждом продолжении.
