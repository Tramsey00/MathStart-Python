# Редактирование уроков

## Найти тему

В [указателе](../curriculum/INDEX.md) найдите класс, предмет, раздел и тему. Ссылка ведёт в `body.html`; остальные файлы лежат рядом. Тема 6.6 «Квадратичная функция y = ax² + bx + c» расположена в 8 классе, в алгебре, в разделе 6.

| Файл | Что менять |
| --- | --- |
| `body.html` | Текст, формулы, таблицы, SVG, задания, решения и разметка интерактивов. Обязательный файл. |
| `lesson.json` | В объекте `page`: название `title`, порядок `order`, SEO и `is_published`. |
| `page.css` | Необязательный CSS для особенностей этой темы. |
| `page.js` | Необязательный JS собственного интерактива, подключаемый после содержимого. |

Общее оформление всех страниц основано на теме «Свойства степенных функций и их графики 2.0» и хранится в `static/mathstart/`; [карта файлов стиля](lesson-theme.md) показывает, что где менять. Не копируйте и не переопределяйте в `page.css` общие правила примеров, таблиц, заданий и заголовков. Если общий компонент нужно изменить, редактируйте его общий CSS: результат должен применяться на всём сайте.

В `page.css` добавляйте только необходимое этой странице оформление, например размеры отдельной схемы или расположение её подписей. Геометрия SVG — линии, координаты и подписи — остаётся в `body.html`. Для карточек и сеток используйте `ms-card` и `ms-card-grid`, для вариантов — общие модификаторы `ms-columns-2`–`ms-columns-6`, `ms-card--success` и `ms-card--error`. Не создавайте копию всего компонента ради числа колонок или смысловой подсветки.

Собственный JavaScript темы храните в `page.js`, без обёртки `<script>`. Для повторно используемых интерактивов подключается общий ресурс: например, график степенных функций 2.0 использует `static/mathstart/js/widgets/power-functions.js`. Не добавляйте его копию в урок.

Если особые стили или скрипт не нужны, соответствующего файла в папке нет. Пустые файлы создавать не следует; экспорт их не создаёт. Удаление `page.css` или `page.js` с последующей публикацией очищает соответствующий ресурс страницы. `body.html` и `lesson.json` обязательны.

У 260 уроков формат `themed_html`: при публикации содержание строится из `h2` учебных разделов. У каждого нового раздела нужен уникальный `id`; вручную исправлять автоматически собранный блок содержания не требуется. У трёх подробных уроков 10 класса формат `component_html`: общие шаблоны собирают разделы и задания, а авторские подписи содержания берутся из его исходного блока. Оба формата подключают одну общую тему; разница относится к сборке HTML.

Метаданные урока хранятся в `lesson.json`.

`schema_version` определяет версию формата исходника, `format` — способ сборки содержимого, а объект `page` содержит идентификационные и редактируемые поля страницы.

Контрольная сумма последней принятой публикации хранится в `LessonPublication` и вручную не редактируется.
## Публикация

Из корня проекта в активированном Python-окружении:

```powershell
python manage.py publish_lessons --slug kvadratichnaya-funkcziya-y-ax2-bx-c --dry-run
python manage.py publish_lessons --slug kvadratichnaya-funkcziya-y-ax2-bx-c
python manage.py check_lesson_sources --slug kvadratichnaya-funkcziya-y-ax2-bx-c
```

`--dry-run` показывает будущие изменения без записи в файлы, базу и резервные копии. Публикация перед записью сохраняет SQLite в `var/backups/`. При первом подключении совпадающего материала создаётся только связь с файлом; повторный запуск ничего не меняет.

Для нескольких тем перечислите адреса после `--slug`; весь каталог выбирается через `--all`. Выбор обязателен.

Проверяйте итог на странице запущенного сайта. Открытый напрямую `body.html` содержит фрагмент урока без общей оболочки Django.

После изменения названий файловый указатель обновляется отдельно:

```powershell
python manage.py index_lessons
```

## Конфликт правок

`LessonPublication` хранит контрольную сумму последней принятой версии урока.

Если страница в базе была изменена независимо от файлового исходника и больше не совпадает с последней принятой публикацией, публикация останавливается.

Принудительного режима перезаписи нет.
