# MathStart

MathStart — образовательный интернет-ресурс по математике для школьников 5–10 классов. В 10 классе доступны первые два раздела алгебры и тема о числовой окружности.

Проект первоначально был разработан на WordPress, после чего контент, структура, изображения, внутренние ссылки и метаданные были перенесены на backend Django.

## Состав проекта

- Python 3.10
- Django 5.2
- SQLite
- Django Admin
- WhiteNoise
- BeautifulSoup
- Pillow
- 279 опубликованных материалов
- 261 учебная тема
- 18 основных страниц
- 6 классов
- 12 предметных направлений
- 63 учебных раздела
- 38 медиафайлов
- 280 правил перенаправления

## Возможности

- управление материалами через Django Admin;
- сохранение исходного HTML, CSS, SVG и JavaScript;
- интерактивные Canvas-графики;
- раскрывающиеся решения заданий;
- автоматическая XML-карта сайта;
- robots.txt;
- canonical URL;
- SEO title и description;
- старые WordPress-адреса перенаправляются на новые;
- проверка целостности внутренних ссылок и медиафайлов;
- восстановление контента из переносимой резервной копии.

## Локальный запуск на Windows

### 1. Создание виртуального окружения

```powershell
py -3.10 -m venv .venv
```

Если интерпретатор, на котором было создано `.venv`, удалён или перенесён,
создайте окружение заново с установленным Python 3.10 или новее.

### 2. Установка и настройка

```powershell
.venv\Scripts\python.exe -m pip install -r requirements.txt
Copy-Item .env.example .env
```

Копируйте `.env.example` только при отсутствии собственного `.env`.
Задайте `DJANGO_SECRET_KEY`, для локальной разработки включите `DJANGO_DEBUG=1`.

### 3. База данных и запуск

Если `db.sqlite3` уже есть, учебные материалы в ней сохранены. Для новой базы:

```powershell
.venv\Scripts\python.exe manage.py migrate
.venv\Scripts\python.exe manage.py loaddata data/mathstart_content.json.gz
```

```powershell
.venv\Scripts\python.exe manage.py runserver
```

Откройте http://127.0.0.1:8000/. В production каталог `media/` должен обслуживаться
веб-сервером отдельно; Django раздаёт его только при `DEBUG=1`.

## Редактура материалов

Тексты, стили, SVG и скрипты уроков находятся в `ContentPage.body_html`.
Обычные изменения вносятся через Django Admin. Общая навигация и адаптивное
отображение рисунков находятся в `templates/page_detail.html` и `templates/includes/`.
Карта сайта формируется из опубликованных материалов и обновляется вместе с ними.

Проверенные исправления 26 страниц сохранены в `data/reviewed_content.json`.
В рабочей базе они уже применены; переносимая копия `data/mathstart_content.json.gz`
также обновлена. Для прежней версии базы:

```powershell
.venv\Scripts\python.exe manage.py apply_content_repairs --dry-run
.venv\Scripts\python.exe manage.py apply_content_repairs
```

Команда создаёт резервную копию SQLite, проверяет контрольные суммы и применяет
все изменения одной транзакцией. Повторный запуск на той же версии ничего не меняет. После добавления алгебры 10 класса главная, материалы и страница проекта получили новые ссылки: для них старый аудит корректно сообщает о конфликте. Повторно применять его к текущей базе не нужно. Если материал
после аудита отредактирован вручную, команда сообщает о конфликте и не перезаписывает
его. `scripts/build_content_repairs.py` содержит воспроизводимую редактуру;
для её пересборки используется `data/backup_before_content_review.sqlite3`.

## Проверка

```powershell
.venv\Scripts\python.exe manage.py check
.venv\Scripts\python.exe manage.py test
.venv\Scripts\python.exe manage.py check_site_integrity
.venv\Scripts\python.exe manage.py check_content_quality
```

`check_content_quality` проверяет ответы всех опубликованных страниц, служебные
заглушки, структуру SVG, повторяющиеся идентификаторы и ссылки на якоря.
Обе команды аудита завершаются с ошибкой при обнаружении проблем и сохраняют
отчёты в `data/`. Это технические проверки; математическое содержание новых
уроков по-прежнему требует редакторской проверки.

## Алгебра 10 класса

Добавлены два раздела по структуре ЯКласс: «Действительные числа» и
«Степени с рациональным показателем. Корни. Степенные функции». Это 9 уроков,
72 задания с решениями и 8 SVG. Раздел для учителей не включён.

Исходные материалы находятся в `content/lessons/grade10/`; сведения об источниках —
в `data/grade10_sources.md`. Уроки уже записаны в рабочую базу и переносимую копию.
Открыть курс: http://127.0.0.1:8000/10-klass-algebra/ либо «10 класс → Алгебра» на главной.

Для добавления в прежнюю базу или обновления после редактирования исходников:

```powershell
.venv\Scripts\python.exe manage.py add_grade10_algebra --dry-run
.venv\Scripts\python.exe manage.py add_grade10_algebra
```

Команда делает резервную копию SQLite, применяет изменения одной транзакцией
и безопасна при повторном запуске. Редакторские изменения тела урока в админке
не перезаписываются: команда остановится и сообщит о конфликте.

Тесты дополнительно проверяют девять тем, 72 решения, повторный запуск, сохранение
редакторских правок, переходы между темами, координаты графиков корней и раздельные
ветви функций с отрицательным показателем.

Две подробные версии 2.0 находятся в `content/lessons/v2/`:
«Свойства степенных функций и их графики» и «Числовая окружность на координатной
плоскости». Каждая содержит 12 заданий с решениями и интерактивный рисунок.
Прежние уроки сохранены. Для обновления этих двух страниц после правки исходников:

```powershell
.venv\Scripts\python.exe manage.py add_grade10_v2
node --test content/lessons/v2/math.test.js
```

Команда `add_grade10_algebra` относится к первоначальному добавлению девяти уроков;
повторно применять её к текущей странице курса не нужно. Полная переносимая копия
уже содержит обе версии 2.0. Их адреса:
`/10-klass-stepennye-funkcii-i-grafiki-2-0/` и `/10-klass-chislovaya-okruzhnost-2-0/`.

Чтобы обновить только страницу степенных функций 2.0, используйте
`manage.py refresh_power_lesson`. Её оформление находится в `power_page.css`,
`power_math.css` и `power_lab.css` и изолировано от остальных уроков.

Версия «Натуральные числа. Повторение 2.0» находится в
`content/lessons/v2/natural.py`; публикация — `manage.py add_natural_v2`
(есть `--dry-run`). Прежняя тема 1.1 сохраняется. Общий блок содержания и плавные
переходы подробных уроков находятся в `lesson_navigation.css` и `lesson_navigation.js`.

Тема 1.2 «Рациональные числа. Повторение 2.0» — `content/lessons/v2/rational.py`.
Команда `manage.py add_rational_v2` добавляет её рядом с прежней версией в разделе 1;
`--dry-run` проверяет публикацию без записи в базу.
