## Охват и исключения

- D001–D197: 196 пунктов исправлены и проверены; D169 — «не подтверждено».
- 325 записей подтверждённых повторов; один R объединяет повторения одного типа на странице. Их количество не суммируется с D как количество уникальных элементов.
- Проверены все 263 темы. В локальную базу опубликованы только 222 изменённых slug.
- Изменения внесены в файлы самих страниц: 222 body.html, 8 локальных page.css (шесть изменённых и два новых) и 2 page.js двух целевых графиков. Изменены три общих CSS и два тестовых файла для D066. Всего 235 существующих отслеживаемых файлов, 2 новых локальных CSS плюс документы этой задачи. В changed-files.json новые CSS включены с change_kind=added и before_sha256=null; для них также указаны D/R и итоговые хеши.
- D169: точки (1;52), (2;57), (3;63), (4;70), (5;76), (6;82) соответствуют таблице. Данные, тренд и геометрия наблюдений сохранены; читаемость проверена отдельно.
- D183: изображение Word сопоставлено с тригонометрическим полукругом темы 9.3.1, а не с ошибочным указателем окружностей 9.2.2.
- D066: временно убрана только указанная ссылка. PDF, media и их идентичность сохранены. Тестовые ожидания обновлены под этот контракт; проверки файлов, ассоциаций, истории и конфликтов публикации остаются.
