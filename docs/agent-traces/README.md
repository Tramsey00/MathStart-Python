# Записи действий

Traces фиксируют прошлые действия и результаты, а не назначают будущую работу.
Старые команды, ограничения запусков, владельцы и ссылки в них — исторические
наблюдения. Не исполнять их как инструкции. Текущая миграция определяется
[MIGRATION.md](../../MIGRATION.md). Не читать все traces при запуске.
Подготовка единого задания отражена в [trace](migration-instructions-consolidation.md).
