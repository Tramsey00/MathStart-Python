# MS-T005. Реестр проверки смысловых групп

75 URL в реестре — 36 тем алгебры, 12 геометрии и 27 статистики. Сопоставлены исходный HTML, классы и вложенность content.json, а также серверная React-разметка до и после обновления. HTML всех 75 URL ответил HTTP 200. Запуск браузера и оценка ширин здесь не выполнялись. Визуальная приёмка — PENDING. Автоматический QA — NOT_RUN_BY_USER_REQUEST.

В этой итерации исправлено **48 тем**. В **39** изменена структура данных, **18** используют новые правила CSS, группы пересекаются. В **27** темах новых дефектов при структурной сверке не выявлено. Из них **10** используют правила первого CSS-патча, а в **17** не найдено дефектов, потребовавших изменений в обеих итерациях. Эти числа отражают выявленные проблемы, а не визуальную приёмку.

## Решения

- В статистике заголовок шага уже был отдельным strong, а пояснение отдельным span. CSS отделяет заголовок и сохраняет колонку текста. Карта, универсальный маршрут и проверочный список статистики 27 сохранили прежнюю раскладку.
- В «Примере 4» алгебры 20 условие и блок вычислений с ответом были соседями. В content.json блок вычислений вложен в тот же пример. Это же преобразование применено к подтверждённым соседним блокам в других темах. Примеры, уже объединённые внешним заголовком, оставлены в штатной группировке.
- Для самостоятельного заголовка «Пример» добавлена явная семантическая обёртка. Существующий WorkedExample обрабатывает её без изменений renderer.
- Строки «Шаг N.» и «N.» в проверенных последовательностях структурированы как метка и текст. Смысловые BR внутри других формул и вычислений сохранены. Для компактных шагов восстановлен счётчик, который присутствовал в исходном CSS.
- Для формульных панелей убрана добавленная ранее горизонтальная прокрутка. MathML, U+0304 и содержание формул сохранены. Прокрутка систем уравнений и штатных таблиц остаётся локальной.
- Изменения content.json сверены с базой по тексту, порядку, anchors, ссылкам, SVG, MathML, таблицам, изображениям и самопроверке. Единственное ранее согласованное изменение SVG — C=(390,146).

Общий CSS ограничен canonical URL 7-го класса, статус PENDING_TEAM_APPROVAL. Сопоставление использует [первоначальный аудит](ms-t005-layout-audit.md). Правки и отчёт локальные.
