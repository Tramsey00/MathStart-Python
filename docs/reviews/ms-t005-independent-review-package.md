## Утверждённые исключения и обязательное сохранение

Нормативный источник — [действующий стандарт переноса](https://github.com/Tramsey00/MathStart-Python/blob/42293cfddb9a3fae08458b801c99dc37dacb04b1/docs/frontend/lesson-migration.md).

- Исключается prerequisite «Что нужно знать перед темой»; его section ID указан в карте.
- Терминальная самопроверка завершает учебный материал. Все последующие учебные блоки исключаются независимо от названия, тега и смысла. **Сама самопроверка сохраняется целиком: каждое задание, условие, полный ответ, решение, формула, таблица, рисунок.** Совпадение количества задач не доказывает равенство содержания.
- Legacy hero/toc/navigation заменяются общей LessonPage оболочкой. Исключённые anchors не должны оставаться рабочими пунктами содержания/ссылками; новые синтетические section IDs не вводятся.
- Пустые абзацы, комментарии и лишние переносы не являются потерей учебного содержания; смысловые интервалы, исходные формулы и атрибуты SVG сохраняются по стандарту.
- Примеры boundary: statistics-4 — поздняя «Проверка результата»; 8 — «Заполненная таблица»/«Результат работы»; 18 — «Лабораторный вывод»; 27 — «Что вы теперь умеете»; 25 — поздний div.ms-note. Они перечислены в карте, не являются разрешением удалить задания/решения внутри self-check.
- Согласованный root figure в statistics-25/26 сохраняется как последний nodes элемент section-3 перед section-4, без отдельной синтетической секции. В laboratory header 26 извлекается один заголовок, остальные данные сохраняются.
- Авторская сложная запись заменяется эквивалентной MathML через явный ledger; не вычислять, не сокращать и не исправлять математику молча. Body/media не удалялись ради успешной обработки.
