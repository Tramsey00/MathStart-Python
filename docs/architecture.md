# Архитектура MathStart

## Открытие страницы

```text
Адрес → config/urls.py → content/urls.py → content/views.py
                                         ↓
                                 ContentPage в SQLite
                                         ↓
                               templates/page_detail.html
                                         ↓
                                      Браузер
```

Посетитель получает опубликованную страницу из базы. Файлы материалов не читаются при каждом запросе и не доступны как публичный каталог. Общая оболочка подключает известные CSS/JS-ресурсы по маркеру `data-lesson-theme="power-v2"`. Все уроки и остальные страницы сайта используют одну общую тему на основе «Свойства степенных функций и их графики 2.0», без отдельной темы для старой разметки и без ограничения подключения настольной шириной.

## Обновление урока

```text
curriculum/.../lesson.json + body.html
              + page.css / page.js, если нужны
                          ↓
            content/services/lesson_sources.py
                          ↓
             content/services/publishing.py
                          ↓
     проверка → резервная копия → одна транзакция
                          ↓
                ContentPage + LessonPublication
```

`ContentPage` хранит опубликованное содержимое. `LessonPublication` связывает страницу с относительным путём `lesson.json` и хранит контрольную сумму последней принятой публикации. При первичном подключении сами страницы не сохраняются заново: прежние HTML, SEO, контрольные суммы, даты и миграционные поля остаются точными копиями исходных значений.

`body.html` обязателен. Дополнительные `page.css` и `page.js` необязательны: если файла нет, соответствующее поле опубликованного урока считается пустым. Поэтому удаление ненужного ресурса и обычная публикация убирают его со страницы. Экспорт не создаёт пустые дополнительные файлы. При запросе страницы сервер использует опубликованный код из базы, а не читает эти файлы напрямую.

Контрольная сумма публикации охватывает HTML, CSS, JavaScript, название, адрес, структуру, порядок, SEO и статус. Если база изменилась независимо от файлов, следующая публикация останавливается. Ошибка в любом выбранном уроке отменяет пакет изменений. Принудительного обхода конфликтов нет.

## Распределение файлов

| Каталог | Назначение |
| --- | --- |
| `config/` | Настройки, база, общие URL. |
| `content/models.py` | Каталог, страницы, медиа, редиректы, связи с исходниками. |
| `content/views.py` | Получение опубликованных страниц. |
| `content/services/` | Чтение, проверка и публикация материалов. |
| `content/management/commands/` | Команды запуска операций и исторические инструменты. |
| `curriculum/` | Исходники всех уроков; `INDEX.md` помогает найти тему. |
| `templates/` | Оболочка сайта, общие включения и компоненты урока в `lessons/components/`. |
| `media/` | Изображения и файлы; ссылки сохранены. |
| `static/mathstart/` | Общие стили, математическое оформление, содержание и повторно используемые интерактивы. |
| `staticfiles/` | Результат `collectstatic`; вручную не редактируется. |
| `var/backups/` | Резервные копии SQLite и архивы исходников перед переносами. |
| `var/exports/` | Актуальные переносимые экспорты базы; при переносе проекта включаются отдельно. |
| `var/verification/` | Отчёты проверки переноса и изолированная тестовая база. |
| `data/` | Предыдущий экспорт базы, исторические резервные копии, исходники импорта и отчёты. При объединении оформления не изменялась. |
| `source/` | Первоначальные материалы WordPress. |
| `content/lessons/` | Прежние генераторы, сохранённые для истории и проверки математической логики. |
| `docs/` | Актуальные инструкции и архив документации. |

`curriculum/` организован как `класс / предмет / номер-раздела / номер-урока`. Папки используют slug, полные названия записаны в метаданных и указателе. Длинные имена сокращаются с добавлением короткого хеша для совместимости с Windows. Изменение порядка не переименовывает зарегистрированную папку.

Общие правила находятся в именованных CSS-файлах: `lesson.css` задаёт основной стиль, `lesson-math.css` — математическое оформление, `lesson-components.css` — дополнительные учебные компоненты, `lesson-diagrams.css` — диаграммы и легенды, `lesson-contents.css` — содержание. `site.css` обслуживает оболочку, навигацию и доступность; `site-pages.css` содержит особенности главной страницы и каталога. Все форматы уроков получают один набор общих стилей. CSS интерактивных графиков подключается только при наличии соответствующего блока.

Уникальные правила SVG и других элементов находятся рядом с материалом в `page.css`; собственный код интерактива — в `page.js`. Разметка самого SVG остаётся в `body.html`. Локальный CSS не переопределяет оформление общих примеров, таблиц, заголовков и заданий: они используют общие классы и модификаторы. Старые `lesson-base.css`, `lesson-legacy.css` и каталог стилей с хешами не являются рабочими зависимостями. Общий код масштабирования схем находится в `static/mathstart/js/lesson-diagrams.js`, а не встроен в шаблон.

## Границы завершённого этапа

- Все 263 урока имеют файловые исходники и общий механизм публикации; прежние страницы и варианты 2.0 сохранены.
- Первый этап выгрузки использовал `legacy_html`. Теперь 260 уроков используют `themed_html` с общим содержанием, а три подробные темы — `component_html` с общими шаблонами разделов и заданий. Код формул, SVG и старых интерактивов сохранён.
- Остальные 18 страниц сайта по-прежнему редактируются в админке.
- Публикация обновляет существующие уроки; она не создаёт курс, не меняет адреса и не перестраивает встроенные программы курсов. Перенос между разделами — отдельная будущая операция.
- Единое оформление общих блоков применяется ко всем страницам. Математические примеры и SVG сохранены; старые карточки и сетки используют общие классы. Отдельная разработка мобильного интерфейса не проводилась, но общий CSS действует на всех размерах экрана. Полная модель редакций и перевод всех старых учебных блоков на единый семантический формат остаются отдельной работой. [Устройство общего стиля](lesson-theme.md).
- Исторические данные и генераторы не перемещались: их ссылки сохранены. Старые команды публикации уроков блокируются после подключения файлов.

## Сохранность

Перед переносом сделана копия базы в `var/backups/`. Пилот на трёх настоящих уроках включал изменение и восстановление содержимого на отдельной базе. При подключении всех исходников проверены точные ответы всех 281 страниц и все поля шести прежних таблиц контента. Отчёты: `var/verification/curriculum-pilot-report.json` и `curriculum-migration-report.json`.

Копия SQLite не включает `curriculum/` и `media/`: для полного восстановления сохраняйте их отдельно вместе с кодом. Актуальный переносимый снимок после объединения оформления — `var/exports/mathstart-content-unified.json.gz`. Предыдущий `data/mathstart_content.json.gz` оставлен без изменений и не соответствует текущей версии оформления. Служебные данные `var/` исключены из контроля версий, поэтому нужный экспорт или резервную копию включают в перенос вручную; редактируемые исходники исключать нельзя.
