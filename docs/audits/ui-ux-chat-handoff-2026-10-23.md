## React, FastAPI и границы интеграции

Production-стек уже FastAPI/Pydantic, SQLAlchemy/Alembic, PostgreSQL,
React/TypeScript/React Router SSG. Исторический Django не возвращать.

Новый интерфейс на 5173 — отдельный CSR-прототип для визуального согласования,
не готовая интеграция в основной публичный runtime.
Vite читает каталог и материал урока из файлов при запуске/сборке.
Пилот напрямую не запрашивает FastAPI. График считает в браузере.
Реальные серверные функции, включая identity, принадлежат FastAPI.
Основная публикация использует SSG, постоянный Node SSR server не нужен.

Интеллектуальные упражнения, Progress/mastery, Tutor и адаптивная практика
остаются будущим scope. Чтение урока не повышает освоение.
Текущая самопроверка — legacy self-check, а не серверная проверка попыток.
