# Первая React-страница учебного материала

Дата: 2026-10-23. Основание: запрос пользователя начать с темы
«Квадратичная функция y = ax² + bx + c» и собрать связную статью на React/TypeScript.
Рабочая база: `192d0fc315e35644eeb9bb713f58d7d15afb34a0`, существующая ветка
`ui/ux`; результат пока в незакоммиченном рабочем дереве. Это визуальный пилот,
не migration acceptance и не изменение установленного сайта.

## Область изменения

- Предпросмотр: `http://127.0.0.1:5173/quadratic.html`.
- Главная, форма авторизации, общие theme tokens, шрифты и структура каталога сохранены.
  Единственное изменение поведения каталога — ссылка этой темы открывает пилот.
- После нового отзыва и видео `содержание.mp4` удалены рамка статьи, цветные
  подложки формул/примеров/ответов. Текст объединён типографикой и интервалами.
  Пользователь разрешил небольшое отступление от палитры: только урок использует
  scoped --lesson-* нейтрали (#f8f9fa / #191d23); общий theme.css не изменён.
- Кнопка слева открывает широкую панель на всю высоту от левого края, включая
  область шапки. Крестик находится в узкой полосе слева, как в видео.
  Панель показывает текущий раздел, закрывается по Escape, кнопке, внешнему
  клику и выбору пункта, удерживает/возвращает фокус.
- Самопроверка — раскрывающаяся строка с вопросом и действием «Ответ»/«Разбор»;
  открытый ответ отображается обычным текстом. Переходы между темами компактны,
  ссылка «Темы раздела» расположена слева на той же строке.
- График — React-компонент с SVG и управляемыми коэффициентами. Математика
  отделена в TypeScript-модуль. Сохранены диапазоны, начальный пример,
  таблица значений, случаи прямой и постоянной функции при a = 0.
  График ниже и шире; коэффициенты, восемь свойств и таблица на desktop находятся
  справа. Автоматически проверяется одновременная видимость при высоте 800px.
- Исправлены отображение отрицательного нуля после округления и подпись
  симметрии постоянной функции: любая вертикальная прямая x = k.
- Новые UI-библиотеки/скилы не устанавливались. Build-only адаптер использует
  parse5, уже имеющийся в зафиксированном дереве зависимостей frontend.

## Сохранение материала

Канонический источник остаётся в curriculum. Адаптер читает lesson.json/body.html
при сборке и передаёт структуру React; ручной копии учебного текста нет.
Компоненты не используют dangerouslySetInnerHTML или исходный DOM-скрипт.

Не изменены lesson.json, body.html, page.css, page.js этой темы, другие уроки,
контент БД, backend, LessonHost и контракты публикации. Проверены:

- все учебные текстовые узлы восьми оставшихся разделов, кроме заменённого
  интерактива, старой навигации/нумерации и переименованных disclosure controls;
- семь блоков вычислений, отдельное условие примера, десять заданий и ответов;
- исходные две учебные SVG-схемы, MathML и ячейки таблицы;
- предыдущая/следующая темы из фактического порядка раздела.

По явному отзыву пользователя исключён девятый раздел «Паспорт параболы за
пять действий» вместе с повторным итогом и «Далее». Это единственное исключение
раздела; оно закреплено отдельным тестом с полным списком оставшихся id.
Канонические файлы и опубликованный урок не изменены: исключение относится к
пилотной проекции. Ответы и математические выводы внутри примеров сохраняются.

Исходные академические SVG сохраняют собственную белую поверхность
и подписи в тёмной теме, чтобы не повредить рисунки. Новый график использует
общий primary и локальные нейтральные поверхности. SHA-256 theme.css остаётся
`d15b103843bdb6cee935e6effb4e9c1c58385008fa5f25432b9d1610953195fa`.

## Следующий этап после оценки пользователем

Публичная публикация продолжает сохранять authored HTML и работать без JS.
Пилот пока является отдельной Vite-страницей для согласования. Он не доказывает
готовность target runtime; общий production gate не запускался, БД/контейнеры
и защищённые окружения не использовались.

После визуального согласования нужно описать общий шаблон в ТЗ/tasks и отдельно
интегрировать его в текущую React/SSG-публикацию с полным статическим текстом,
выборочной интерактивностью, сохранением URL/MathML/SVG и проверками без JavaScript.
Затем применять к другим темам по инвентаризации, сохраняя их особые рисунки
и интерактивы. Этот пилот не включает массовое преобразование остальных уроков.
