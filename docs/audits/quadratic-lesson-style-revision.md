# Доработка учебной страницы, 2026-10-23

Основание: шесть визуальных замечаний пользователя и разрешение изменить стиль
пилотной страницы с добавлением цвета. Визуальная приёмка остаётся за пользователем.
Работа выполнена в существующем dirty checkout ui/ux, без переключения ветки,
коммита, push и агентов. HEAD и хеши кандидата — в соседнем evidence JSON.

## Изменения

- Убраны вертикальная полоска активного пункта содержания и линия у раскрытий.
- Подписи ±10 интерактивных осей выровнены внутрь сетки; область координат,
  математические вычисления и authored SVG не изменены.
- Убрано изменение координат от hover. Ползунок сохраняет клавиатурный доступ;
  нажатие мышью/касание графика выбирает x с точностью 0,1 и сохраняет выбор.
- Общая рамка и спокойная тонированная поверхность объединяют график, управление,
  вычисленные свойства, таблицу и легенду. Desktop сохраняет две колонки.
- Действие раскрытия ответа расположено под заданием и оформлено кнопкой с
  цветным фоном; ответ без вертикальной полоски. Семантика details/summary сохранена.
- Переходы между темами получили крупные области нажатия с рамкой и полными
  названиями; следующая тема выделена цветом. На телефоне одна колонка.
- Цвета задаются локальными --lesson-* для обеих тем. Общие theme.css, главная,
  каталог, авторизация, содержание урока и математический модуль не менялись.

## Проверка и просмотр

- 32/32 Playwright PASS, 360/768/1440/1920 px, обе темы, без skips/flaky/retries.
  Сценарий hover обновлён на отсутствие изменения и сохранение выбора при клике.
  Сохранены keyboard, touch, SVG enlargement, navigation destinations, overflow,
  console/pageerror, coefficients/reset, настоящий Chrome zoom 200%.
- 196/196 frontend tests PASS, 23 suites, включая точное сохранение учебного
  текста и authored SVG. TypeScript основного frontend и прототипа PASS.
- Prototype Vite build PASS, 44 modules. git diff --check PASS.
- Просмотрены свежие screenshots графика desktop light/dark, графика телефона,
  самопроверки desktop/phone и переходов phone. Evidence — Playwright outputDir.
- Первый sandbox-прогон не засчитывается: Playwright не смог использовать занятый
  порт, Vitest получил EPERM при rename временного кеша. Повтор вне ограничения
  успешно использовал существующий сервер и завершился полностью.

Это локальная проверка прототипа, не полная production-приёмка. Нет физического
телефона, Safari, NVDA/VoiceOver и полного PostgreSQL/publication runtime gate.
