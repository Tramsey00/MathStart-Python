# Карта проекта

## Где менять урок

Начни с [указателя всех тем](../curriculum/INDEX.md). Для перенесённой темы
ссылка открывает content.json; у ещё не перенесённой — body.html. URL указан
отдельно: путь папки не определяет публичный адрес.

| Папка | Что здесь хранится |
| --- | --- |
| curriculum/<класс>/<предмет>/<раздел>/<тема>/ | lesson.json — метаданные; content.json — новый материал; body.html/page.css/page.js — исходник и совместимость |
| frontend/src/app/ | Маршруты и композиция приложения |
| frontend/src/features/ | Каталог, главная и предметные интерактивы |
| frontend/src/shared/lesson/ | Общая оболочка, renderer, блоки и стили урока |
| frontend/src/shared/styles/ | Тема, базовые стили, шрифты |
| frontend/src/server/ | Данные для React/SSG и dev-проекция |
| frontend/*.py | Python-часть подготовки и сборки публичного артефакта |
| backend/content/, users/, staff/ | Действующие доменные модули |
| backend/infrastructure/, models/, migrations/ | HTTP, persistence и версия схемы |
| site_content/ | Каталог, назначения адресов, redirects, общие страницы и медиа |
| static/ | Сохраняемые ресурсы старых страниц и переходного runtime |
| scripts/ | Операторские команды и инструменты разработки |
| deploy/ | Образы, Compose, выпуск и восстановление |
| specs/ | Контракты, схемы и сохранённые доказательства этапов |
| docs/tasks/, skills/tasks/ | Очередь и инструкции конкретного задания |
| docs/audits/, docs/reviews/ | Существующие отчёты и ревью; не текущие поручения |
| var/ | Локальные настройки, публикации, логи; вне Git |

## Что не является мусором

Старые body.html/page.css/page.js пока нужны загрузчику Content и сравнению.
Не удалять их по одному признаку renderer_version. Immutable публикации и
применённые миграции не переписываются. Отдельный прототип выведен. Его тестовый адаптер находится в frontend/tests/helpers/,
реестр принятой темы — docs/ux/theme.registry.json.
Тестовые файлы остаются для отдельно порученных проверок, при dev не запускаются.

## Правило новых файлов

Продолжай существующий модуль. Не создавай вторую реализацию renderer, отдельную
страницу TSX на каждый урок, резервные tracked копии и новый реестр маршрутов.
Новый повторяемый инструмент имеет одного владельца и понятную команду;
одноразовая обработка — var/tmp/<task>/. После работы удалить свои временные
файлы. Активные конфигурации, releases, receipts и recovery logs не являются кешем.
При переносе файла обновить imports, CLI, сборочные входы и действующие ссылки.
Исторические SHA и ссылки в receipts сохранять.

## Решение по структуре

Сохраняем модульный монолит и curriculum: это уже группировка по предметной
области. Массовое переименование backend/frontend или перенос всей истории
не улучшает владение кодом и затрагивает пути публикации. Упорядочивание идёт
через действующие входы, точные названия модулей и отделение истории от статуса.


## var, static и корневые tests

var полностью исключён из Git. В нём сохраняются рабочие local/team и serving,
конфигурации, планы и журналы публикаций. Старые виртуальные окружения и
сгенерированные результаты проверок можно удалить после проверки потребителей;
основное окружение проекта — .venv. Не удалять var целиком.

static содержит ресурсы, которые backend/content/build.py включает в legacy
страницы, а frontend account/staff/debug импортирует напрямую. UI JavaScript
также потребляют существующие проверки совместимости. До замены этих
потребителей static сохраняется.

Корневые tests — контракты/совместимость и инструменты выпуска, backend/tests —
сервер, frontend/tests — React и браузерные данные. Старые даты и R02/R03 в имени
не означают неиспользуемый тест. Эти проверки запускаются только по отдельному
поручению; их сохранение не включает их в dev startup.

В push входят только отслеживаемые коммиты. .gitignore дополнительно исключает
локальные настройки агентов, приватные конфигурации, ключи, дампы и отчёты.
Он не удаляет секрет из уже существующей истории Git: если такое обнаружено,
нужны отдельные отзыв секрета и разбор истории. В текущем дереве Issue #66
таких секретов не обнаружено; полная история не сканировалась.
