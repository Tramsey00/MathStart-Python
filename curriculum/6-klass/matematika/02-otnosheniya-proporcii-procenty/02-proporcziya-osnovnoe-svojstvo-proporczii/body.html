Что нужно знать перед темой

Пропорция строится на отношениях. Поэтому перед этой темой важно понимать, что отношение двух чисел — это частное этих чисел, а равные отношения можно записывать разными способами.

  • Отношение двух чисел можно записать как деление или как дробь.
  • Отношение можно сокращать, если обе его части имеют общий делитель.
  • Две дроби равны, если они показывают одно и то же число.
  • При сравнении величин их нужно приводить к одинаковым единицам измерения.
  • Делить на ноль нельзя, поэтому знаменатели и делители в пропорции не должны быть равны нулю.

1. Что такое пропорция

Пропорция — это равенство двух отношений. Если два отношения равны, то их можно записать в виде пропорции.

Пропорция — это равенство двух отношений. Например, запись 2 : 3 = 4 : 6 является пропорцией, потому что оба отношения равны одному и тому же числу.
Общий вид пропорции:
a : b = c : d
или ab = cd, где b ≠ 0 и d ≠ 0.

Пример 1. Проверим, является ли равенство пропорцией

Условие Проверить, является ли равенство 3 : 5 = 9 : 15 пропорцией.
Решение.
Найдём значения отношений.
3 : 5 = 35.
9 : 15 = 915 = 35.
Отношения равны, значит равенство является пропорцией.
Ответ: да, это пропорция.

2. Крайние и средние члены пропорции

В пропорции есть четыре числа. Первое и последнее число называют крайними членами, а два числа в середине — средними членами.

В пропорции a : b = c : d числа a и d называются крайними членами, а числа b и c называются средними членами.

3. Основное свойство пропорции

У любой верной пропорции есть важное свойство: произведение крайних членов равно произведению средних членов. Это свойство помогает проверять пропорции и решать уравнения.

Основное свойство пропорции: если a : b = c : d, то a · d = b · c. То есть произведение крайних членов равно произведению средних членов.

Схема: перемножение крест-накрест

Пример 2. Проверим пропорцию основным свойством

Условие Проверить, верна ли пропорция 4 : 7 = 12 : 21.
Решение.
Крайние члены: 4 и 21. Их произведение: 4 · 21 = 84.
Средние члены: 7 и 12. Их произведение: 7 · 12 = 84.
Произведения равны, значит пропорция верна.
Ответ: пропорция верна.
Проверять пропорцию через основное свойство обычно быстрее, чем находить значения обоих отношений.

4. Как найти неизвестный член пропорции

Если в пропорции одно число неизвестно, его можно найти с помощью основного свойства. Сначала записывают произведение крайних и средних членов, а затем решают получившееся уравнение.

Чтобы найти неизвестный член пропорции:
1. Определите крайние и средние члены.
2. Запишите равенство произведений: произведение крайних равно произведению средних.
3. Найдите неизвестное число.
4. Проверьте ответ подстановкой.

Пример 3. Неизвестный крайний член

Условие Решить пропорцию x : 5 = 12 : 15.
Решение.
Запишем пропорцию: x : 5 = 12 : 15.
Крайние члены: x и 15. Средние члены: 5 и 12.
По основному свойству пропорции: x · 15 = 5 · 12.
x · 15 = 60.
x = 60 : 15.
x = 4.
Ответ: x = 4.

Пример 4. Неизвестный средний член

Условие Решить пропорцию 9 : x = 27 : 12.
Решение.
Крайние члены: 9 и 12. Средние члены: x и 27.
По основному свойству пропорции: 9 · 12 = x · 27.
108 = 27x.
x = 108 : 27.
x = 4.
Ответ: x = 4.

5. Проверка пропорции через дроби

Иногда пропорцию удобнее записать в виде равенства дробей. Тогда основное свойство пропорции выглядит как перемножение чисел крест-накрест.

Если ab = cd, то a · d = b · c.

Пример 5. Проверим равенство дробей

Условие Проверить, верно ли равенство: 810 = 1215.
Решение.
Перемножим крест-накрест.
8 · 15 = 120.
10 · 12 = 120.
Произведения равны, значит равенство дробей верно.
Ответ: равенство верно.

6. Пропорции в задачах

Пропорции часто используют в задачах, где две величины изменяются согласованно: например, больше товара — больше стоимость, больше времени — больше путь при одинаковой скорости.

Пример 6. Задача на стоимость

Условие 4 одинаковые тетради стоят 72 рубля. Сколько стоят 7 таких тетрадей?
Решение.
Пусть 7 тетрадей стоят x рублей.
Запишем пропорцию: 4 : 7 = 72 : x.
По основному свойству пропорции: 4 · x = 7 · 72.
4x = 504.
x = 504 : 4.
x = 126.
Ответ: 126 рублей.
В задачах важно записывать отношения в одном порядке. Если слева сравниваем количество тетрадей, то справа сравниваем их стоимости в том же порядке.

7. Задания для самопроверки

Задание 1. Проверить, верна ли пропорция 5 : 8 = 15 : 24.

Показать решение
Крайние члены: 5 и 24. Их произведение: 5 · 24 = 120.
Средние члены: 8 и 15. Их произведение: 8 · 15 = 120.
Произведения равны.
Ответ: пропорция верна.

Задание 2. Проверить, верна ли пропорция 6 : 7 = 18 : 20.

Показать решение
Крайние члены: 6 и 20. Их произведение: 6 · 20 = 120.
Средние члены: 7 и 18. Их произведение: 7 · 18 = 126.
Произведения не равны.
Ответ: пропорция неверна.

Задание 3. Решить пропорцию x : 6 = 10 : 15.

Показать решение
Крайние члены: x и 15. Средние члены: 6 и 10.
По основному свойству пропорции: 15x = 6 · 10.
15x = 60.
x = 60 : 15.
x = 4.
Ответ: x = 4.

Задание 4. Решить пропорцию 14 : x = 7 : 9.

Показать решение
Крайние члены: 14 и 9. Средние члены: x и 7.
По основному свойству пропорции: 14 · 9 = 7x.
126 = 7x.
x = 126 : 7.
x = 18.
Ответ: x = 18.

Задание 5. За 3 кг яблок заплатили 270 рублей. Сколько рублей нужно заплатить за 5 кг таких яблок?

Показать решение
Пусть 5 кг яблок стоят x рублей.
Запишем пропорцию: 3 : 5 = 270 : x.
По основному свойству пропорции: 3x = 5 · 270.
3x = 1350.
x = 1350 : 3.
x = 450.
Ответ: 450 рублей.

Задание 6. Турист прошёл 18 км за 3 часа. Сколько километров он пройдёт за 5 часов с той же скоростью?

Показать решение
Пусть за 5 часов турист пройдёт x км.
Запишем пропорцию: 3 : 5 = 18 : x.
По основному свойству пропорции: 3x = 5 · 18.
3x = 90.
x = 90 : 3.
x = 30.
Ответ: 30 км.

8. Короткая памятка

Пропорция — это равенство двух отношений.
В пропорции a : b = c : d числа a и d — крайние члены, а числа b и c — средние члены.
Основное свойство пропорции: произведение крайних членов равно произведению средних: a · d = b · c.
