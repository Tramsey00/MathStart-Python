Решение линейных уравнений

В этой теме разберём, что такое линейное уравнение, что значит решить уравнение, как находить неизвестное число и как проверять найденный корень подстановкой.

Что нужно знать перед темой

Уравнение — это равенство с неизвестным числом. Решать уравнение значит найти такое значение буквы, при котором левая и правая части становятся равными. В 6 классе чаще всего встречаются линейные уравнения с одной переменной.

  • Буква в уравнении обозначает неизвестное число.
  • Левая и правая части уравнения разделены знаком равенства.
  • Корень уравнения — это значение переменной, при котором равенство верно.
  • Одинаковые действия можно выполнять с обеими частями уравнения.
  • Слагаемые можно переносить через знак равенства с изменением знака.
  • Найденный ответ нужно проверять подстановкой.

1. Что такое уравнение

Уравнение похоже на весы: левая и правая части должны быть равны. Неизвестное число нужно найти так, чтобы равновесие сохранилось.

Уравнение — это равенство, содержащее неизвестное число.
Решить уравнение — значит найти все значения неизвестного, при которых равенство становится верным.

Схема: уравнение как равновесие

Пример 1. Проверим значение переменной

Условие Проверить, является ли число 6 корнем уравнения x + 4 = 10.
Решение.
Подставим x = 6 в левую часть уравнения.
6 + 4 = 10.
Левая часть равна правой части.
Ответ: число 6 является корнем уравнения.

2. Простые уравнения на сложение и вычитание

В простых уравнениях неизвестное число можно найти обратным действием. Если к неизвестному прибавили число, то это число нужно вычесть. Если из неизвестного вычли число, то это число нужно прибавить.

x + a = b решаем так: x = b − a.
x − a = b решаем так: x = b + a.

Пример 2. Неизвестное слагаемое

Условие Решить уравнение x + 9 = 23.
Решение.
Чтобы найти x, нужно из 23 вычесть 9.
x = 23 − 9.
x = 14.
Ответ: x = 14.

Пример 3. Неизвестное уменьшаемое

Условие Решить уравнение x − 7 = 18.
Решение.
Чтобы найти x, нужно к 18 прибавить 7.
x = 18 + 7.
x = 25.
Ответ: x = 25.

Пример 4. Неизвестное вычитаемое

Условие Решить уравнение 31 − x = 12.
Решение.
В этом уравнении неизвестно вычитаемое.
Чтобы найти вычитаемое, нужно из уменьшаемого вычесть разность.
x = 31 − 12.
x = 19.
Ответ: x = 19.

3. Простые уравнения на умножение и деление

Если неизвестное число умножили на число, то для нахождения неизвестного нужно разделить. Если неизвестное число разделили на число, то нужно умножить.

ax = b решаем так: x = b : a, если a ≠ 0.
x : a = b решаем так: x = b · a, если a ≠ 0.

Схема: обратные действия

Пример 5. Неизвестный множитель

Условие Решить уравнение 6x = 42.
Решение.
Чтобы найти x, нужно 42 разделить на 6.
x = 42 : 6.
x = 7.
Ответ: x = 7.

Пример 6. Неизвестное делимое

Условие Решить уравнение x : 5 = 8.
Решение.
Чтобы найти x, нужно 8 умножить на 5.
x = 8 · 5.
x = 40.
Ответ: x = 40.

Пример 7. Неизвестный делитель

Условие Решить уравнение 48 : x = 6.
Решение.
В этом уравнении неизвестен делитель.
Чтобы найти делитель, нужно делимое разделить на частное.
x = 48 : 6.
x = 8.
Ответ: x = 8.

4. Линейное уравнение вида ax + b = c

Часто неизвестное сначала умножают на число, а потом прибавляют или вычитают другое число. Такое уравнение удобно решать в обратном порядке: сначала убрать свободное число, затем найти x.

Для уравнения ax + b = c:
1. Сначала убрать b.
2. Затем разделить на коэффициент при x.

Схема: решаем в обратном порядке

Пример 8. Решим уравнение с прибавлением

Условие Решить уравнение 4x + 3 = 19.
Решение.
Сначала уберём +3: для этого вычтем 3 из правой части.
4x = 19 − 3.
4x = 16.
Теперь делим на 4.
x = 16 : 4.
x = 4.
Ответ: x = 4.

Пример 9. Решим уравнение с вычитанием

Условие Решить уравнение 5x − 7 = 18.
Решение.
Сначала уберём −7: для этого прибавим 7 к правой части.
5x = 18 + 7.
5x = 25.
Теперь делим на 5.
x = 25 : 5.
x = 5.
Ответ: x = 5.

5. Перенос слагаемых через знак равенства

В уравнениях удобно переносить слагаемые из одной части в другую. При переносе через знак равенства знак слагаемого меняется на противоположный.

Если слагаемое переносится через знак равенства, его знак меняется:
+7 превращается в −7, а −7 превращается в +7.

Схема: перенос слагаемого

Пример 10. Перенесём число

Условие Решить уравнение 7x + 9 = 30.
Решение.
Перенесём +9 в правую часть со знаком минус.
7x = 30 − 9.
7x = 21.
x = 21 : 7.
x = 3.
Ответ: x = 3.

Пример 11. Перенесём слагаемое с переменной

Условие Решить уравнение 8x − 5 = 3x + 20.
Решение.
Перенесём 3x в левую часть со знаком минус.
8x − 3x − 5 = 20.
5x − 5 = 20.
Перенесём −5 в правую часть со знаком плюс.
5x = 20 + 5.
5x = 25.
x = 5.
Ответ: x = 5.

6. Уравнения со скобками

Если в уравнении есть скобки, сначала обычно раскрывают скобки, затем приводят подобные слагаемые и только после этого находят неизвестное.

В уравнении со скобками:
1. Раскрываем скобки.
2. Приводим подобные слагаемые.
3. Переносим слагаемые.
4. Находим x.
5. Проверяем ответ.

Пример 12. Уравнение со скобками

Условие Решить уравнение 3(x + 2) = 21.
Решение.
Раскрываем скобки: 3(x + 2) = 3x + 6.
Получаем уравнение: 3x + 6 = 21.
Переносим +6 в правую часть со знаком минус.
3x = 21 − 6.
3x = 15.
x = 5.
Ответ: x = 5.

Пример 13. Скобки в обеих частях

Условие Решить уравнение 2(x + 4) = x + 13.
Решение.
Раскрываем скобки: 2(x + 4) = 2x + 8.
Получаем: 2x + 8 = x + 13.
Перенесём x в левую часть, а 8 в правую.
2x − x = 13 − 8.
x = 5.
Ответ: x = 5.

7. Уравнения с отрицательными числами

В уравнениях с отрицательными числами действуют те же правила. Главное — аккуратно работать со знаками, особенно при переносе слагаемых и делении на отрицательный коэффициент.

Если коэффициент при x отрицательный, то обе части уравнения делят на отрицательное число.
Например: −4x = 20, значит x = 20 : (−4) = −5.

Пример 14. Деление на отрицательное число

Условие Решить уравнение −6x = 42.
Решение.
Чтобы найти x, нужно 42 разделить на −6.
x = 42 : (−6).
x = −7.
Ответ: x = −7.

Пример 15. Уравнение с переносом и минусами

Условие Решить уравнение −3x + 8 = 20.
Решение.
Переносим +8 в правую часть со знаком минус.
−3x = 20 − 8.
−3x = 12.
Делим обе части на −3.
x = 12 : (−3).
x = −4.
Ответ: x = −4.

8. Проверка корня уравнения

Проверка нужна, чтобы убедиться, что найденное число действительно подходит. Для этого найденное значение x подставляют в исходное уравнение.

Чтобы проверить корень:
1. Подставьте найденное число вместо x.
2. Посчитайте левую часть.
3. Посчитайте правую часть.
4. Если части равны, корень найден верно.

Пример 16. Проверим найденный корень

Условие Проверить ответ x = 5 для уравнения 2(x + 4) = x + 13.
Проверка.
Подставим x = 5.
Левая часть: 2(5 + 4) = 2 · 9 = 18.
Правая часть: 5 + 13 = 18.
Левая часть равна правой части.
Значит, x = 5 найдено верно.

9. Частые ошибки

В линейных уравнениях ошибки чаще всего возникают из-за неверного переноса слагаемых, неправильного раскрытия скобок или отсутствия проверки.

Ошибка Почему неверно Как правильно
3x + 5 = 20, значит 3x = 20 + 5 При переносе +5 знак должен измениться 3x = 20 − 5
−4x = 16, значит x = 4 Делим на −4, поэтому ответ отрицательный x = 16 : (−4) = −4
2(x + 3) = 2x + 3 Множитель 2 должен умножиться на оба слагаемых 2(x + 3) = 2x + 6
Ответ не проверили Можно не заметить ошибку в знаке Подставить x в исходное уравнение
Самая надёжная проверка — подстановка в исходное уравнение, а не в промежуточную строку.

Показать решение

4x = 30 − 6.
4x = 24.

Показать решение
3x = 16 + 8.
3x = 24.
x = 24 : 3.
x = 8.

Показать решение
Перенесём 3x в левую часть, а 5 в правую.
7x − 3x = 25 − 5.
4x = 20.

Показать решение

Показать решение

2x + 10 = 24.

x = 7.

Показать решение

Ответ: x = 10.

Показать решение

Ответ: x = −7.

11. Уравнение как маршрут назад

Уравнение удобно воспринимать как цепочку действий, которую нужно пройти в обратную сторону. Если с неизвестным сначала что-то сделали, то при решении мы отменяем эти действия в обратном порядке.

Было прибавление Чтобы убрать прибавленное число, его вычитают. Например: x + 8 = 19, значит x = 19 − 8.
Было вычитание Чтобы убрать вычитание, число прибавляют. Например: x − 6 = 20, значит x = 20 + 6.
Было умножение Чтобы убрать множитель при x, делят на этот множитель. Например: 5x = 40, значит x = 40 : 5.
Было деление Чтобы убрать деление, умножают. Например: x : 3 = 12, значит x = 12 · 3.
Если в уравнении есть скобки, сначала лучше раскрыть их. Если ответ вызывает сомнение, подставьте его в исходное уравнение и проверьте равенство.
