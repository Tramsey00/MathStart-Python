Этапы решения линейных уравнений

В этой теме соберём все правила в один понятный алгоритм: как решать линейные уравнения со скобками, переносом слагаемых, подобными членами и проверкой ответа.

Зачем нужен алгоритм

Линейные уравнения могут выглядеть по-разному: где-то есть скобки, где-то переменная стоит в обеих частях, где-то встречаются отрицательные числа. Но почти любое такое уравнение можно решать по одному маршруту.

  • Сначала выражение нужно привести к удобному виду.
  • Скобки раскрываются до переноса слагаемых.
  • Слагаемые с переменной лучше собирать в одной части.
  • Числа без переменной лучше собирать в другой части.
  • После приведения должно получиться уравнение вида ax = b.
  • Последний шаг — деление на коэффициент при x и проверка.

1. Общий алгоритм решения

Алгоритм нужен для того, чтобы не решать уравнение хаотично. Если каждый раз идти по одним и тем же шагам, меньше риск потерять знак, забыть раскрыть скобки или неправильно перенести слагаемое.

1
Раскрыть скобки Если скобок нет, этот шаг просто пропускаем.
2
Привести подобные Упростить левую и правую части отдельно.
3
Собрать x Переменные перенести в одну часть уравнения.
4
Собрать числа Числа без x перенести в другую часть.
5
Получить ax = b Должно остаться простое уравнение.
6
Найти и проверить Разделить на коэффициент и подставить ответ.

Схема: маршрут решения линейного уравнения

Главное правило: каждый перенос через знак равенства меняет знак слагаемого.
+a становится −a, а −a становится +a.

2. Пример без скобок

Начнём с уравнения, где переменная встречается в обеих частях. Здесь не нужно раскрывать скобки, поэтому сразу собираем переменные и числа.

Пример 1. Переменная в обеих частях

Условие Решить уравнение 7x + 4 = 3x + 20.
Решение.
Перенесём 3x в левую часть со знаком минус.
7x − 3x + 4 = 20.
4x + 4 = 20.
Перенесём +4 в правую часть со знаком минус.
4x = 20 − 4.
4x = 16.
x = 16 : 4.
x = 4.
Ответ: x = 4.

Проверка

Подставим x = 4 в исходное уравнение.
Левая часть: 7 · 4 + 4 = 28 + 4 = 32.
Правая часть: 3 · 4 + 20 = 12 + 20 = 32.
Левая часть равна правой части.
Значит, x = 4 найдено верно.

3. Уравнение со скобками

Если в уравнении есть скобки, не нужно сразу переносить слагаемые. Сначала раскрываем скобки, а затем решаем получившееся уравнение обычным способом.

Скобки раскрываются до переноса слагаемых.
Это помогает не запутаться в знаках и коэффициентах.

Схема: сначала скобки, потом перенос

Пример 2. Скобки в одной части

Условие Решить уравнение 3(x + 5) = 2x + 25.
Решение.
Раскрываем скобки в левой части.
3x + 15 = 2x + 25.
Перенесём 2x в левую часть.
3x − 2x + 15 = 25.
x + 15 = 25.
Перенесём +15 в правую часть.
x = 25 − 15.
x = 10.
Ответ: x = 10.

Пример 3. Скобки в обеих частях

Условие Решить уравнение 2(x − 4) = 5x − 17.
Решение.
Раскрываем скобки.
2x − 8 = 5x − 17.
Перенесём 5x в левую часть, а −8 в правую.
2x − 5x = −17 + 8.
−3x = −9.
x = −9 : (−3).
x = 3.
Ответ: x = 3.

4. Уравнение с минусом перед скобками

Минус перед скобками — один из самых частых источников ошибок. При раскрытии таких скобок нужно изменить знаки всех слагаемых внутри скобок.

Минус перед скобками меняет все знаки внутри скобок:
−(x + 7) = −x − 7
−(x − 7) = −x + 7

Пример 4. Минус перед скобками

Условие Решить уравнение 18 − (x + 4) = 7.
Решение.
Раскрываем скобки: перед скобками стоит минус.
18 − x − 4 = 7.
Приведём подобные числа: 18 − 4 = 14.
14 − x = 7.
Перенесём 14 в правую часть.
−x = 7 − 14.
−x = −7.
x = 7.
Ответ: x = 7.

Пример 5. Минус перед разностью

Условие Решить уравнение 12 − (2x − 5) = 3.
Решение.
Раскрываем скобки: 2x становится −2x, а −5 становится +5.
12 − 2x + 5 = 3.
17 − 2x = 3.
Перенесём 17 в правую часть.
−2x = 3 − 17.
−2x = −14.
x = −14 : (−2).
x = 7.
Ответ: x = 7.

5. Когда в уравнении дроби

Если в уравнении есть дробные коэффициенты, можно решать обычным способом. В 6 классе чаще всего достаточно аккуратно выполнить действия с дробями и в конце разделить на коэффициент при переменной.

Если получилось abx = c , то x можно найти делением: x = c : ab .

Пример 6. Дробный коэффициент при x

Условие Решить уравнение 12x + 3 = 8.
Решение.
Перенесём +3 в правую часть.
12x = 8 − 3.
12x = 5.
Чтобы найти x, нужно 5 разделить на 12.
x = 5 : 12 = 5 · 2 = 10.
Ответ: x = 10.

Пример 7. Дроби в обеих частях

Условие Решить уравнение 34x − 2 = 14x + 4.
Решение.
Перенесём дробное слагаемое с x в левую часть, а −2 в правую.
34x − 14x = 4 + 2.
24x = 6.
12x = 6.
x = 6 : 12 = 12.
Ответ: x = 12.

6. Проверка после решения

Проверка особенно важна в уравнениях со скобками и отрицательными числами. Проверять нужно не по последней строке решения, а по исходному уравнению.

Для проверки подставляем найденное значение x в исходное уравнение. Если левая часть равна правой, ответ верный.

Пример 8. Проверим решение

Условие Проверить x = 7 для уравнения 12 − (2x − 5) = 3.
Проверка.
Подставим x = 7 в исходное уравнение.
Левая часть: 12 − (2 · 7 − 5).
12 − (14 − 5) = 12 − 9 = 3.
Правая часть равна 3.
Левая часть равна правой части.
Значит, x = 7 найдено верно.
Если при проверке левая и правая части не совпали, нужно искать ошибку выше: чаще всего это знак перед скобками или перенос через знак равенства.

7. Особые случаи

Иногда после преобразований переменная исчезает. Тогда нужно внимательно посмотреть, какое равенство получилось. Такие случаи встречаются реже, но их полезно знать.

Что получилось Что это значит Пример
0 = 0 Равенство верно всегда Решением является любое число
0 = 5 Равенство неверно Корней нет
ax = b, a ≠ 0 Обычный случай Один корень

Пример 9. Любое число подходит

Условие Решить уравнение 2(x + 3) = 2x + 6.
Решение.
Раскрываем скобки: 2x + 6 = 2x + 6.
Перенесём 2x в левую часть.
2x − 2x + 6 = 6.
6 = 6.
Получилось верное равенство.
Ответ: подходит любое число.

Пример 10. Корней нет

Условие Решить уравнение 3(x − 2) = 3x + 5.
Решение.
Раскрываем скобки: 3x − 6 = 3x + 5.
Перенесём 3x в левую часть.
3x − 3x − 6 = 5.
−6 = 5.
Получилось неверное равенство.
Ответ: корней нет.

8. Ошибки на разных этапах

У каждого этапа решения есть своя типичная ошибка. Если решение не сходится, удобно проверять его именно по этапам.

Этап Частая ошибка Как избежать
Раскрытие скобок Множитель подействовал не на все слагаемые Умножать каждое слагаемое внутри скобок
Минус перед скобками Изменили только первый знак Менять знаки у всех слагаемых внутри скобок
Перенос Не поменяли знак при переходе через равенство Каждый перенос сопровождается сменой знака
Деление Забыли знак коэффициента при x Если −3x = 12, то x = 12 : (−3)
Проверка Проверили не в исходном уравнении Подставлять ответ именно в начальную запись

9. Задания для самопроверки

Задание 1. Решите уравнение 6x + 5 = 2x + 21.

Показать решение
Перенесём 2x влево, 5 вправо.
6x − 2x = 21 − 5.
4x = 16.
x = 4.
Ответ: x = 4.

Задание 2. Решите уравнение 9x − 7 = 4x + 18.

Показать решение
9x − 4x = 18 + 7.
5x = 25.
x = 5.
Ответ: x = 5.

Задание 3. Решите уравнение 3(x + 4) = 24.

Показать решение
3x + 12 = 24.
3x = 24 − 12.
3x = 12.
x = 4.
Ответ: x = 4.

Задание 4. Решите уравнение 5(x − 2) = 3x + 8.

Показать решение
5x − 10 = 3x + 8.
5x − 3x = 8 + 10.
2x = 18.
x = 9.
Ответ: x = 9.

Задание 5. Решите уравнение 4(x + 1) = 2(x + 7).

Показать решение
4x + 4 = 2x + 14.
4x − 2x = 14 − 4.
2x = 10.
x = 5.
Ответ: x = 5.

Задание 6. Решите уравнение 20 − (x + 6) = 9.

Показать решение
20 − x − 6 = 9.
14 − x = 9.
−x = 9 − 14.
−x = −5.
x = 5.
Ответ: x = 5.

Задание 7. Решите уравнение 15 − (2x − 3) = 6.

Показать решение
15 − 2x + 3 = 6.
18 − 2x = 6.
−2x = 6 − 18.
−2x = −12.
x = 6.
Ответ: x = 6.

Задание 8. Решите уравнение −3x + 8 = 23.

Показать решение
−3x = 23 − 8.
−3x = 15.
x = 15 : (−3).
x = −5.
Ответ: x = −5.

Задание 9. Решите уравнение 13x + 2 = 7.

Показать решение
Перенесём +2 вправо:
13x = 5.
x = 5 : 13 = 15.
Ответ: x = 15.

Задание 10. Решите уравнение 35x − 1 = 15x + 7.

Показать решение
Перенесём дробное слагаемое с x влево, −1 вправо:
35x − 15x = 7 + 1.
25x = 8.
x = 8 : 25 = 20.
Ответ: x = 20.

Задание 11. Решите уравнение 2(x + 5) = 2x + 10.

Показать решение
Раскроем скобки:
2x + 10 = 2x + 10.
Получилось верное равенство при любом x.
Ответ: подходит любое число.

Задание 12. Решите уравнение 4(x − 1) = 4x + 3.

Показать решение
Раскроем скобки:
4x − 4 = 4x + 3.
Перенесём 4x влево:
4x − 4x − 4 = 3.
−4 = 3.
Получилось неверное равенство.
Ответ: корней нет.

10. Карта решения уравнения

Уравнение удобно решать как задачу на наведение порядка: сначала убрать лишние конструкции, потом разложить слагаемые по сторонам, затем получить простое уравнение.

Сначала упрощаем Раскрываем скобки и приводим подобные слагаемые отдельно в каждой части уравнения.
Потом разделяем Все слагаемые с x собираем в одной части, числа без x — в другой части.
Затем находим x Когда получилось ax = b, делим обе части на коэффициент a.
После этого проверяем Подставляем найденное значение в исходное уравнение, а не в сокращённую запись.
Если решение запуталось, вернитесь к началу и проверьте только два места: раскрытие скобок и перенос слагаемых через знак равенства.
