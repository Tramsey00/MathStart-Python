Умножение и деление рациональных чисел

В этой теме разберём правила знаков при умножении и делении рациональных чисел: когда ответ получается положительным, когда отрицательным, почему сначала удобно определить знак, а уже потом выполнять вычисления.

Что нужно знать перед темой

При сложении рациональных чисел знак результата зависел от модулей слагаемых. При умножении и делении всё устроено проще: знак ответа зависит только от знаков чисел. А сами числа без знаков умножаются или делятся обычным способом.

  • Положительное число имеет знак плюс, даже если плюс не написан.
  • Отрицательное число записывается со знаком минус.
  • Модуль числа показывает его значение без учёта знака.
  • Произведение — результат умножения.
  • Частное — результат деления.
  • На ноль делить нельзя.

1. Главное правило знаков

При умножении и делении рациональных чисел сначала удобно определить знак результата. Если знаки одинаковые, результат будет положительным. Если знаки разные, результат будет отрицательным.

Одинаковые знаки дают положительный результат.
Разные знаки дают отрицательный результат.

Схема: правило знаков

Пример 1. Одинаковые знаки

Условие Определить знак результата: −8 · (−3).
Решение.
Оба множителя отрицательные.
Знаки одинаковые, значит результат положительный.
8 · 3 = 24.
Ответ: −8 · (−3) = 24.

Пример 2. Разные знаки

Условие Определить знак результата: −8 · 3.
Решение.
Первый множитель отрицательный, второй положительный.
Знаки разные, значит результат отрицательный.
8 · 3 = 24.
Ответ: −8 · 3 = −24.

2. Умножение рациональных чисел

При умножении рациональных чисел сначала определяют знак произведения, затем умножают модули чисел. Это правило работает для целых чисел, десятичных дробей и обыкновенных дробей.

Чтобы умножить два рациональных числа:
1. Определите знак результата.
2. Умножьте модули чисел.
3. Поставьте перед ответом найденный знак.

Пример 3. Положительное на положительное

Условие Вычислить 7 · 6.
Решение.
Оба числа положительные.
Значит, результат положительный.
7 · 6 = 42.
Ответ: 42.

Пример 4. Отрицательное на положительное

Условие Вычислить −7 · 6.
Решение.
Знаки разные: минус и плюс.
Значит, ответ будет отрицательным.
7 · 6 = 42.
Ответ: −42.

Пример 5. Отрицательное на отрицательное

Условие Вычислить −7 · (−6).
Решение.
Оба числа отрицательные.
Знаки одинаковые, значит ответ будет положительным.
7 · 6 = 42.
Ответ: 42.

3. Умножение на 0 и на 1

Числа 0, 1 и −1 часто встречаются в примерах. Их свойства помогают быстро упрощать выражения.

Любое число, умноженное на 0, даёт 0.
Любое число, умноженное на 1, не меняется.
Умножение на −1 меняет знак числа на противоположный.
Правило Пример Результат
a · 0 = 0 −15 · 0 0
a · 1 = a −15 · 1 −15
a · (−1) = −a −15 · (−1) 15
0 · a = 0 0 · 42 0

Пример 6. Умножение на −1

Условие Вычислить −23 · (−1).
Решение.
Умножение на −1 меняет знак числа на противоположный.
Число −23 станет числом 23.
Ответ: 23.

4. Деление рациональных чисел

При делении рациональных чисел правило знаков такое же, как при умножении. Одинаковые знаки дают положительное частное, разные знаки дают отрицательное частное.

Чтобы разделить два рациональных числа:
1. Определите знак частного.
2. Разделите модули чисел.
3. Поставьте перед ответом найденный знак.
Делить на ноль нельзя.

Пример 7. Положительное деление

Условие Вычислить 36 : 6.
Решение.
Оба числа положительные.
Ответ положительный.
36 : 6 = 6.
Ответ: 6.

Пример 8. Разные знаки при делении

Условие Вычислить −36 : 6.
Решение.
Знаки разные: минус и плюс.
Ответ будет отрицательным.
36 : 6 = 6.
Ответ: −6.

Пример 9. Два отрицательных числа

Условие Вычислить −36 : (−6).
Решение.
Оба числа отрицательные.
Знаки одинаковые, значит ответ положительный.
36 : 6 = 6.
Ответ: 6.

5. Почему нельзя делить на ноль

Деление связано с проверкой умножением. Например, 12 : 3 = 4, потому что 4 · 3 = 12. Если попытаться разделить число на ноль, проверка умножением становится невозможной.

На ноль делить нельзя.
Записи вида 8 : 0, −15 : 0, 0 : 0 не имеют значения в школьной арифметике.

Пример 10. Проверим деление на ноль

Условие Можно ли вычислить −24 : 0?
Решение.
Деление на ноль не определено.
Нельзя найти число, которое при умножении на 0 даст −24.
Любое число при умножении на 0 даёт 0, а не −24.
Ответ: вычислить нельзя.
Не путайте 0 : a и a : 0. Если a не равно нулю, то 0 : a = 0. Но a : 0 вычислить нельзя.

6. Десятичные дроби при умножении и делении

В десятичных дробях знак определяется отдельно, а вычисление выполняется так же, как с положительными десятичными дробями.

Пример 11. Умножение десятичных дробей

Условие Вычислить −2,5 · 4.
Решение.
Знаки разные, значит результат отрицательный.
Умножаем модули: 2,5 · 4 = 10.
Ответ: −10.

Пример 12. Деление десятичных дробей

Условие Вычислить −7,2 : (−0,8).
Решение.
Оба числа отрицательные, значит результат положительный.
Делим модули: 7,2 : 0,8 = 9.
Ответ: 9.

Пример 13. Деление с отрицательным ответом

Условие Вычислить 6,3 : (−0,7).
Решение.
Знаки разные, значит результат отрицательный.
Делим модули: 6,3 : 0,7 = 9.
Ответ: −9.

7. Несколько множителей

Если в произведении больше двух множителей, знак результата зависит от количества отрицательных множителей. Если отрицательных множителей чётное количество, произведение положительное. Если нечётное — отрицательное.

В произведении нескольких чисел:
чётное количество минусов даёт плюс;
нечётное количество минусов даёт минус.

Пример 14. Два отрицательных множителя

Условие Вычислить −2 · 3 · (−5).
Решение.
Отрицательных множителей два: −2 и −5.
Два — чётное число, значит результат положительный.
2 · 3 · 5 = 30.
Ответ: 30.

Пример 15. Три отрицательных множителя

Условие Вычислить −2 · (−3) · (−4).
Решение.
Отрицательных множителей три.
Три — нечётное число, значит результат отрицательный.
2 · 3 · 4 = 24.
Ответ: −24.

Пример 16. Если среди множителей есть ноль

Условие Вычислить −5 · 0 · (−12).
Решение.
В произведении есть множитель 0.
Если хотя бы один множитель равен нулю, всё произведение равно нулю.
Ответ: 0.

8. Смешанные выражения с умножением и делением

В выражениях, где есть и умножение, и деление, действия выполняются по порядку слева направо, если нет скобок. Перед каждым действием полезно определять знак промежуточного результата.

Умножение и деление имеют одинаковый приоритет.
Если они стоят рядом без скобок, выполняем их слева направо.

Пример 17. Выражение без скобок

Условие Вычислить −48 : 6 · (−2).
Решение.
Выполняем действия слева направо.
−48 : 6 = −8.
−8 · (−2) = 16.
Ответ: 16.

Пример 18. Выражение со скобками

Условие Вычислить −6 · (18 : (−3)).
Решение.
Сначала выполняем действие в скобках.
18 : (−3) = −6.
Теперь умножаем: −6 · (−6) = 36.
Ответ: 36.

9. Задания для самопроверки

Задание 1. Вычислите −9 · 4.

Показать решение
Знаки разные, значит ответ отрицательный.
9 · 4 = 36.
Ответ: −36.

Задание 2. Вычислите −9 · (−4).

Показать решение
Оба числа отрицательные, значит ответ положительный.
9 · 4 = 36.
Ответ: 36.

Задание 3. Вычислите 56 : (−7).

Показать решение
Знаки разные, значит ответ отрицательный.
56 : 7 = 8.
Ответ: −8.

Задание 4. Вычислите −56 : (−7).

Показать решение
Оба числа отрицательные, значит ответ положительный.
56 : 7 = 8.
Ответ: 8.

Задание 5. Вычислите −12 · 0.

Показать решение
Если один из множителей равен нулю, произведение равно нулю.
Ответ: 0.

Задание 6. Вычислите −18 · (−1).

Показать решение
Умножение на −1 меняет знак числа.
Число −18 становится числом 18.
Ответ: 18.

Задание 7. Вычислите −2,5 · 8.

Показать решение
Знаки разные, значит ответ отрицательный.
2,5 · 8 = 20.
Ответ: −20.

Задание 8. Вычислите −6,4 : (−0,8).

Показать решение
Оба числа отрицательные, значит ответ положительный.
6,4 : 0,8 = 8.
Ответ: 8.

Задание 9. Вычислите −3 · 4 · (−5).

Показать решение
Отрицательных множителей два.
Чётное количество минусов даёт положительный результат.
3 · 4 · 5 = 60.

Задание 10. Вычислите −2 · (−3) · (−6).

Показать решение
Отрицательных множителей три.
Нечётное количество минусов даёт отрицательный результат.
2 · 3 · 6 = 36.
Ответ: −36.

Задание 11. Вычислите −72 : 9 · (−2).

Показать решение

−72 : 9 = −8.

Показать решение

10. Проверка перед переходом к дробям

Перед следующей темой важно отделить две вещи: знак ответа и само вычисление. Сначала решаем вопрос со знаком, затем спокойно умножаем или делим модули.

Одинаковые знаки При умножении и делении дают положительный результат.
Примеры: −6 · (−2) = 12, −18 : (−3) = 6.
Разные знаки При умножении и делении дают отрицательный результат.
Примеры: −6 · 2 = −12, 18 : (−3) = −6.
Ноль Если в произведении есть множитель 0, всё произведение равно 0.
Но делить на 0 нельзя.
Несколько минусов Чётное количество минусов даёт плюс, нечётное количество минусов даёт минус.
В следующей теме эти же правила знаков будут использоваться для обыкновенных дробей. Главное отличие будет не в знаках, а в технике умножения и деления дробей.
