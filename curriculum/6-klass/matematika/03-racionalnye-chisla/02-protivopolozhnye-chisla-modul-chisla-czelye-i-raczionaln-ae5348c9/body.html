Что нужно знать перед темой

Перед этой темой нужно уверенно понимать, как устроена координатная прямая: где находится ноль, где расположены положительные и отрицательные числа, в какую сторону числа увеличиваются и как читать координаты точек.

  • Положительные числа расположены справа от нуля.
  • Отрицательные числа расположены слева от нуля.
  • Число 0 не является ни положительным, ни отрицательным.
  • Координата точки показывает её положение на координатной прямой.
  • Расстояние на координатной прямой не бывает отрицательным.

1. Противоположные числа

На координатной прямой можно увидеть пары чисел, которые находятся на одинаковом расстоянии от нуля, но по разные стороны от него. Такие числа называют противоположными.

Противоположные числа — это два числа, которые отличаются только знаками.
Например, 7 и −7 — противоположные числа.
Число 0 противоположно самому себе.

Схема: противоположные числа

Пример 1. Назовём противоположные числа

Условие Назвать числа, противоположные числам 9, −4, 0, 2,5.
Решение.
Числу 9 противоположно число −9.
Числу −4 противоположно число 4.
Числу 0 противоположно число 0.
Числу 2,5 противоположно число −2,5.
Ответ: −9; 4; 0; −2,5.

2. Запись числа, противоположного данному

Число, противоположное числу a, записывают как −a. Но важно понимать: запись −a не всегда означает отрицательное число. Она означает число, противоположное числу a.

Если a = 6, то −a = −6.
Если a = −6, то −a = 6.
Поэтому −(−6) = 6.

Пример 2. Найдём значение выражения −a

Условие Найти −a, если a = −12.
Решение.
Запись −a означает число, противоположное числу a.
Если a = −12, то противоположное ему число равно 12.
Ответ: −a = 12.

Пример 3. Упростим запись с двумя минусами

Условие Найти значение выражения −(−35).
Решение.
Выражение −(−35) означает число, противоположное числу −35.
Числу −35 противоположно число 35.
Ответ: 35.
Два минуса подряд в такой записи не нужно читать как «плохой знак». Здесь смысл такой: берём число, противоположное отрицательному числу.

3. Модуль числа

Модуль числа показывает, на каком расстоянии это число находится от нуля на координатной прямой. Поэтому модуль не может быть отрицательным: расстояние всегда равно нулю или положительному числу.

Модуль числа — это расстояние от начала отсчёта до точки, изображающей это число на координатной прямой.
Модуль числа a записывают так: |a|.

Схема: модуль как расстояние

Пример 4. Найдём модули чисел

Условие Найти |8|, |−8|, |0|, |−2,5|.
Решение.
|8| = 8, потому что число 8 находится на расстоянии 8 от нуля.
|−8| = 8, потому что число −8 тоже находится на расстоянии 8 от нуля.
|0| = 0, потому что ноль находится в начале отсчёта.
|−2,5| = 2,5.
Ответ: 8; 8; 0; 2,5.

4. Свойства модуля

Модуль положительного числа равен самому числу. Модуль отрицательного числа равен числу, противоположному ему. Модуль нуля равен нулю.

Если a > 0, то |a| = a.
Если a < 0, то |a| = −a.
Если a = 0, то |a| = 0.
Число Где находится Модуль
7 справа от нуля |7| = 7
−7 слева от нуля |−7| = 7
0 в начале отсчёта |0| = 0
−12,4 слева от нуля |−12,4| = 12,4

Пример 5. Найдём значение выражения с модулем

Условие Вычислить |−14| + |6|.
Решение.
|−14| = 14.
|6| = 6.
Значит, |−14| + |6| = 14 + 6 = 20.
Ответ: 20.

Пример 6. Выражение с противоположным числом

Условие Найти значение выражения −|−9|.
Решение.
Сначала находим модуль: |−9| = 9.
Перед модулем стоит знак минус: −|−9| = −9.
Ответ: −9.
Важно различать записи |−9| и −|−9|. В первой получается 9, а во второй — −9.

5. Расстояние между числом и нулём

Модуль удобно использовать в задачах, где спрашивают расстояние от числа до нуля. Например, числа −5 и 5 находятся на одинаковом расстоянии от нуля, поэтому их модули равны.

Если число находится на расстоянии k от нуля, то его модуль равен k.
Поэтому уравнение |x| = 5 имеет два решения: x = 5 и x = −5.

Пример 7. Найдём числа по модулю

Условие Какие числа имеют модуль 4?
Решение.
Модуль 4 означает расстояние 4 от нуля.
На координатной прямой на расстоянии 4 от нуля находятся две точки: 4 и −4.
Ответ: 4 и −4.

Пример 8. Модуль не может быть отрицательным

Условие Может ли быть верным равенство |x| = −3?
Решение.
Модуль — это расстояние от числа до нуля.
Расстояние не может быть отрицательным.
Ответ: нет, равенство |x| = −3 невозможно.

6. Целые числа

После появления отрицательных чисел множество натуральных чисел расширяется. Теперь вместе рассматривают положительные целые числа, отрицательные целые числа и ноль. Все они образуют множество целых чисел.

Целые числа — это числа:
..., −4, −3, −2, −1, 0, 1, 2, 3, 4, ...
Группа Примеры Входят в целые?
Положительные целые 1, 2, 3, 10, 45 да
Отрицательные целые −1, −2, −9, −100 да
Ноль 0 да
Дробные числа 0,5; −2,7; 3/4 нет

Пример 9. Выберем целые числа

УсловиеСреди чисел −8; 4; 0; 2,5; −3,7; 5/2; 16 выберите целые числа.
Решение.
Целые числа записываются без дробной части.
Из данного списка целыми являются: −8; 4; 0; 16.
Числа 2,5; −3,7 и 5/2 не являются целыми: у них есть ненулевая дробная часть.
Ответ: −8; 4; 0; 16.

7. Рациональные числа

Рациональные числа — это числа, которые можно записать в виде дроби, где числитель — целое число, а знаменатель — натуральное число. В 6 классе сюда относят целые числа, обыкновенные дроби, десятичные дроби и их отрицательные варианты.

Рациональные числа — это числа, которые можно записать в виде mn, где m — целое число, а n — натуральное число.

Схема: целые и рациональные числа

Пример 10. Выберем рациональные числа

Условие Среди чисел −5, 0, 7, 2,4, −0,8, 35 выбрать рациональные числа.
Решение.
Все данные числа можно записать в виде дроби.
Целые числа тоже можно записать дробью: например, 7 = 7/1.
Десятичные дроби тоже можно записать обыкновенными дробями.
Ответ: все данные числа рациональные.
В этой теме главное понять включение: натуральные числа входят в целые, а целые числа входят в рациональные.

8. Как не путать целые и рациональные числа

Рациональные числа — более широкая группа, чем целые. Каждое целое число является рациональным, но не каждое рациональное число является целым.

Все целые числа — рациональные.
Но дробные рациональные числа, например 0,6 или 58, не являются целыми.

Пример 11. Проверим утверждения

Условие Верно ли утверждение: «Каждое рациональное число является целым»?
Решение.
Нет. Например, число 0,5 является рациональным.
Но 0,5 не является целым числом, потому что имеет дробную часть.
Ответ: утверждение неверно.

Пример 12. Другое утверждение

Условие Верно ли утверждение: «Каждое целое число является рациональным»?
Решение.
Да. Любое целое число можно записать в виде дроби со знаменателем 1.
Например, −6 = −6/1, 0 = 0/1, 12 = 12/1.
Ответ: утверждение верно.

10. Короткая памятка

Противоположные числа отличаются только знаками.
Число 0 противоположно самому себе.
Модуль числа — это расстояние от этого числа до нуля.
Модуль не может быть отрицательным.
Целые числа: ..., −3, −2, −1, 0, 1, 2, 3, ...
Рациональные числа можно записать в виде дроби.
