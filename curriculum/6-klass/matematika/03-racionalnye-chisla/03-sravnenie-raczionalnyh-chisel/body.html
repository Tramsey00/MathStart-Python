Сравнение рациональных чисел

В этой теме разберём, как сравнивать положительные и отрицательные числа, как пользоваться координатной прямой, почему из двух отрицательных чисел меньше то, у которого модуль больше, и как сравнивать десятичные дроби и обыкновенные дроби со знаками.

Что нужно знать перед темой

Рациональные числа можно сравнивать разными способами: по координатной прямой, по знаку, по модулю, через десятичную запись или через общий знаменатель. Но главный смысл всегда один: больше то число, которое на координатной прямой расположено правее.

  • Положительные числа расположены справа от нуля.
  • Отрицательные числа расположены слева от нуля.
  • Число справа на координатной прямой больше числа слева.
  • Модуль числа показывает расстояние от числа до нуля.
  • Положительное число всегда больше отрицательного.
  • Ноль больше любого отрицательного числа, но меньше любого положительного числа.

1. Главное правило сравнения

Координатная прямая помогает увидеть порядок чисел. Если одно число расположено правее другого, то оно больше. Если число расположено левее, то оно меньше.

Главное правило: на координатной прямой больше то число, которое расположено правее.
Меньше то число, которое расположено левее.

Схема: правее — больше

Пример 1. Сравним числа по координатной прямой

Условие Сравнить числа −2 и 3.
Решение.
На координатной прямой число 3 расположено правее числа −2.
Значит, число 3 больше числа −2.
Ответ: −2 < 3.

2. Сравнение чисел разных знаков

Если одно число положительное, а другое отрицательное, то сравнение выполняется сразу: положительное число больше отрицательного. Ноль находится между ними.

Любое положительное число больше любого отрицательного числа.
Любое отрицательное число меньше нуля.
Любое положительное число больше нуля.
Порядок на координатной прямой:
отрицательные числа < 0 < положительные числа.

Пример 2. Положительное и отрицательное число

Условие Сравнить числа −15 и 4.
Решение.
Число −15 отрицательное.
Число 4 положительное.
Положительное число всегда больше отрицательного.
Ответ: −15 < 4.

Пример 3. Ноль и отрицательное число

Условие Сравнить числа 0 и −0,7.
Решение.
Число −0,7 отрицательное, значит оно меньше нуля.
Ответ: −0,7 < 0.

3. Сравнение двух положительных чисел

Положительные рациональные числа сравнивают так же, как обычные числа: больше то число, у которого больше значение. Для дробей можно привести к общему знаменателю или перевести в десятичную дробь.

Если оба числа положительные, сравниваем их обычным способом: по целой части, по десятичной записи или через общий знаменатель.

Пример 4. Сравним десятичные дроби

Условие Сравнить числа 2,4 и 2,37.
Решение.
Запишем 2,4 как 2,40.
Сравним: 2,40 и 2,37.
Так как 40 сотых больше 37 сотых, то 2,40 > 2,37.
Ответ: 2,4 > 2,37.

Пример 5. Сравним обыкновенные дроби

Условие Сравнить дроби 35 и 710.
Решение.
Приведём дроби к общему знаменателю 10.
35 = 610.
Сравним: 610 и 710.
Так как 6 < 7, то 610 < 710.
Ответ: 35 < 710.

4. Сравнение двух отрицательных чисел

С отрицательными числами нужно быть особенно внимательным. Из двух отрицательных чисел меньше то, которое находится левее на координатной прямой. А левее будет число с большим модулем.

Из двух отрицательных чисел меньше то, у которого модуль больше.
Например, −8 < −3, потому что |−8| = 8, а |−3| = 3.

Схема: сравнение отрицательных чисел

Пример 6. Сравним отрицательные числа

Условие Сравнить числа −9 и −4.
Решение.
Оба числа отрицательные.
Сравним модули: |−9| = 9, |−4| = 4.
У числа −9 модуль больше, значит само число меньше.
Ответ: −9 < −4.

Пример 7. Десятичные отрицательные числа

Условие Сравнить числа −2,8 и −2,3.
Решение.
Оба числа отрицательные.
Число −2,8 расположено левее числа −2,3.
Значит, −2,8 меньше.
Ответ: −2,8 < −2,3.

5. Сравнение дробей со знаками

Рациональные числа могут быть записаны десятичными или обыкновенными дробями. Если дроби имеют разные знаки, сначала смотрим на знак. Если обе дроби отрицательные, сравнение идёт наоборот: больше модуль — меньше число.

При сравнении дробей со знаками удобно действовать так:
1. Сначала определить знаки чисел.
2. Если знаки разные, положительное число больше.
3. Если оба числа положительные, сравнить дроби обычным способом.
4. Если оба числа отрицательные, сравнить модули и поменять смысл сравнения.

Пример 8. Отрицательные обыкновенные дроби

Условие Сравнить числа −12 и −34.
Решение.
Оба числа отрицательные.
Сравним модули: 12 и 34.
12 = 24, а 24 < 34.
У второго числа модуль больше, значит второе отрицательное число меньше.
Ответ: −12 > −34.

Пример 9. Дробь и десятичное число

Условие Сравнить числа −0,6 и −23.
Решение.
Оба числа отрицательные.
Переведём дробь: 23 ≈ 0,666...
Значит, сравниваем −0,6 и −0,666...
Число −0,6 находится правее, поэтому оно больше.
Ответ: −0,6 > −23.

6. Алгоритм сравнения рациональных чисел

Чтобы не путаться в знаках, удобно использовать один общий алгоритм. Он подходит для целых чисел, десятичных дробей и обыкновенных дробей.

Алгоритм:
1. Посмотреть на знаки чисел.
2. Если одно число положительное, а другое отрицательное, больше положительное.
3. Если одно число равно нулю, сравнить второе число с нулём.
4. Если оба числа положительные, сравнить их обычным способом.
5. Если оба числа отрицательные, сравнить их модули: больше модуль — меньше число.
Случай Как сравнивать Пример
Положительное и отрицательное Положительное больше 5 > −12
Ноль и отрицательное Ноль больше 0 > −0,4
Ноль и положительное Положительное больше 0 < 0,2
Два положительных Сравниваем как обычно 3,8 > 3,75
Два отрицательных Больше модуль — меньше число −10 < −2
Самая частая ошибка: считать, что −10 больше −2, потому что 10 больше 2. На самом деле −10 находится левее −2, значит −10 меньше.

7. Расположение чисел по порядку

Если нужно расположить числа по возрастанию, мысленно расставляем их на координатной прямой слева направо. Сначала идут отрицательные числа с большими модулями, затем отрицательные с меньшими модулями, потом ноль, затем положительные числа.

Пример 10. Расположим числа по возрастанию

Условие Расположить числа −1,5; 0; 2; −3; 0,8 по возрастанию.
Решение.
По возрастанию — значит от меньшего к большему.
Сначала идут отрицательные числа.
Из чисел −3 и −1,5 меньше число −3, потому что оно левее.
Затем идёт 0.
После нуля идут положительные числа: 0,8 и 2.
Ответ: −3; −1,5; 0; 0,8; 2.

Пример 11. Расположим числа по убыванию

Условие Расположить числа −4; 1,2; −0,5; 3; 0 по убыванию.
Решение.
По убыванию — значит от большего к меньшему.
Сначала идут положительные числа: 3 и 1,2.
Затем идёт 0.
После нуля идут отрицательные числа. Из −0,5 и −4 больше число −0,5.
Ответ: 3; 1,2; 0; −0,5; −4.

8. Задания для самопроверки

Задание 1. Сравните числа −6 и 2.

Показать решение
Число −6 отрицательное, а число 2 положительное.
Положительное число больше отрицательного.
Ответ: −6 < 2.

Задание 2. Сравните числа 0 и −3,4.

Показать решение
Число −3,4 отрицательное.
Ноль больше любого отрицательного числа.
Ответ: 0 > −3,4.

Задание 3. Сравните числа −8 и −5.

Показать решение
Оба числа отрицательные.
Число −8 находится левее числа −5.
Значит, −8 меньше.
Ответ: −8 < −5.

Задание 4. Сравните числа −1,7 и −1,2.

Показать решение
Оба числа отрицательные.
Число −1,7 находится левее числа −1,2.
Ответ: −1,7 < −1,2.

Задание 5. Сравните числа 4,05 и 4,5.

Показать решение
Запишем 4,5 как 4,50.
Сравним 4,05 и 4,50.
4,05 меньше, чем 4,50.
Ответ: 4,05 < 4,5.

Задание 6. Сравните дроби 56 и 34.

Показать решение
Приведём дроби к общему знаменателю 12.
56 = 1012, а 34 = 912.
1012 > 912.
Ответ: 56 > 34.

Задание 7. Сравните числа −13 и −23.

Показать решение
Оба числа отрицательные.
У числа −23 модуль больше, поэтому само число меньше.
Ответ: −13 > −23.

Задание 8. Расположите числа −2; 3; 0; −5; 1 по возрастанию.

Показать решение
По возрастанию числа идут слева направо на координатной прямой.
Сначала отрицательные: −5, −2.
Потом 0, затем положительные: 1, 3.
Ответ: −5; −2; 0; 1; 3.

Задание 9. Расположите числа 0,4; −1,2; 2; −0,5; 0 по возрастанию.

Показать решение
Сначала идут отрицательные числа.
Из −1,2 и −0,5 меньше число −1,2.
Потом идёт 0.
Затем положительные числа: 0,4 и 2.
Ответ: −1,2; −0,5; 0; 0,4; 2.

Задание 10. Какое число больше: −0,08 или −0,8?

Показать решение
Оба числа отрицательные.
Число −0,08 ближе к нулю, чем −0,8.
Значит, −0,08 больше.
Ответ: −0,08 > −0,8.

Задание 11. Выберите наибольшее число: −4, 0, −1, 3, −7.

Показать решение
Положительное число больше нуля и отрицательных чисел.
Среди данных чисел положительное только 3.
Ответ: 3.

Задание 12. Выберите наименьшее число: −0,3; −2; 1; 0; −1,5.

Показать решение
Наименьшее число будет самым левым на координатной прямой.
Среди отрицательных чисел меньше то, у которого модуль больше.
Самый большой модуль у числа −2.
Ответ: −2.

9. Короткая памятка

На координатной прямой больше то число, которое расположено правее.
Любое положительное число больше любого отрицательного.
Ноль больше любого отрицательного числа и меньше любого положительного.
Два положительных числа сравниваем обычным способом.
Из двух отрицательных чисел меньше то, у которого модуль больше.
При расположении по возрастанию идём слева направо.
