Комбинаторное правило умножения

Научимся считать количество возможных вариантов без полного перебора: разбирать выбор на последовательные шаги, определять число возможностей на каждом шаге и перемножать эти числа.

Как считать варианты без длинного перебора

Во многих задачах результат составляется из нескольких последовательных выборов. Например, сначала выбирают рубашку, затем брюки; сначала выбирают дорогу до пересадочного пункта, затем дорогу до места назначения; последовательно задают символы кода.

Одежда

3 рубашки и 2 пары брюк

К каждой рубашке подходят обе пары брюк, поэтому получается 3 · 2 = 6 комплектов.

Маршрут

4 пути до B и 3 пути от B до C

Каждый первый участок можно продолжить тремя способами: всего 4 · 3 = 12 маршрутов.

Дерево вариантов: три рубашки и две пары брюк

1. Комбинаторное правило умножения

Пусть некоторый результат получают последовательно в несколько шагов. Если первый шаг можно выполнить n1 способами, после каждого такого выбора второй шаг — n2 способами, затем третий — n3 способами и так далее, то общее число результатов равно произведению чисел способов на всех шагах.

Правило умножения: если выбор состоит из последовательных шагов и для каждого варианта предыдущих шагов число продолжений одинаково, то количество полных вариантов находят умножением.
N = n1 · n2 · … · nk
1. Выделить шаги 2. Посчитать варианты каждого шага 3. Перемножить 4. Проверить ограничения

2. Пример с последовательным выбором

В школьной столовой предлагают 2 супа, 3 вторых блюда и 2 напитка. Сколько различных обедов можно составить, если выбрать по одному блюду каждого вида?

Шаг Что выбираем Количество способов
1 Суп 2
2 Второе блюдо 3
3 Напиток 2
N = 2 · 3 · 2 = 12.

Каждый из двух супов можно соединить с любым из трёх вторых блюд, а каждую полученную пару — с любым из двух напитков. Поэтому получается 12 различных обедов.

3. Таблица и дерево вариантов

Когда шагов немного, варианты можно показать таблицей или деревом. Эти способы помогают увидеть, почему возникает произведение.

Таблица

Подходит для двух выборов. Строки соответствуют вариантам первого выбора, столбцы — вариантам второго. Каждая клетка задаёт один результат.

Дерево

Подходит для последовательности из нескольких шагов. Каждый путь от начала до конечной вершины соответствует одному полному варианту.

При большом количестве вариантов таблица и дерево становятся громоздкими. Правило умножения позволяет сразу получить число результатов, не выписывая каждый из них.

4. Повторения разрешены и запрещены

Перед умножением важно выяснить, меняется ли число вариантов после каждого выбора.

Повторения разрешены

Трёхзначный код из цифр 0–9

На каждой позиции доступно 10 цифр: 10 · 10 · 10 = 1000 кодов. Код может начинаться с нуля.

Повторения запрещены

Три разные буквы из пяти

Для первой позиции есть 5 вариантов, для второй остаётся 4, для третьей — 3: 5 · 4 · 3 = 60.

Главная проверка: на каждом шаге нужно считать только те варианты, которые действительно остаются допустимыми после предыдущих выборов.

5. Когда умножать, а когда складывать

Последовательно: «и»

Используем умножение

Нужно выбрать рубашку и брюки; пройти первый участок и второй; задать первую, вторую и третью позиции кода.

Один из вариантов: «или»

Используем сложение

Можно выбрать один из 4 автобусов или один из 3 поездов. Если варианты не пересекаются, всего 4 + 3 = 7 способов.

Смешанный пример До города можно добраться либо одним из 3 прямых автобусов, либо сначала одним из 2 поездов до станции B, а затем одним из 4 автобусов до города. Число способов: 3 + 2 · 4 = 11.

6. Разобранные задачи

Задача 1. Маршруты Из A в B ведут 5 дорог, а из B в C — 4 дороги. Маршрут обязательно проходит через B. Первый участок выбирают 5 способами, после него второй — 4 способами. Поэтому N = 5 · 4 = 20 маршрутов.
Задача 2. Трёхзначные числа Сколько трёхзначных чисел можно составить из цифр 0, 2, 4, 6, если цифры могут повторяться? Первая цифра не может быть нулём, поэтому для неё есть 3 варианта. Для второй и третьей цифр доступно по 4 варианта. Получаем N = 3 · 4 · 4 = 48.
Задача 3. Выбор представителей Из 6 девятиклассников и 4 восьмиклассников выбирают одного представителя от каждого класса. Представителя 9 класса можно выбрать 6 способами, а представителя 8 класса — 4 способами. Всего 6 · 4 = 24 пары.

Самопроверка

1. В кафе есть 4 вида сэндвичей и 3 вида напитков. Сколько различных наборов «сэндвич и напиток» можно составить?

Показать решение

Сэндвич выбирают 4 способами, напиток — 3 способами.

N = 4 · 3 = 12.

2. Из посёлка A в B ведут 3 дороги, из B в C — 2 дороги, а из C в D — 4 дороги. Сколько маршрутов из A в D проходит через B и C?

Показать решение

Маршрут состоит из трёх последовательных участков.

N = 3 · 2 · 4 = 24.

3. Сколько четырёхзначных кодов можно составить из цифр 0–9, если цифры могут повторяться?

Показать решение

Код, в отличие от четырёхзначного числа, может начинаться с нуля. На каждой из четырёх позиций есть 10 вариантов.

N = 10 · 10 · 10 · 10 = 10 000.

4. Сколько трёхзначных чисел можно составить из цифр 1, 2, 3, 4, 5 без повторений?

Показать решение

Для первой цифры есть 5 вариантов, для второй остаётся 4, для третьей — 3.

N = 5 · 4 · 3 = 60.

5. В школьной форме разрешены 3 цвета рубашек, 2 цвета жилетов и 2 вида галстуков. Сколько различных комплектов можно составить?

Показать решение

Выбор состоит из трёх последовательных шагов.

N = 3 · 2 · 2 = 12.

6. В меню есть 2 супа, 4 горячих блюда и 3 десерта. Ученик выбирает либо только один суп, либо одно горячее блюдо и один десерт. Сколько вариантов заказа?

Показать решение

Только суп можно выбрать 2 способами.

Пару «горячее блюдо и десерт» можно выбрать 4 · 3 = 12 способами.

Эти два случая не пересекаются, поэтому 2 + 12 = 14.

7. Сколько трёхзначных чётных чисел можно составить из цифр 0, 1, 2, 3, 4 без повторений?

Показать решение

Разделим варианты на случаи по последней цифре.

Если последняя цифра равна 0, первую цифру выбираем 4 способами, вторую — 3 способами: 4 · 3 = 12.

Если последняя цифра равна 2 или 4, её выбираем 2 способами. Первую цифру можно выбрать из трёх оставшихся ненулевых цифр, а вторую — из трёх оставшихся цифр: 2 · 3 · 3 = 18.

Всего: 12 + 18 = 30.

8. Пароль состоит из двух разных букв из набора А, Б, В, Г и одной цифры от 0 до 9. Буквы записываются первыми. Сколько паролей можно составить?

Показать решение

Первую букву выбирают 4 способами, вторую — 3 способами, цифру — 10 способами.

N = 4 · 3 · 10 = 120.

Итог

Разбей выбор на шаги Определи, какие решения принимаются последовательно и что считается полным результатом.
Посчитай продолжения На каждом шаге учитывай ограничения, запрет повторений и невозможность нуля в начале числа.
Перемножь числа способов Если нужно выполнить первый шаг и второй, применяется правило умножения; для непересекающихся случаев «или» результаты складывают.
