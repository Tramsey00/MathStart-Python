Случайная величина и распределение вероятностей

Научимся описывать числовой результат случайного опыта, находить возможные значения случайной величины, составлять таблицу распределения и вычислять вероятности событий по ней.

От исхода опыта — к числу

Результат случайного опыта не всегда удобно описывать словами. Часто каждому исходу ставят в соответствие число. Например, при двух бросках монеты можно подсчитать число выпавших орлов.

Случайный опыт

Два броска монеты

Элементарные исходы: ОО, ОР, РО, РР, где О — орёл, Р — решка.

Числовой результат

Число орлов

Величина X принимает значения 0, 1 или 2 в зависимости от результата опыта.

Случайная величина — числовая величина, значение которой определяется результатом случайного опыта. До проведения опыта её точное значение неизвестно.

1. Возможные значения случайной величины

Все числа, которые случайная величина может принять, называют её возможными значениями.

Случайная величина X Возможные значения
Число орлов при двух бросках монеты 0, 1, 2
Число шестёрок при трёх бросках кубика 0, 1, 2, 3
Число исправных деталей среди четырёх проверенных 0, 1, 2, 3, 4
Число очков при одном броске кубика 1, 2, 3, 4, 5, 6
Случайная величина — это не одно событие. Она объединяет несколько событий вида X = xi, каждое из которых имеет свою вероятность.

2. Распределение вероятностей

Чтобы полностью описать дискретную случайную величину, указывают все её возможные значения и вероятность каждого значения.

P(X = x1) = p1, P(X = x2) = p2, …, P(X = xn) = pn
p1 + p2 + … + pn = 1
Таблица, в которой каждому возможному значению случайной величины сопоставлена его вероятность, называется распределением вероятностей.

3. Распределение числа орлов

Рассмотрим два броска симметричной монеты. Все четыре исхода ОО, ОР, РО, РР равновозможны.

Значение X Благоприятные исходы Вероятность
0 РР 1 4
1 ОР, РО 2 4 = 1 2
2 ОО 1 4
1 4 + 1 2 + 1 4 = 1

Распределение случайной величины X — числа орлов

4. Как находить вероятность события по таблице

Если событие включает несколько возможных значений случайной величины, соответствующие вероятности складывают.

Вероятность хотя бы одного орла Событие X ≥ 1 включает значения X = 1 и X = 2:
P(X ≥ 1) = P(X = 1) + P(X = 2) = 1 2 + 1 4 = 3 4
Вероятность не более одного орла Событие X ≤ 1 включает значения X = 0 и X = 1:
P(X ≤ 1) = 1 4 + 1 2 = 3 4

5. Как восстановить неизвестную вероятность

Сумма всех вероятностей распределения равна единице. Это свойство позволяет находить пропущенное значение.

Пример Случайная величина принимает значения −1, 0 и 2 с вероятностями 0,2; 0,5 и a.
0,2 + 0,5 + a = 1
a = 1 − 0,7 = 0,3

Самопроверка

1. Кубик бросают три раза. Случайная величина X равна числу выпавших шестёрок. Какие значения может принимать X?

Показать решение

Шестёрка может не выпасть ни разу, выпасть один, два или три раза.

X = 0, 1, 2, 3.

2. Случайная величина принимает значения −1, 0 и 2 с вероятностями 0,2; 0,5 и a. Найдите a.

Показать решение

0,2 + 0,5 + a = 1.

a = 0,3.

3. Для числа орлов при двух бросках монеты найдите P(X ≥ 1).

Показать решение

P(X ≥ 1) = P(X = 1) + P(X = 2).

P = 1 2 + 1 4 = 3 4 .

4. Составьте распределение числа решек при двух бросках симметричной монеты.

Показать решение

Возможные значения: 0, 1, 2.

Вероятности соответственно: 1 4 , 1 2 , 1 4 .

5. Кубик бросают один раз. X = 1, если выпало чётное число, и X = 0, если выпало нечётное число. Найдите распределение X.

Показать решение

Чётных и нечётных граней по три.

P(X = 0) = 1 2 , P(X = 1) = 1 2 .

6. X принимает значения −2, 0 и 3 с вероятностями 0,15; 0,50 и 0,35. Найдите P(X ≠ 0).

Показать решение

P(X ≠ 0) = P(X = −2) + P(X = 3).

P = 0,15 + 0,35 = 0,50.

7. Может ли набор вероятностей 0,2; 0,3; 0,4 задавать полное распределение случайной величины?

Показать решение

0,2 + 0,3 + 0,4 = 0,9, а сумма должна быть равна 1.

Нет, такое распределение неполно.

8. Две монеты бросают одновременно. X = 1, если результаты на монетах различны, и X = 0, если одинаковы. Найдите распределение X.

Показать решение

Одинаковые результаты: ОО, РР — два исхода из четырёх. Различные: ОР, РО — также два исхода.

P(X = 0) = 0,5, P(X = 1) = 0,5.

Проверка распределения

Перечислены все значения В таблице должны присутствовать все возможные значения случайной величины и не должно быть невозможных значений.
Вероятности допустимы Каждая вероятность находится от 0 до 1, а сумма всех вероятностей распределения равна единице.
Событие переведено на язык X Для условий «не менее», «не более» и «между» сложены вероятности всех подходящих значений.
