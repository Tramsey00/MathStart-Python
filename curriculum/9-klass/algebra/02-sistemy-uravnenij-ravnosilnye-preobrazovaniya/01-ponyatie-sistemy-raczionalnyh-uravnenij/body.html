1. Рациональное уравнение с двумя переменными

Уравнение с переменными x и y называют рациональным уравнением с двумя переменными, если его левая и правая части являются рациональными выражениями относительно x и y.

Целое рациональное уравнение

Переменные не находятся в знаменателях. Например: x² + y = 7 или xy − 2x + y = 0.

Дробно-рациональное уравнение

Переменная входит в знаменатель. Например: 1 x − 2 + y = 3.

Рациональные уравнения:
x² + y² = 25;
y = x + 1 x − 3 ;
xy − 4x + 2y = 7.
В дробно-рациональном уравнении обязательно учитывают область допустимых значений. Например, для дроби x + 1 x − 3 должно выполняться условие x ≠ 3.

2. Что называют системой рациональных уравнений

Несколько рациональных уравнений с одними и теми же переменными, которые должны выполняться одновременно, образуют систему рациональных уравнений.

x² + y = 5,
x + y = 3.
Фигурная скобка означает, что нужно найти такие значения x и y, при которых каждое уравнение системы превращается в верное числовое равенство.

3. Решение системы — упорядоченная пара чисел

Решением системы двух уравнений с переменными x и y называют упорядоченную пару чисел (x₀; y₀), которая обращает каждое уравнение системы в верное равенство.

Сначала записывается значение x, затем — значение y: (x; y). Пары (1; 2) и (2; 1) обычно являются разными решениями.
Пример 1. Проверим пару (2; 1) Рассмотрим систему:
{
x + y = 3,
x² + y = 5.
Подставим x = 2 и y = 1:
2 + 1 = 3 — верно;
2² + 1 = 5 — верно.
Значит, пара (2; 1) является решением системы.
Пример 2. Почему порядок чисел важен Проверим в той же системе пару (1; 2):
1 + 2 = 3 — верно;
1² + 2 = 3, а не 5 — неверно.
Следовательно, пара (1; 2) решением этой системы не является.

4. Как проверить готовую пару

Чтобы установить, является ли пара решением, не нужно решать систему заново. Достаточно выполнить прямую проверку.

  1. Подставьте первое число пары вместо x, а второе число — вместо y.
  2. Проверьте полученное равенство в каждом уравнении системы.
  3. Убедитесь, что не нарушены ограничения: знаменатели не равны нулю, а все выражения определены.
  4. Сделайте вывод. Если верны все уравнения, пара является решением. Если неверно хотя бы одно — не является.
Пример 3. Проверка с дробно-рациональным уравнением Проверим пару (3; 2) для системы:
{
x + 1 x − 1 = y,
x + y = 5.
ОДЗ: x ≠ 1. При x = 3 ограничение выполнено.
3 + 1 3 − 1 = 2 — верно.
3 + 2 = 5 — верно.
Пара (3; 2) является решением.

5. Сколько решений может иметь система

Система двух уравнений может не иметь решений, иметь одно, несколько или бесконечно много решений.

Количество решений Пример системы Объяснение
Нет решений y = x²,
y = −1 		Для действительных x значение x² не может быть отрицательным.
Одно решение y = x²,
y = 0 		Графики имеют единственную общую точку (0; 0).
Несколько решений y = x²,
y = x + 2 		Графики пересекаются в двух точках.
Бесконечно много x + y = 3,
2x + 2y = 6 		Второе уравнение задаёт ту же прямую, что и первое.

6. Графический смысл решения системы

Каждое уравнение с двумя переменными задаёт на координатной плоскости некоторый график. Решения системы — это координаты общих точек графиков.

Графики y = x² и y = x + 2 имеют две общие точки

Парабола y = x² Прямая y = x + 2 Решения системы
Общие точки графиков: (−1; 1) и (2; 4).
Значит, система имеет два решения.
Графический способ помогает увидеть количество решений, но координаты точек не всегда можно точно считать с рисунка. Для точного ответа обычно выполняют алгебраические преобразования.

7. Равносильные системы

Две системы называют равносильными, если они имеют одно и то же множество решений.

Пример 4. Равносильное преобразование Исходная система:
{
x + y = 4,
x − y = 2.
Сложим уравнения: 2x = 6. Получаем систему:
{
x + y = 4,
2x = 6.
Обе системы имеют единственное решение (3; 1), поэтому они равносильны.

Преобразования, которые сохраняют решения

  • перестановка уравнений местами;
  • перенос слагаемых из одной части уравнения в другую;
  • умножение обеих частей уравнения на одно и то же ненулевое число;
  • замена одного уравнения равносильным ему уравнением;
  • замена одного уравнения суммой этого уравнения и другого уравнения, умноженного на число.
Цель преобразований — получить более простую систему, не изменив множество её решений.

8. Неравносильные преобразования и посторонние корни

Некоторые действия могут изменить множество решений: добавить посторонние пары или, наоборот, потерять допустимые решения.

Возведение в квадрат

Из равенства x = 1 следует x² = 1, но уравнение x² = 1 имеет ещё корень x = −1.

Умножение на выражение с переменной

Если выражение может быть равно нулю, после умножения могут появиться новые решения.

Сокращение без ОДЗ

Сокращённый множитель исчезает из записи, но его нуль может оставаться запрещённым.

Деление на неизвестное выражение

Деление на выражение, которое может быть равно нулю, способно привести к потере решений.

Пример 5. Ограничение сохраняется после сокращения Рассмотрим уравнение:
x − 2 x − 2 = 1.
После сокращения получается верное равенство 1 = 1, но исходное выражение определено только при x ≠ 2.
Решение: все действительные числа, кроме 2.
После преобразований, которые могут быть неравносильными, найденные пары обязательно проверяют в исходной системе.

9. Уравнение окружности

Важный пример рационального уравнения с двумя переменными — уравнение окружности.

Окружность с центром C(a; b) и радиусом r задаётся уравнением: (x − a)² + (y − b)² = r².
Пример 6. Читаем уравнение окружности
(x − 2)² + (y + 1)² = 9.
Сравниваем с формулой:
a = 2, b = −1, r² = 9, поэтому r = 3.
Центр окружности: C(2; −1), радиус: 3.

Окружность (x − 2)² + (y + 1)² = 9

Пример 7. Проверим точку окружности Подставим точку P(5; −1):
(5 − 2)² + (−1 + 1)² = 3² + 0² = 9.
Равенство верно, поэтому точка P лежит на окружности.

10. Типичные ошибки

Проверяют только одно уравнение

Пара является решением системы только тогда, когда выполняются все её уравнения.

Меняют координаты местами

В паре (x; y) первое число относится к x, а второе — к y.

Забывают об ОДЗ

Пара не может быть решением, если при подстановке знаменатель становится равным нулю.

Не проверяют посторонние корни

После возведения в квадрат или сокращения найденные пары нужно подставить в исходную систему.

11. Самопроверка

В заданиях важно не только выполнить вычисления, но и правильно работать с упорядоченными парами и ограничениями.

1. Является ли пара (2; 1) решением системы x + y = 3, x² + y = 5?

Показать решение

2 + 1 = 3 — верно.

2² + 1 = 5 — верно.

Ответ: да, является.

2. Проверьте пару (−1; 2) для системы x² + y = 3, xy = −2.

Показать решение

(−1)² + 2 = 1 + 2 = 3.

(−1) · 2 = −2.

Ответ: пара является решением.

3. Какая из пар (1; 2) и (2; 1) является решением системы x − y = −1, x + y = 3?

Показать решение

Для (1; 2): 1 − 2 = −1 и 1 + 2 = 3. Оба равенства верны.

Для (2; 1): 2 − 1 = 1, а не −1.

Ответ: только пара (1; 2).

4. Найдите y, если пара (2; y) является решением системы x + y = 5, xy = 6.

Показать решение

Из первого уравнения: 2 + y = 5, поэтому y = 3.

Проверка: 2 · 3 = 6.

Ответ: y = 3.

5. Сколько решений имеет система y = x², y = −1?

Показать решение

Для действительного x всегда x² ≥ 0, поэтому равенство x² = −1 невозможно.

Ответ: решений нет.

6. Найдите точки пересечения графиков y = x² и y = x + 2.

Показать решение

Приравниваем выражения: x² = x + 2.

x² − x − 2 = 0;
(x − 2)(x + 1) = 0.

x = 2 или x = −1.

При x = 2 получаем y = 4.
При x = −1 получаем y = 1.

Ответ: (−1; 1) и (2; 4).

7. Равносильны ли системы x + y = 4, x − y = 2 и x + y = 4, 2x = 6?

Показать решение

Второе уравнение новой системы получается сложением двух уравнений исходной системы.

Обе системы имеют решение (3; 1).

Ответ: да, системы равносильны.

8. Укажите множество решений уравнения x − 3 x − 3 = 1.

Показать решение

Исходная дробь определена только при x ≠ 3.

При любом другом x дробь равна 1.

Ответ: x ∈ (−∞; 3) ∪ (3; +∞).

12. Финальная сверка: паспорт системы

Перед переходом к методам решения проверьте, что основные понятия темы собраны в единую картину.

Ключевое условие Пара (x₀; y₀) является решением системы тогда и только тогда, когда она удовлетворяет каждому уравнению системы.
1
Решение записывается упорядоченной парой: сначала x, затем y.
2
На графике решения системы являются общими точками графиков её уравнений.
3
Равносильные системы имеют одинаковое множество решений.
4
ОДЗ и проверка защищают от запрещённых значений и посторонних корней.
