Методы решения систем рациональных уравнений

Научимся выбирать подходящий способ решения системы: выражать переменную и подставлять, складывать уравнения, вводить новые переменные и находить решения по графикам.

1. Почему для систем нужны разные методы

Одну и ту же систему иногда можно решить несколькими способами, но эти способы будут различаться по длине и сложности вычислений. Поэтому перед началом решения полезно изучить форму уравнений.

Метод 1

Подстановка

Удобна, если одна переменная уже выражена через другую или её легко выразить.

Метод 2

Алгебраическое сложение

Применяется, если после сложения или вычитания уравнений одна из переменных исчезает.

Метод 3

Новые переменные

Полезны, когда в системе несколько раз повторяются одинаковые сложные выражения.

Метод 4

Графический способ

Решения системы находят как координаты точек пересечения графиков её уравнений.

Лучший метод — не самый необычный, а тот, который быстрее сводит систему к одному уравнению с одной переменной.

2. Метод подстановки

При подстановке одну переменную выражают через другую, а затем полученное выражение подставляют во второе уравнение.

  1. Выразите одну переменную из наиболее простого уравнения.
  2. Подставьте полученное выражение вместо этой переменной в другое уравнение.
  3. Решите уравнение с одной переменной.
  4. Для каждого найденного значения вычислите вторую переменную.
  5. Запишите решения упорядоченными парами и выполните проверку.
Пример 1. Переменная уже выражена Решим систему:
{
y = x + 1,
xy = 6.
Подставим y = x + 1 во второе уравнение:
x(x + 1) = 6;
x² + x − 6 = 0;
(x − 2)(x + 3) = 0.
Получаем:
x₁ = 2, тогда y₁ = 2 + 1 = 3;
x₂ = −3, тогда y₂ = −3 + 1 = −2.
Ответ: (2; 3), (−3; −2).
Если после подстановки получилось квадратное уравнение, нужно рассмотреть все его действительные корни. Каждому допустимому значению x соответствует своя пара (x; y).

3. Метод алгебраического сложения

При этом способе уравнения складывают или вычитают так, чтобы одна из переменных или одно повторяющееся выражение исчезло.

  1. Расположите одинаковые выражения друг под другом.
  2. При необходимости умножьте одно или оба уравнения на подходящие ненулевые числа.
  3. Сложите или вычтите уравнения.
  4. Решите полученное уравнение с одной переменной.
  5. Подставьте найденные значения в любое исходное уравнение.
Пример 2. При сложении исчезает y
{
x² + y = 7,
x² − y = 1.
Сложим левые и правые части уравнений:
x² + y + x² − y = 7 + 1;
2x² = 8;
x² = 4;
x = 2 или x = −2.
Найдём y из первого уравнения:
При x = 2: y = 7 − 4 = 3.
При x = −2: y = 7 − 4 = 3.
Ответ: (2; 3), (−2; 3).
Из равенства x² = 4 следуют два значения: x = 2 и x = −2. Потеря знака «±» приводит к потере решения.

4. Разложение на множители внутри системы

Иногда перед сложением или подстановкой полезно применить формулу сокращённого умножения.

Пример 3. Используем разность квадратов
{
x + y = 7,
x² − y² = 21.
Разложим разность квадратов:
x² − y² = (x − y)(x + y).
Поскольку x + y = 7, получаем:
7(x − y) = 21;
x − y = 3.
Теперь решаем линейную систему:
{
x + y = 7,
x − y = 3.
Складываем уравнения:
2x = 10, поэтому x = 5.
y = 7 − 5 = 2.
Ответ: (5; 2).

5. Симметрические системы

Система называется симметрической, если при перестановке x и y её уравнения не изменяются. В таких системах часто используют сумму x + y и произведение xy.

Если известны s = x + y и p = xy, то числа x и y являются корнями уравнения t² − st + p = 0.
Пример 4. Находим сумму и произведение
{
x + y = 5,
x² + y² = 13.
Используем формулу:
(x + y)² = x² + 2xy + y².
Подставляем известные значения:
5² = 13 + 2xy;
25 = 13 + 2xy;
xy = 6.
Значит, x и y — корни уравнения:
t² − 5t + 6 = 0;
(t − 2)(t − 3) = 0.
Числа равны 2 и 3. Поскольку порядок координат важен, получаем две пары.
Ответ: (2; 3), (3; 2).

6. Метод введения новых переменных

Если одинаковые выражения многократно повторяются, их временно заменяют новыми переменными. После решения упрощённой системы возвращаются к исходным x и y.

Пример 5. Повторяются выражения x + y и xy
{
x + y + xy = 5,
(x + y)xy = 6.
Введём обозначения:
u = x + y, v = xy.
Получаем систему:
{
u + v = 5,
uv = 6.
Числа u и v имеют сумму 5 и произведение 6:
(u; v) = (2; 3) или (3; 2).
Рассмотрим оба случая.
1) x + y = 2, xy = 3.
Уравнение t² − 2t + 3 = 0 имеет D = −8. Действительных решений нет.
2) x + y = 3, xy = 2.
t² − 3t + 2 = 0; t = 1 или t = 2.
Ответ: (1; 2), (2; 1).
Новые переменные — временные обозначения. После нахождения u и v решение ещё не закончено: нужно обязательно вернуться к переменным x и y.

7. Графический метод

Каждое уравнение системы преобразуют к виду y = f(x), строят оба графика и находят координаты их общих точек.

  1. Выразите y через x в каждом уравнении, если это возможно.
  2. Постройте графики полученных функций в одной системе координат.
  3. Найдите точки пересечения графиков.
  4. Запишите координаты точек как решения системы.
Пример 6. Парабола и прямая
{
y = x² − 1,
y = x + 1.
Общие точки графиков имеют одинаковые ординаты, поэтому приравняем правые части:
x² − 1 = x + 1;
x² − x − 2 = 0;
(x − 2)(x + 1) = 0.
При x = −1 получаем y = 0.
При x = 2 получаем y = 3.

Точки пересечения графиков y = x² − 1 и y = x + 1

y = x² − 1 y = x + 1 Решения системы
Ответ: (−1; 0), (2; 3).
По рисунку не всегда можно определить координаты точно. Графический способ особенно удобен для оценки количества решений, а точные значения часто находят алгебраически.

8. Дробно-рациональные системы

В системах с дробями сначала записывают ОДЗ, затем избавляются от знаменателей допустимыми преобразованиями.

Пример 7. Используем сумму и произведение
{
1 x + 1 y = 5 6 ,
x + y = 5.
ОДЗ:
x ≠ 0, y ≠ 0.
Приведём дроби к общему знаменателю:
x + y xy = 5 6.
Поскольку x + y = 5:
5 xy = 5 6;
xy = 6.
Числа x и y имеют сумму 5 и произведение 6, поэтому равны 2 и 3.
Ответ: (2; 3), (3; 2).

10. Типичные ошибки

Потерян второй корень

Из x² = a при a > 0 следуют два значения: x = √a и x = −√a.

Получены числа, но не пары

Ответ системы записывают в виде упорядоченных пар (x; y), а не отдельным списком значений.

Не выполнен возврат к замене

Найденные u и v ещё не являются значениями x и y. Нужно решить обратную систему.

Не учтено ОДЗ

После избавления от знаменателей запрещённые значения не исчезают и не могут входить в ответ.

11. Самопроверка

Сначала определите удобный метод, затем решите систему и запишите ответ упорядоченными парами.

1. Решите систему: { y = x − 1, xy = 6.

Показать решение

Подставим y = x − 1:

x(x − 1) = 6;
x² − x − 6 = 0;
(x − 3)(x + 2) = 0.

x = 3, y = 2;
x = −2, y = −3.

Ответ: (3; 2), (−2; −3).

2. Решите систему: { x² + y = 10, x² − y = 8.

Показать решение

Складываем уравнения: 2x² = 18, поэтому x² = 9.

x = 3 или x = −3.

Из первого уравнения: y = 10 − 9 = 1.

Ответ: (3; 1), (−3; 1).

3. Решите систему: { x + y = 7, x² − y² = 21.

Показать решение

x² − y² = (x − y)(x + y).

7(x − y) = 21, поэтому x − y = 3.

Решаем систему x + y = 7, x − y = 3.

x = 5, y = 2.

Ответ: (5; 2).

4. Решите систему: { x + y = 6, xy = 8.

Показать решение

Числа x и y являются корнями уравнения:

t² − 6t + 8 = 0;
(t − 2)(t − 4) = 0.

Числа равны 2 и 4.

Ответ: (2; 4), (4; 2).

5. Решите систему: { 1 x + 1 y = 5 6 , x + y = 5.

Показать решение

ОДЗ: x ≠ 0, y ≠ 0.

(x + y) / xy = 5 / 6.

Поскольку x + y = 5, получаем xy = 6.

Числа с суммой 5 и произведением 6 равны 2 и 3.

Ответ: (2; 3), (3; 2).

6. Найдите точки пересечения графиков: { y = x², y = 2x.

Показать решение

Приравниваем: x² = 2x.

x² − 2x = 0;
x(x − 2) = 0.

x = 0 или x = 2.

При x = 0: y = 0.
При x = 2: y = 4.

Ответ: (0; 0), (2; 4).

7. Решите систему: { x + y = 3, x² + y² = 1.

Показать решение

(x + y)² = x² + 2xy + y².

9 = 1 + 2xy, поэтому xy = 4.

x и y должны быть корнями уравнения:

t² − 3t + 4 = 0.

D = 9 − 16 = −7 < 0.

Ответ: действительных решений нет.

8. Решите систему: { x + y + xy = 5, (x + y)xy = 6.

Показать решение

Пусть u = x + y, v = xy.

Получаем u + v = 5, uv = 6.

Возможны пары (u; v) = (2; 3) и (3; 2).

При x + y = 2, xy = 3 действительных решений нет.

При x + y = 3, xy = 2 числа x и y равны 1 и 2.

Ответ: (1; 2), (2; 1).

12. Экспресс-диагностика метода

Перед вычислениями пройдите четыре строки сверху вниз. Первая подходящая строка обычно подсказывает самый короткий путь.

Переменная уже выражена?
Подставьте готовое выражение в другое уравнение и получите уравнение с одной переменной.
Подстановка
Слагаемые можно уничтожить?
Сложите или вычтите уравнения, при необходимости предварительно умножив их на числа.
Сложение
Повторяются сложные выражения?
Обозначьте их новыми буквами, решите упрощённую систему и вернитесь к x и y.
Новая переменная
Графики легко построить?
Изобразите обе зависимости и найдите координаты всех общих точек.
Графический метод
Независимо от выбранного способа финальные действия одинаковы: учесть ОДЗ, составить упорядоченные пары и проверить их в исходной системе.
