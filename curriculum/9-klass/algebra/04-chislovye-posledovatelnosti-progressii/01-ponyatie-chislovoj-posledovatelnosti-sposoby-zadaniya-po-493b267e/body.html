1. Что называют числовой последовательностью

Числовая последовательность — это набор чисел, расположенных в определённом порядке. Каждому натуральному номеру n соответствует одно число — член последовательности с этим номером.

Последовательность можно рассматривать как функцию натурального аргумента: n → an, где n=1,2,3,…
a1=1→ a2=4→ a3=9→ a4=16→ …
Порядок членов имеет значение. Наборы 1, 4, 9, 16, … и 4, 1, 9, 16, … содержат похожие числа, но задают разные последовательности.

2. Номер и значение члена последовательности

В записи an буква a обозначает последовательность, а нижний индекс n — номер выбранного члена.

ЗаписьКак читаетсяЧто означает
a1«а первое»Первый член последовательности
a7«а седьмое»Член последовательности с номером 7
an«а энное»Общий, или n-й, член последовательности
(an)«последовательность а эн»Вся последовательность целиком
Пример 1. Читаем последовательностьДана последовательность 3, 6, 9, 12, 15, … Здесь a1=3, a2=6, a5=15. Число 5 в записи a5 — это номер, а число 15 — значение члена.

3. Конечные и бесконечные последовательности

Конечная последовательность

Имеет последний член. Например, температуры воздуха за семь дней: t1, t2, …, t7.

Бесконечная последовательность

Не имеет последнего члена. Например, натуральные числа 1, 2, 3, 4, …

Многоточие в конце записи обычно показывает, что последовательность продолжается. Но правило продолжения должно быть понятно из условия, формулы или предыдущих членов.

4. Основные способы задания последовательности

Задать последовательность — значит указать правило, позволяющее определить её члены и их порядок.

1
Перечислением или таблицейЗаписывают несколько или все члены: 2, 4, 6, 8, … либо помещают номера и значения в таблицу.
2
Словесным правиломОписывают, какие числа входят в последовательность: «положительные нечётные числа по возрастанию».
3
Формулой n-го членаЗначение любого члена вычисляют непосредственно по его номеру: an=2n−1.
4
Рекуррентным способомЗадают один или несколько первых членов и правило получения следующего через предыдущие.

5. Задание формулой n-го члена

Формула n-го члена позволяет сразу найти член с любым номером, не вычисляя все предыдущие.

Пример 2. Находим несколько членов по формуле Пусть an=3n−2.
a1=3·1−2=1;
a4=3·4−2=10;
a20=3·20−2=58.
Первые члены: 1, 4, 7, 10, …
Пример 3. Чередование знаков Последовательность задана формулой an=(−1)n+1n.
a1=(−1)²·1=1;
a2=(−1)³·2=−2;
a3=(−1)⁴·3=3.
Последовательность: 1, −2, 3, −4, 5, …
При подстановке отрицательного основания −1 обязательно учитывайте скобки и чётность показателя.

6. Рекуррентный способ

Рекуррентная формула показывает, как получить новый член последовательности через один или несколько предыдущих членов.

Чтобы рекуррентное правило определяло последовательность однозначно, вместе с ним указывают начальный член или несколько первых членов.
Пример 4. Каждый следующий член на 3 больше
a1=2;
an=an−1+3, n≥2.
a2=2+3=5;
a3=5+3=8;
a4=8+3=11.
Последовательность: 2, 5, 8, 11, …
Пример 5. Последовательность Фибоначчи
a1=1, a2=1;
an=an−1+an−2, n≥3.
Каждый новый член равен сумме двух предыдущих: 1, 1, 2, 3, 5, 8, 13, …

7. Как восстановить формулу по первым членам

По нескольким первым членам иногда можно заметить закономерность и предложить формулу. Однако один короткий список сам по себе не всегда определяет правило единственным образом.

Пример 6. Постоянная разностьПоследовательность 4, 7, 10, 13, … увеличивается на 3. Первый член можно записать как 3·1+1, второй — как 3·2+1. Поэтому подходит формула an=3n+1.
Пример 7. Дроби с растущим знаменателемДля последовательности 1/2, 1/3, 1/4, 1/5, … номер n на единицу меньше знаменателя. Поэтому an=1/(n+1).
Пример 8. Квадраты натуральных чиселПоследовательность 1, 4, 9, 16, 25, … состоит из квадратов номеров: an=n².

8. Графическое изображение последовательности

Последовательность можно изображать точками (n;an) на координатной плоскости. По горизонтали откладывают номер n, по вертикали — значение члена.

Первые шесть членов последовательности an=2n−1

Точки последовательности обычно не соединяют сплошной линией: аргумент n принимает только натуральные значения 1, 2, 3, …

9. Свойства, которые можно заметить по первым членам

Возрастающая

Каждый следующий член больше предыдущего: 2, 5, 8, 11, …

Убывающая

Каждый следующий член меньше предыдущего: 10, 8, 6, 4, …

Постоянная

Все члены равны: 7, 7, 7, 7, …

Знакочередующаяся

Положительные и отрицательные члены чередуются: 1, −2, 3, −4, …

Наблюдение по первым членам помогает предположить правило, но окончательный вывод делают по формуле или точному условию задания последовательности.

10. Типичные ошибки

Путают номер и значение

В записи a6=17 число 6 — номер члена, а 17 — его значение.

Начинают нумерацию с нуля

В школьных задачах, если не сказано иное, первый член имеет номер n=1.

Используют рекуррентную формулу без начала

Правило an=an−1+2 не задаёт конкретную последовательность без значения a1.

Соединяют точки графика

Между соседними натуральными номерами у последовательности нет промежуточных аргументов.

11. Самопроверка

Определяйте номера и значения членов, вычисляйте их по формуле и восстанавливайте правило по первым элементам.

1. Дана последовательность 5, 9, 13, 17, 21, … Найдите a2 и a5.

Показать решение

Второй член равен 9, пятый — 21.

Ответ: a2=9, a5=21.

2. Последовательность задана формулой an=4n−3. Найдите a1, a6 и a25.

Показать решение

a1=4·1−3=1.

a6=4·6−3=21.

a25=4·25−3=97.

Ответ: 1; 21; 97.

3. Выпишите первые четыре члена последовательности an=n²+1.

Показать решение

a1=2, a2=5, a3=10, a4=17.

Ответ: 2, 5, 10, 17.

4. Выпишите первые пять членов последовательности an=(−1)n.

Показать решение

При нечётном n значение равно −1, при чётном — 1.

Ответ: −1, 1, −1, 1, −1.

5. Последовательность задана рекуррентно: a1=4, an=an−1−2 при n≥2. Найдите a2, a3, a4.

Показать решение

a2=4−2=2.

a3=2−2=0.

a4=0−2=−2.

Ответ: 2; 0; −2.

6. Предложите формулу n-го члена последовательности 6, 11, 16, 21, …

Показать решение

Каждый член на 5 больше предыдущего. Числа можно представить как 5·1+1, 5·2+1, 5·3+1, …

Ответ: an=5n+1.

7. Предложите формулу n-го члена последовательности 1/3, 1/4, 1/5, 1/6, …

Показать решение

Знаменатель на 2 больше номера.

Ответ: an=1/(n+2).

8. Последовательность задана: a1=2, a2=3, an=an−1+an−2 при n≥3. Найдите a5.

Показать решение

a3=3+2=5.

a4=5+3=8.

a5=8+5=13.

Ответ: 13.

12. Памятка: как работать с последовательностью

Перед вычислением нового члена быстро определите, как именно задана последовательность и какие данные уже известны.

Главная идеяНомер n выбирает ровно один член an.
1
Найдите, с какого номера начинается последовательность и является ли она конечной.
2
Определите способ задания: список, словесное правило, формула или рекурсия.
3
При формуле подставьте нужный номер; при рекурсии последовательно вычислите предыдущие члены.
4
Не путайте индекс с самим значением и проверяйте первые члены по исходному правилу.
Короткая запись темы: последовательность (an) — функция натурального аргумента n.

В следующей теме рассмотрим арифметическую прогрессию — последовательность, в которой каждый следующий член отличается от предыдущего на одно и то же число.
