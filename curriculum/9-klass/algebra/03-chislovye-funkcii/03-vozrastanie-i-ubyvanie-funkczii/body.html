1. Что означает монотонность функции

Монотонность описывает, как меняются значения функции при движении аргумента слева направо. На одном промежутке функция может возрастать, на другом — убывать.

Возрастающая функция

Если x₁<x₂, то f(x₁)<f(x₂). Большему аргументу соответствует большее значение функции.

Убывающая функция

Если x₁<x₂, то f(x₁)>f(x₂). Большему аргументу соответствует меньшее значение функции.

Возрастание: x₁<x₂ ⇒ f(x₁)<f(x₂).
Убывание: x₁<x₂ ⇒ f(x₁)>f(x₂).
Сравнивать нужно аргументы из одного и того же промежутка монотонности. Например, функция y=1/x убывает отдельно на (−∞;0) и на (0;+∞), но промежуток нельзя проводить через запрещённую точку x=0.

2. Как читать монотонность по графику

Двигайтесь по графику слева направо. Если линия поднимается — функция возрастает; если опускается — убывает. Точки, в которых направление меняется, разделяют промежутки монотонности.

↗График поднимаетсяПри увеличении x значения y становятся больше: функция возрастает.
↘График опускаетсяПри увеличении x значения y становятся меньше: функция убывает.
→График горизонталенЗначение не меняется: функция постоянна на данном промежутке.

Пример графика с тремя промежутками монотонности

По графику: функция возрастает на (−∞;−1] и [2;+∞), убывает на [−1;2].

3. Монотонность линейной функции

Для функции y=kx+b направление движения полностью определяется коэффициентом k.

Коэффициент kПоведение функцииЧто видно на графике
k>0Возрастает на ℝПрямая поднимается слева направо.
k<0Убывает на ℝПрямая опускается слева направо.
k=0Постоянна на ℝГрафик y=b параллелен оси Ox.
Пример 1. Определяем без построенияФункция f(x)=5x−7 возрастает на ℝ, потому что k=5>0.
Функция g(x)=−3x+4 убывает на ℝ, потому что k=−3<0.

4. Монотонность квадратичной функции

График y=ax²+bx+c меняет направление в вершине параболы. Абсцисса вершины равна x₀=−b/(2a).

Направление ветвейДо вершины x₀После вершины x₀
a>0, ветви вверхУбывает на (−∞;x₀]Возрастает на [x₀;+∞)
a<0, ветви внизВозрастает на (−∞;x₀]Убывает на [x₀;+∞)
Пример 2. Парабола с ветвями вверх Для f(x)=(x−2)² вершина имеет абсциссу x₀=2. Поэтому функция убывает на (−∞;2] и возрастает на [2;+∞).
Пример 3. Парабола с ветвями вниз Для g(x)=−(x+1)²+4 вершина имеет абсциссу x₀=−1. Поэтому функция возрастает на (−∞;−1] и убывает на [−1;+∞).

ФункцияВозрастаетУбывает

y=x²[0;+∞)(−∞;0]

Для y=1/x два промежутка записывают раздельно. Нельзя объединять их в одну запись с помощью символа ∪ и называть функцию убывающей на получившемся множестве: монотонность рассматривают на каждом промежутке отдельно.

6. Сравнение значений без вычислений

Зная направление изменения функции, можно сравнивать её значения по аргументам.

Функция возрастает

Порядок сохраняется: если x₁<x₂, то f(x₁)<f(x₂).

Функция убывает

Порядок меняется: если x₁<x₂, то f(x₁)>f(x₂).

Пример 4. Возрастающая функцияФункция y=x³ возрастает на ℝ. Так как 1,7<2, то 1,7³<2³.
Пример 5. Убывающая функцияФункция y=1/x убывает на (0;+∞). Так как 4<7, то 1/4>1/7.
Сначала убедитесь, что оба аргумента находятся в одном промежутке монотонности. Только после этого применяйте правило сравнения.

7. Алгоритм определения промежутков

1. Найдите область определения функции.
2. Постройте или распознайте форму графика.
3. Найдите точки, где график меняет направление, и разрывы области определения.
4. Просмотрите каждый получившийся промежуток слева направо.
5. Запишите отдельно промежутки возрастания и убывания.
Пример 6. Функция с модулемДля y=|x+3|−2 вершина графика находится при x=−3. Слева от вершины функция убывает, справа возрастает.
Ответ: убывает на (−∞;−3], возрастает на [−3;+∞).

8. Самопроверка

Определяйте направление изменения по коэффициенту, вершине графика или известным свойствам основной функции.

1. Определите монотонность функции f(x)=5x−3.

Показать решение

Коэффициент при x равен 5>0.

Ответ: функция возрастает на ℝ.

2. Определите монотонность функции g(x)=−7x+2.

Показать решение

Коэффициент при x равен −7<0.

Ответ: функция убывает на ℝ.

3. Как ведёт себя функция y=4?

Показать решение

При любом x значение функции равно 4.

Ответ: функция постоянна на ℝ.

4. Укажите промежутки монотонности функции y=(x−4)².

Показать решение

Вершина параболы имеет абсциссу 4, ветви направлены вверх.

Убывает на (−∞;4], возрастает на [4;+∞).

5. Укажите промежутки монотонности функции y=−(x+2)²+1.

Показать решение

Вершина имеет абсциссу −2, ветви направлены вниз.

Возрастает на (−∞;−2], убывает на [−2;+∞).

6. Сравните 2,7³ и 3³, не вычисляя значения.

Показать решение

Функция y=x³ возрастает на ℝ.

Так как 2,7<3, то 2,7³<3³.

7. Сравните 1/4 и 1/7 с помощью свойства функции y=1/x.

Показать решение

На (0;+∞) функция y=1/x убывает.

Так как 4<7, порядок значений меняется: 1/4>1/7.

8. Укажите промежутки монотонности функции y=|x+3|−2.

Показать решение

Вершина графика находится при x=−3.

Убывает на (−∞;−3], возрастает на [−3;+∞).
