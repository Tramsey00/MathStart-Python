1. Что означает чётность функции

Чётность и нечётность описывают связь между значениями функции в противоположных точках x и −x. Исследование всегда начинается с области определения.

Чётная функция

Для каждого допустимого x выполняется равенство f(−x)=f(x). Противоположным аргументам соответствуют одинаковые значения.

Нечётная функция

Для каждого допустимого x выполняется равенство f(−x)=−f(x). Значения в противоположных точках также противоположны.

Чётная: f(−x)=f(x).
Нечётная: f(−x)=−f(x).
Ни чётная, ни нечётная: не выполняется ни одно из двух равенств.
Слова «чётная» и «нечётная» относятся к функции, а не к отдельному значению x. Проверка должна выполняться для всех аргументов из области определения.

2. Симметричная область определения

Область определения называется симметричной относительно нуля, если вместе с каждым числом x она содержит и число −x.

Обязательное условие: чётная или нечётная функция должна иметь симметричную область определения.
Область определенияСимметрична?Вывод
ℝДаИсследование можно продолжать.
(−5;5)ДаВместе с x входит −x.
(−∞;−2) ∪ (2;+∞)ДаПромежутки зеркальны относительно нуля.
[0;+∞)НетФункция не может быть ни чётной, ни нечётной.
(−3;4)НетНапример, 3,5 входит, а −3,5 не входит.
Пример 1. Почему функция √x не относится ни к одному видуДля f(x)=√x область определения равна [0;+∞). Она несимметрична относительно нуля, поэтому функция не является ни чётной, ни нечётной.

3. Симметрия графиков

Формулы чётности имеют наглядный геометрический смысл.

Чётная и нечётная функции на координатной плоскости

Чётная функция

График симметричен относительно оси Oy. Если точка (x;y) лежит на графике, то точка (−x;y) тоже лежит на нём.

Нечётная функция

График симметричен относительно начала координат. Вместе с точкой (x;y) график содержит точку (−x;−y).

4. Алгоритм исследования на чётность

  1. Найдите D(f). Проверьте, симметрична ли область определения относительно нуля.
  2. Замените x на −x. Аккуратно запишите выражение f(−x), используя скобки.
  3. Упростите f(−x). Раскройте скобки, приведите подобные слагаемые и сократите дробь, если это допустимо.
  4. Сравните результаты. При f(−x)=f(x) функция чётная; при f(−x)=−f(x) — нечётная.
  5. Сделайте полный вывод. Если ни одно равенство не выполняется, функция ни чётная, ни нечётная.
Нельзя начинать сразу с подстановки −x, пропуская область определения. Несимметричная область определения сразу исключает оба варианта.

5. Чётные функции

Пример 2. Многочлен с чётными степенями Исследуем f(x)=x⁴−3x²+2. Область определения — ℝ, она симметрична.
f(−x)=(−x)⁴−3(−x)²+2;
f(−x)=x⁴−3x²+2=f(x).
Функция чётная.
Пример 3. Дробно-рациональная функция Исследуем f(x)=(x²+1)/(x²−4). Область определения: x≠−2 и x≠2. Она симметрична.
f(−x)=((−x)²+1)/((−x)²−4)=(x²+1)/(x²−4)=f(x).
Функция чётная.
Многочлен, содержащий только чётные степени x и свободный член, является чётной функцией. Но это удобный признак, а не замена общей проверки.

6. Нечётные функции

Пример 4. Многочлен с нечётными степенями Исследуем g(x)=2x³−5x. Область определения — ℝ.
g(−x)=2(−x)³−5(−x);
g(−x)=−2x³+5x=−(2x³−5x)=−g(x).
Функция нечётная.
Пример 5. Обратная пропорциональность Для h(x)=1/x область определения равна (−∞;0)∪(0;+∞), она симметрична.
h(−x)=1/(−x)=−1/x=−h(x).
Функция нечётная.
Многочлен без свободного члена, содержащий только нечётные степени x, является нечётной функцией.

7. Функция ни чётная, ни нечётная

Пример 6. Смешанные степени Исследуем f(x)=x²+x. Область определения — ℝ.
f(−x)=(−x)²+(−x)=x²−x;
f(−x)≠x²+x=f(x);
f(−x)≠−x²−x=−f(x).
Функция ни чётная, ни нечётная.
Пример 7. Горизонтальный сдвиг разрушает симметрию Функция y=(x−2)² не является чётной относительно оси Oy: её график симметричен относительно прямой x=2. Она также не является нечётной.
Наличие собственной оси симметрии ещё не означает чётность. Для чётной функции осью симметрии должна быть именно ось Oy.

9. Типичные ошибки

Не проверили D(f)

При несимметричной области определения функция не может быть чётной или нечётной, даже если формула кажется подходящей.

Потеряли скобки

В выражении f(−x) число −x нужно подставлять вместо каждого x целиком: (−x)², (−x)³ и так далее.

Проверили одно число

Совпадение для одного аргумента ничего не доказывает. Равенство должно выполняться для каждого допустимого x.

Перепутали виды симметрии

Ось Oy соответствует чётной функции, а начало координат — нечётной.

10. Самопроверка

В каждом задании сначала проверьте область определения, затем найдите f(−x).

1. Определите чётность функции f(x)=x⁶−4x²+7.

Показать решение

D(f)=ℝ.

f(−x)=(−x)⁶−4(−x)²+7=x⁶−4x²+7=f(x).

Ответ: функция чётная.

2. Определите чётность функции g(x)=3x⁵−2x³+x.

Показать решение

D(g)=ℝ.

g(−x)=−3x⁵+2x³−x=−g(x).

Ответ: функция нечётная.

3. Исследуйте функцию h(x)=x²+3x−1.

Показать решение

h(−x)=x²−3x−1.

Полученное выражение не равно ни h(x), ни −h(x).

Ответ: функция ни чётная, ни нечётная.

4. Определите чётность функции f(x)=1/x³.

Показать решение

D(f)=ℝ\{0}; область определения симметрична.

f(−x)=1/(−x)³=−1/x³=−f(x).

Ответ: функция нечётная.

5. Может ли функция f(x)=√(x+2) быть чётной или нечётной?

Показать решение

D(f)=[−2;+∞).

Область определения несимметрична относительно нуля.

Ответ: функция ни чётная, ни нечётная.

6. Функция чётная, и f(4)=−7. Найдите f(−4).

Показать решение

Для чётной функции f(−x)=f(x).

Следовательно, f(−4)=f(4)=−7.

Ответ: −7.

7. Функция нечётная, и g(−3)=5. Найдите g(3).

Показать решение

Для нечётной функции g(−3)=−g(3).

5=−g(3), поэтому g(3)=−5.

Ответ: −5.

8. Известно, что график функции симметричен относительно оси Oy и проходит через точку (6;2). Какая ещё точка обязательно принадлежит графику?

Показать решение

Симметрия относительно оси Oy означает чётность.

Точке (x;y) соответствует точка (−x;y).

Ответ: (−6;2).

11. Три вопроса перед вердиктом

Не пытайтесь определять чётность только по внешнему виду формулы. Последовательно ответьте на три вопроса.

1. D(f) симметрична?Если нет, исследование закончено: функция ни чётная, ни нечётная.
2. Чему равно f(−x)?Подставьте −x вместо каждого аргумента и полностью упростите выражение.
3. С чем совпал результат?С f(x) — чётная; с −f(x) — нечётная; ни с чем — третий случай.
Финальный ориентир: чётная функция зеркальна относительно Oy, нечётная — относительно начала координат.
