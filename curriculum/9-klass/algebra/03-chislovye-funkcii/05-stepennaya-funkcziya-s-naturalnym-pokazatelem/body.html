1. Определение степенной функции

Степенной функцией с натуральным показателем называют функцию вида y=xⁿ, где n — натуральное число.

Главная идея: форма и свойства графика зависят прежде всего от того, является показатель n чётным или нечётным.

Чётный показатель

n=2,4,6,… График симметричен относительно оси Oy, а все значения функции неотрицательны.

Нечётный показатель

n=1,3,5,… График симметричен относительно начала координат и принимает значения любого знака.

При любом n: f(0)=0 и f(1)=1.
При чётном n: f(−1)=1.
При нечётном n: f(−1)=−1.

3. Чётный натуральный показатель

Форма графикаОбе ветви расположены выше оси Ox и зеркальны относительно Oy. График проходит через точки (−1;1), (0;0), (1;1).
СвойстваD(f)=ℝ, E(f)=[0;+∞). Функция убывает на (−∞;0] и возрастает на [0;+∞). Наименьшее значение равно 0.
Пример 1. Функция y=x⁶Показатель 6 чётный, поэтому функция чётная. f(−2)=(−2)⁶=64, а f(2)=2⁶=64. Равные значения при противоположных аргументах подтверждают симметрию относительно Oy.

4. Нечётный натуральный показатель

Форма графикаГрафик проходит через начало координат и симметричен относительно точки O. Для отрицательных x значения функции отрицательны, для положительных — положительны.
СвойстваD(f)=ℝ, E(f)=ℝ. Функция возрастает на всей числовой прямой. При n=1 получается прямая y=x.
Пример 2. Функция y=x⁵Показатель 5 нечётный, поэтому f(−x)=−f(x). Например, f(−2)=−32 и f(2)=32.

5. Как показатель n меняет график

Сравнивайте степени отдельно для аргументов внутри и вне промежутка [−1;1].

|x|<1При увеличении n абсолютное значение xⁿ уменьшается и приближается к нулю.
|x|=1При x=1 значение всегда равно 1. При x=−1 знак зависит от чётности n.
|x|>1При увеличении n абсолютное значение xⁿ быстро возрастает.
Пример 3. Сравнение без вычисленийТак как 0<0,8<1, то при увеличении показателя значение степени уменьшается: 0,8⁴>0,8⁸.
Пример 4. Основание больше единицыТак как 1,2>1, то большему показателю соответствует большая степень: 1,2⁵<1,2⁷.

6. Решение простейших уравнений

Чётная степень

Уравнение x²ᵏ=a при a>0 имеет два противоположных корня. При a=0 корень один, а при a<0 действительных корней нет.

Нечётная степень

Уравнение x²ᵏ⁺¹=a имеет ровно один действительный корень при любом действительном a.

Пример 5. Чётная степеньx⁴=16. Числа 2 и −2 при возведении в четвёртую степень дают 16.
Ответ: x=−2; x=2.
Пример 6. Нечётная степеньx⁵=−32. Единственное подходящее число — −2, потому что (−2)⁵=−32.
Ответ: x=−2.

8. Типичные ошибки

Забывают второй корень

Из x⁴=16 следуют два корня: 2 и −2, потому что показатель чётный.

Путают знак отрицательного числа

(−2)⁴=16, но (−2)⁵=−32. Знак определяется чётностью показателя.

Считают все графики одинаковыми

Чётный показатель даёт симметрию относительно Oy, нечётный — относительно начала координат.

Неверно сравнивают степени

Для 0<x<1 увеличение показателя уменьшает значение, а для x>1 — увеличивает.

9. Самопроверка

Определяйте свойства функции по чётности показателя, а вычисления выполняйте с учётом знака основания.

1. Определите чётность функции f(x)=x⁸.

Показать решение

Показатель 8 чётный, поэтому f(−x)=(−x)⁸=x⁸=f(x).

Ответ: функция чётная.

2. Определите чётность функции g(x)=x⁷.

Показать решение

Показатель 7 нечётный, поэтому g(−x)=−x⁷=−g(x).

Ответ: функция нечётная.

3. Найдите область значений функции y=x¹⁰.

Показать решение

Десятая степень любого действительного числа неотрицательна, а значение 0 достигается при x=0.

Ответ: [0;+∞).

4. Укажите промежутки монотонности функции y=x⁶.

Показать решение

Показатель чётный.

Убывает на (−∞;0], возрастает на [0;+∞).

5. Решите уравнение x⁶=64.

Показать решение

2⁶=64 и (−2)⁶=64.

Ответ: x=−2; x=2.

6. Решите уравнение x⁵=−243.

Показать решение

(−3)⁵=−243. Для нечётной степени действительный корень единственный.

Ответ: x=−3.

7. Сравните 0,6³ и 0,6⁷ без вычислений.

Показать решение

Основание находится между 0 и 1, поэтому при увеличении показателя степень уменьшается.

Ответ: 0,6³>0,6⁷.

8. Какие точки обязательно принадлежат графику y=xⁿ при любом натуральном n?

Показать решение

0ⁿ=0 и 1ⁿ=1 при любом натуральном n.

Ответ: (0;0) и (1;1).

10. Переключатель формы графика

Чтобы быстро восстановить свойства степенной функции, достаточно пройти три шага.

1. Посмотрите на nЧётность показателя сразу определяет тип симметрии и знак значений.
→
2. Определите формуЧётный n даёт две зеркальные ветви, нечётный — возрастающую кривую через начало координат.
→
3. Проверьте масштабВнутри промежутка (−1;1) большие степени ближе к нулю, вне его — растут быстрее.
Финальный чек: точки (0;0) и (1;1) сохраняются при любом n, а поведение слева от нуля полностью определяется чётностью показателя.
