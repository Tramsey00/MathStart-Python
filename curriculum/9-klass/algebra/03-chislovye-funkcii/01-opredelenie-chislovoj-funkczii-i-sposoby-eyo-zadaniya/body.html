1. Что называют числовой функцией

Пусть дано некоторое множество чисел X. Если каждому числу x из множества X по определённому правилу ставится в соответствие единственное число y, то такое соответствие называют числовой функцией.

Функция — это правило, по которому каждому допустимому значению аргумента x соответствует ровно одно значение y.
y = f(x)
x — независимая переменная, или аргумент;
y — зависимая переменная, или значение функции;
f — обозначение правила, связывающего x и y.
Одному значению x нельзя сопоставить два разных значения y. При этом разные значения x могут иметь одно и то же значение функции.

2. Как работает соответствие

Рассмотрим функцию y = x² на множестве X = {−2; −1; 0; 1; 2}. Каждое число из X имеет ровно один квадрат.

Функция y = x² как соответствие между двумя множествами

Значения −2 и 2 имеют одинаковый квадрат 4. Это не нарушает определение функции: у каждого отдельного аргумента всё равно только одно значение функции.

3. Основные обозначения

Запись Название Смысл
y = f(x) Функциональная зависимость Значение y определяется выбранным значением x.
x Аргумент Независимая переменная, значение которой выбирают.
f(x) Значение функции Число, полученное после применения правила к x.
D(f) Область определения Все допустимые значения аргумента.
E(f) Область значений Все значения, которые может принимать функция.
Пример 1. Читаем запись функции Пусть f(x) = 3x − 2.
f(4) означает значение функции при x = 4.
f(4) = 3 · 4 − 2 = 10.
При аргументе 4 значение функции равно 10.

4. Как найти значение функции

Чтобы найти f(a), нужно подставить число a вместо каждого x в формуле функции и выполнить вычисления.

  1. Запишите формулу функции.
  2. Вместо каждого x подставьте данное значение аргумента.
  3. Если число отрицательное, заключите его в скобки.
  4. Выполните действия в правильном порядке.
Пример 2. Значение квадратичной функции Найдём f(−2), если:
f(x) = x² − 4x + 3.
Подставим x = −2:
f(−2) = (−2)² − 4 · (−2) + 3;
f(−2) = 4 + 8 + 3 = 15.
Ответ: f(−2) = 15.
Ошибка f(−2) = −2² − 4 · (−2) + 3 возникает, если забыть скобки. Квадрат относится ко всему числу −2: (−2)² = 4.

5. Как найти аргумент по известному значению функции

Если известно значение функции f(x) = b, формулу функции приравнивают к числу b и решают полученное уравнение относительно x.

Пример 3. Находим аргумент Функция задана формулой:
f(x) = 2x + 5.
Найдём x, при котором f(x) = 17.
2x + 5 = 17;
2x = 12;
x = 6.
Ответ: при x = 6 функция принимает значение 17.
Пример 4. Одно значение функции может соответствовать двум аргументам Пусть f(x) = x². Найдём x, если f(x) = 9.
x² = 9;
x = −3 или x = 3.
Значение функции 9 получается при двух аргументах: x = −3 и x = 3.

6. Область определения функции

Область определения D(f) — множество всех значений x, при которых формула функции имеет смысл.

Многочлен Выражения x², 3x − 5, x³ + 2x определены при всех действительных x.
Дробь Знаменатель не должен быть равен нулю.
Квадратный корень Подкоренное выражение должно быть неотрицательным.
Пример 5. Функция с переменной в знаменателе Найдём область определения:
f(x) = x + 1 x − 4 .
Знаменатель не равен нулю:
x − 4 ≠ 0;
x ≠ 4.
D(f) = (−∞; 4) ∪ (4; +∞).
Пример 6. Функция с квадратным корнем Найдём область определения:
f(x) = √(2x − 6).
Подкоренное выражение должно быть неотрицательным:
2x − 6 ≥ 0;
2x ≥ 6;
x ≥ 3.
D(f) = [3; +∞).

7. Область значений функции

Область значений E(f) — множество всех чисел y, которые функция принимает при переборе всех допустимых аргументов.

Пример 7. Область значений функции y = x² Квадрат действительного числа не может быть отрицательным:
x² ≥ 0.
Значение 0 достигается при x = 0, а любое положительное число также может быть квадратом некоторого действительного числа.
E(f) = [0; +∞).
Пример 8. Область значений по таблице
x −2 −1 0 1 2
f(x) 4 1 0 1 4
В нижней строке встречаются значения 0, 1 и 4.
Для данной таблицы E(f) = {0; 1; 4}.

8. Способы задания функции

Задать функцию — значит указать правило, позволяющее по допустимому аргументу определить соответствующее значение функции.

f(x)

Аналитический способ

Функция задаётся формулой. Например: f(x) = 2x − 3.

▦

Табличный способ

Для выбранных аргументов в таблице записывают соответствующие значения функции.

↗

Графический способ

Функция задаётся множеством точек на координатной плоскости.

Aa

Словесный способ

Правило зависимости описывается словами, без обязательной записи формулы.

9. Аналитический и табличный способы

Функция задана формулой

Аналитический способ позволяет вычислить значение функции для любого допустимого аргумента.

Пример 9. Составляем таблицу по формуле Пусть f(x) = 2x + 1. Вычислим значения при x = −2, −1, 0, 1, 2.
x −2 −1 0 1 2
f(x) = 2x + 1 −3 −1 1 3 5

Функция задана таблицей

По таблице можно определить только те значения, которые в ней представлены.

Пример 10. Читаем таблицу
x −3 0 2 5
f(x) 7 1 −3 4
f(2) = −3;
значение 4 функция принимает при x = 5;
D(f) = {−3; 0; 2; 5};
E(f) = {−3; 1; 4; 7}.

10. Графический способ

График функции — множество всех точек координатной плоскости с координатами (x; f(x)).

График функции y = 2x + 1

Чтобы определить значение функции по графику, от выбранного x проводят вертикальную линию до графика, а затем определяют соответствующую координату y.

Как проверить, является ли линия графиком функции

Если любая вертикальная прямая пересекает линию не более чем в одной точке, то линия может быть графиком функции y = f(x).

Окружность целиком не является графиком функции y = f(x): некоторые вертикальные прямые пересекают её в двух точках, поэтому одному x соответствуют два разных значения y.

11. Словесный способ

При словесном способе правило зависимости описывается предложением. Иногда по описанию можно составить формулу.

Пример 11. Периметр квадрата Каждой положительной длине стороны квадрата поставлен в соответствие его периметр.
Если сторона равна x, то периметр равен 4x.
P(x) = 4x, x > 0.
Здесь аргумент — длина стороны, а значение функции — периметр квадрата.
Пример 12. Температура воздуха Каждому моменту времени в течение суток ставится в соответствие температура воздуха.
Аргумент — время наблюдения.
Значение функции — температура в этот момент.
Такая функция может быть представлена таблицей или графиком наблюдений.

12. Типичные ошибки

Одному x назначают два значения y

Такое соответствие не является функцией, потому что нарушено условие единственности.

Путают f(x) и x

x — аргумент, а f(x) — результат применения правила к этому аргументу.

Не учитывают область определения

Нельзя подставлять значение, при котором знаменатель равен нулю или квадратный корень не определён.

Неверно читают таблицу

Значение функции нужно брать из той же колонки, в которой расположен выбранный аргумент.

13. Самопроверка

Выполните задания на вычисление значений функции, определение аргумента, области определения и чтение разных способов задания.

1. Является ли функцией соответствие, при котором каждому действительному числу x ставится в соответствие его квадрат?

Показать решение

Каждое действительное число имеет единственный квадрат.

Ответ: да, является.

2. Найдите f(−2), если f(x) = 2x² − 3x + 1.

Показать решение

f(−2) = 2 · (−2)² − 3 · (−2) + 1.

f(−2) = 2 · 4 + 6 + 1 = 15.

Ответ: 15.

3. При каком значении x функция f(x) = 3x − 5 принимает значение 16?

Показать решение

3x − 5 = 16.

3x = 21.

x = 7.

Ответ: 7.

4. Найдите область определения функции f(x) = 2x − 1 x − 4 .

Показать решение

Знаменатель не должен быть равен нулю.

x − 4 ≠ 0, поэтому x ≠ 4.

Ответ: D(f) = (−∞; 4) ∪ (4; +∞).

5. Найдите область определения функции f(x) = √(2x − 6).

Показать решение

Подкоренное выражение должно быть неотрицательным:

2x − 6 ≥ 0;
x ≥ 3.

Ответ: D(f) = [3; +∞).

6. Функция задана таблицей: x: −3, 0, 2, 5;
f(x): 7, 1, −3, 4. Найдите f(2) и укажите аргумент, при котором значение функции равно 4.

Показать решение

В колонке x = 2 записано значение f(x) = −3.

Значение 4 находится в колонке x = 5.

Ответ: f(2) = −3; x = 5.

7. Может ли окружность x² + y² = 9 быть графиком функции y = f(x)?

Показать решение

Например, при x = 0 получаем y² = 9.

Отсюда y = 3 или y = −3.

Одному аргументу x = 0 соответствуют два значения y.

Ответ: нет, вся окружность не является графиком функции y = f(x).

8. Периметр квадрата зависит от длины его стороны. Запишите функцию, если сторона равна x, и найдите периметр при x = 7 см.

Показать решение

Периметр квадрата равен четырём сторонам:

P(x) = 4x, x > 0.

P(7) = 4 · 7 = 28 см.

Ответ: P(x) = 4x; 28 см.

14. Итоговая карта функции

Любую новую функцию начинайте изучать с трёх главных вопросов.

Главное определение Каждому допустимому значению x соответствует ровно одно значение f(x).
1
Какие значения x допустимы? Ответ на этот вопрос образует область определения D(f).
2
Как по x получить y? Используйте формулу, таблицу, график или словесное правило.
3
Какие значения y получаются? Все возможные результаты образуют область значений E(f).
Короткая запись темы:
аргумент x → правило f → значение y = f(x).
