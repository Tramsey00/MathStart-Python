1. Что называют множеством

Множество — это совокупность объектов, рассматриваемых как единое целое. Объекты, из которых составлено множество, называются его элементами.

Множества обычно обозначают заглавными латинскими буквами A, B, C, а их элементы записывают внутри фигурных скобок.

A = {2; 4; 6; 8} — множество первых четырёх положительных чётных чисел.
∈ принадлежит множеству ∉ не принадлежит множеству ∅ пустое множество
Пример 1. Принадлежность элемента Пусть A = {−3; 0; 2; 7}. Тогда 2 ∈ A, 0 ∈ A, но 5 ∉ A. Запись 2 ∈ A читают: «число 2 принадлежит множеству A».
Один и тот же элемент в множестве записывают только один раз. Порядок элементов значения не имеет: {1; 3; 5} = {5; 1; 3}.

2. Как задать множество

Множество можно задать двумя основными способами.

Перечислением элементов

Подходит для небольшого конечного множества:
A = {1; 4; 9; 16}.

Описанием свойства

Указывают общее свойство всех элементов:
B = {x ∈ ℤ | −2 ≤ x < 3}.

Пример 2. Переход от свойства к перечислению B = {x ∈ ℤ | −2 ≤ x < 3}. Здесь выбирают только целые числа от −2 включительно до 3 не включительно. Поэтому B = {−2; −1; 0; 1; 2}.

3. Подмножество

Множество A называется подмножеством множества B, если каждый элемент A принадлежит B. Это записывают так: A ⊆ B.

Чтобы проверить A ⊆ B, нужно проверить не отдельные элементы, а каждый элемент множества A. Если хотя бы одного элемента A нет в B, включение неверно.
Пример 3. Проверка включения A = {2; 4}, B = {1; 2; 3; 4; 5}. Оба элемента A находятся в B, значит A ⊆ B. Но B ⊆ A неверно, так как, например, 1 ∈ B и 1 ∉ A.

Любое множество является подмножеством самого себя. Пустое множество ∅ является подмножеством любого множества.

4. Пустое и универсальное множества

Пустое множество не содержит ни одного элемента и обозначается символом ∅. Например, множество действительных решений уравнения x² + 1 = 0 пусто.

Универсальное множество содержит все объекты, рассматриваемые в данной задаче. Его часто обозначают буквой U. Например, при работе с целыми числами можно принять U = ℤ.

A ∩ ∅ = ∅
A ∪ ∅ = A
A ∩ U = A
A ∪ U = U

5. Объединение множеств

Объединением множеств A и B называется множество, состоящее из всех элементов, которые принадлежат хотя бы одному из множеств A или B.

A ∪ B читают: «объединение множеств A и B». Ключевое слово — «или». Общие элементы записывают только один раз.
Пример 4. Находим объединение A = {1; 2; 4; 6}, B = {2; 3; 4; 5}.
Собираем все элементы из двух множеств без повторений:
A ∪ B = {1; 2; 3; 4; 5; 6}.

6. Пересечение множеств

Пересечением множеств A и B называется множество, состоящее из элементов, которые одновременно принадлежат и A, и B.

A ∩ B читают: «пересечение множеств A и B». Ключевое слово — «и».
Пример 5. Находим пересечение Для A = {1; 2; 4; 6} и B = {2; 3; 4; 5} общими являются числа 2 и 4.
Поэтому A ∩ B = {2; 4}.
Если общих элементов нет, множества называют непересекающимися, а их пересечение равно ∅.

8. Операции с числовыми промежутками

Числовой промежуток тоже является множеством. Поэтому к промежуткам применяют объединение и пересечение.

Пример 6. Пересечение промежутков A = (−∞; 3], B = (1; 6). Общие числа должны одновременно лежать в обоих промежутках.
A ∩ B = (1; 3].
Пример 7. Объединение промежутков A = (−∞; 3], B = (1; 6). Промежутки перекрываются и вместе покрывают все числа меньше 6.
A ∪ B = (−∞; 6).
Слово в условии Операция Что нужно оставить
«и», «одновременно» Пересечение ∩ Только общую часть множеств
«или», «хотя бы одно» Объединение ∪ Все элементы обоих множеств
«входит в», «содержится в» Включение ⊆ Проверить каждый элемент меньшего множества

9. Множества в системах и совокупностях неравенств

Каждое неравенство задаёт множество решений. Поэтому решение системы — это пересечение, а решение совокупности — объединение множеств решений.

Система: выполняются оба условия

x ≥ −1 и x < 4.
[−1; +∞) ∩ (−∞; 4) = [−1; 4).

Совокупность: достаточно одного условия

x ≤ −2 или x > 3.
(−∞; −2] ∪ (3; +∞).

10. Количество элементов объединения

При сложении количества элементов A и B общие элементы учитываются дважды. Поэтому количество общих элементов нужно один раз вычесть.

|A ∪ B| = |A| + |B| − |A ∩ B|.
Пример 8. Два кружка В классе 30 учеников. Математический кружок посещают 18 учеников, кружок программирования — 15, а оба кружка — 8 учеников.
|A ∪ B| = 18 + 15 − 8 = 25.
Значит, хотя бы один кружок посещают 25 учеников, а ни один — 30 − 25 = 5 учеников.

11. Самопроверка

Сначала выполните задания самостоятельно, затем раскройте решение.

1. Дано A = {−4; −1; 0; 5}. Определите, верны ли записи: −1 ∈ A, 3 ∈ A, 5 ∉ A.

Показать решение

−1 ∈ A — верно.

3 ∈ A — неверно, так как числа 3 в множестве нет.

5 ∉ A — неверно, потому что 5 ∈ A.

2. Перечислите элементы множества B = {x ∈ ℤ | −3 < x ≤ 2}.

Показать решение

Подходящие целые числа: −2, −1, 0, 1, 2.

Ответ: B = {−2; −1; 0; 1; 2}.

3. Дано A = {3; 6; 9}, B = {0; 3; 6; 9; 12}. Верно ли A ⊆ B?

Показать решение

Каждый элемент A — числа 3, 6 и 9 — принадлежит B.

Ответ: да, A ⊆ B.

4. A = {1; 2; 5; 7}, B = {2; 4; 5; 8}. Найдите A ∪ B и A ∩ B.

Показать решение

В объединение входят все элементы без повторений:

A ∪ B = {1; 2; 4; 5; 7; 8}.

Общие элементы — 2 и 5:

A ∩ B = {2; 5}.

5. Найдите пересечение промежутков [−4; 2) и (−1; 5].

Показать решение

Общая часть начинается после −1 и заканчивается перед 2.

Обе границы исключены.

Ответ: (−1; 2).

6. Найдите объединение промежутков (−∞; 1] и (−2; 4).

Показать решение

Промежутки пересекаются. Вместе они покрывают все числа, меньшие 4.

Ответ: (−∞; 4).

7. Найдите множество чисел, для которых одновременно выполняются x > −3 и x ≤ 5.

Показать решение

Нужно пересечь промежутки (−3; +∞) и (−∞; 5].

Ответ: (−3; 5].

8. В группе 28 человек. Английский изучают 17 человек, немецкий — 13, оба языка — 6. Сколько человек изучают хотя бы один из этих языков?

Показать решение

|A ∪ B| = |A| + |B| − |A ∩ B|.

|A ∪ B| = 17 + 13 − 6 = 24.

Ответ: 24 человека.

12. Финишная схема: прочитайте запись без ошибок

В этой теме важнее всего не заучить символы отдельно, а связать каждый знак с точным смыслом.

Определите элементы множеств
→
Выберите слово «и», «или» или «входит»
→
Запишите ∩, ∪ или ⊆
x ∈ A Элемент x принадлежит множеству A.
A ⊆ B Каждый элемент A принадлежит B.
A ∩ B Оставляем только элементы, которые входят одновременно в A и B.
A ∪ B Собираем элементы, входящие хотя бы в одно из множеств A или B.

Система условий означает пересечение, совокупность условий — объединение.
