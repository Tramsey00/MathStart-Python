Как определить вид неравенства

Сначала упростите обе части: раскройте скобки, приведите подобные слагаемые и перенесите выражения. Только после этого можно надёжно определить, линейное перед вами неравенство или квадратное.

Линейное неравенство

После преобразований имеет вид ax + b > 0, ax + b < 0, ax + b ≥ 0 или ax + b ≤ 0, где a ≠ 0.

Квадратное неравенство

После преобразований содержит x² и имеет вид ax² + bx + c ⊙ 0, где a ≠ 0, а ⊙ — один из знаков неравенства.

Числовое неравенство

Иногда переменная сокращается. Тогда остаётся верное или неверное числовое утверждение, от которого зависит ответ.

Сложная запись

Скобки, дроби и произведения не определяют тип сами по себе: сначала выражение нужно преобразовать.

Главный ориентир — наибольшая степень переменной после упрощения: первая степень указывает на линейное неравенство, вторая — на квадратное.

1. Линейные неравенства

Решение линейного неравенства похоже на решение линейного уравнения. Отличие появляется при умножении или делении обеих частей на отрицательное число.

Если обе части неравенства умножить или разделить на отрицательное число, знак неравенства меняется на противоположный:

> меняется на <,   < меняется на >,   ≥ меняется на ≤,   ≤ меняется на ≥.
Шаг Действие
1 Раскрыть скобки и избавиться от дробей, если это удобно.
2 Перенести слагаемые с x в одну часть, числа — в другую.
3 Привести подобные слагаемые и получить неравенство ax ⊙ b.
4 Разделить обе части на a; если a < 0, изменить знак неравенства.
5 Записать ответ неравенством или числовым промежутком.

Пример 1. Положительный коэффициент при x

Условие Решить неравенство 3x − 7 > 5.
Решение.
3x − 7 > 5,
3x > 12,
x > 4.
Ответ: x ∈ (4; +∞).

Пример 2. Деление на отрицательное число

Условие Решить неравенство 5 − 2x ≥ 11.
Решение.
−2x ≥ 6.
Делим обе части на −2 и меняем знак ≥ на ≤:
x ≤ −3.
Ответ: x ∈ (−∞; −3].

Пример 3. Скобки в обеих частях

Условие Решить неравенство 2(3x − 1) − 5 ≤ 4x + 7.
Решение.
6x − 2 − 5 ≤ 4x + 7,
6x − 7 ≤ 4x + 7,
2x ≤ 14,
x ≤ 7.
Ответ: x ∈ (−∞; 7].

2. Как записать ответ линейного неравенства

Строгая и нестрогая границы на числовой прямой

Знаки > и <

Граничное число не входит в решение. На прямой ставят пустую точку, а в записи промежутка используют круглую скобку.

Знаки ≥ и ≤

Граничное число входит в решение. На прямой ставят закрашенную точку, а возле конечной границы используют квадратную скобку.

3. Квадратные неравенства

В квадратном неравенстве недостаточно просто найти корни. Нужно определить, на каких промежутках квадратный трёхчлен имеет требуемый знак.

Шаг Действие
1 Перенести все слагаемые в одну часть и получить ax² + bx + c ⊙ 0.
2 Найти корни трёхчлена или установить, что действительных корней нет.
3 Определить направление ветвей по знаку коэффициента a.
4 Расставить знаки на промежутках и выбрать подходящие.
5 Учесть, включаются ли корни при данном знаке неравенства.

Пример 4. Положительный старший коэффициент

Условие Решить неравенство x² − x − 6 ≥ 0.
Решение.
x² − x − 6 = (x − 3)(x + 2).
Корни: x₁ = −2 и x₂ = 3.
Так как a = 1 > 0, выражение неотрицательно снаружи корней.
Корни включаются, потому что знак неравенства ≥.
Ответ: x ∈ (−∞; −2] ∪ [3; +∞).

Пример 5. Отрицательный старший коэффициент

Условие Решить неравенство −x² + 4x + 5 < 0.
Решение.
−x² + 4x + 5 = 0.
Умножим уравнение на −1: x² − 4x − 5 = 0.
Корни: x₁ = −1 и x₂ = 5.
В исходном трёхчлене a = −1 < 0, поэтому он отрицателен снаружи корней.
Знак строгий, корни не включаются.
Ответ: x ∈ (−∞; −1) ∪ (5; +∞).

Пример 6. Единственное решение

Условие Решить неравенство (2x − 1)² ≤ 0.
Решение.
Квадрат любого выражения неотрицателен.
Поэтому условие ≤ 0 выполняется только при равенстве нулю:
2x − 1 = 0,
x = 12.
Ответ: {12}.

4. Сходства и различия двух методов

Вопрос Линейное неравенство Квадратное неравенство
К чему приводим К виду ax ⊙ b К виду ax² + bx + c ⊙ 0
Главное действие Выразить x Найти корни и определить знаки трёхчлена
Когда меняется знак При умножении или делении на отрицательное число Знак исходного неравенства при анализе промежутков не меняют
Роль границ Одно граничное число Обычно два корня, один корень или отсутствие корней
Как выбирают ответ По направлению знака после выражения x По знакам трёхчлена на промежутках
В квадратном неравенстве нельзя записывать ответ сразу после нахождения корней. Корни лишь делят числовую прямую на промежутки; затем нужно определить знак выражения.

5. Как быстро выбрать способ решения

Схема выбора алгоритма после упрощения неравенства

6. Неравенства, которые сначала нужно преобразовать

Пример 7. Дроби приводят к линейному неравенству

Условие Решить неравенство 3x − 14 > x + 52.
Решение.
Умножим обе части на 4. Число 4 положительно, поэтому знак не меняется:
3x − 1 > 2(x + 5),
3x − 1 > 2x + 10,
x > 11.
Ответ: x ∈ (11; +∞).

Пример 8. После раскрытия скобок получается квадратное неравенство

Условие Решить неравенство (x − 1)(x + 4) ≤ 2x + 8.
Решение.
x² + 3x − 4 ≤ 2x + 8,
x² + x − 12 ≤ 0,
(x + 4)(x − 3) ≤ 0.
Корни: −4 и 3. Ветви направлены вверх, поэтому выражение неположительно между корнями.
Ответ: x ∈ [−4; 3].

Пример 9. Квадратный трёхчлен без действительных корней

Условие Решить неравенство −2x² + 4x − 7 < 0.
Решение.
D = 4² − 4 · (−2) · (−7) = 16 − 56 = −40 < 0.
Действительных корней нет, а коэффициент a = −2 < 0.
Следовательно, трёхчлен отрицателен при всех действительных x.
Ответ: x ∈ ℝ.

7. Как проверить полученный ответ

Подставьте число

Возьмите одно число из найденного промежутка и проверьте, выполняется ли исходное неравенство.

Проверьте границы

Подстановка граничного числа показывает, должно ли оно входить в решение при нестрогом знаке.

Сверьте направление

Для линейного неравенства проверьте, не забыли ли изменить знак после деления на отрицательное число.

Оцените форму ответа

В квадратном неравенстве ответ может состоять из одного промежутка, объединения двух промежутков, одной точки, ℝ или ∅.

8. Типичные ошибки

Не изменили знак

При делении линейного неравенства на отрицательное число знак обязательно меняется на противоположный.

Определили тип слишком рано

Сначала раскройте скобки и приведите подобные слагаемые: квадратные члены могут сократиться или, наоборот, появиться.

Остановились на корнях

Корни квадратного трёхчлена не являются готовым ответом: нужно выбрать промежутки с нужным знаком.

Перепутали скобки

При строгом знаке граница исключается, при нестрогом — включается, если выражение в этой точке определено.

Опасно: делить обе части на выражение с переменной, не зная его знака.
Надёжно: переносить всё в одну часть и применять подходящий алгоритм к полученному выражению.

9. Самопроверка

Сначала определите вид каждого неравенства, затем решите его и раскройте ответ.

Задание 1. Решите неравенство 7x − 4 > 17.

Показать решение
7x > 21, поэтому x > 3.

Ответ: x ∈ (3; +∞).

Задание 2. Решите неравенство 5 − 3x ≤ 14.

Показать решение
−3x ≤ 9. Делим на −3 и меняем знак: x ≥ −3.

Ответ: x ∈ [−3; +∞).

Задание 3. Решите неравенство 2(x − 4) + 3 ≥ x + 1.

Показать решение
2x − 8 + 3 ≥ x + 1,
2x − 5 ≥ x + 1,
x ≥ 6.

Ответ: x ∈ [6; +∞).

Задание 4. Решите неравенство x² − 9 < 0.

Показать решение
x² − 9 = (x − 3)(x + 3). Корни: −3 и 3. Коэффициент при x² положительный, поэтому выражение отрицательно между корнями.

Ответ: x ∈ (−3; 3).

Задание 5. Решите неравенство x² + 5x + 6 ≥ 0.

Показать решение
x² + 5x + 6 = (x + 2)(x + 3). Корни: −3 и −2. Ветви направлены вверх, поэтому выражение неотрицательно снаружи корней.

Ответ: x ∈ (−∞; −3] ∪ [−2; +∞).

Задание 6. Решите неравенство −x² + 2x + 3 > 0.

Показать решение
Корни уравнения −x² + 2x + 3 = 0: x₁ = −1 и x₂ = 3. Ветви направлены вниз, поэтому выражение положительно между корнями.

Ответ: x ∈ (−1; 3).

Задание 7. Решите неравенство (x − 2)² ≤ 0.

Показать решение
Квадрат неотрицателен и может быть ≤ 0 только при равенстве нулю. x − 2 = 0, поэтому x = 2.

Ответ: {2}.

Задание 8. Решите неравенство 2x² − 4x + 5 < 0.

Показать решение
D = (−4)² − 4 · 2 · 5 = 16 − 40 = −24 < 0. Корней нет, а a = 2 > 0, поэтому трёхчлен положителен при всех x.

Ответ: ∅.

10. Финальный чек-ап

Перед переходом к рациональным неравенствам проверьте, что два базовых алгоритма не смешиваются между собой.

Сначала упростите Раскройте скобки и приведите подобные слагаемые, прежде чем определять вид неравенства.
Посмотрите на степень Первая степень ведёт к линейному алгоритму, вторая — к квадратному.
Следите за минусом При делении линейного неравенства на отрицательное число знак меняется.
Не останавливайтесь на корнях В квадратном неравенстве после корней обязательно определяются знаки на промежутках.
Проверьте границы Строгий знак исключает границу, нестрогий включает её, если выражение определено.
Сделайте подстановку Одно контрольное число из ответа помогает быстро заметить ошибку в направлении или знаках.

Следующий шаг — рациональные неравенства, где знаки числителя и знаменателя будут анализироваться методом интервалов.
