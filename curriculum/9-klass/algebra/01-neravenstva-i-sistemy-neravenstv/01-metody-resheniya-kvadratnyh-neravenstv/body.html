Что называют квадратным неравенством

Квадратным неравенством с одной переменной называют неравенство, которое можно привести к одному из видов

ax² + bx + c > 0,   ax² + bx + c < 0,   ax² + bx + c ≥ 0  или   ax² + bx + c ≤ 0,

где a ≠ 0.

Решить такое неравенство — значит найти все значения x, при которых квадратный трёхчлен ax² + bx + c имеет требуемый знак. Для этого удобно рассматривать функцию y = ax² + bx + c. Её график — парабола.

Выражение положительно

Ищем те значения x, при которых график параболы расположен выше оси Ox.

Выражение отрицательно

Ищем те значения x, при которых график параболы расположен ниже оси Ox.

Строгое неравенство

При знаках > и < корни квадратного трёхчлена в ответ не включаются.

Нестрогое неравенство

При знаках ≥ и ≤ корни включаются, потому что в них выражение равно нулю.

1. Главная идея: определить знаки трёхчлена

Если квадратное уравнение ax² + bx + c = 0 имеет два различных корня x₁ и x₂, где x₁ < x₂, то эти корни делят числовую прямую на три промежутка. На каждом из них квадратный трёхчлен сохраняет знак.

Парабола с ветвями вверх: снаружи корней знак «+», между корнями знак «−»

Если a > 0, ветви параболы направлены вверх: знак квадратного трёхчлена снаружи корней положительный, а между корнями — отрицательный.

Если a < 0, ветви направлены вниз, поэтому все знаки меняются на противоположные.

2. Выбор метода и алгоритм решения

Все способы основаны на одном факте: нужно определить знак квадратного трёхчлена. Конкретная запись решения зависит от вида выражения.

Графический способ

Схематично изобразите параболу и выберите участки, расположенные выше или ниже оси Ox. Точный масштаб обычно не требуется.

Схема знаков

Отметьте корни на числовой прямой и расставьте знаки трёхчлена на полученных промежутках.

Разложение на множители

Если трёхчлен легко представить произведением, его нули находятся без вычисления дискриминанта.

Анализ D и коэффициента a

При D ≤ 0 часто достаточно определить число корней и направление ветвей параболы.

Шаг Что нужно сделать
1 Перенести все слагаемые в одну часть, чтобы в другой части остался ноль.
2 Найти корни квадратного трёхчлена ax² + bx + c или установить, что действительных корней нет.
3 Определить направление ветвей параболы по знаку коэффициента a.
4 Определить, на каких промежутках выражение положительно или отрицательно.
5 Выбрать промежутки, соответствующие знаку исходного неравенства.
6 Включить корни при знаках ≥ или ≤ и исключить при знаках > или <.
Перед поиском дискриминанта проверьте, нельзя ли быстро разложить трёхчлен на множители или вынести общий множитель. Это часто сокращает решение.

3. Два различных корня: D > 0

Пример 1. Ветви направлены вверх

Условие Решить неравенство x² − 5x + 6 < 0.
Решение.
Решим уравнение x² − 5x + 6 = 0.
x² − 5x + 6 = (x − 2)(x − 3), поэтому x₁ = 2, x₂ = 3.
Коэффициент при x² положительный: a = 1 > 0. Ветви параболы направлены вверх.
Трёхчлен отрицателен между корнями.
Знак неравенства строгий, поэтому точки 2 и 3 не включаются.
Ответ: x ∈ (2; 3).

Пример 2. Ветви направлены вниз

Условие Решить неравенство −2x² + x + 3 ≥ 0.
Решение.
Решим уравнение −2x² + x + 3 = 0.
Умножим уравнение на −1: 2x² − x − 3 = 0.
D = (−1)² − 4 · 2 · (−3) = 25.
x₁ = 1 − 54 = −1,   x₂ = 1 + 54 = 32.
В исходном трёхчлене a = −2 < 0, поэтому ветви параболы направлены вниз.
Трёхчлен неотрицателен между корнями. Знак ≥ позволяет включить оба корня.
Ответ: x ∈ [−1; 32].

4. Один корень: D = 0

Если D = 0, парабола касается оси Ox в одной точке x₀. Во всех остальных точках знак трёхчлена совпадает со знаком коэффициента a.

Пример 3. Выражение обращается в ноль в одной точке

Условие Решить неравенство 4x² − 12x + 9 > 0.
Решение.
4x² − 12x + 9 = (2x − 3)².
Квадрат выражения не может быть отрицательным.
Он равен нулю только при 2x − 3 = 0, то есть при x = 32.
Значит, выражение положительно при всех действительных x, кроме x = 32.
Ответ: x ∈ (−∞; 32) ∪ (32; +∞).
При D = 0 удобно представить трёхчлен в виде a(x − x₀)². Квадрат неотрицателен, а знак всего выражения определяется коэффициентом a.

5. Действительных корней нет: D < 0

Если D < 0, парабола не пересекает ось Ox. Поэтому квадратный трёхчлен не меняет знак: при a > 0 он положителен для всех x, а при a < 0 — отрицателен для всех x.

Пример 4. Неравенство не имеет решений

Условие Решить неравенство 2x² + 3x + 5 ≤ 0.
Решение.
D = 3² − 4 · 2 · 5 = 9 − 40 = −31 < 0.
Действительных корней нет, а a = 2 > 0.
Следовательно, 2x² + 3x + 5 > 0 при любом действительном x.
Требование 2x² + 3x + 5 ≤ 0 не выполняется ни при одном x.
Ответ: ∅.

Пример 5. Решением являются все действительные числа

Условие Решить неравенство −x² + 4x − 7 < 0.
Решение.
D = 4² − 4 · (−1) · (−7) = 16 − 28 = −12 < 0.
Действительных корней нет, а a = −1 < 0.
Значит, выражение отрицательно при всех действительных x.
Ответ: x ∈ ℝ.

6. Быстрое решение после разложения на множители

Если квадратный трёхчлен уже разложен на множители или легко раскладывается, его нули видны сразу. Затем можно расставить знаки на промежутках.

Пример 6. Неполное квадратное неравенство

Условие Решить неравенство x² − 9 ≥ 0.
Решение.
x² − 9 = (x − 3)(x + 3).
Нули выражения: x = −3 и x = 3.
Коэффициент при x² положительный, поэтому выражение неотрицательно снаружи корней.
Корни включаются, так как знак неравенства ≥.
Ответ: x ∈ (−∞; −3] ∪ [3; +∞).
Умножать или делить неравенство на выражение с переменной без анализа его знака нельзя. Например, нельзя просто «сократить на x», если неизвестно, положителен x или отрицателен.

7. Таблица основных случаев

Условие a > 0 a < 0
D > 0, корни x₁ < x₂ «+» снаружи, «−» между корнями «−» снаружи, «+» между корнями
D = 0, корень x₀ Выражение ≥ 0; ноль только при x = x₀ Выражение ≤ 0; ноль только при x = x₀
D < 0 Выражение > 0 при всех x Выражение < 0 при всех x

8. Типичные ошибки

Забыли знак коэффициента a

При a < 0 ветви направлены вниз, поэтому знаки на промежутках противоположны случаю a > 0.

Неверно включили корни

Скобки зависят от знака неравенства: при ≥ и ≤ корни включаются, при > и < — нет.

Сразу сделали вывод по D

При D < 0 нужно обязательно посмотреть на знак a: именно он определяет постоянный знак трёхчлена.

Потеряли часть решения

Если подходят два раздельных промежутка, их записывают через знак объединения ∪.

Неверно: если корни 2 и 5, то автоматически выбирать (2; 5).
Верно: сначала определить знак a и выяснить, требуется положительное или отрицательное значение трёхчлена.

9. Самопроверка

Решите неравенства и только после этого раскройте решения.

Задание 1. Решите неравенство x² − 7x + 12 < 0.

Показать решение
x² − 7x + 12 = (x − 3)(x − 4). Корни: 3 и 4. Коэффициент при x² положительный, поэтому выражение отрицательно между корнями.

Ответ: x ∈ (3; 4).

Задание 2. Решите неравенство x² + x − 6 ≥ 0.

Показать решение
x² + x − 6 = (x + 3)(x − 2). Корни: −3 и 2. Ветви направлены вверх, поэтому выражение неотрицательно снаружи корней. Корни включаются.

Ответ: x ∈ (−∞; −3] ∪ [2; +∞).

Задание 3. Решите неравенство −x² + 5x − 6 > 0.

Показать решение
−x² + 5x − 6 = −(x − 2)(x − 3). Корни: 2 и 3. Коэффициент при x² отрицательный, поэтому выражение положительно между корнями.

Ответ: x ∈ (2; 3).

Задание 4. Решите неравенство 4x² − 12x + 9 ≤ 0.

Показать решение
4x² − 12x + 9 = (2x − 3)². Квадрат неотрицателен, поэтому условие ≤ 0 выполняется только тогда, когда квадрат равен нулю.

2x − 3 = 0, x = 32.

Ответ: { 32}.

Задание 5. Решите неравенство 3x² + 2x + 5 < 0.

Показать решение
D = 2² − 4 · 3 · 5 = 4 − 60 = −56 < 0. Корней нет, а a = 3 > 0, поэтому трёхчлен положителен при всех x.

Ответ: ∅.

Задание 6. Решите неравенство −2x² + 4x − 5 ≤ 0.

Показать решение
D = 4² − 4 · (−2) · (−5) = 16 − 40 = −24 < 0. Корней нет, а a = −2 < 0, поэтому выражение отрицательно при всех x. Следовательно, условие ≤ 0 выполняется для любого действительного числа.

Ответ: x ∈ ℝ.

Задание 7. Решите неравенство x(2x − 10) ≥ 0.

Показать решение
Нули множителей: x = 0 и 2x − 10 = 0, откуда x = 5. После раскрытия скобок старший коэффициент положительный: x(2x − 10) = 2x² − 10x. Значит, выражение неотрицательно снаружи корней.

Ответ: x ∈ (−∞; 0] ∪ [5; +∞).

Задание 8. Решите неравенство (x + 1)² > 0.

Показать решение
Квадрат выражения положителен при всех значениях x, кроме того значения, при котором он равен нулю.

x + 1 = 0, значит, x = −1.

Ответ: x ∈ (−∞; −1) ∪ (−1; +∞).

10. Итог

При решении квадратного неравенства нужно определить не только корни, но и знак трёхчлена на промежутках.

Приведите к нулю Перенесите все слагаемые в одну часть и получите квадратный трёхчлен.
Найдите корни Используйте разложение на множители, дискриминант или формулу корней.
Проверьте знак a Он показывает, вверх или вниз направлены ветви параболы.
Выберите промежутки Сопоставьте знаки трёхчлена со знаком исходного неравенства.
Учтите границы При ≥ и ≤ корни включаются, а при > и < исключаются.
Проверьте особые случаи При D = 0 есть точка касания, а при D < 0 знак выражения постоянен.
