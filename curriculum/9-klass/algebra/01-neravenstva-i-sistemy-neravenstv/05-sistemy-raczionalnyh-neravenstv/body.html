Системы рациональных неравенств

Научимся решать каждое неравенство системы отдельно, изображать полученные множества на числовой прямой и находить их пересечение без потери запрещённых значений и граничных точек.

1. Что называют системой рациональных неравенств

Система неравенств — это несколько неравенств с одной переменной, которые должны выполняться одновременно. Фигурная скобка слева читается как слово «и».

{
x − 1 x + 2 ≥ 0,
x − 4 x − 3 < 0.
Решением системы является пересечение множеств решений всех её неравенств: нужно оставить только те значения x, которые подходят каждому условию одновременно.
Не путайте систему и совокупность. В системе действует слово «и» и выполняется пересечение. В совокупности действует слово «или» и выполняется объединение.

2. Главный алгоритм решения

Систему не нужно превращать в одно большое неравенство. Надёжнее последовательно решить каждую строку, а затем сопоставить полученные промежутки.

  1. Запишите ОДЗ. Все нули знаменателей исключаются независимо от знака неравенства.
  2. Решите первое неравенство. Приведите его к одной дроби и примените метод интервалов.
  3. Решите остальные неравенства. Для каждой строки постройте собственную схему знаков.
  4. Изобразите ответы на одной числовой прямой. Так легче увидеть общую часть.
  5. Найдите пересечение. Оставьте только значения, принадлежащие всем найденным множествам.
  6. Проверьте границы. Нули знаменателей исключаются всегда, а нули числителей зависят от строгости знака.

3. Как решать отдельное рациональное неравенство

В каждой строке системы используется тот же метод интервалов, который применялся в предыдущей теме.

Нули числителя

Они могут войти в ответ при знаках ≤ или ≥. При строгих знаках < и > такие точки исключаются.

Нули знаменателя

Они не принадлежат области допустимых значений и всегда отмечаются пустыми точками.

Кратность корня

При нечётной кратности знак меняется, при чётной — сохраняется.

Последний шаг

Ответы отдельных неравенств ещё не являются ответом системы: их обязательно нужно пересечь.

Тип точки Строгое неравенство Нестрогое неравенство
Нуль числителя Не включается Включается, если выражение определено
Нуль знаменателя Не включается Не включается
Обычная граница после пересечения Берёт тип скобки из того условия, которое задаёт эту границу

4. Подробный пример: от двух решений к одному ответу

Решим систему:

{
x − 1 x + 2 ≥ 0,
x − 4 x − 3 < 0.

Первое неравенство

x − 1 x + 2 ≥ 0.
Критические точки: x = −2 и x = 1.
x = −2 запрещено, x = 1 включается.
x ∈ (−∞; −2) ∪ [1; +∞).

Второе неравенство

x − 4 x − 3 < 0.
Критические точки: x = 3 и x = 4.
Обе границы исключаются: x = 3 запрещено, а знак неравенства строгий.
x ∈ (3; 4).

Пересечение решений двух неравенств

Общая часть множеств (−∞; −2) ∪ [1; +∞) и (3; 4) — промежуток (3; 4).
Ответ: x ∈ (3; 4).

5. Система со смешанными типами неравенств

В одной системе могут встречаться дробно-рациональные и целые рациональные неравенства. Способ решения каждой строки выбирают отдельно.

Пример 1. Квадратное и дробное неравенства
{ x² − 9 ≤ 0, x − 1 x + 2 > 0.
1) x² − 9 ≤ 0, значит x ∈ [−3; 3].
2) x − 1 x + 2 > 0, значит x ∈ (−∞; −2) ∪ (1; +∞).
3) Пересекаем множества.
Ответ: [−3; −2) ∪ (1; 3].
Пример 2. Система из трёх неравенств
{ x + 2 x − 1 > 0, x − 3 x + 4 ≤ 0, x − 2 x + 5 ≥ 0.
Первое: (−∞; −2) ∪ (1; +∞).
Второе: (−4; 3].
Третье: (−∞; −5) ∪ [2; +∞).
Общая часть всех трёх множеств — [2; 3].
Ответ: [2; 3].

6. Особые результаты пересечения

Пересечение не обязательно является одним промежутком. Возможны несколько принципиально разных результатов.

Один промежуток Например, (2; 7].
Несколько промежутков Например, (−∞; −1) ∪ [3; 5).
Одна точка Например, {2}.
Пустое множество Общих решений нет: ∅.
Пример 3. Единственное решение Первое неравенство даёт [−1; 2], второе — (−∞; −4) ∪ [2; +∞).
Их общая часть состоит только из числа 2.
Ответ: x = 2.
Пример 4. Решений нет Первое неравенство даёт (−∞; −5) ∪ (2; +∞), второе — (−5; 1).
Ни одно число не принадлежит обоим множествам одновременно.
Ответ: ∅.

7. Сокращение дроби и потерянная точка

При сокращении одинакового множителя выражение упрощается, но исходный нуль знаменателя остаётся запрещённым.

Пример 5. Сокращаем, но сохраняем ОДЗ
{ (x − 2)(x + 1) x − 2 > 0, x − 4 x + 1 ≤ 0.
Для первой дроби x ≠ 2. После сокращения получаем x + 1 > 0, но точку 2 возвращать нельзя.
Первое множество: (−1; 2) ∪ (2; +∞).
Второе множество: (−1; 4].
Ответ: (−1; 2) ∪ (2; 4].
Запрещённое значение может оказаться внутри итогового промежутка. Тогда ответ обязательно разбивается на две части.

8. Типичные ошибки

Объединяют вместо пересечения

Система требует выполнения всех условий, поэтому ответы нужно пересекать, а не собирать вместе.

Решают только одну строку

Значение x должно удовлетворять каждому неравенству системы.

Включают нуль знаменателя

Даже при знаках ≤ и ≥ знаменатель не может быть равен нулю.

Теряют точку после сокращения

Ограничение из исходной дроби сохраняется после любых преобразований.

9. Самопроверка

Решите каждое неравенство отдельно, а затем найдите пересечение полученных множеств.

1. Решите систему: { x − 2 x + 1 > 0, x − 5 x − 3 < 0.

Показать решение

Первое неравенство: x ∈ (−∞; −1) ∪ (2; +∞).

Второе неравенство: x ∈ (3; 5).

Пересечение: (3; 5).

2. Решите систему: { x + 4 x − 1 ≤ 0, x − 2 x + 3 ≥ 0.

Показать решение

Первое неравенство: x ∈ [−4; 1).

Второе неравенство: x ∈ (−∞; −3) ∪ [2; +∞).

Ответ: [−4; −3).

3. Решите систему: { x² − 9 ≤ 0, x − 1 x + 2 > 0.

Показать решение

x² − 9 ≤ 0 при x ∈ [−3; 3].

Дробное неравенство выполняется на (−∞; −2) ∪ (1; +∞).

Ответ: [−3; −2) ∪ (1; 3].

4. Решите систему: { (x + 1)(x − 3) ≤ 0, x − 3 x + 5 ≥ 0.

Показать решение

Первое множество: [−1; 3].

Второе множество: (−∞; −5) ∪ [3; +∞).

Общая часть состоит из одной точки.

Ответ: x = 3.

5. Решите систему: { x − 2 x + 5 > 0, x + 5 x − 1 < 0.

Показать решение

Первое множество: (−∞; −5) ∪ (2; +∞).

Второе множество: (−5; 1).

Общих значений нет.

Ответ: ∅.

6. Решите систему: { (x − 2)(x + 1) x − 2 > 0, x − 4 x + 1 ≤ 0.

Показать решение

После сокращения первой дроби получаем x + 1 > 0, но сохраняем ограничение x ≠ 2.

Первое множество: (−1; 2) ∪ (2; +∞).

Второе множество: (−1; 4].

Ответ: (−1; 2) ∪ (2; 4].

7. Решите систему из трёх неравенств: { x + 2 x − 1 > 0, x − 3 x + 4 ≤ 0, x − 2 x + 5 ≥ 0.

Показать решение

Первое множество: (−∞; −2) ∪ (1; +∞).

Второе множество: (−4; 3].

Третье множество: (−∞; −5) ∪ [2; +∞).

Ответ: [2; 3].

8. Решите систему: { x − 1 (x + 2)² ≤ 0, x + 4 x − 3 > 0.

Показать решение

В первой дроби знаменатель положителен при всех x ≠ −2. Поэтому нужно x − 1 ≤ 0 и x ≠ −2.

Первое множество: (−∞; −2) ∪ (−2; 1].

Второе множество: (−∞; −4) ∪ (3; +∞).

Ответ: (−∞; −4).

10. Итоговый светофор

Перед записью ответа быстро проверьте решение по трём сигналам.

Можно записывать ответ
Каждое неравенство решено отдельно, множества изображены на одной прямой, а в ответ взята только их общая часть.
Нужно перепроверить
Граница получилась из нуля числителя: уточните, строгий ли знак и определено ли выражение в этой точке.
Так делать нельзя
Нельзя объединять ответы системы, включать нули знаменателей или возвращать точку, исчезнувшую при сокращении дроби.
Главная формула темы:
решение системы = решение первого неравенства ∩ решение второго неравенства ∩ …

Далее переходим к системам рациональных уравнений и равносильным преобразованиям.
