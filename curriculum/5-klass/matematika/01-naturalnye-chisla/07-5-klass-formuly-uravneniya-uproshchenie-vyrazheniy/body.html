Что нужно знать перед темой

Эта тема объединяет несколько важных идей: буквенные выражения, вычисления, законы арифметических действий и простейшие уравнения.

  • Буква в выражении может обозначать неизвестное или изменяющееся число.
  • Чтобы найти значение буквенного выражения, нужно подставить вместо буквы число.
  • Вычисления выполняются по порядку действий: скобки, умножение и деление, сложение и вычитание.
  • Законы сложения и умножения помогают считать удобнее.
  • Уравнение — это равенство с неизвестным числом.

1. Что такое формула

Формула — это запись правила с помощью букв, чисел и знаков действий. Формула помогает быстро находить нужную величину, если известны остальные величины.

Формула — это математическая запись, которая показывает связь между величинами.

Например, если прямоугольник имеет длину a и ширину b, то его периметр можно найти по формуле:

P = 2 · (a + b)

Формулы периметра и площади прямоугольника

Пример 1. Найдём периметр прямоугольника по формуле

Условие Длина прямоугольника равна 12 см, ширина — 7 см. Найдите периметр прямоугольника.
Решение.
Используем формулу периметра прямоугольника:
P = 2 · (a + b).
Подставляем a = 12, b = 7:
P = 2 · (12 + 7) = 2 · 19 = 38.
Ответ: 38 см.

Пример 2. Найдём площадь прямоугольника

Условие Длина прямоугольника равна 15 м, ширина — 6 м. Найдите площадь прямоугольника.
Решение.
Площадь прямоугольника находят по формуле:
S = a · b.
Подставляем a = 15, b = 6:
S = 15 · 6 = 90.
Ответ: 90 м².

2. Что такое уравнение

Уравнение — это равенство, в котором есть неизвестное число. Обычно неизвестное число обозначают буквой: x, a, b и так далее.

Уравнение — это равенство с неизвестным числом.
Корень уравнения — это значение неизвестного, при котором равенство становится верным.
x + 18 = 45 — уравнение.
Если x = 27, то 27 + 18 = 45. Значит, 27 — корень этого уравнения.

Пример 3. Решим уравнение на неизвестное слагаемое

Уравнение: x + 37 = 92
Неизвестно первое слагаемое.
Чтобы найти неизвестное слагаемое, нужно из суммы вычесть известное слагаемое.
x = 92 − 37
x = 55
Проверка: 55 + 37 = 92.
Ответ: x = 55.

Пример 4. Решим уравнение на неизвестное уменьшаемое

Уравнение: x − 28 = 64
Неизвестно уменьшаемое.
Чтобы найти уменьшаемое, нужно к разности прибавить вычитаемое.
x = 64 + 28
x = 92
Проверка: 92 − 28 = 64.
Ответ: x = 92.

Пример 5. Решим уравнение на неизвестный множитель

Уравнение: 9 · x = 108
Неизвестен множитель.
Чтобы найти неизвестный множитель, нужно произведение разделить на известный множитель.
x = 108 : 9
x = 12
Проверка: 9 · 12 = 108.
Ответ: x = 12.

3. Правила для простейших уравнений

В 5 классе часто решают уравнения, где неизвестен один из компонентов действия. Важно знать, как найти неизвестное слагаемое, уменьшаемое, вычитаемое, множитель, делимое или делитель.

Тип уравнения Как найти неизвестное Пример
x + a = b x = b − a x + 14 = 50 → x = 36
x − a = b x = b + a x − 9 = 31 → x = 40
a − x = b x = a − b 80 − x = 23 → x = 57
a · x = b x = b : a 7 · x = 84 → x = 12
x : a = b x = b · a x : 6 = 11 → x = 66
a : x = b x = a : b 96 : x = 8 → x = 12
После решения уравнения всегда полезно выполнить проверку: подставить найденное значение вместо буквы.

4. Упрощение выражений

Упрощение выражения — это преобразование выражения в более короткую или удобную запись. Значение выражения при этом не должно измениться.

Упростить выражение — значит записать его проще, не меняя его значения.

Чаще всего в 5 классе выражения упрощают с помощью распределительного закона:

a · b + a · c = a · (b + c)
a · b − a · c = a · (b − c)

Как общий множитель помогает упростить выражение

Пример 6. Упростим выражение с общим множителем

Упростить: 8 · 17 + 8 · 23
В обоих произведениях есть общий множитель 8.
8 · 17 + 8 · 23 = 8 · (17 + 23)
17 + 23 = 40
8 · 40 = 320
Ответ: 320.

Пример 7. Упростим буквенное выражение

Упростить: 12 · x + 5 · x
В обоих слагаемых есть общий множитель x.
12 · x + 5 · x = (12 + 5) · x
12 + 5 = 17
Получаем 17 · x.
Ответ: 17 · x.

Пример 8. Упростим выражение с вычитанием

Упростить: 19 · a − 7 · a
В обоих произведениях есть общий множитель a.
19 · a − 7 · a = (19 − 7) · a
19 − 7 = 12
Ответ: 12 · a.

5. Формулы, уравнения и выражения в одной задаче

В задачах часто приходится соединять разные умения: составить выражение, упростить его, подставить значение или решить уравнение.

Пример 9. Составим и упростим выражение

Условие В одной коробке лежит x карандашей, а во второй — в 3 раза больше. Сколько карандашей в двух коробках вместе?
Решение.
В первой коробке x карандашей.
Во второй коробке в 3 раза больше: 3 · x.
Всего: x + 3 · x.
Упрощаем: x + 3 · x = 4 · x.
Ответ: 4 · x карандашей.

Пример 10. Решим задачу с уравнением

Условие После того как из коробки взяли 18 деталей, в ней осталось 47 деталей. Сколько деталей было в коробке сначала?
Решение.
Пусть x — количество деталей в коробке сначала.
Из коробки взяли 18 деталей, осталось 47.
Составим уравнение: x − 18 = 47.
x = 47 + 18
x = 65
Проверка: 65 − 18 = 47.
Ответ: 65 деталей.

6. Задания для самопроверки

Решите задания самостоятельно, затем раскройте решение.

Задание 1. Найдите периметр прямоугольника со сторонами 14 см и 9 см.

Показать решение
Периметр прямоугольника:
P = 2 · (a + b).
P = 2 · (14 + 9) = 2 · 23 = 46.
Ответ: 46 см.

Задание 2. Найдите площадь прямоугольника со сторонами 18 м и 7 м.

Показать решение
Площадь прямоугольника:
S = a · b.
S = 18 · 7 = 126.
Ответ: 126 м².

Задание 3. Решите уравнение: x + 29 = 84.

Показать решение
Чтобы найти неизвестное слагаемое, из суммы вычитаем известное слагаемое:
x = 84 − 29 = 55.
Проверка: 55 + 29 = 84.
Ответ: x = 55.

Задание 4. Решите уравнение: x − 46 = 128.

Показать решение
Чтобы найти уменьшаемое, к разности прибавляем вычитаемое:
x = 128 + 46 = 174.
Проверка: 174 − 46 = 128.
Ответ: x = 174.

Задание 5. Решите уравнение: 12 · x = 144.

Показать решение
Чтобы найти неизвестный множитель, произведение делим на известный множитель:
x = 144 : 12 = 12.
Проверка: 12 · 12 = 144.
Ответ: x = 12.

Задание 6. Решите уравнение: 96 : x = 8.

Показать решение
Неизвестен делитель.
Чтобы найти делитель, нужно делимое разделить на частное:
x = 96 : 8 = 12.
Проверка: 96 : 12 = 8.
Ответ: x = 12.

Задание 7. Упростите выражение: 9 · a + 6 · a.

Показать решение
В обоих слагаемых есть общий множитель a:
9 · a + 6 · a = (9 + 6) · a = 15 · a.
Ответ: 15 · a.

Задание 8. Упростите выражение: 18 · x − 7 · x.

Показать решение
Выносим общий множитель x:
18 · x − 7 · x = (18 − 7) · x = 11 · x.
Ответ: 11 · x.

Задание 9. В одной коробке b тетрадей, а во второй — в 4 раза больше. Запишите выражение для количества тетрадей в двух коробках вместе и упростите его.

Показать решение
В первой коробке b тетрадей.
Во второй коробке 4 · b тетрадей.
Всего: b + 4 · b = 5 · b.
Ответ: 5 · b.

Задание 10. После того как к числу прибавили 37, получилось 105. Составьте уравнение и найдите число.

Показать решение
Пусть x — неизвестное число.
Составим уравнение:
x + 37 = 105.
x = 105 − 37 = 68.
Ответ: 68.

7. Мини-итог

  • Формула показывает связь между величинами.
  • Чтобы использовать формулу, нужно подставить известные значения вместо букв.
  • Уравнение — это равенство с неизвестным числом.
  • Корень уравнения — значение неизвестного, при котором равенство верно.
  • Упростить выражение — значит записать его удобнее, не меняя значения.
  • При упрощении часто используют распределительный закон.
