Свойство углов треугольника

В этой теме разберём главное свойство углов треугольника: сумма трёх внутренних углов любого треугольника равна 180°. Научимся находить неизвестный угол и проверять, может ли существовать треугольник с заданными углами.

Что нужно знать перед темой

У треугольника есть три вершины, три стороны и три угла. В этой теме нас будут интересовать именно углы треугольника. Главное правило: все три внутренних угла треугольника вместе дают развёрнутый угол, то есть 180°.

  • Прямой угол равен 90°.
  • Развёрнутый угол равен 180°.
  • Острый угол меньше 90°.
  • Тупой угол больше 90°, но меньше 180°.
  • Чтобы найти неизвестную часть суммы, нужно из всей суммы вычесть известные части.

1. Главное свойство углов треугольника

В любом треугольнике сумма трёх внутренних углов всегда равна 180°. Это верно для любого треугольника: острого, тупого, прямоугольного, большого, маленького, равнобедренного или обычного.

Сумма углов треугольника равна 180°.
Если дан треугольник ABC, то:
∠A + ∠B + ∠C = 180°.

Три угла треугольника вместе дают 180°

Внутренние углы — это углы внутри треугольника при его вершинах.
Их сумма всегда равна 180°: это главное свойство углов треугольника.

Пример 1. Проверим сумму углов

Условие Углы треугольника равны 50°, 60° и 70°. Проверьте, верна ли сумма углов.
Решение.
Сложим все три угла:
50° + 60° + 70° = 180°.
Сумма получилась 180°, значит такие углы могут быть углами треугольника.
Ответ: да, сумма углов верна.

2. Как найти неизвестный угол треугольника

Если в треугольнике известны два угла, третий угол можно найти. Для этого нужно из 180° вычесть сумму двух известных углов.

Чтобы найти неизвестный угол треугольника:
1. Сложите два известных угла.
2. Вычтите полученную сумму из 180°.
3. Получится третий угол.

Находим третий угол

Пример 2. Найдём третий угол

Условие В треугольнике два угла равны 45° и 65°. Найдите третий угол.
Решение.
Сумма углов треугольника равна 180°.
Сначала сложим известные углы:
45° + 65° = 110°.
Теперь найдём третий угол:
180° − 110° = 70°.
Ответ: 70°.

Пример 3. Найдём угол без промежуточной записи

Условие В треугольнике углы равны 38°, 72° и x°. Найдите x.
Решение.
Запишем сумму углов:
38° + 72° + x = 180°.
Сложим известные углы:
38° + 72° = 110°.
Тогда x = 180° − 110° = 70°.
Ответ: x = 70°.

3. Можно ли составить треугольник с такими углами

Если даны три угла, можно проверить, могут ли они быть углами одного треугольника. Для этого нужно сложить их. Если сумма равна 180°, такие углы подходят. Если сумма не равна 180°, такого треугольника не существует.

Три угла могут быть углами треугольника только тогда, когда их сумма равна 180°.

Проверяем набор углов

Пример 4. Проверим существование треугольника

Условие Могут ли углы 80°, 70° и 40° быть углами одного треугольника?
Решение.
Сложим данные углы:
80° + 70° + 40° = 190°.
Сумма углов треугольника должна быть 180°.
190° ≠ 180°, значит такого треугольника не существует.
Ответ: нет, не могут.

Пример 5. Проверим другой набор углов

Условие Могут ли углы 35°, 65° и 80° быть углами одного треугольника?
Решение.
Сложим углы:
35° + 65° + 80° = 180°.
Сумма равна 180°, значит такие углы могут быть углами треугольника.
Ответ: да, могут.

4. Углы прямоугольного треугольника

Если один угол треугольника равен 90°, то треугольник называется прямоугольным. В таком треугольнике два остальных угла вместе дают 90°, потому что вся сумма углов треугольника равна 180°.

В прямоугольном треугольнике:
один угол равен 90°,
два остальных угла в сумме равны 90°.

Два острых угла прямоугольного треугольника

Пример 6. Найдём второй острый угол

Условие В прямоугольном треугольнике один острый угол равен 35°. Найдите второй острый угол.
Решение.
В прямоугольном треугольнике два острых угла в сумме дают 90°.
Один острый угол равен 35°.
Найдём второй:
90° − 35° = 55°.
Ответ: 55°.

5. Виды треугольников по углам

Треугольники можно различать по углам. Если все углы острые, треугольник называют остроугольным. Если один угол прямой — прямоугольным. Если один угол тупой — тупоугольным.

Вид треугольника Какие углы Пример
Остроугольный Все три угла меньше 90° 50°, 60°, 70°
Прямоугольный Один угол равен 90° 90°, 35°, 55°
Тупоугольный Один угол больше 90° 110°, 30°, 40°

Пример 7. Определим вид треугольника

Условие Углы треугольника равны 30°, 40° и 110°. Как называется такой треугольник по углам?
Решение.
Один угол равен 110°.
110° больше 90°, значит этот угол тупой.
Если в треугольнике есть тупой угол, треугольник называется тупоугольным.
Ответ: тупоугольный треугольник.

Пример 8. Может ли быть два тупых угла

Условие Может ли в одном треугольнике быть два тупых угла?
Решение.
Тупой угол больше 90°.
Если взять два тупых угла, их сумма уже будет больше 180°.
Но сумма всех углов треугольника должна быть ровно 180°.
Значит, два тупых угла в одном треугольнике невозможны.
Ответ: нет, не может.

6. Задания для самопроверки

Решите задания самостоятельно. После решения раскройте ответ и сравните ход рассуждений.

Задание 1. Чему равна сумма углов любого треугольника?

Показать решение
Сумма углов любого треугольника равна 180°.
Ответ: 180°.

Задание 2. В треугольнике два угла равны 40° и 70°. Найдите третий угол.

Показать решение
Сумма углов треугольника равна 180°.
40° + 70° = 110°.
180° − 110° = 70°.
Ответ: 70°.

Задание 3. В треугольнике углы равны 35°, 55° и x°. Найдите x.

Показать решение
35° + 55° = 90°.
x = 180° − 90° = 90°.
Ответ: x = 90°.

Задание 4. Могут ли углы 60°, 60° и 60° быть углами одного треугольника?

Показать решение
Проверим сумму:
60° + 60° + 60° = 180°.
Сумма равна 180°, значит такие углы могут быть углами треугольника.
Ответ: да, могут.

Задание 5. Могут ли углы 90°, 60° и 40° быть углами одного треугольника?

Показать решение
Проверим сумму:
90° + 60° + 40° = 190°.
Сумма не равна 180°, значит такого треугольника не существует.
Ответ: нет, не могут.

Задание 6. В прямоугольном треугольнике один острый угол равен 28°. Найдите второй острый угол.

Показать решение
В прямоугольном треугольнике два острых угла в сумме равны 90°.
90° − 28° = 62°.
Ответ: 62°.

Задание 7. Углы треугольника равны 45°, 45° и 90°. Как называется такой треугольник по углам?

Показать решение
Один угол равен 90°.
Треугольник с прямым углом называется прямоугольным.
Ответ: прямоугольный треугольник.

Задание 8. Углы треугольника равны 100°, 50° и 30°. Как называется такой треугольник по углам?

Показать решение
Один угол равен 100°.
100° больше 90°, значит угол тупой.
Треугольник с тупым углом называется тупоугольным.
Ответ: тупоугольный треугольник.

Задание 9. Углы треугольника равны 48°, 62° и 70°. Как называется такой треугольник по углам?

Показать решение
Все углы меньше 90°.
Значит, все углы острые.
Такой треугольник называется остроугольным.
Ответ: остроугольный треугольник.

Задание 10. Один угол треугольника равен 120°. Второй угол равен 25°. Найдите третий угол.

Показать решение
120° + 25° = 145°.
Третий угол:
180° − 145° = 35°.
Ответ: 35°.

Задание 11. Может ли в треугольнике быть два прямых угла?

Показать решение
Два прямых угла дают:
90° + 90° = 180°.
Тогда на третий угол ничего не останется, а у треугольника должно быть три настоящих угла.
Значит, два прямых угла в одном треугольнике невозможны.
Ответ: нет, не может.

Задание 12. В треугольнике один угол равен 80°, а два других равны между собой. Найдите эти два угла.

Показать решение
Сумма всех углов равна 180°.
На два равных угла остаётся:
180° − 80° = 100°.
Так как углы равны, делим 100° на 2:
100° : 2 = 50°.
Ответ: 50° и 50°.

7. Мини-итог

  • Сумма углов любого треугольника равна 180°.
  • Если известны два угла треугольника, третий угол можно найти вычитанием из 180°.
  • Три угла могут быть углами треугольника только тогда, когда их сумма равна 180°.
  • В прямоугольном треугольнике два острых угла в сумме равны 90°.
  • Если все углы треугольника острые, треугольник называется остроугольным.
  • Если один угол равен 90°, треугольник называется прямоугольным.
  • Если один угол больше 90°, треугольник называется тупоугольным.
  • В одном треугольнике не может быть двух прямых или двух тупых углов.
