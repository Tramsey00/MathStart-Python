1. Зачем извлекать корень из дисперсии

Дисперсия вычисляется из квадратов отклонений, поэтому её единицы тоже оказываются квадратными. Например, если рост измеряется в сантиметрах, дисперсия измеряется в квадратных сантиметрах.

Стандартное отклонение числового набора — квадратный корень из дисперсии этого набора.
σ = √D

Стандартное отклонение измеряется в тех же единицах, что и исходные данные. Чем оно меньше, тем ближе значения набора расположены к среднему.

D = 9 см²

σ = √9 = 3 см. Результат снова выражен в сантиметрах.

D = 0

σ = 0. Это возможно, когда все числа набора одинаковы.

2. Полный пример вычисления

Для набора 2, 4, 6, 8 в предыдущей теме была получена дисперсия D = 5.

σ = √5 ≈ 2,24

Значит, характерный масштаб разброса значений около среднего 5 составляет примерно 2,24 единицы.

Сравнение двух наборовЕсли DA = 0,4, то σA = √0,4 ≈ 0,63. Если DB = 8, то σB = √8 ≈ 2,83. Набор A заметно стабильнее.

3. Что такое диаграмма рассеивания

Иногда для каждого объекта измеряют сразу две величины. Например, для каждого ученика можно записать время подготовки и результат работы. Каждая пара значений изображается точкой с координатами (x; y).

Диаграмма рассеивания — изображение пар совместно наблюдаемых величин точками на координатной плоскости.
Время подготовки x, ч123456
Результат y, баллы525763707682

Диаграмма рассеивания для данных из таблицы

Точки группируются около восходящей линии: при увеличении времени подготовки результат обычно возрастает. Это позволяет предположить положительную связь между величинами.

4. Как читать облако точек

↗ Положительная связь

При росте x значения y в целом тоже растут. Облако вытянуто снизу слева вверх направо.

↘ Отрицательная связь

При росте x значения y в целом уменьшаются. Облако вытянуто сверху слева вниз направо.

· · · Нет ясной связи

Точки расположены без заметного направления, поэтому очевидная зависимость не просматривается.

Узкое или широкое облако

Чем плотнее точки группируются около некоторой линии, тем отчётливее предполагаемая связь.

Важно: диаграмма рассеивания помогает выдвинуть гипотезу о связи, но сама по себе не доказывает, что одна величина является причиной другой.

5. Алгоритм построения

  1. Составьте пары совместных наблюдений (xi; yi).
  2. Выберите масштабы обеих осей и подпишите величины с единицами измерения.
  3. Для каждой пары отметьте одну точку на координатной плоскости.
  4. Оцените направление и плотность облака точек, не соединяя точки ломаной без специальной причины.
Первые две точки таблицыПара (1; 52) означает: 1 час подготовки и 52 балла. Пара (2; 57) означает: 2 часа подготовки и 57 баллов.

Самопроверка

1. Дисперсия набора равна 25. Найдите стандартное отклонение.

Показать решение

σ = √25 = 5.

2. Дисперсия равна 0,81. Найдите стандартное отклонение.

Показать решение

σ = √0,81 = 0,9.

3. Чему равно стандартное отклонение набора 4, 4, 4, 4?

Показать решение

Все отклонения равны нулю, поэтому D = 0 и σ = 0.

4. Для набора 1, 3, 5, 7 дисперсия равна 5. Найдите стандартное отклонение с точностью до сотых.

Показать решение

σ = √5 ≈ 2,24.

5. У двух серий измерений дисперсии равны 0,49 и 6,25. Какая серия стабильнее? Найдите оба стандартных отклонения.

Показать решение

σ1 = √0,49 = 0,7; σ2 = √6,25 = 2,5.

Стабильнее первая серия, потому что её стандартное отклонение меньше.

6. Для пар x = 1, 2, 3, 4 и y = 10, 13, 16, 19 перечислите точки диаграммы и укажите вид связи.

Показать решение

Точки: (1; 10), (2; 13), (3; 16), (4; 19). При росте x величина y растёт, поэтому наблюдается положительная связь.

7. На диаграмме при увеличении скорости автомобиля расход времени на один и тот же путь уменьшается. Какое направление связи ожидается?

Показать решение

При росте одной величины другая уменьшается. Ожидается отрицательная связь.

8. Точки имеют координаты (1; 7), (2; 2), (3; 8), (4; 3), (5; 6). Можно ли уверенно говорить о возрастающей или убывающей связи?

Показать решение

Значения y то уменьшаются, то увеличиваются, а точки не образуют заметно направленное облако. По этим данным ясная возрастающая или убывающая связь не просматривается.
