Одинаковое среднее — разный разброс

Среднее арифметическое показывает центр числового набора, но не сообщает, насколько далеко отдельные значения находятся от этого центра.

Набор A

4, 5, 6, 7, 8

Среднее равно 6. Значения расположены близко к среднему.

Набор B

0, 3, 6, 9, 12

Среднее тоже равно 6, но значения разбросаны значительно сильнее.

Расположение значений двух наборов относительно общего среднего

1. Отклонение от среднего

Пусть среднее арифметическое набора равно x̄. Отклонением числа xi от среднего называют разность:

xi − x̄

Отклонение положительно, если число больше среднего, отрицательно, если меньше среднего, и равно нулю, если число совпадает со средним.

Важное свойство: сумма отклонений всех чисел набора от их среднего арифметического всегда равна нулю.
Пример Для набора 3, 5, 7 среднее равно 5. Отклонения: 3 − 5 = −2; 5 − 5 = 0; 7 − 5 = 2. Их сумма равна −2 + 0 + 2 = 0.

2. Как устроена дисперсия

Обычное среднее отклонений использовать нельзя: положительные и отрицательные отклонения взаимно уничтожаются. Поэтому отклонения возводят в квадрат, а затем находят их среднее арифметическое.

Дисперсия числового набора — среднее арифметическое квадратов отклонений чисел от среднего арифметического набора.
D = (x1 − x̄)2 + (x2 − x̄)2 + … + (xn − x̄)2 n
1. Найти среднее 2. Найти отклонения 3. Возвести их в квадрат 4. Сложить и разделить на n

3. Полный расчёт по таблице

Найдём дисперсию набора 2, 4, 6, 8.

x̄ = (2 + 4 + 6 + 8) : 4 = 5
Число xiОтклонение xi − x̄Квадрат отклонения
22 − 5 = −3(−3)2 = 9
44 − 5 = −1(−1)2 = 1
66 − 5 = 112 = 1
88 − 5 = 332 = 9
D = 9 + 1 + 1 + 94 = 5

Дисперсия набора равна 5. Она неотрицательна, потому что складываются квадраты.

4. Сравнение стабильности результатов

Пять результатов двух команд имеют одинаковое среднее значение 8 баллов.

Команда A: 7, 8, 8, 9, 8

Квадраты отклонений: 1, 0, 0, 1, 0. Дисперсия: 2 : 5 = 0,4.

Команда B: 4, 6, 8, 10, 12

Квадраты отклонений: 16, 4, 0, 4, 16. Дисперсия: 40 : 5 = 8.

У команды A дисперсия меньше, поэтому её результаты расположены ближе к среднему и являются более стабильными.

Самопроверка

1. Найдите среднее и отклонения чисел набора 3, 5, 7.

Показать решение

Среднее: (3 + 5 + 7) : 3 = 5. Отклонения: −2, 0, 2.

2. Найдите дисперсию набора 1, 3, 5, 7.

Показать решение

Среднее равно 4. Отклонения: −3, −1, 1, 3. Квадраты: 9, 1, 1, 9.

D = (9 + 1 + 1 + 9) : 4 = 5.

3. Чему равна дисперсия набора 6, 6, 6, 6?

Показать решение

Среднее равно 6, каждое отклонение равно нулю. Поэтому D = 0.

4. Сравните разброс наборов A = {4, 5, 6} и B = {1, 5, 9}. Среднее обоих наборов равно 5.

Показать решение

DA = (1 + 0 + 1) : 3 = 2/3.

DB = (16 + 0 + 16) : 3 = 32/3.

У набора B дисперсия больше, значит, его значения разбросаны сильнее.

5. Среднее набора 5, 7, 9, x равно 8. Найдите x, а затем дисперсию набора.

Показать решение

Сумма четырёх чисел должна быть 8 · 4 = 32, поэтому x = 32 − 21 = 11.

Отклонения: −3, −1, 1, 3. D = (9 + 1 + 1 + 9) : 4 = 5.

6. Какая последовательность может быть полным набором отклонений от среднего: а) −3, 1, 2; б) −2, 0, 3?

Показать решение

Сумма всех отклонений должна быть равна нулю. В варианте а: −3 + 1 + 2 = 0. В варианте б: −2 + 0 + 3 = 1. Подходит только вариант а.

7. Сумма квадратов отклонений шести чисел равна 24. Ученик разделил 24 на 5. В чём ошибка и чему равна дисперсия?

Показать решение

В школьном определении дисперсии сумму квадратов отклонений делят на количество чисел набора. Нужно разделить на 6: D = 24 : 6 = 4.

8. Два датчика дали результаты A = {19, 20, 20, 20, 21} и B = {17, 19, 20, 21, 23}. Какой датчик работает стабильнее?

Показать решение

Среднее обоих наборов равно 20.

DA = (1 + 0 + 0 + 0 + 1) : 5 = 0,4.

DB = (9 + 1 + 0 + 1 + 9) : 5 = 4.

Стабильнее датчик A, потому что его дисперсия меньше.
