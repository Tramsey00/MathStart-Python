1. Что показывает дерево случайного эксперимента

Каждый уровень дерева соответствует очередному этапу опыта, ветви — возможным результатам этапа, а листья — полным элементарным исходам всего эксперимента.

●Вершина

Состояние эксперимента до или после некоторого этапа.

—Ветвь

Один из возможных результатов следующего шага.

1Сумма ветвей

Вероятности всех ветвей из одной вершины должны давать 1.

2. Пример дерева: два выстрела

Вероятность попадания при каждом выстреле равна 0,7, промаха — 0,3. Считаем выстрелы независимыми.

Дерево двух последовательных испытаний

3. Два правила чтения дерева

Вдоль пути — умножаем
Вероятность одного полного исхода равна произведению вероятностей всех ветвей на пути к нему.
Подходящие пути — складываем
Если событию соответствуют несколько разных листьев, вероятности этих несовместных путей складывают.
Ровно одно попаданиеПодходят пути ПМ и МП: 0,7 · 0,3 + 0,3 · 0,7 = 0,21 + 0,21 = 0,42.

4. Алгоритм построения дерева

1Отметьте стартИзобразите начальное состояние опыта.
2Проведите ветвиДля каждого возможного результата следующего этапа.
3Подпишите вероятностиОколо ветвей; из одной вершины их сумма равна 1.
4Найдите нужные путиУмножьте вдоль каждого и сложите подходящие результаты.

5. Зависимые ветви

Дерево удобно и тогда, когда вероятности на втором этапе зависят от результата первого.

Два шара без возвращенияВ коробке 2 белых и 1 чёрный шар. Вероятность пути ББ равна 2/3 · 1/2 = 1/3. После первого белого шара в коробке остаются один белый и один чёрный, поэтому вероятности второго шага изменяются.
Проверка дерева: на каждом разветвлении сумма вероятностей равна 1, а сумма вероятностей всех листьев всего дерева также равна 1.

6. Разобранные примеры

Пример 1. Две монетыЧетыре пути ОО, ОР, РО, РР имеют вероятность 1/4 каждый. Вероятность ровно одного орла: 1/4 + 1/4 = 1/2.
Пример 2. Проверка качестваИзделие проходит первый тест с вероятностью 0,9. После успешного первого теста второй проходит с вероятностью 0,8. Вероятность пройти оба: 0,9 · 0,8 = 0,72.
Пример 3. Хотя бы одно попаданиеПроще использовать противоположное событие: P(хотя бы одно попадание) = 1 − P(два промаха) = 1 − 0,3 · 0,3 = 0,91.

Самопроверка

1. Монету бросают дважды. Сколько листьев будет у полного дерева?

Показать решение

На каждом из двух этапов по 2 исхода: 2 · 2 = 4 листа.

2. Вероятность успеха равна 0,6. Какую вероятность нужно подписать на ветви неудачи?

Показать решение

1 − 0,6 = 0,4.

3. Для двух независимых попыток P(успеха) = 0,6. Найдите вероятность двух успехов.

Показать решение

0,6 · 0,6 = 0,36.

4. Найдите вероятность ровно одного успеха в предыдущей задаче.

Показать решение

УН или НУ: 0,6 · 0,4 + 0,4 · 0,6 = 0,24 + 0,24 = 0,48.

5. Найдите вероятность хотя бы одного успеха в двух попытках.

Показать решение

1 − P(две неудачи) = 1 − 0,4 · 0,4 = 1 − 0,16 = 0,84.

6. Из урны с 3 белыми и 2 чёрными шарами вынимают два шара без возвращения. Найдите вероятность пути «белый, затем чёрный».

Показать решение

3/5 · 2/4 = 6/20 = 3/10.

7. В дереве из одной вершины выходят ветви с вероятностями 0,25; 0,35 и x. Найдите x.

Показать решение

0,25 + 0,35 + x = 1, поэтому x = 0,40.

8. Вероятности четырёх листьев дерева равны 0,18; 0,27; 0,15 и x. Найдите x.

Показать решение

Сумма листьев равна 1: x = 1 − 0,18 − 0,27 − 0,15 = 0,40.

Маршрут к ответу: прочитайте дерево целиком

Из одной вершиныСумма вероятностей всех выходящих ветвей равна 1.
По одному путиВероятности ветвей последовательно перемножаются.
По нескольким путямВероятности подходящих несовместных путей складываются.
Всё деревоСумма вероятностей всех конечных исходов равна 1.
