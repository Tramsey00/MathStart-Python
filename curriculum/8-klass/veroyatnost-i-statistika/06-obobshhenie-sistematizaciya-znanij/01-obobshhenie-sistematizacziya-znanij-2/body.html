2. Формулы и условия их применения

Формулу нельзя выбирать только по знакомым словам. Сначала проверяют условия, при которых она верна.

СитуацияЗаписьЧто обязательно проверить
Дисперсия набораD = ((x₁ − x̄)² + … + (xₙ − x̄)²) : nСначала найдено среднее x̄; делим на число элементов n.
Стандартное отклонениеσ = √DD ≥ 0; σ выражено в единицах исходной величины.
Равновозможные исходыP(A) = m : nВсе n исходов равновозможны; m из них благоприятствуют A.
Противоположное событиеP(Ā) = 1 − P(A)A и Ā вместе образуют все исходы и не пересекаются.
Несовместные событияP(A ∪ B) = P(A) + P(B)A и B не могут произойти одновременно.
Последовательные событияP(A ∩ B) = P(A) · P(B | A)Вторая вероятность берётся после наступления A.
Независимые событияP(A ∩ B) = P(A) · P(B)Наступление A не меняет вероятность B.
Дерево как графE = V − 1Граф связен и не содержит циклов.
Главная проверка: одинаковая формула может выглядеть подходящей, но быть неприменимой из-за несовместности, зависимости, неравновозможности исходов или отсутствия свойства дерева.

3. Разбор: одинаковое среднее — разное рассеивание

Сравним два набора: A = {2, 2, 4, 4} и B = {1, 3, 3, 5}. Среднее каждого набора равно 3.

НаборОтклонения от 3Квадраты отклоненийDσ
A−1, −1, 1, 11, 1, 1, 14 : 4 = 11
B−2, 0, 0, 24, 0, 0, 48 : 4 = 2√2 ≈ 1,41
У набора A меньше дисперсия и стандартное отклонение, поэтому его значения расположены ближе к среднему. Одного среднего значения для сравнения наборов недостаточно.
ДисперсияСравнивает средний квадрат отклонения от среднего.
Стандартное отклонениеВозвращает меру разброса в исходные единицы.
Диаграмма рассеиванияПоказывает расположение пар (x; y) и направление связи.

4. Разбор: множества превращаются в вероятности

В классе 20 учеников. Шахматами занимаются 12 человек, программированием — 9, а обоими направлениями — 5.

Диаграмма Эйлера для двух кружков

7только шахматы: 12 − 5
4только программирование: 9 − 5
16хотя бы один кружок: 12 + 9 − 5
4ни одного кружка: 20 − 16
Случайно выбранный ученикP(A ∪ B) = 16 : 20 = 0,8. Вероятность не посещать ни один из двух кружков равна 4 : 20 = 0,2. Эти события противоположны, поэтому 0,8 + 0,2 = 1.

5. Разбор: дерево опыта без возвращения

В коробке 3 синих и 2 оранжевых шара. Два шара извлекают подряд без возвращения.

P(СС) = 3/5 · 2/4 = 3/10
После первого синего шара в коробке остаются 2 синих шара из 4, поэтому вероятность на втором шаге изменилась.
P(ровно один синий) = 3/5
Подходят два пути: СО и ОС. Их вероятности равны 3/5 · 2/4 и 2/5 · 3/4; результаты складываются.

Вдоль одного пути

Вероятности последовательных ветвей перемножаются.

Несколько подходящих путей

Вероятности несовместных конечных путей складываются.

Связь с теорией графов: дерево опыта является связным графом без циклов. Если в нём V вершин, то число рёбер равно V − 1.

6. Как выбрать способ решения

1Определите объектЧисловой набор, множества, случайное событие, граф или многоэтапный опыт?
2Запишите данныеПеречислите значения, исходы, вершины, рёбра или элементы множеств.
3Проверьте условиеРавновозможность, несовместность, независимость, связность и отсутствие циклов.
4Выберите инструментФормула, диаграмма Эйлера, таблица, граф или дерево вероятностей.
5Проверьте ответВероятность лежит от 0 до 1, количества согласованы, единицы указаны.

7. Проверка условий перед вычислением

ДисперсияОтклонения возводятся в квадрат, затем их сумма делится на количество элементов.
МножестваЭлементы пересечения нельзя второй раз учитывать при подсчёте объединения.
Сложение вероятностейПростая сумма применяется только к несовместным событиям.
НезависимостьНезависимые события могут произойти вместе; это не то же самое, что несовместность.
Дерево вероятностейСумма вероятностей ветвей, выходящих из одной вершины, равна 1.
Формула E = V − 1Она описывает дерево, а не любой граф с подходящими числами.

Самопроверка по всему курсу

1. Для набора {1, 3, 3, 5} найдите среднее, дисперсию и стандартное отклонение.

Показать решение

Среднее: (1 + 3 + 3 + 5) : 4 = 3.

Отклонения: −2, 0, 0, 2. Квадраты: 4, 0, 0, 4.

D = (4 + 0 + 0 + 4) : 4 = 2, σ = √2 ≈ 1,41.

2. Наборы A = {2, 2, 4, 4} и B = {1, 3, 3, 5} имеют среднее 3. Какой набор менее рассеян?

Показать решение

Для A: D = (1 + 1 + 1 + 1) : 4 = 1.

Для B: D = (4 + 0 + 0 + 4) : 4 = 2.

Меньше рассеян набор A, поскольку 1 < 2.

3. Даны A = {1, 2, 3, 5} и B = {2, 4, 5}. Найдите A ∪ B, A ∩ B и A \ B.

Показать решение

A ∪ B = {1, 2, 3, 4, 5}.

A ∩ B = {2, 5}.

A \ B = {1, 3}.

4. Из 28 учеников 17 изучают испанский язык, 13 — китайский, 6 — оба языка. Сколько учеников изучают хотя бы один язык и сколько не изучают ни один?

Показать решение

Хотя бы один: 17 + 13 − 6 = 24.

Ни один: 28 − 24 = 4.

5. Бросают правильный кубик. A — выпало простое число, B — выпало число больше 4. Найдите P(A ∪ B) и P(A ∩ B).

Показать решение

A = {2, 3, 5}, B = {5, 6}.

A ∪ B = {2, 3, 5, 6}, поэтому P(A ∪ B) = 4/6 = 2/3.

A ∩ B = {5}, поэтому P(A ∩ B) = 1/6.

6. P(A) = 0,38. Событие B несовместно с A и P(B) = 0,27. Найдите P(Ā) и P(A ∪ B).

Показать решение

P(Ā) = 1 − 0,38 = 0,62.

События несовместны, поэтому P(A ∪ B) = 0,38 + 0,27 = 0,65.

7. В коробке 4 белых и 2 чёрных шара. Два шара извлекают без возвращения. Найдите вероятность получить два чёрных шара и вероятность получить ровно один чёрный.

Показать решение

Два чёрных: 2/6 · 1/5 = 1/15.

Ровно один чёрный: 2/6 · 4/5 + 4/6 · 2/5 = 8/30 + 8/30 = 16/30 = 8/15.

8. На первом шаге дерева выбора есть 4 варианта, после каждого — 3 варианта, затем после каждого — ещё 2. Сколько конечных исходов? Во всём дереве 1 + 4 + 12 + 24 = 41 вершина. Сколько в нём рёбер?

Показать решение

По правилу умножения число исходов: 4 · 3 · 2 = 24.

Дерево имеет 41 вершину, поэтому E = V − 1 = 41 − 1 = 40 рёбер.

Финальный компас курса: условие подсказывает инструмент

Дан числовой наборНайдите среднее, отклонения, D и σ; сравните разброс.
Даны группы объектовИспользуйте множества, пересечение, объединение и диаграмму Эйлера.
Исходы равновозможныПосчитайте благоприятные исходы и примените P(A) = m/n.
Опыт состоит из этаповПостройте дерево: вдоль пути умножайте, подходящие пути складывайте.
Дан граф без цикловПроверьте связность; для дерева выполняется E = V − 1.
Ответ полученПроверьте диапазон вероятности, единицы и соответствие условию.
