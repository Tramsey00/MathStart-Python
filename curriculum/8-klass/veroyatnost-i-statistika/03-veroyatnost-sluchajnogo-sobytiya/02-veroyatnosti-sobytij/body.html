Вероятности событий

1. Что показывает вероятность

Вероятность события A — число, которое характеризует возможность наступления этого события. Вероятность обозначают P(A).

Главное ограничение: для любого события A выполняется 0 ≤ P(A) ≤ 1.

P(A) = 0

Событие невозможно в рассматриваемом опыте.

P(A) = 1

Событие достоверно и происходит обязательно.

0 < P(A) < 1

Событие случайно: оно может произойти, а может не произойти.

Чем больше вероятность

Тем более возможным считают событие в данном случайном опыте.

2. Шкала вероятностей

Числа на шкале помогают сравнивать события без лишних слов.

0невозможно 0,25маловероятно 0,5равные шансы 0,75вероятно 1достоверно
СравнениеЕсли P(A) = 0,72, а P(B) = 0,35, то событие A более вероятно, чем событие B, потому что 0,72 > 0,35.

3. Вероятности элементарных событий

Каждому элементарному событию можно поставить в соответствие его вероятность. Вероятности всех возможных элементарных событий одного опыта в сумме дают 1.

p₁ + p₂ + … + pₙ = 1
Исход вращения указателяКрасныйСинийЗелёныйЖёлтый
Вероятность0,100,250,350,30
Проверка0,10 + 0,25 + 0,35 + 0,30 = 1. Таблица описывает полный набор возможных исходов.

4. Вероятность события как сумма

Если событию A благоприятствуют несколько элементарных исходов, вероятность события равна сумме вероятностей этих исходов.

P(A) = сумма вероятностей всех исходов, благоприятствующих A
Пример 1. Холодный цветПусть событие A означает «указатель остановился на синем или зелёном цвете». Тогда P(A) = 0,25 + 0,35 = 0,60.
Пример 2. Не жёлтый цветСобытию B благоприятствуют красный, синий и зелёный исходы. Поэтому P(B) = 0,10 + 0,25 + 0,35 = 0,70.
Складывать можно вероятности разных элементарных исходов одного опыта: при одном проведении опыта наступает только один из них.

5. Как оценить вероятность по частоте

Иногда точные вероятности неизвестны. Тогда опыт повторяют много раз и находят относительную частоту события.

Относительная частота = число наступлений события ÷ число опытов
ПримерКнопку случайного генератора нажали 200 раз. Число 7 появилось 46 раз. Относительная частота равна 46 ÷ 200 = 0,23. Это даёт экспериментальную оценку вероятности появления числа 7.
При небольшой серии опытов частота может заметно меняться. При длинной серии она обычно становится устойчивее и приближается к вероятности события.

6. Проверки, которые нельзя пропускать

✓Каждая вероятность находится между 0 и 1.
✓Вероятности всех элементарных исходов полного пространства в сумме дают 1.
✓Для события складываются только вероятности благоприятствующих ему исходов.
✓Относительная частота — результат наблюдений, а не гарантированное точное значение вероятности.

Самопроверка

1. Определите вид события по его вероятности: а) 0; б) 0,38; в) 1.

Показать решение

а) невозможное; б) случайное; в) достоверное.

2. Какое событие более вероятно: P(A) = 0,47 или P(B) = 0,64?

Показать решение

Более вероятно событие B, потому что 0,64 > 0,47.

3. Исходы α, β и γ имеют вероятности 0,2; 0,5 и 0,3. Событию A благоприятствуют α и γ. Найдите P(A).

Показать решение

P(A) = 0,2 + 0,3 = 0,5.

4. Опыт имеет четыре возможных исхода с вероятностями 0,15; 0,20; 0,40 и x. Найдите x.

Показать решение

x = 1 − (0,15 + 0,20 + 0,40) = 0,25.

5. Для указателя из таблицы выше найдите вероятность события «выпал красный, синий или жёлтый цвет».

Показать решение

0,10 + 0,25 + 0,30 = 0,65.

6. В 120 опытах событие A произошло 39 раз. Найдите его относительную частоту.

Показать решение

39 ÷ 120 = 0,325.

7. Ученик получил P(C) = 1,08. Может ли это быть вероятностью события?

Показать решение

Нет. Вероятность не может быть больше 1. В вычислениях или исходных данных допущена ошибка.

8. Вероятности четырёх элементарных исходов равны 0,12; 0,28; 0,31 и 0,29. Событию D благоприятствуют второй и четвёртый исходы. Найдите P(D) и проверьте полноту таблицы.

Показать решение

P(D) = 0,28 + 0,29 = 0,57.

0,12 + 0,28 + 0,31 + 0,29 = 1, значит, таблица полна.
