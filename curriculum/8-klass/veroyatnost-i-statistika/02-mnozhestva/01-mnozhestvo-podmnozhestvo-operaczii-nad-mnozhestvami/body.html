1. Что называют множеством

Множество — совокупность объектов, рассматриваемых как единое целое. Объекты, входящие в множество, называют его элементами.

Множества обычно обозначают заглавными латинскими буквами, а элементы записывают в фигурных скобках: A = {2, 4, 6, 8}.

Принадлежит множеству

Запись 4 ∈ A читают: «число 4 принадлежит множеству A».

Не принадлежит множеству

Запись 5 ∉ A означает, что числа 5 среди элементов A нет.

Порядок и повторенияМножества {1, 2, 3}, {3, 1, 2} и {1, 1, 2, 3, 3} равны: порядок элементов не важен, а одинаковый элемент записывают только один раз.

2. Как можно задать множество

Перечислением элементов

A = {2, 4, 6, 8, 10} — множество положительных чётных чисел, не превосходящих 10.

С помощью свойства

A = {x | x — положительное чётное число, x ≤ 10}. После вертикальной черты указано общее свойство элементов.

Пустое множество не содержит ни одного элемента и обозначается символом ∅. Например, множество натуральных чисел, которые одновременно меньше 2 и больше 5, пусто.

3. Подмножество

Множество B называют подмножеством множества A, если каждый элемент B принадлежит A.

B ⊆ A — множество B является подмножеством множества A.
ПримерПусть A = {1, 2, 3, 4, 5}, B = {2, 4}. Оба элемента B входят в A, поэтому B ⊆ A.

Само множество

Любое множество является подмножеством самого себя: A ⊆ A.

Пустое множество

Пустое множество считают подмножеством любого множества: ∅ ⊆ A.

Равные множества состоят из одних и тех же элементов. Иначе говоря, A = B тогда и только тогда, когда A ⊆ B и B ⊆ A.

4. Три основные операции

Пусть A = {1, 2, 3, 4, 5}, а B = {4, 5, 6, 7}.

Пересечение A ∩ B

Элементы, принадлежащие одновременно A и B: A ∩ B = {4, 5}.

Объединение A ∪ B

Все элементы, принадлежащие хотя бы одному множеству: A ∪ B = {1, 2, 3, 4, 5, 6, 7}.

Разность A ∖ B

Элементы A, которые не принадлежат B: A ∖ B = {1, 2, 3}.

Разность B ∖ A

Элементы B, которых нет в A: B ∖ A = {6, 7}.

Не перепутайте: объединение отвечает слову «или», пересечение — слову «и», а разность зависит от порядка множеств.

5. Разбор составного примера

Рассмотрим множества A = {1, 2, 3, 4, 5, 6}, B = {2, 4, 6, 8}, C = {1, 2, 8}.

Шаг 1. Найдём B ∩ CОбщими являются 2 и 8, поэтому B ∩ C = {2, 8}.
Шаг 2. Найдём A ∪ (B ∩ C)A ∪ {2, 8} = {1, 2, 3, 4, 5, 6, 8}. Элемент 2 уже был в A, поэтому второй раз его не записываем.
Шаг 3. Найдём A ∖ BИз A исключаем чётные элементы, входящие в B: A ∖ B = {1, 3, 5}.

Самопроверка

1. Пусть A = {2, 4, 6, 8}. Какие из записей верны: 6 ∈ A, 7 ∈ A, 5 ∉ A?

Показать решение

Верны записи 6 ∈ A и 5 ∉ A. Запись 7 ∈ A неверна, потому что 7 не входит в A.

2. Запишите множество различных букв слова «МАТЕМАТИКА».

Показать решение

{М, А, Т, Е, И, К}. Повторяющиеся буквы записывают один раз.

3. Является ли B = {1, 3} подмножеством A = {1, 2, 3, 4}?

Показать решение

Да. Оба элемента множества B входят в A, поэтому B ⊆ A.

4. Перечислите все подмножества множества {a, b}.

Показать решение

∅, {a}, {b}, {a, b}.

5. Для A = {1, 2, 3, 4, 5} и B = {4, 5, 6} найдите A ∩ B, A ∪ B и A ∖ B.

Показать решение

A ∩ B = {4, 5}.

A ∪ B = {1, 2, 3, 4, 5, 6}.

A ∖ B = {1, 2, 3}.

6. Запишите перечислением множество целых чисел x, для которых −2 ≤ x ≤ 2.

Показать решение

{−2, −1, 0, 1, 2}.

7. A = {2, 4, 6, 8, 10}, B = {1, 2, 3, 4, 6, 12}. Найдите A ∩ B и A ∪ B.

Показать решение

A ∩ B = {2, 4, 6}.

A ∪ B = {1, 2, 3, 4, 6, 8, 10, 12}.

8. Пусть A — множество учеников, изучающих английский язык, B — множество учеников, изучающих немецкий язык. Объясните смысл множеств A ∩ B, A ∪ B и A ∖ B.

Показать решение

A ∩ B — ученики, изучающие оба языка.

A ∪ B — ученики, изучающие хотя бы один из двух языков.

A ∖ B — ученики, изучающие английский, но не немецкий.

Быстрая проверка: язык множеств освоен

∈ и ∉Показывают, входит ли отдельный элемент в множество.
⊆Связывает два множества: каждый элемент подмножества должен входить в исходное множество.
∩, ∪, ∖Обозначают соответственно общую часть, совокупность всех элементов и разность множеств.
