Что показывает функция y = x²

Функция y = x² каждому действительному значению x ставит в соответствие квадрат этого числа. Поэтому её значения никогда не бывают отрицательными.

Противоположные значения аргумента имеют одинаковые квадраты: (−x)² = x².

1. График функции y = x²

График функции y = x² называется параболой. Он проходит через начало координат, расположен не ниже оси Ox и симметричен относительно оси Oy.

Статический график базовой функции y = x². Полный интерактивный график с коэффициентами будет размещён в теме 6.7.
Название графика Парабола.
Вершина Точка O(0; 0).
Ось симметрии Ось Oy, то есть прямая x = 0.
Направление ветвей Обе ветви направлены вверх.
Пересечение с осями Единственная общая точка с Ox и Oy — O(0; 0).

Пример 1. Строим опорные точки

При x = −2 получаем y = (−2)² = 4.
При x = −1 получаем y = 1.
При x = 0 получаем y = 0.
При x = 1 получаем y = 1.
При x = 2 получаем y = 4.
Точки соединяют одной плавной кривой без изломов.

2. Основные свойства функции

Область определения D(f) = R. Возвести в квадрат можно любое действительное число.
Множество значений E(f) = [0; +∞), потому что x² ≥ 0 при любом x.
Нуль функции Единственный нуль — x = 0, так как x² = 0 только при x = 0.
Знак функции f(x) > 0 при x ≠ 0 и f(0) = 0.
Наименьшее значение ymin = 0 и достигается при x = 0.
Наибольшее значение На всей числовой прямой наибольшего значения нет.

3. Чётность и симметрия

Подставим вместо x противоположное число −x: f(−x) = (−x)² = x² = f(x). Поэтому функция y = x² является чётной.

Точка (x; x²) Например, точка (2; 4) принадлежит правой ветви параболы.
⇔
Точка (−x; x²) Симметричная точка (−2; 4) принадлежит левой ветви.

Пример 2. Значения в противоположных точках

f(−3) = (−3)² = 9.
f(3) = 3² = 9.
Следовательно, f(−3) = f(3).

4. Возрастание и убывание

На промежутке (−∞; 0] При движении слева направо значения функции уменьшаются: левая ветвь параболы опускается к вершине.
На промежутке [0; +∞) При движении слева направо значения функции увеличиваются: правая ветвь поднимается от вершины.

Пример 3. Сравнение значений функции

Сравним f(−4) и f(3).
f(−4) = 16, f(3) = 9.
Ответ: f(−4) > f(3).
Для функции y = x² удобно сравнивать модули аргументов: если |x₁| > |x₂|, то x₁² > x₂².

5. Как читать график

Найти y по известному x От значения x поднимаются до параболы и затем переходят к оси Oy.
Найти x по известному y Горизонтальная линия y = m при m > 0 обычно пересекает параболу в двух точках.
Проверить точку Для точки (a; b) проверяют равенство b = a².

Пример 4. Принадлежит ли точка графику

Проверим точку A(−3; 9).
(−3)² = 9.
Точка A принадлежит графику.
Для точки B(2; −4): 2² = 4 ≠ −4.
Точка B не принадлежит графику.

Пример 5. Значения аргумента при y = 4

Нужно решить x² = 4.
x = −2 или x = 2.
На графике это точки (−2; 4) и (2; 4).

6. Наибольшее и наименьшее значения на промежутке

На ограниченном промежутке значения функции сравнивают в вершине параболы и на концах промежутка. Если промежуток содержит нуль, наименьшее значение равно нулю.

Пример 6. Промежуток [−3; 1]

Промежуток содержит x = 0, поэтому ymin = 0.
На концах: f(−3) = 9, f(1) = 1.
Наибольшее значение равно 9 и достигается при x = −3.
Ответ: ymin = 0, ymax = 9.

Как аккуратно построить параболу

1 Отметьте вершину Для y = x² это точка O(0; 0).
2 Проведите ось симметрии Ею является ось Oy.
3 Поставьте пары точек Например, (±1; 1), (±2; 4), (±3; 9).
4 Соедините плавно Обе ветви должны быть симметричными и направленными вверх.

7. Самопроверка

Задание 1. Найдите f(−4), если f(x) = x².

Показать решение
f(−4) = (−4)² = 16.

Ответ: 16.

Задание 2. Принадлежит ли точка A(3; 9) графику y = x²?

Показать решение
3² = 9.

Ответ: да, принадлежит.

Задание 3. Принадлежит ли точка B(−2; −4) графику y = x²?

Показать решение
(−2)² = 4, а не −4.

Ответ: нет, не принадлежит.

Задание 4. Укажите область определения функции y = x².

Показать ответ
Возвести в квадрат можно любое действительное число.

Ответ: R.

Задание 5. Укажите множество значений функции y = x².

Показать ответ
Квадрат действительного числа неотрицателен.

Ответ: [0; +∞).

Задание 6. Сравните f(−5) и f(4), если f(x) = x².

Показать решение
f(−5) = 25, f(4) = 16.

Ответ: f(−5) > f(4).

Задание 7. При каких значениях x функция y = x² принимает значение 9?

Показать решение
x² = 9.
x = −3 или x = 3.

Ответ: −3; 3.

Задание 8. На каком промежутке функция y = x² возрастает?

Показать ответ
Правая ветвь параболы поднимается при движении вправо от нуля.

Ответ: [0; +∞).

Задание 9. Найдите наименьшее значение функции y = x² на промежутке [−3; 2].

Показать решение
Промежуток содержит x = 0.
f(0) = 0.

Ответ: 0.

Задание 10. Найдите наибольшее значение функции y = x² на промежутке [−2; 1].

Показать решение
f(−2) = 4, f(1) = 1. Наибольшее значение достигается при x = −2.

Ответ: 4.

8. Паспорт функции y = x²

График Парабола с вершиной O(0; 0), ветви направлены вверх.
Области D(f) = R, E(f) = [0; +∞).
Симметрия Функция чётная, ось симметрии — Oy.
Изменение Убывает на (−∞; 0] и возрастает на [0; +∞).
Самое важное:
x² ≥ 0;
(−x)² = x²;
вершина параболы — O(0; 0);
чем больше |x|, тем больше значение x².
