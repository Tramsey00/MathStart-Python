Главная идея графического метода

Пусть требуется решить уравнение f(x) = g(x). Построим в одной системе координат графики функций y = f(x) и y = g(x). В точке их пересечения значения функций равны.

f(x) = g(x)  ⇔  графики y = f(x) и y = g(x) имеют общую точку Решениями уравнения являются абсциссы всех точек пересечения графиков.
Для ответа берут координату x, а не координату y точки пересечения.

1. Алгоритм графического решения

1 Разделите уравнение на две части Обозначьте левую часть как f(x), правую — как g(x).
2 Постройте оба графика Используйте одну систему координат и одинаковый масштаб.
3 Найдите точки пересечения Отметьте все общие точки двух графиков.
4 Запишите абсциссы Координаты x точек пересечения являются решениями уравнения.

Пример 1. Уравнение x² = x + 2

Графики y = x² и y = x + 2
Графики пересекаются в точках A(−1; 1) и B(2; 4).
Абсциссы точек пересечения: x = −1 и x = 2.
Проверка: (−1)² = −1 + 2 = 1; 2² = 2 + 2 = 4.
Ответ: −1; 2.

2. Количество решений по взаимному расположению графиков

2 Две точки пересечения Уравнение имеет два различных решения.
1 Одна общая точка Уравнение имеет одно решение. Прямая может касаться параболы.
0 Графики не пересекаются Уравнение не имеет действительных решений.
Одно решение: x² = 2x − 1
Графики имеют единственную общую точку A(1; 1), поэтому x = 1.
Нет решений: x² = −1
Парабола расположена не ниже оси Ox, а прямая y = −1 — ниже неё.

Пример 2. Единственное решение

x² = 2x − 1.
Графики y = x² и y = 2x − 1 касаются в точке (1; 1).
Ответ: 1.

Пример 3. Решений нет

x² = −1.
График y = x² не пересекает прямую y = −1.
Ответ: действительных решений нет.

3. Уравнение можно разделить на функции по-разному

Одно и то же уравнение иногда можно представить несколькими парами функций. Лучше выбирать тот вариант, в котором оба графика строятся проще.

Уравнение Первый вариант Второй вариант
x² − x − 2 = 0 y = x² и y = x + 2 y = x² − x − 2 и y = 0
x² + 1 = 3x y = x² + 1 и y = 3x y = x² − 3x + 1 и y = 0
x² = 4 y = x² и y = 4 y = x² − 4 и y = 0

Пример 4. Выбираем простые графики

Для уравнения x² − x − 2 = 0 удобно перенести −x − 2 вправо:
x² = x + 2.
Тогда строятся базовая парабола y = x² и прямая y = x + 2.
Решения: −1 и 2.

4. Приближённые решения

Если точные координаты пересечения трудно определить, графический метод позволяет получить приближённые значения. Точность зависит от масштаба и аккуратности построения.

Графическое решение x² = 2
Абсциссы точек пересечения приблизительно равны −1,41 и 1,41.
Как уточнять результат Сначала находят промежуток между соседними целыми числами, затем увеличивают масштаб и читают координату с точностью до десятых или сотых. Для x² = 2 получаем x ≈ −1,41 и x ≈ 1,41.

Пример 5. Сравнение точного и приближённого ответа

Точное решение: x = ± 2 .
По графику: x ≈ −1,41 и x ≈ 1,41.
Графический ответ является приближённым, если координаты не читаются точно.

5. Проверка графического ответа вычислениями

График помогает увидеть количество и примерное расположение корней. Если требуется точный ответ, найденные значения полезно проверить алгебраически или подстановкой.

Пример 6. График и квадратное уравнение дают одинаковый результат

x² = 3x − 2.
По графику y = x² и y = 3x − 2 видны пересечения при x = 1 и x = 2.
Алгебраическая проверка: x² − 3x + 2 = 0.
(x − 1)(x − 2) = 0.
Ответ: 1; 2.

6. Типичные ошибки

Записывают ординаты точек В уравнении ищется x, поэтому ответом являются абсциссы, а не значения y.
Правильно Для точки пересечения (2; 4) решением уравнения является x = 2.
Используют разные масштабы Искажённый масштаб по осям может изменить визуальное положение графиков.
Правильно Оба графика строятся в одной системе координат с единым масштабом по каждой оси.
Округляют слишком рано Грубое построение может дать неточный корень.
Правильно Увеличьте масштаб и укажите, что найденное значение является приближённым.

8. Графический метод за один взгляд

Два графика Уравнение f(x) = g(x) заменяется графиками y = f(x) и y = g(x).
Общие точки Каждой точке пересечения соответствует одно решение.
Нужна координата x В ответ записывают абсциссы, а не ординаты точек.
Точность ограничена Неочевидные координаты читаются приближённо и проверяются вычислениями.
Количество решений равно количеству точек пересечения:
две точки — два решения;
одна точка — одно решение;
нет общих точек — нет действительных решений.
