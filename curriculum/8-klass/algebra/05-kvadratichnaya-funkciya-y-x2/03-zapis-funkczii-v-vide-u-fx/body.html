Что означает буква f

Запись y = f(x) означает, что значение переменной y зависит от выбранного значения x по некоторому правилу. Буквой f обозначают само правило соответствия.

y = f(x) Читается: «игрек равен эф от икс» или «значение функции f в точке x».
x Аргумент Независимая переменная, значение которой выбирают.
f Функция Правило, по которому аргументу ставят в соответствие значение.
f(x) Значение функции Результат применения правила к выбранному значению x.
Запись f(x) не означает произведение f · x. Это единое обозначение значения функции при аргументе x.

1. Как вычислить значение функции

Чтобы найти f(a), вместо каждого x в формуле подставляют число a и выполняют действия в правильном порядке.

1 Запишите формулу Например, f(x) = 2x² − 3x + 1.
2 Замените x числом Для f(2) вместо каждого x подставьте 2.
3 Используйте скобки Особенно важно заключать в скобки отрицательные числа и дроби.
4 Выполните вычисления Сначала степени, затем умножение, сложение и вычитание.

Пример 1. Положительный аргумент

f(x) = 2x² − 3x + 1.
f(2) = 2 · 2² − 3 · 2 + 1.
f(2) = 8 − 6 + 1 = 3.
Ответ: f(2) = 3.

Пример 2. Отрицательный аргумент

g(x) = x² + 4x − 5.
g(−3) = (−3)² + 4 · (−3) − 5.
g(−3) = 9 − 12 − 5 = −8.
Ответ: g(−3) = −8.

2. Функция как «машина»

Функцию удобно представлять как правило обработки числа: на вход поступает аргумент, затем выполняются действия, и на выходе получается значение функции.

Вход x = 3
→
Правило f(x) = 2x − 1
→
Выход f(3) = 5

Пример 3. Составляем таблицу значений

x −2 −1 0 1 2
f(x) = 2x − 1 −5 −3 −1 1 3
Например, при x = −2: f(−2) = 2 · (−2) − 1 = −5.
При x = 2: f(2) = 2 · 2 − 1 = 3.

3. Область определения функции

Область определения — множество всех значений аргумента x, при которых формула функции имеет смысл.

f(x) = x² − 3x + 1 Многочлен Допустимы все действительные числа: D(f) = R.
g(x) = 1 x−4 Переменная в знаменателе Знаменатель не равен нулю: x ≠ 4.
h(x) = x+2 Квадратный корень Подкоренное выражение неотрицательно: x ≥ −2.

Пример 4. Значение существует не при каждом x

g(x) = 5 x−3 .
g(5) = 52 .
g(3) не существует, потому что знаменатель равен нулю.
Область определения: все x, кроме 3.

4. Нули функции

Нулём функции называют значение аргумента, при котором значение функции равно нулю.

Функциональная запись f(x) = 0
⇔
Графический смысл Абсцисса точки пересечения графика функции с осью Ox.

Пример 5. Находим нули квадратного трёхчлена

f(x) = x² − 5x + 6.
Ищем значения, при которых f(x) = 0:
x² − 5x + 6 = 0.
(x − 2)(x − 3) = 0.
Нули функции: 2 и 3.

5. Что можно узнать из записи f(a) = b

Равенство f(a) = b означает, что при аргументе a значение функции равно b. На графике этому соответствует точка (a; b).

f(2) = 7 При x = 2 значение функции равно 7.
f(0) = −3 График пересекает ось Oy в точке (0; −3).
f(5) = 0 Число 5 является нулём функции.
f(−a) = f(a) Такая запись характерна для чётной функции.

Пример 6. Находим параметр по значению функции

Условие f(x) = kx + 2 и f(3) = 11. Найдите k.
f(3) = 3k + 2.
3k + 2 = 11.
3k = 9, поэтому k = 3.
Ответ: 3.

6. Типичные ошибки в функциональной записи

Ошибка Почему неверно Как правильно
Считают f(x) произведением f · x Буква f обозначает правило зависимости. Читать «значение функции f в точке x».
При f(−2) пишут −2² Без скобок знак минус не возводится в квадрат. Подставлять (−2) вместо каждого x.
Путают f(2) и f(x) = 2 В первом случае известен аргумент, во втором — значение функции. f(2): подставить x = 2; f(x) = 2: решить уравнение.
Не проверяют область определения Формула может не иметь смысла при некоторых x. Проверять знаменатели и подкоренные выражения.
Записи f(2) и f(x) = 2 отвечают на разные вопросы: первая просит найти значение функции, вторая — найти аргументы, при которых значение равно 2.

7. Самопроверка

Задание 1. Найдите f(3), если f(x) = 2x + 5.

Показать решение
f(3) = 2 · 3 + 5 = 11.

Ответ: 11.

Задание 2. Найдите g(−2), если g(x) = x² − 3x + 1.

Показать решение
g(−2) = (−2)² − 3 · (−2) + 1.
g(−2) = 4 + 6 + 1 = 11.

Ответ: 11.

Задание 3. Найдите h(0), если h(x) = 4 − x².

Показать решение
h(0) = 4 − 0² = 4.

Ответ: 4.

Задание 4. Найдите область определения функции f(x) = 7/(x + 2).

Показать решение
Знаменатель не должен быть равен нулю: x + 2 ≠ 0.

Ответ: x ≠ −2.

Задание 5. Найдите область определения функции f(x) = x−5 .

Показать решение
x − 5 ≥ 0.

Ответ: x ≥ 5.

Задание 6. Найдите нули функции f(x) = x² − 9.

Показать решение
x² − 9 = 0.
(x − 3)(x + 3) = 0.

Ответ: −3; 3.

Задание 7. Решите уравнение f(x) = 5, если f(x) = 2x − 1.

Показать решение
2x − 1 = 5.
2x = 6, поэтому x = 3.

Ответ: 3.

Задание 8. Известно, что f(4) = −2. Какая точка графика функции известна?

Показать ответ
Аргумент равен 4, значение функции равно −2.

Ответ: точка (4; −2).

Задание 9. Функция задана формулой f(x) = ax + 1. Известно, что f(2) = 9. Найдите a.

Показать решение
2a + 1 = 9.
2a = 8, поэтому a = 4.

Ответ: 4.

Задание 10. Вычислите f(−1) + f(1), если f(x) = x² + 2x.

Показать решение
f(−1) = (−1)² + 2 · (−1) = −1.
f(1) = 1² + 2 · 1 = 3.
f(−1) + f(1) = 2.

Ответ: 2.

8. Шпаргалка по функциональной записи

f(a) Подставить число a вместо каждого x и вычислить результат.
f(x) = b Решить уравнение и найти аргументы, при которых значение равно b.
f(a) = b График функции проходит через точку (a; b).
f(x) = 0 Найти нули функции — абсциссы точек пересечения с осью Ox.
Запомните:
x — аргумент;
f(x) — значение функции;
f(a) получают подстановкой x = a;
запись f(a) = b соответствует точке (a; b).
