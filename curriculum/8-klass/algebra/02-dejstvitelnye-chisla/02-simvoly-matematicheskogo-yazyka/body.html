Зачем нужен математический язык

Математический язык позволяет коротко и однозначно записывать мысли, для которых обычными словами потребовалось бы несколько предложений. Каждый символ имеет точное значение, поэтому его нельзя заменять похожим знаком без проверки смысла.

Краткость

Запись x ∈ Z короче фразы «число x является целым».

Точность

Знаки ∈ и ⊂ выглядят похоже по смыслу, но связывают разные объекты.

Логика

Символы ⇒ и ⇔ показывают, в каком направлении связаны утверждения.

Универсальность

Формулы и обозначения одинаково читаются в разных задачах и разделах математики.

1. Знаки равенства и сравнения

= Равно Левая и правая части имеют одно значение.
≠ Не равно Значения левой и правой частей различаются.
< Меньше Левая величина меньше правой.
> Больше Левая величина больше правой.
≤ Меньше или равно Допускаются оба случая: меньше либо равно.
≥ Больше или равно Допускаются оба случая: больше либо равно.

Пример 1. Чтение записей

7 ≠ 5 — «семь не равно пяти».
−3 < 1 — «минус три меньше единицы».
x ≥ 4 — «x больше или равен четырём».
a ≤ b — «a меньше или равно b».
У знаков < и > широкая сторона всегда обращена к большему числу, а острый угол — к меньшему.

2. Принадлежность элемента множеству

Символы ∈ и ∉ связывают отдельный объект и множество. Слева записывают элемент, справа — множество.

a ∈ A — «элемент a принадлежит множеству A».

a ∉ A — «элемент a не принадлежит множеству A».

Пример 2. Верные и неверные записи

Запись Оценка Чтение
8 ∈ N Верно Число 8 является натуральным.
−8 ∈ N Неверно Отрицательное число не принадлежит N.
−8 ∈ Z Верно Число −8 является целым.
3 5 ∈ Q Верно Обыкновенная дробь является рациональным числом.
Нельзя писать N ∈ Z, если речь идёт о связи двух множеств. Множество N не является отдельным целым числом.

3. Включение одного множества в другое

Символы ⊂ и ⊆ связывают два множества. Они показывают, что каждый элемент первого множества входит во второе.

⊂ Строгое включение A ⊂ B: все элементы A входят в B, но множества не равны.
⊆ Включение с равенством A ⊆ B: множество A может совпадать с B.
⊄ Не является подмножеством В A существует хотя бы один элемент, которого нет в B.

Пример 3. Различие между ∈ и ⊂

5 ∈ N — число 5 является элементом множества N.
N ⊂ Z — множество натуральных чисел входит в множество целых чисел.
5 ⊂ N — неверная запись: число 5 не является множеством.
N ∈ Z — неверная запись: N не является отдельным целым числом.
Удобная проверка:

слева число, справа множество → используйте ∈ или ∉;
слева множество, справа множество → используйте ⊂, ⊆ или ⊄.

4. Объединение, пересечение и пустое множество

∪ Объединение Все элементы, которые принадлежат хотя бы одному из множеств.
∩ Пересечение Только элементы, общие для обоих множеств.
∅ Пустое множество Множество, в котором нет ни одного элемента.

Пример 4. Действия с конечными множествами

Дано A = {1, 2, 3, 4}, B = {3, 4, 5}.
A ∪ B = {1, 2, 3, 4, 5}.
A ∩ B = {3, 4}.
Если C = {7, 8}, то A ∩ C = ∅.

Пример 5. Действия с числовыми множествами

N ∩ Z = N, потому что каждое натуральное число является целым.
N ∪ Z = Z, потому что множество Z уже содержит все элементы N.
Z ∩ Q = Z, а Z ∪ Q = Q.

5. Следование, равносильность и логические обозначения

⇒ Следует Из первого утверждения можно получить второе.
⇔ Равносильно Оба утверждения следуют друг из друга.
∀ Для любого Утверждение выполняется для каждого допустимого элемента.
∃ Существует Найдётся хотя бы один элемент с указанным свойством.

Пример 6. Следование не всегда можно обратить

x = 3 ⇒ x2 = 9 — верно.
x2 = 9 ⇒ x = 3 — неверно, потому что подходит также x = −3.
x − 5 = 0 ⇔ x = 5 — равносильные утверждения.
∀n ∈ N: n + 1 ∈ N — для любого натурального n число n + 1 натурально.
∃x ∈ Z: x2 = 16 — существует целое число, квадрат которого равен 16.
Символ ⇔ сильнее символа ⇒. Равносильность требует, чтобы связь работала в обоих направлениях.

6. Перевод с обычного языка на математический

Обычная фраза
Число −6 является целым, но не является натуральным.
→
Математическая запись
−6 ∈ Z, −6 ∉ N.
Обычная фраза
Все натуральные числа являются рациональными.
→
Математическая запись
N ⊂ Q.
Обычная фраза
Множества A и B не имеют общих элементов.
→
Математическая запись
A ∩ B = ∅.
Распространённая ошибка Почему неверно Правильная запись
4 ⊂ N Число 4 — элемент, а не множество. 4 ∈ N
N ∈ Z N — множество, а не целое число. N ⊂ Z
A ∪ B = общие элементы Общие элементы образуют пересечение. A ∩ B
x² = 9 ⇔ x = 3 Потерян корень x = −3. x² = 9 ⇔ x = 3 или x = −3

7. Самопроверка

Задание 1. Прочитайте запись: −7 ∈ Z.

Показать ответ
Число −7 принадлежит множеству целых чисел.

Ответ: «минус семь является целым числом».

Задание 2. Выберите правильный символ: число 2 3 ___ Q.

Показать ответ
Дробь 2/3 является рациональным числом.

Ответ: 2 3 ∈ Q.

Задание 3. Исправьте запись: N ∈ Z.

Показать ответ
N и Z — множества, поэтому нужен знак включения.

Ответ: N ⊂ Z.

Задание 4. Даны A = {1, 2, 3} и B = {3, 4, 5}. Найдите A ∩ B.

Показать решение
Общим для двух множеств является только число 3.

Ответ: A ∩ B = {3}.

Задание 5. Для тех же множеств A = {1, 2, 3} и B = {3, 4, 5} найдите A ∪ B.

Показать решение
В объединение входят все элементы без повторений.

Ответ: A ∪ B = {1, 2, 3, 4, 5}.

Задание 6. Верна ли запись N ∩ Z = N?

Показать решение
Да. Все натуральные числа являются целыми, поэтому общая часть множеств N и Z совпадает с N.

Ответ: запись верна.

Задание 7. Какой символ нужно поставить: x = 4 ___ x² = 16?

Показать решение
Из x = 4 следует x² = 16. Обратное утверждение неверно, потому что x может быть равно −4.

Ответ: x = 4 ⇒ x² = 16.

Задание 8. Какой символ нужно поставить: x + 3 = 0 ___ x = −3?

Показать решение
Оба утверждения следуют друг из друга.

Ответ: x + 3 = 0 ⇔ x = −3.

Задание 9. Запишите символами: «число 0 принадлежит Z и Q, но не принадлежит N» в принятом на сайте соглашении.

Показать ответ
Ответ: 0 ∈ Z, 0 ∈ Q, 0 ∉ N.

Задание 10. Найдите ошибку в утверждении: «A ∪ B содержит только элементы, принадлежащие одновременно A и B».

Показать ответ
Элементы, принадлежащие одновременно A и B, образуют пересечение A ∩ B. Объединение A ∪ B содержит элементы хотя бы одного из множеств.

Ответ: вместо ∪ должен использоваться знак ∩.

8. Прочитай запись за четыре шага

Перед чтением формулы определите, что находится слева и справа от символа. Это почти всегда подсказывает его значение.

1 Найдите главный символ Именно он задаёт смысл всей записи.
2 Определите объекты Это числа, выражения, элементы или множества?
3 Прочитайте слева направо Не меняйте местами элемент и множество.
4 Проверьте смысл Запись должна быть верной не только по виду, но и по содержанию.
Число ∈ множество; множество ⊂ множество; общая часть — ∩; все элементы — ∪; односторонняя связь — ⇒; связь в обе стороны — ⇔.

В следующей теме введём понятие квадратного корня, разберём арифметический квадратный корень и условия, при которых выражение √a имеет смысл.
