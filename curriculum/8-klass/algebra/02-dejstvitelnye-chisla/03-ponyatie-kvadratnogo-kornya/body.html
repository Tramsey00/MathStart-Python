Понятие квадратного корня

Разберём, какие числа называют квадратными корнями, чем квадратный корень отличается от арифметического квадратного корня, когда выражение √a имеет смысл и почему запись √9 равна 3, а не ±3.

Откуда появляется квадратный корень

S = 49
a = 7 a = 7

Площадь квадрата вычисляется по формуле S = a². Если площадь известна, а сторону нужно найти, возникает обратная задача: какое неотрицательное число нужно возвести в квадрат, чтобы получить S?

Если S = 49, то a² = 49. Поскольку длина стороны неотрицательна, получаем a = 7.

Это записывают так: √49 = 7.

1. Квадратные корни из числа

Квадратным корнем из числа a называют число b, квадрат которого равен a.

b — квадратный корень из a, если b² = a.

Пример 1. Два квадратных корня

5² = 25 и (−5)² = 25.
Следовательно, числа 5 и −5 являются квадратными корнями из 25.
a > 0 У положительного числа два квадратных корня: положительный и противоположный ему отрицательный.
a = 0 У числа 0 один квадратный корень: 0, потому что 0² = 0.
a < 0 В множестве действительных чисел квадратных корней нет: квадрат любого действительного числа неотрицателен.

2. Арифметический квадратный корень

Чтобы из двух противоположных квадратных корней выбирать одно число, используют понятие арифметического квадратного корня.

Арифметическим квадратным корнем из неотрицательного числа a называют неотрицательное число b, квадрат которого равен a.

√a = b означает одновременно:
b ≥ 0 и b² = a.

Пример 2. Почему √36 = 6

Числа 6 и −6 являются квадратными корнями из 36.
Но арифметический квадратный корень должен быть неотрицательным.
Поэтому √36 = 6.
Запись √36 = ±6 неверна.
Знак «±» появляется при перечислении двух решений уравнения x² = a, но не является частью значения арифметического квадратного корня.

3. Знак корня и подкоренное выражение

√ Знак радикала Символ, обозначающий извлечение арифметического квадратного корня.
a Подкоренное выражение Число или выражение, записанное под знаком корня.
√a Значение корня Неотрицательное число, квадрат которого равен a.
В множестве действительных чисел выражение √a имеет смысл только при a ≥ 0.

Пример 3. Допустимые подкоренные выражения

Выражение Имеет смысл? Значение или объяснение
√49 Да √49 = 7
√0 Да √0 = 0
√0,04 Да √0,04 = 0,2
√(−9) Нет Квадрат действительного числа не может быть равен −9.

4. Извлечение квадратного корня

Найти значение √a — значит найти неотрицательное число, квадрат которого равен a. Это действие называют извлечением арифметического квадратного корня.

Чтобы проверить равенство √a = b, убедитесь, что:

1. b ≥ 0;
2. b² = a.

Пример 4. Корень из обыкновенной дроби

Вычислить √49 √64 .
√49 = 7, потому что 7 ≥ 0 и 7² = 49.
√64 = 8, потому что 8 ≥ 0 и 8² = 64.
√49 √64 = 7 8 .
Ответ: 7 8 .

Пример 5. Корень из десятичной дроби

Вычислить √1,44.
1,2² = 1,44 и 1,2 ≥ 0.
Поэтому √1,44 = 1,2.
Квадратные корни легко извлекаются точно, когда подкоренное число является квадратом рационального числа. В следующей теме появятся числа, корни из которых нельзя представить конечной или периодической дробью.

5. Уравнение x² = a

Понятие квадратного корня связано с решением простейших квадратных уравнений.

Значение a Количество действительных решений Решение уравнения x² = a
a > 0 Два x = √a или x = −√a
a = 0 Одно x = 0
a < 0 Нет Действительных решений нет

Пример 6. Решение простейшего уравнения

Решить x² = 81.
√81 = 9.
Положительное число 81 имеет два квадратных корня: 9 и −9.
x = 9 или x = −9.
Ответ: −9; 9.

6. Не путайте похожие записи

Запись Что она означает Результат
√25 Арифметический квадратный корень 5
Квадратные корни из 25 Все числа, квадрат которых равен 25 −5 и 5
x² = 25 Уравнение x = −5 или x = 5
−√25 Число, противоположное арифметическому корню −5
Самая частая ошибка — записывать √a = ±b. Знак корня √ уже обозначает неотрицательное значение.

7. Самопроверка

Задание 1. Вычислите √49.

Показать решение
7 ≥ 0 и 7² = 49.

Ответ: 7.

Задание 2. Назовите все квадратные корни из 36.

Показать решение
6² = 36 и (−6)² = 36.

Ответ: −6 и 6.

Задание 3. Вычислите √0,81.

Показать решение
0,9 ≥ 0 и 0,9² = 0,81.

Ответ: 0,9.

Задание 4. Имеет ли смысл выражение √(−4) в множестве действительных чисел?

Показать ответ
Нет. Квадрат любого действительного числа неотрицателен.

Ответ: не имеет смысла.

Задание 5. Решите уравнение x² = 25.

Показать решение
√25 = 5. Положительное число имеет два противоположных квадратных корня.

Ответ: x = −5 или x = 5.

Задание 6. Является ли число −7 квадратным корнем из 49? Является ли оно арифметическим квадратным корнем?

Показать решение
(−7)² = 49, поэтому −7 является квадратным корнем из 49. Но арифметический квадратный корень неотрицателен.

Ответ: является квадратным корнем, но не является арифметическим.

Задание 7. Вычислите: √ 16 81 .

Показать решение
Число 4 9 неотрицательно, а его квадрат равен 16 81 .

Ответ: 4 9 .

Задание 8. Площадь квадрата равна 121 см². Найдите длину его стороны.

Показать решение
Длина стороны неотрицательна: a = √121 = 11.

Ответ: 11 см.

Задание 9. Сравните числа √64 и −√64.

Показать решение
√64 = 8, а −√64 = −8.

Ответ: √64 > −√64.

Задание 10. Найдите a, если √a = 12.

Показать решение
Возведём обе части равенства в квадрат: a = 12² = 144.

Ответ: 144.

8. Не перепутай две разные задачи

Вычислить √a Нужно назвать одно неотрицательное число. Например, √49 = 7.
≠
Решить x² = a При a > 0 нужно назвать два противоположных корня. Например, x² = 49 означает x = −7 или x = 7.
√a всегда неотрицателен;
√a существует в действительных числах при a ≥ 0;
если a > 0, то уравнение x² = a имеет решения x = ±√a.

В следующей теме выясним, почему значения √2, √3 и некоторых других корней нельзя представить обыкновенной дробью, и введём понятие иррационального числа.
