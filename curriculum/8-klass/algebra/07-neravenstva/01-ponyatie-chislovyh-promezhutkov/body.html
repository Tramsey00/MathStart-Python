1. Что называют числовым промежутком

Числовой промежуток — это множество действительных чисел, расположенных между указанными границами или по одну сторону от заданного числа. Промежуток можно описать неравенством, записать с помощью скобок и изобразить на координатной прямой.

Если a < b, то запись a ≤ x ≤ b означает: число x находится между a и b и может совпадать с обеими границами. В интервальной форме это записывают так: x ∈ [a; b].
Граница включена Используют квадратную скобку и закрашенную точку: x ≥ a, x ≤ b.
Граница не включена Используют круглую скобку и пустую точку: x > a, x < b.

Пример 1. Отрезок

−2 ≤ x ≤ 5.
Обе границы входят в множество.
Интервальная запись: x ∈ [−2; 5].

2. Круглые и квадратные скобки

[   ] Квадратные скобки Соответствующая конечная граница входит в промежуток.
(   ) Круглые скобки Соответствующая граница не входит в промежуток.
±∞ Бесконечность Около бесконечности всегда ставят круглую скобку.
Символы +∞ и −∞ не обозначают конкретные числа. Поэтому бесконечность нельзя «включить» в промежуток и рядом с ней не используют квадратную скобку.

Пример 2. Полуинтервал

1 < x ≤ 4.
Число 1 не входит, а число 4 входит.
Ответ: x ∈ (1; 4].

3. Основные виды промежутков

[a; b]

Отрезок: a ≤ x ≤ b. Обе границы включены.

(a; b)

Интервал: a < x < b. Обе границы исключены.

[a; b)

Полуинтервал: a ≤ x < b.

(a; b]

Полуинтервал: a < x ≤ b.

Пример 3. Читаем запись промежутка

x ∈ [−3; 2).
Левая граница −3 входит, правая граница 2 не входит.
Неравенство: −3 ≤ x < 2.

4. Числовые лучи и бесконечные промежутки

Неравенство Промежуток Граница Направление
x ≥ a [a; +∞) a включено вправо
x > a (a; +∞) a исключено вправо
x ≤ a (−∞; a] a включено влево
x < a (−∞; a) a исключено влево

Пример 4. Луч вправо

x ≥ −3.
Число −3 включено, поэтому слева ставим квадратную скобку.
Промежуток продолжается вправо без ограничения.
Ответ: x ∈ [−3; +∞).

Пример 5. Луч влево

x < 2.
Число 2 не включено, поэтому около 2 ставим круглую скобку.
Ответ: x ∈ (−∞; 2).

5. Как переводить неравенство в промежуток

1 Найдите границы Определите левое и правое конечные числа.
2 Проверьте строгие знаки Знаки < и > требуют круглых скобок.
3 Проверьте нестрогие знаки Знаки ≤ и ≥ включают конечную границу.
4 Укажите бесконечность Около ±∞ всегда оставляйте круглую скобку.

Пример 6. Двойное неравенство

−5 < x < 7.
Обе границы исключены.
Ответ: x ∈ (−5; 7).

Пример 7. Вся числовая прямая

Если переменная может принимать любое действительное значение, то x ∈ R.
В интервальной записи: x ∈ (−∞; +∞).

6. Принадлежит ли число промежутку

Чтобы проверить принадлежность числа, достаточно сравнить его с границами и отдельно проверить, включены ли сами границы.

Проверка для промежутка (−2; 5] Число −2 не принадлежит промежутку, потому что левая граница исключена. Число 0 принадлежит, так как −2 < 0 ≤ 5. Число 5 принадлежит, потому что правая граница включена. Число 6 не принадлежит, так как 6 > 5.
Нельзя определять включение границы только по рисунку «на глаз». Смотрите на тип точки и на скобку в записи промежутка.

7. Самопроверка

Задание 1. Запишите промежутком неравенство −4 ≤ x ≤ 6.

Показать ответ
Ответ: [−4; 6].

Задание 2. Запишите промежутком неравенство 2 < x < 9.

Показать ответ
Ответ: (2; 9).

Задание 3. Запишите неравенством промежуток [−1; 7).

Показать ответ
Ответ: −1 ≤ x < 7.

Задание 4. Запишите промежутком неравенство x > 3.

Показать ответ
Ответ: (3; +∞).

Задание 5. Запишите промежутком неравенство x ≤ −5.

Показать ответ
Ответ: (−∞; −5].

Задание 6. Принадлежит ли число 4 промежутку (−2; 4]?

Показать решение
Правая граница 4 включена.

Ответ: да.

Задание 7. Принадлежит ли число −3 промежутку (−3; 8)?

Показать решение
Левая граница записана круглой скобкой.

Ответ: нет.

Задание 8. Какой промежуток задаёт вся числовая прямая?

Показать ответ
Ответ: (−∞; +∞).

Задание 9. Исправьте ошибку в записи x ≥ 2 ⇔ x ∈ [2; +∞].

Показать ответ
Около +∞ должна быть круглая скобка.

Ответ: [2; +∞).

Задание 10. Запишите неравенством промежуток (−∞; 1].

Показать ответ
Ответ: x ≤ 1.

8. Памятка по числовым промежуткам

Квадратная скобка Конечная граница включена в множество.
Круглая скобка Конечная граница не входит в множество.
Бесконечность Около +∞ и −∞ всегда ставят круглую скобку.
Направление луча Для x > a идём вправо, для x < a — влево.
[a; b] ⇔ a ≤ x ≤ b;
(a; b) ⇔ a < x < b;
[a; b) ⇔ a ≤ x < b;
(a; b] ⇔ a < x ≤ b.
