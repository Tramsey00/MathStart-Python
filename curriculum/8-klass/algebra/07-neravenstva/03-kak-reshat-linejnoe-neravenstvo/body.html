Как решать линейное неравенство

Научимся решать линейные неравенства с одной переменной: раскрывать скобки, переносить слагаемые, приводить подобные члены, правильно делить на коэффициент при x и записывать ответ числовым промежутком.

1. Что называют линейным неравенством

Линейное неравенство с одной переменной после преобразований можно привести к виду ax > b, ax < b, ax ≥ b или ax ≤ b, где a и b — числа.

ax + b > c Задача решения — оставить переменную x в одной части, а известные числа перенести в другую.
Решение неравенства Любое значение x, при котором исходное сравнение становится верным.
Множество решений Обычно это числовой промежуток или вся числовая прямая; иногда решений нет.

Пример 1. Проверяем число

Проверим x = 4 для неравенства 2x − 3 > 4.
2 · 4 − 3 = 5, а 5 > 4.
Число 4 является решением.

2. Равносильные преобразования

a < b ⇒ a + c < b + c Прибавление или вычитание Можно прибавить одно число к обеим частям; знак не изменяется.
c > 0 ⇒ ac < bc Положительный множитель При умножении или делении на положительное число знак сохраняется.
c < 0 ⇒ ac > bc Отрицательный множитель При умножении или делении на отрицательное число знак меняется на противоположный.
Перенос слагаемого через знак неравенства — это сокращённая запись прибавления противоположного числа к обеим частям. Сам знак неравенства при переносе не меняется.

3. Алгоритм решения

1 Раскройте скобки Если они есть, примените распределительный закон.
2 Перенесите слагаемые Члены с x соберите слева, числа — справа.
3 Приведите подобные Получите неравенство вида ax > b или ax ≤ b.
4 Разделите на a При a < 0 обязательно измените знак неравенства.

Пример 2. Положительный коэффициент при x

3x − 7 > 8.
3x > 15.
x > 5.
Ответ: x ∈ (5; +∞).

4. Деление на отрицательный коэффициент

Это главный момент при решении линейных неравенств: если коэффициент при x отрицательный, при делении знак нужно заменить на противоположный.

Пример 3. Меняем знак неравенства

−4x + 6 ≥ 18.
−4x ≥ 12.
Делим на −4 и меняем ≥ на ≤:
x ≤ −3.
Ответ: x ∈ (−∞; −3].
Неправильно −4x ≥ 12 ⇒ x ≥ −3. Знак оставлен прежним, поэтому получен неверный ответ.
Правильно −4x ≥ 12 ⇒ x ≤ −3. При делении на отрицательное число знак меняется.

5. Решение на координатной прямой

Строгое неравенство x > 3
Точка 3 пустая, луч направлен вправо.
Нестрогое неравенство x ≤ −2
Точка −2 закрашена, луч направлен влево.

Пример 4. Неравенство со скобками

2(3x − 1) < 4x + 10.
6x − 2 < 4x + 10.
2x < 12.
x < 6.
Ответ: x ∈ (−∞; 6).

6. Неравенства с дробными коэффициентами

Дробные коэффициенты можно убрать умножением обеих частей на общий положительный знаменатель. Если умножитель положительный, знак сохраняется.

Пример 5. Убираем знаменатель

x3 − 2 > 4.
x3 > 6.
Умножим обе части на 3:
x > 18.
Ответ: x ∈ (18; +∞).

Пример 6. Переменная в обеих частях

7x − 5 ≤ 3x + 11.
7x − 3x ≤ 11 + 5.
4x ≤ 16.
x ≤ 4.
Ответ: x ∈ (−∞; 4].

7. Особые случаи после приведения подобных

0 · x > 3 Решений нет Получается неверное сравнение 0 > 3.
0 · x ≤ 3 Подходит любое x Сравнение 0 ≤ 3 верно при всех действительных x.
0 · x < 0 Решений нет Строгое сравнение 0 < 0 является неверным.

Пример 7. Переменная исчезла

3(x + 2) > 3x − 1.
3x + 6 > 3x − 1.
6 > −1 — верное неравенство.
Ответ: x ∈ (−∞; +∞).
Нельзя делить неравенство на нулевой коэффициент. Если после упрощения переменная исчезла, нужно проверить получившееся числовое сравнение.

8. Самопроверка

Задание 1. Решите неравенство 2x + 5 > 13.

Показать решение
2x > 8, поэтому x > 4.

Ответ: (4; +∞).

Задание 2. Решите неравенство 5x − 9 ≤ 6.

Показать решение
5x ≤ 15, поэтому x ≤ 3.

Ответ: (−∞; 3].

Задание 3. Решите неравенство −3x > 12.

Показать решение
Делим на −3 и меняем знак.

Ответ: x < −4, то есть (−∞; −4).

Задание 4. Решите неравенство 4 − 2x ≥ 10.

Показать решение
−2x ≥ 6. Делим на −2 и меняем знак.

Ответ: x ≤ −3, то есть (−∞; −3].

Задание 5. Решите неравенство 3(x − 2) < 2x + 5.

Показать решение
3x − 6 < 2x + 5.
x < 11.

Ответ: (−∞; 11).

Задание 6. Решите неравенство 8x + 1 > 5x + 16.

Показать решение
3x > 15, поэтому x > 5.

Ответ: (5; +∞).

Задание 7. Решите неравенство x4 + 3 ≥ 5.

Показать решение
x/4 ≥ 2. Умножаем на 4.

Ответ: x ≥ 8, то есть [8; +∞).

Задание 8. Решите неравенство 2(x + 4) ≤ 2x + 1.

Показать решение
2x + 8 ≤ 2x + 1.
8 ≤ 1 — неверно.

Ответ: решений нет.

Задание 9. Решите неравенство 5(x − 1) > 5x − 8.

Показать решение
5x − 5 > 5x − 8.
−5 > −8 — верно.

Ответ: любое действительное x.

Задание 10. Решите неравенство −2(3x − 1) < 4x + 12.

Показать решение
−6x + 2 < 4x + 12.
−10x < 10.
Делим на −10 и меняем знак.

Ответ: x > −1, то есть (−1; +∞).

9. Линейное неравенство без ошибок

Соберите переменную Перенесите члены с x в одну часть, числа — в другую.
Следите за коэффициентом При положительном коэффициенте знак сохраняется.
Меняйте знак вовремя Деление на отрицательное число меняет направление неравенства.
Запишите промежуток Учтите строгий знак, включение границы и направление луча.
ax > b:
если a > 0, то x > b/a;
если a < 0, то x < b/a;
если a = 0, проверяют получившееся числовое неравенство.
