Приближённые значения по недостатку и по избытку

Научимся заключать точное число между двумя десятичными приближениями, находить приближение по недостатку и по избытку с заданным количеством знаков, правильно работать с отрицательными числами и отличать направленное приближение от обычного округления.

1. Точное и приближённое значение

Точное значение полностью задаёт число. Приближённое значение заменяет его более простой десятичной записью и отличается от точного на небольшую величину.

a ≤ x ≤ b a — приближение по недостатку, b — приближение по избытку для точного числа x.
a ≤ x По недостатку Берут число, которое не превосходит точное значение. Оно находится левее точного числа на координатной прямой.
x ≤ b По избытку Берут число, которое не меньше точного значения. Оно находится правее точного числа.

Пример 1. Заключаем число между сотыми

Число 4,376 находится между 4,37 и 4,38.
4,37 < 4,376 < 4,38.
До сотых: 4,37 — по недостатку, 4,38 — по избытку.

2. Что означает заданная точность

До единиц Шаг между соседними приближениями равен 1.
До десятых Шаг равен 0,1.
До сотых Шаг равен 0,01.
До тысячных Шаг равен 0,001.
При приближении до сотых точное число заключают между двумя соседними числами с двумя знаками после запятой. При приближении до тысячных используют три знака после запятой.

Пример 2. Приближение числа π

π = 3,141592…
До десятых: 3,1 < π < 3,2.
До сотых: 3,14 < π < 3,15.
Чем больше сохранено разрядов, тем уже промежуток.

3. Положительные числа

2 до сотых
Точное число расположено между нижней и верхней сотой.
Число 6,2831 до тысячных
6,283 < 6,2831 < 6,284.
По недостатку: 6,283.
По избытку: 6,284.
Разность между соседними тысячными равна 0,001.

Пример 3. Квадратный корень

7 ≈ 2,64575…
До сотых: 2,64 < 7 < 2,65.
По недостатку: 2,64; по избытку: 2,65.

4. Отрицательные числа

Для отрицательных чисел нельзя механически считать отброшенную запись приближением по недостатку. Нужно смотреть на порядок чисел: более отрицательное число меньше.

Приближение числа −3,147 до сотых
−3,15 меньше точного числа, а −3,14 больше него.

Пример 4. Главная ловушка со знаком минус

x = −8,263.
−8,27 < −8,263 < −8,26.
До сотых: −8,27 — по недостатку, −8,26 — по избытку.
Слово «недостаток» означает меньшее числовое значение, а не меньшее количество цифр и не приближение к нулю.

5. Связь с обычным округлением

Следующая цифра 0–4 Обычное округление оставляет выбранный разряд без изменения и для положительного числа даёт приближение по недостатку.
Следующая цифра 5–9 Выбранный разряд увеличивают на единицу; для положительного числа получается приближение по избытку.
Не смешивайте правила В задании «по недостатку» или «по избытку» направление задано заранее и обычное округление может не подойти.

Пример 5. Три разных результата

Число По недостатку до сотых По избытку до сотых Округление до сотых
5,437 5,43 5,44 5,44
5,432 5,43 5,44 5,43
−5,437 −5,44 −5,43 −5,44

6. Алгоритм нахождения двух приближений

1 Определите разряд Установите, до единиц, десятых, сотых или тысячных нужно приближать.
2 Найдите соседние числа Выберите два ближайших числа с нужным количеством знаков.
3 Сравните с точным Запишите меньшее число слева, большее — справа.
4 Назовите приближения Левое — по недостатку, правое — по избытку.

Пример 6. Число задано неравенством

Известно: 1,732 < x < 1,733.
Число x заключено между соседними тысячными.
1,732 — по недостатку, 1,733 — по избытку до тысячных.

Пример 7. Практическая величина

Длина детали равна 12,468 см.
До десятых: 12,4 < 12,468 < 12,5.
По недостатку: 12,4 см; по избытку: 12,5 см.

7. Типичные ошибки

Обычное округление вместо направленного Для 7,234 до сотых округление равно 7,23, но приближение по избытку равно 7,24.
Неверный порядок отрицательных чисел Для −2,678 приближение по недостатку до сотых — −2,68, а не −2,67.
Лишние знаки после запятой При точности до сотых ответ должен иметь два знака после запятой.
Одинаковые границы для неточного числа Если число не записывается точно в выбранном разряде, нижнее и верхнее приближения различаются на единицу этого разряда.

8. Самопроверка

Задание 1. Найдите приближения числа 6,784 по недостатку и по избытку до десятых.

Показать решение
6,7 < 6,784 < 6,8.

Ответ: 6,7 и 6,8.

Задание 2. Найдите приближения числа 2,316 по недостатку и по избытку до сотых.

Показать решение
2,31 < 2,316 < 2,32.

Ответ: 2,31 и 2,32.

Задание 3. Найдите приближения числа −4,583 до сотых.

Показать решение
−4,59 < −4,583 < −4,58.

Ответ: по недостатку −4,59; по избытку −4,58.

Задание 4. Запишите приближение числа π по недостатку до тысячных.

Показать ответ
π = 3,141592…

Ответ: 3,141.

Задание 5. Запишите приближение числа π по избытку до тысячных.

Показать ответ
Следующая тысячная после 3,141 равна 3,142.

Ответ: 3,142.

Задание 6. Известно 5,09 < x < 5,10. Какие приближения числа x до сотых указаны?

Показать ответ
Ответ: 5,09 — по недостатку; 5,10 — по избытку.

Задание 7. Число 8,261 округлили до сотых. Получено ли приближение по недостатку или по избытку?

Показать решение
8,261 ≈ 8,26, а 8,26 < 8,261.

Ответ: по недостатку.

Задание 8. Число 8,268 округлили до сотых. Получено ли приближение по недостатку или по избытку?

Показать решение
8,268 ≈ 8,27, а 8,27 > 8,268.

Ответ: по избытку.

Задание 9. Исправьте ошибку: для −1,236 приближение по недостатку до сотых равно −1,23.

Показать решение
−1,23 больше числа −1,236, поэтому это приближение по избытку.

Ответ: по недостатку нужно взять −1,24.

Задание 10. Найдите приближения 3 ≈ 1,73205… до тысячных.

Показать решение
1,732 < 3 < 1,733.

Ответ: 1,732 и 1,733.

9. Приближение без путаницы

По недостатку Берите ближайшее допустимое число, не превосходящее точное.
По избытку Берите ближайшее допустимое число, не меньшее точного.
Следите за знаком Для отрицательных чисел более отрицательное значение меньше.
Не путайте с округлением Округление выбирает ближайшее число, а не заданное направление.
До сотых:
a ≤ x ≤ a + 0,01;
a — приближение по недостатку, a + 0,01 — приближение по избытку, если x не совпадает точно с сотой.

В следующей теме разберём понятие степени с отрицательным целым показателем.
