Понятие степени с отрицательным целым показателем

Разберём смысл отрицательного показателя степени, научимся превращать такую степень в дробь, работать с целыми и дробными основаниями, учитывать знак отрицательного основания и не забывать об ограничении a ≠ 0.

1. Определение отрицательной степени

Пусть a — ненулевое число, а n — натуральное число. Степенью a с показателем −n называют число, обратное степени a с показателем n.

a−n = 1 an Формула имеет смысл только при a ≠ 0.
a ≠ 0 Основание не равно нулю После преобразования степень оказывается в знаменателе.
n ∈ N n — натуральное число Число n показывает положительную степень в знаменателе.
−n < 0 Показатель отрицательный Минус не делает значение степени отрицательным автоматически.

Пример 1. Числовая степень

2−3 = 123 = 18.
Отрицательный показатель указывает на переход к обратному числу.

2. Почему появляется обратное число

Положительный и отрицательный показатели
Сначала вычисляют степень с положительным показателем, затем берут обратное число.
10−1 = 0,1;   10−2 = 0,01;   10−3 = 0,001.

Пример 2. Степени числа 10

10−4 = 1104 = 110000 = 0,0001.

3. Как превращать отрицательную степень в дробь

1 Проверьте основание Убедитесь, что основание не равно нулю.
2 Уберите минус из показателя Замените −n на положительный показатель n.
3 Переверните число Запишите единицу над степенью основания.
4 Вычислите степень Упростите полученную дробь.

Пример 3. Отрицательная степень целого числа

5−2 = 152 = 125.

4. Дробное основание

( ab )−n = ( ba )n Дробь переворачивается Числитель и знаменатель меняются местами, а показатель становится положительным.
a−n = 1an Целое число тоже можно считать дробью Например, 3 = 3/1, поэтому при отрицательной степени получается основание 1/3.

Пример 4. Степень обыкновенной дроби

( 23 )−3 = ( 32 )3 = 278.

Пример 5. Отрицательная степень обратной дроби

( 17 )−2 = 72 = 49.
Результат отрицательной степени может быть больше единицы.

5. Отрицательное основание и скобки

(−2)−2 = 1/4 Чётная положительная степень делает результат положительным.
(−2)−3 = −1/8 Нечётная положительная степень сохраняет отрицательный знак.
−2−2 = −1/4 Без скобок основанием степени является только число 2.

Пример 6. Сравниваем записи со скобками

(−3)−2 = 1(−3)2 = 19.
−3−2 = −19.
Скобки изменяют основание степени и знак результата.

6. Таблица значений и сравнение степеней

Показатель n 3n 2n 1n (1/2)n
−1 1/3 1/2 1 2
−2 1/9 1/4 1 4
−3 1/27 1/8 1 8

Если основание больше 1, отрицательная степень даёт число между 0 и 1. Если основание находится между 0 и 1, отрицательная степень может быть больше 1.

Пример 7. Сравнение степеней

2−3 = 18, а 2−2 = 14.
Поэтому 2−3 < 2−2.

7. Что нельзя делать

Нельзя менять только знак показателя Неверно: 4−2 = −42. Верно: 4−2 = 1/16.
Нельзя использовать нулевое основание Запись 0−3 привела бы к делению 1/0, поэтому она не имеет смысла.
Нельзя забывать скобки (−2)−2 и −2−2 имеют разные значения.
Нельзя переворачивать только основание без степени Для (2/5)−3 нужно получить (5/2)3, а не просто 5/2.

8. Самопроверка

Задание 1. Представьте 3−2 в виде дроби.

Показать решение
3−2 = 1/3² = 1/9.

Ответ: 1/9.

Задание 2. Вычислите 10−3.

Показать решение
10−3 = 1/1000.

Ответ: 0,001.

Задание 3. Вычислите (−2)−3.

Показать решение
(−2)−3 = 1/(−2)³ = −1/8.

Ответ: −1/8.

Задание 4. Вычислите (34)−2.

Показать решение
(3/4)−2 = (4/3)² = 16/9.

Ответ: 16/9.

Задание 5. Вычислите (15)−3.

Показать решение
(1/5)−3 = 5³.

Ответ: 125.

Задание 6. Сравните 5−1 и 5−2.

Показать решение
5−1 = 1/5, а 5−2 = 1/25.

Ответ: 5−1 > 5−2.

Задание 7. При каком условии выражение a−4 имеет смысл?

Показать ответ
Основание не должно обращаться в нуль.

Ответ: a ≠ 0.

Задание 8. Найдите значение выражения 2−2 + 2−3.

Показать решение
1/4 + 1/8 = 3/8.

Ответ: 3/8.

Задание 9. Исправьте ошибку: 6−2 = −36.

Показать решение
Отрицательный показатель означает обратное число, а не отрицательный результат.

Ответ: 6−2 = 1/36.

Задание 10. Сравните (−3)−2 и −3−2.

Показать решение
(−3)−2 = 1/9, а −3−2 = −1/9.

Ответ: (−3)−2 > −3−2.

9. Отрицательная степень без ошибок

Переходите к дроби Записывайте единицу над степенью с положительным показателем.
Переворачивайте дробь Для дробного основания поменяйте местами числитель и знаменатель.
Проверяйте основание Нулевое основание при отрицательном показателе запрещено.
Следите за скобками Они определяют, входит ли знак минус в основание степени.
a−n = 1/an, a ≠ 0;
(a/b)−n = (b/a)n, a ≠ 0, b ≠ 0.
