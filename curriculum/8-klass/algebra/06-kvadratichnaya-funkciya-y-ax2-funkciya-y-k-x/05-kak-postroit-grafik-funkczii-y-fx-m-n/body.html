Как построить график функции y = f(x + m) + n

Объединим горизонтальный и вертикальный сдвиги: научимся правильно читать числа m и n, переносить весь график вдоль двух осей, находить новые координаты точек, вершины, нули и область определения.

Главное правило двойного сдвига

Число m находится внутри аргумента и отвечает за перемещение вдоль оси Ox. Число n находится вне скобок и отвечает за перемещение вдоль оси Oy.

(x; y) → (x − m; y + n) Сначала изменяется абсцисса точки, затем её ордината.
m > 0 Влево Горизонтальный сдвиг на m единиц влево.
m < 0 Вправо Горизонтальный сдвиг на |m| единиц вправо.
n > 0 Вверх Вертикальный сдвиг на n единиц вверх.
n < 0 Вниз Вертикальный сдвиг на |n| единиц вниз.
Для m знак действует противоположно, а для n — прямо. Например, y = f(x + 3) − 2 означает: влево на 3 и вниз на 2.

1. Как переносится каждая точка

Исходная точка A(a; f(a)) принадлежит графику y = f(x).
→
После двойного сдвига A₁(a − m; f(a) + n) принадлежит графику y = f(x + m) + n.

Пример 1. Перенос отдельной точки

Точка A(4; 5) принадлежит графику y = f(x).
Рассмотрим y = f(x + 3) − 2.
Новая абсцисса: 4 − 3 = 1.
Новая ордината: 5 − 2 = 3.
Новая точка: A₁(1; 3).

2. Как выглядит двойное перемещение

Двойные сдвиги параболы y = x²
Форма и направление ветвей сохраняются, изменяется положение вершины.
Двойные сдвиги графика y = |x|
Вершина перемещается сразу по горизонтали и вертикали.

Пример 2. График y = (x + 2)² + 3

Исходная функция: y = x².
m = 2, поэтому сдвигаем параболу влево на 2.
n = 3, поэтому затем сдвигаем её вверх на 3.
Вершина (0; 0) переходит в точку (−2; 3).
Ось симметрии нового графика: x = −2.

Пример 3. График y = |x − 3| − 3

Запишем x − 3 как x + (−3), поэтому m = −3.
График y = |x| сдвигаем вправо на 3.
n = −3, поэтому дополнительно опускаем график на 3.
Новая вершина: (3; −3).

3. Алгоритм построения

1 Постройте y = f(x) Отметьте опорные точки и важные элементы исходного графика.
2 Найдите m Определите горизонтальное направление, помня об обратном знаке.
3 Сдвиньте по Ox Каждую абсциссу замените на x − m.
4 Найдите n Определите вертикальное направление по обычному знаку.
5 Сдвиньте по Oy К каждой ординате прибавьте n и соедините точки плавно.

Пример 4. Таблица координат до и после двойного сдвига

Точка A B C D E
y = x² (−2; 4) (−1; 1) (0; 0) (1; 1) (2; 4)
y = (x + 2)² + 3 (−4; 7) (−3; 4) (−2; 3) (−1; 4) (0; 7)

Каждая абсцисса уменьшилась на 2, а каждая ордината увеличилась на 3.

4. Вершина, ось симметрии и область значений

Вершина базового графика Если вершина y = f(x) имеет координаты (a; b), новая вершина будет (a − m; b + n).
Ось симметрии Если исходная ось имела вид x = a, после сдвига она станет x = a − m.
Множество значений Сдвигается только на n, потому что горизонтальный перенос не меняет значения y.

Пример 5. Свойства параболы y = (x − 4)² − 5

m = −4, поэтому сдвиг вправо на 4.
n = −5, поэтому сдвиг вниз на 5.
Вершина: (4; −5).
Ось симметрии: x = 4.
Множество значений: [−5; +∞).

5. В каком порядке выполнять сдвиги

Сначала по Ox Переносим график на −m вдоль горизонтальной оси.
→
Затем по Oy Переносим полученный график на n вдоль вертикальной оси.

Для обычных параллельных переносов итоговое положение не зависит от порядка: можно сначала выполнить вертикальный сдвиг, а затем горизонтальный. Однако в записи формулы удобнее сначала разобрать выражение внутри скобок.

Пример 6. Находим нули функции

Найдём нули функции y = (x + 1)² − 4.
(x + 1)² − 4 = 0.
(x + 1)² = 4.
x + 1 = −2 или x + 1 = 2.
x = −3 или x = 1.
Нули функции: −3 и 1.

Пример 7. Восстанавливаем формулу по перемещению

Условие График y = g(x) получен из y = f(x) сдвигом вправо на 5 и вверх на 2. Запишите g(x).
Сдвиг вправо на 5 даёт выражение f(x − 5).
Сдвиг вверх на 2 означает прибавление числа 2.
g(x) = f(x − 5) + 2.

6. Самопроверка

Задание 1. Как перемещается график y = f(x + 3) + 5?

Показать ответ
Плюс 3 внутри скобок означает сдвиг влево на 3. Плюс 5 вне скобок означает сдвиг вверх на 5.

Ответ: влево на 3 и вверх на 5.

Задание 2. Как перемещается график y = f(x − 4) − 2?

Показать ответ
Минус 4 внутри скобок означает сдвиг вправо на 4. Минус 2 вне скобок означает сдвиг вниз на 2.

Ответ: вправо на 4 и вниз на 2.

Задание 3. Точка A(2; 7) принадлежит графику y = f(x). Какая точка принадлежит графику y = f(x + 5) − 3?

Показать решение
Новая абсцисса: 2 − 5 = −3.
Новая ордината: 7 − 3 = 4.

Ответ: (−3; 4).

Задание 4. Точка B(−1; 4) принадлежит графику y = f(x). Какая точка принадлежит графику y = f(x − 2) + 6?

Показать решение
Сдвиг вправо на 2: −1 + 2 = 1.
Сдвиг вверх на 6: 4 + 6 = 10.

Ответ: (1; 10).

Задание 5. Назовите вершину параболы y = (x + 4)² − 3.

Показать ответ
График сдвинут влево на 4 и вниз на 3.

Ответ: (−4; −3).

Задание 6. Назовите вершину графика y = |x − 2| + 5.

Показать ответ
График сдвинут вправо на 2 и вверх на 5.

Ответ: (2; 5).

Задание 7. Найдите множество значений функции y = (x + 1)² − 6.

Показать решение
Горизонтальный сдвиг не меняет множество значений. Вертикальный сдвиг вниз на 6 даёт:

Ответ: [−6; +∞).

Задание 8. Найдите нули функции y = (x − 1)² − 9.

Показать решение
(x − 1)² = 9.
x − 1 = −3 или x − 1 = 3.
x = −2 или x = 4.

Ответ: −2; 4.

Задание 9. Вершина графика y = f(x) имеет координаты (3; −2). Найдите вершину графика y = f(x + 4) + 7.

Показать решение
Новая абсцисса: 3 − 4 = −1.
Новая ордината: −2 + 7 = 5.

Ответ: (−1; 5).

Задание 10. Запишите формулу графика, полученного из y = f(x) сдвигом влево на 6 и вниз на 4.

Показать ответ
Сдвиг влево на 6 даёт f(x + 6). Сдвиг вниз на 4 означает вычитание 4.

Ответ: y = f(x + 6) − 4.

7. Двойной сдвиг без путаницы

Сначала найдите m Он отвечает за горизонтальное перемещение и действует с обратным знаком.
Затем найдите n Он отвечает за вертикальное перемещение и действует с обычным знаком.
Перенесите точку Используйте правило (x; y) → (x − m; y + n).
Сохраните форму Параллельный перенос не растягивает и не отражает график.
y = f(x + m) + n:
горизонтальный сдвиг — на −m;
вертикальный сдвиг — на n;
точка (x; y) переходит в точку (x − m; y + n).

В следующей теме разберём квадратичную функцию y = ax² + bx + c: научимся находить вершину, ось симметрии, направление ветвей и точки пересечения с осями.
