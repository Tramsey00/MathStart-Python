Как построить график функции y = f(x + m)

Научимся строить новый график по известному графику y = f(x): выполнять горизонтальный сдвиг вдоль оси Ox, правильно учитывать знак числа m, переносить точки, вершину, нули и область определения.

Главное правило горизонтального сдвига

В функции y = f(x + m) изменяется аргумент функции. Поэтому весь график перемещается вдоль оси Ox, причём направление сдвига противоположно знаку внутри скобок.

(x; y) → (x − m; y) Ординаты точек не меняются, а каждая абсцисса уменьшается на m.
m > 0 Сдвиг влево График y = f(x + m) перемещают влево на m единиц.
m = 0 График не меняется Получается исходная функция y = f(x).
m < 0 Сдвиг вправо График перемещают вправо на |m| единиц.
Знак внутри скобок действует «наоборот»: y = f(x + 3) — сдвиг влево на 3, а y = f(x − 3) — сдвиг вправо на 3.

1. Что происходит с каждой точкой графика

Исходная точка A(a; f(a)) принадлежит графику y = f(x).
→
После преобразования A₁(a − m; f(a)) принадлежит графику y = f(x + m).

Пример 1. Перенос отдельной точки

Точка A(4; 7) принадлежит графику y = f(x).
Для y = f(x + 3): x = 4 − 3 = 1.
Новая точка: A₁(1; 7).
Для y = f(x − 2) число m = −2: x = 4 − (−2) = 6.
Получаем точку A₂(6; 7).

2. Как выглядит горизонтальный сдвиг

Сдвиги параболы y = x²
Вершина перемещается вдоль оси Ox, а форма параболы сохраняется.
Сдвиги графика y = |x|
Горизонтальный сдвиг одинаково действует на график любой функции.

Пример 2. График y = (x + 2)²

Исходный график: y = x².
Внутри скобок стоит +2, поэтому график сдвигают влево на 2.
Вершина (0; 0) переходит в точку (−2; 0).
Ось симметрии нового графика: x = −2.

Пример 3. График y = |x − 3|

Формулу можно записать как y = f(x + m), где m = −3.
График y = |x| сдвигают вправо на 3 единицы.
Вершина переходит из точки (0; 0) в точку (3; 0).

3. Алгоритм построения

1 Постройте y = f(x) Используйте исходный график или известные опорные точки.
2 Определите число m Найдите число, прибавленное к x внутри скобок.
3 Выберите направление При m > 0 двигайтесь влево, при m < 0 — вправо.
4 Перенесите весь график Сохраните ординаты, форму и взаимное расположение точек.

Пример 4. Таблица координат до и после сдвига

Точка A B C D E
y = x² (−2; 4) (−1; 1) (0; 0) (1; 1) (2; 4)
y = (x + 2)² (−4; 4) (−3; 1) (−2; 0) (−1; 1) (0; 4)

Каждая абсцисса уменьшилась на 2, а все ординаты остались прежними.

4. Какие свойства изменяются, а какие сохраняются

Область определения Сдвигается вместе с графиком: к каждой границе по x прибавляют −m.
Множество значений Не изменяется, потому что ординаты точек остаются прежними.
Форма графика Полностью сохраняется: нет растяжения, сжатия и отражения.
Нули функции Перемещаются на −m вдоль оси Ox вместе со всем графиком.
Экстремальные значения Значения максимумов и минимумов не меняются, меняются только точки их достижения.
Промежутки изменения Сдвигаются по оси Ox на −m.

Пример 5. Область определения после сдвига

Функция f определена на промежутке [−1; 5].
Рассмотрим y = f(x + 3).
Необходимо x + 3 ∈ [−1; 5].
−1 ≤ x + 3 ≤ 5.
−4 ≤ x ≤ 2.
Новая область определения: [−4; 2].

5. Почему знак внутри скобок кажется обратным

Хотим получить старый аргумент a В новой функции нужно решить x + m = a.
→
Новая абсцисса x = a − m. Поэтому при положительном m точка уходит влево.

Пример 6. Находим новую вершину

Вершина графика y = f(x) находится в точке (5; −2).
Для графика y = f(x + 4): x = 5 − 4 = 1.
Новая вершина: (1; −2).

Пример 7. Восстанавливаем формулу преобразования

Условие График y = g(x) получен из графика y = f(x) сдвигом вправо на 6 единиц. Запишите g(x).
Для сдвига вправо внутри скобок должен стоять минус.
g(x) = f(x − 6).

6. Самопроверка

Задание 1. Как получить график y = f(x + 5) из графика y = f(x)?

Показать ответ
Внутри скобок стоит +5.

Ответ: сдвинуть влево на 5 единиц.

Задание 2. Как получить график y = f(x − 3) из графика y = f(x)?

Показать ответ
x − 3 = x + (−3).

Ответ: сдвинуть вправо на 3 единицы.

Задание 3. Точка A(4; 7) принадлежит графику y = f(x). Какая точка принадлежит графику y = f(x + 2)?

Показать решение
Новая абсцисса: 4 − 2 = 2. Ордината не меняется.

Ответ: (2; 7).

Задание 4. Точка B(−1; 5) принадлежит графику y = f(x). Какая точка принадлежит графику y = f(x − 4)?

Показать решение
Сдвиг вправо на 4: −1 + 4 = 3.

Ответ: (3; 5).

Задание 5. Назовите вершину параболы y = (x + 6)².

Показать ответ
График y = x² сдвинут влево на 6.

Ответ: (−6; 0).

Задание 6. Назовите вершину графика y = |x − 2|.

Показать ответ
График y = |x| сдвинут вправо на 2.

Ответ: (2; 0).

Задание 7. Нули функции f равны −3 и 4. Найдите нули функции y = f(x + 2).

Показать решение
Каждый нуль сдвигается влево на 2:
−3 − 2 = −5, 4 − 2 = 2.

Ответ: −5; 2.

Задание 8. Функция f определена на [0; 8]. Найдите область определения функции y = f(x − 3).

Показать решение
Необходимо x − 3 ∈ [0; 8].
0 ≤ x − 3 ≤ 8.
3 ≤ x ≤ 11.

Ответ: [3; 11].

Задание 9. Вершина графика y = f(x) имеет координаты (−2; 6). Найдите вершину графика y = f(x + 5).

Показать решение
Сдвиг влево на 5: −2 − 5 = −7.

Ответ: (−7; 6).

Задание 10. Какой формулой задаётся график, полученный из y = f(x) сдвигом вправо на 7 единиц?

Показать ответ
Для движения вправо внутри скобок ставят минус.

Ответ: y = f(x − 7).

7. Горизонтальный сдвиг без путаницы

Изменяется аргумент Число m находится внутри скобок рядом с x.
Знак работает наоборот Плюс сдвигает влево, минус — вправо.
y не изменяется Все ординаты точек остаются прежними.
Форма сохраняется График целиком перемещается вдоль оси Ox.
y = f(x + m):
m > 0 — сдвиг влево на m;
m < 0 — сдвиг вправо на |m|;
точка (x; y) переходит в точку (x − m; y).
