Главное правило вертикального сдвига

В функции y = f(x) + n число n прибавляется к каждому значению функции. Поэтому абсциссы всех точек сохраняются, а каждая ордината увеличивается на n.

(x; y) → (x; y + n) График перемещается вдоль оси Oy, не изменяя своей формы.
n > 0 Сдвиг вверх Каждая точка поднимается на n единиц.
n = 0 График не меняется Получается исходная функция y = f(x).
n < 0 Сдвиг вниз Каждая точка опускается на |n| единиц.
В отличие от горизонтального сдвига, здесь направление совпадает со знаком: плюс — вверх, минус — вниз.

1. Что происходит с каждой точкой графика

Исходная точка A(a; f(a)) принадлежит графику y = f(x).
→
После преобразования A₁(a; f(a) + n) принадлежит графику y = f(x) + n.

Пример 1. Перенос отдельной точки

Точка A(−2; 5) принадлежит графику y = f(x).
Для y = f(x) + 4: y = 5 + 4 = 9.
Новая точка: A₁(−2; 9).
Для y = f(x) − 3: y = 5 − 3 = 2.
Получаем точку A₂(−2; 2).

2. Как выглядит вертикальный сдвиг

Сдвиги параболы y = x²
Вершина перемещается вдоль оси Oy, а ось симметрии остаётся прежней.
Сдвиги графика y = |x|
Вертикальное перемещение одинаково действует на график любой функции.

Пример 2. График y = x² + 3

Исходный график: y = x².
n = 3 > 0, поэтому параболу сдвигают вверх на 3.
Вершина (0; 0) переходит в точку (0; 3).
Ось симметрии остаётся x = 0.

Пример 3. График y = |x| − 3

n = −3, поэтому график y = |x| опускают на 3 единицы.
Вершина (0; 0) переходит в точку (0; −3).
Форма графика и ось симметрии не изменяются.

3. Алгоритм построения

1 Постройте y = f(x) Используйте исходный график или известные опорные точки.
2 Определите знак n Положительное число задаёт движение вверх, отрицательное — вниз.
3 Измените ординаты К каждой координате y прибавьте n, не изменяя x.
4 Перенесите весь график Сохраните форму и взаимное расположение точек.

Пример 4. Таблица значений до и после сдвига

x −2 −1 0 1 2
f(x) = x² 4 1 0 1 4
f(x) + 2 6 3 2 3 6

Вторая строка получена прибавлением числа 2 к каждому значению функции.

4. Какие свойства изменяются, а какие сохраняются

Область определения Не изменяется, потому что допустимые значения x остаются прежними.
Множество значений Сдвигается на n: к каждой границе по y прибавляют n.
Форма графика Полностью сохраняется: нет растяжения, сжатия и отражения.
Нули функции Обычно изменяются: для нового графика решают f(x) = −n.
Экстремальные значения Максимум и минимум увеличиваются на n вместе со всем графиком.
Промежутки изменения Промежутки возрастания и убывания по x остаются прежними.

Пример 5. Множество значений после сдвига

Для функции y = x² множество значений: [0; +∞).
Рассмотрим y = x² − 5.
Все значения уменьшились на 5.
Новое множество значений: [−5; +∞).

5. Как изменяются нули функции

Для y = f(x) Нули находят из уравнения f(x) = 0.
→
Для y = f(x) + n Нужно решить f(x) + n = 0, то есть f(x) = −n.

Пример 6. Нули функции y = x² − 4

x² − 4 = 0.
x² = 4.
x = −2 или x = 2.
График пересекает ось Ox в точках (−2; 0) и (2; 0).

Пример 7. Находим новое наименьшее значение

Условие Наименьшее значение функции f равно −3. Найдите наименьшее значение функции y = f(x) + 8.
Все значения функции увеличиваются на 8.
−3 + 8 = 5.
Ответ: 5.

6. Самопроверка

Задание 1. Как получить график y = f(x) + 6 из графика y = f(x)?

Показать ответ
n = 6 > 0.

Ответ: сдвинуть вверх на 6 единиц.

Задание 2. Как получить график y = f(x) − 4 из графика y = f(x)?

Показать ответ
n = −4.

Ответ: сдвинуть вниз на 4 единицы.

Задание 3. Точка A(3; 2) принадлежит графику y = f(x). Какая точка принадлежит графику y = f(x) + 5?

Показать решение
Абсцисса не меняется.
2 + 5 = 7.

Ответ: (3; 7).

Задание 4. Точка B(−1; 6) принадлежит графику y = f(x). Какая точка принадлежит графику y = f(x) − 8?

Показать решение
6 − 8 = −2.

Ответ: (−1; −2).

Задание 5. Назовите вершину параболы y = x² + 7.

Показать ответ
Вершина (0; 0) сдвинута вверх на 7.

Ответ: (0; 7).

Задание 6. Назовите вершину графика y = |x| − 3.

Показать ответ
Вершина (0; 0) сдвинута вниз на 3.

Ответ: (0; −3).

Задание 7. Найдите множество значений функции y = x² + 4.

Показать решение
Для y = x² множество значений [0; +∞). После сдвига вверх на 4:

Ответ: [4; +∞).

Задание 8. Найдите нули функции y = x² − 16.

Показать решение
x² − 16 = 0.
x² = 16.
x = −4 или x = 4.

Ответ: −4; 4.

Задание 9. Область определения функции f равна [−2; 5]. Какова область определения функции y = f(x) + 100?

Показать ответ
Вертикальный сдвиг не изменяет допустимые значения x.

Ответ: [−2; 5].

Задание 10. Наибольшее значение функции f равно 12. Найдите наибольшее значение функции y = f(x) − 7.

Показать решение
Все значения уменьшаются на 7.

12 − 7 = 5.

Ответ: 5.

7. Вертикальный сдвиг без ошибок

Изменяется значение функции Число n находится вне скобок и прибавляется ко всему f(x).
Знак работает прямо Плюс сдвигает вверх, минус — вниз.
x не изменяется Все абсциссы точек остаются прежними.
Форма сохраняется График целиком перемещается вдоль оси Oy.
y = f(x) + n:
n > 0 — сдвиг вверх на n;
n < 0 — сдвиг вниз на |n|;
точка (x; y) переходит в точку (x; y + n).
