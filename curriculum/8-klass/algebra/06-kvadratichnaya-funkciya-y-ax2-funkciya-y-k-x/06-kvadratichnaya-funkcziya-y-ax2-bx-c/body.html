Общий вид квадратичной функции

Квадратичной называют функцию, которую можно записать в виде y = ax² + bx + c, где a, b и c — числа, а a ≠ 0. Её графиком является парабола.

y = ax² + bx + c,   a ≠ 0 Коэффициенты определяют форму и положение параболы на координатной плоскости.
a Направление и ширина Знак a определяет направление ветвей, а |a| влияет на ширину параболы.
b Положение оси симметрии Вместе с a коэффициент b определяет абсциссу вершины.
c Пересечение с осью Oy При x = 0 получаем y = c, поэтому график проходит через точку (0; c).

2. Вершина и ось симметрии параболы

Абсцисса вершины x₀ = − b2a
Ордината вершины y₀ = f(x₀)
или y₀ = − D4a
Вершина: V(x₀; y₀).
Ось симметрии: x = x₀.

Пример 1. Находим вершину и направление ветвей

y = −2x² + 8x − 5.
a = −2 < 0, поэтому ветви направлены вниз.
x₀ = −8/(2 · (−2)) = 2.
y₀ = −2 · 2² + 8 · 2 − 5 = 3.
Вершина V(2; 3), ось симметрии x = 2, наибольшее значение равно 3.

3. Ключевые элементы графика

Пересечение с Oy Подставьте x = 0. Получится точка (0; c).
Пересечения с Ox Решите квадратное уравнение ax² + bx + c = 0.
Симметричные точки Точки, равноудалённые от оси x = x₀, имеют одинаковые ординаты.
Парабола с ветвями вверх
Видны вершина, ось симметрии и обе точки пересечения с Ox.
Парабола с ветвями вниз
Вершина задаёт наибольшее значение функции.

Пример 2. Полный разбор функции y = x² − 4x + 3

a = 1 > 0, поэтому ветви направлены вверх.
x₀ = 2, y₀ = −1.
Вершина V(2; −1), ось симметрии x = 2.
При x = 0: y = 3, поэтому график проходит через (0; 3).
x² − 4x + 3 = 0 ⇒ (x − 1)(x − 3) = 0.
Пересечения с Ox: (1; 0) и (3; 0). Множество значений: [−1; +∞).

4. Число пересечений параболы с осью Ox

Точки пересечения с осью Ox соответствуют корням квадратного уравнения. Их количество можно определить по дискриминанту D = b² − 4ac.

D > 0 Два пересечения Парабола пересекает ось Ox в двух различных точках.
D = 0 Одно касание Вершина параболы лежит на оси Ox.
D < 0 Пересечений нет Парабола не имеет общих точек с осью Ox.

Пример 3. Парабола не пересекает ось Ox

y = 2x² + 4x + 5.
x₀ = −1.
y₀ = 2 · (−1)² + 4 · (−1) + 5 = 3.
D = 4² − 4 · 2 · 5 = −24 < 0.
Вершина V(−1; 3), пересечений с Ox нет, множество значений [3; +∞).

5. Вершинная форма квадратичной функции

После выделения полного квадрата функцию можно записать в виде y = a(x − x₀)² + y₀. Из такой записи сразу видны вершина, ось симметрии и направление ветвей.

y = a(x − x₀)² + y₀

Вершина: V(x₀; y₀).
Ось симметрии: x = x₀.

Пример 4. Выделяем полный квадрат

y = 3x² − 12x + 7.
y = 3(x² − 4x) + 7.
y = 3((x − 2)² − 4) + 7.
y = 3(x − 2)² − 5.
Вершина V(2; −5), ось x = 2, ветви направлены вверх.

Таблица симметричных значений

x 0 1 2 3 4
y = x² − 4x + 3 3 0 −1 0 3

Значения при x = 0 и x = 4 совпадают, как и значения при x = 1 и x = 3: эти пары точек симметричны относительно прямой x = 2.

6. Алгоритм построения квадратичной функции

1 Посмотрите на a Определите направление ветвей и примерную ширину параболы.
2 Найдите вершину Вычислите x₀ и y₀, проведите ось симметрии x = x₀.
3 Отметьте точку (0; c) Это гарантированное пересечение графика с осью Oy.
4 Найдите пересечения с Ox Решите ax² + bx + c = 0 или установите, что корней нет.
5 Добавьте симметричные точки Соедините все точки плавной параболой без изломов.

Пример 5. Составляем функцию по корням

Условие Корни квадратичной функции равны −1 и 4, а старший коэффициент равен 2. Запишите формулу функции.
y = 2(x + 1)(x − 4).
y = 2(x² − 3x − 4).
y = 2x² − 6x − 8.

Пример 6. Составляем функцию по вершине и точке

Вершина V(1; −2), поэтому y = a(x − 1)² − 2.
График проходит через точку (3; 6): 6 = a(3 − 1)² − 2.
8 = 4a, поэтому a = 2.
y = 2(x − 1)² − 2.
После раскрытия скобок: y = 2x² − 4x.

Пример 7. Наибольшее и наименьшее значения на промежутке

y = −x² + 4x + 5 на промежутке [0; 5].
Вершина: x₀ = 2, y₀ = 9.
f(0) = 5, f(5) = 0.
Наибольшее значение равно 9, наименьшее значение равно 0.

7. Самопроверка

Задание 1. Назовите коэффициенты a, b и c функции y = 3x² − 7x + 2.

Показать ответ
Ответ: a = 3, b = −7, c = 2.

Задание 2. Куда направлены ветви функции y = −2x² + x + 5 и в какой точке график пересекает ось Oy?

Показать ответ
a = −2 < 0, поэтому ветви направлены вниз. c = 5, поэтому пересечение с Oy — точка (0; 5).

Ответ: вниз; (0; 5).

Задание 3. Найдите вершину параболы y = x² − 6x + 5.

Показать решение
x₀ = 6/2 = 3.
y₀ = 3² − 6 · 3 + 5 = −4.

Ответ: V(3; −4).

Задание 4. Найдите ось симметрии параболы y = −3x² + 12x − 1.

Показать решение
x₀ = −12/(2 · (−3)) = 2.

Ответ: x = 2.

Задание 5. Запишите функцию y = x² + 4x + 1 в вершинной форме.

Показать решение
x² + 4x + 1 = (x + 2)² − 4 + 1.

Ответ: y = (x + 2)² − 3.

Задание 6. Найдите точки пересечения графика y = x² − 5x + 6 с осью Ox.

Показать решение
x² − 5x + 6 = 0.
(x − 2)(x − 3) = 0.

Ответ: (2; 0) и (3; 0).

Задание 7. Сколько точек пересечения с осью Ox имеет график y = 2x² + 4x + 5?

Показать решение
D = 4² − 4 · 2 · 5 = −24 < 0.

Ответ: ни одной.

Задание 8. Укажите множество значений функции y = −2(x − 1)² + 7.

Показать ответ
Ветви направлены вниз, вершина имеет ординату 7.

Ответ: (−∞; 7].

Задание 9. Парабола имеет вершину V(2; −1) и проходит через точку (4; 7). Найдите её формулу.

Показать решение
y = a(x − 2)² − 1.
7 = a · 2² − 1.
8 = 4a, поэтому a = 2.

Ответ: y = 2(x − 2)² − 1.

Задание 10. Найдите наименьшее значение функции y = (x − 1)² − 4 на промежутке [−1; 3].

Показать решение
Вершина x = 1 принадлежит промежутку.
y(1) = −4.

Ответ: −4.

8. Паспорт параболы за пять действий

1. Коэффициент a Определите направление ветвей и форму параболы.
2. Вершина Вычислите x₀ и y₀, проведите ось x = x₀.
3. Точка (0; c) Отметьте пересечение с вертикальной осью.
4. Корни Найдите пересечения с Ox по квадратному уравнению.
5. Симметрия Добавьте парные точки и соедините их плавной кривой.
Для y = ax² + bx + c:
x₀ = −b/(2a);
y₀ = f(x₀);
ось симметрии x = x₀;
пересечение с Oy — точка (0; c).
