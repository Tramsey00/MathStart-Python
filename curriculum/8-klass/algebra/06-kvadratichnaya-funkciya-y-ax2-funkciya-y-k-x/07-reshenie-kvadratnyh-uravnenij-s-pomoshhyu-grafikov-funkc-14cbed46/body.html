1. Что означает решить уравнение графически

Корнем уравнения ax² + bx + c = 0 является такое значение x, при котором значение функции y = ax² + bx + c равно нулю. На графике это абсцисса точки пересечения параболы с осью Ox.

ax² + bx + c = 0   ⇔   y = ax² + bx + c пересекает Ox Корни уравнения — это x-координаты точек пересечения графика с осью Ox.

Пример 1. Два корня

Решим уравнение x² − 5x + 6 = 0.
Строим параболу y = x² − 5x + 6.
Она пересекает ось Ox в точках (2; 0) и (3; 0).
Ответ: x = 2 и x = 3.

2. Сколько корней можно увидеть на графике

Два различных корня
Парабола пересекает Ox два раза, поэтому уравнение имеет два корня.
Один корень
Парабола касается Ox вершиной, поэтому существует один корень.
Действительных корней нет
График не имеет общих точек с Ox, поэтому действительных корней нет.

Пример 2. Один корень

y = x² + 4x + 4 = (x + 2)².
Вершина параболы имеет координаты (−2; 0).
График касается оси Ox только в этой точке.
Ответ: x = −2.

Пример 3. Корней нет

y = x² + 2x + 5 = (x + 1)² + 4.
Наименьшее значение функции равно 4.
Вся парабола расположена выше оси Ox.
Уравнение x² + 2x + 5 = 0 не имеет действительных корней.

3. Алгоритм решения уравнения по одной параболе

1 Перенесите всё в одну часть Получите уравнение вида ax² + bx + c = 0.
2 Постройте параболу Используйте вершину, ось симметрии и несколько опорных точек.
3 Найдите пересечения с Ox Отметьте все общие точки параболы и горизонтальной оси.
4 Запишите абсциссы Их x-координаты являются корнями исходного уравнения.

Пример 4. Уравнение после переноса всех членов

x² + 2 = 5x − 4.
Перенесём все члены в левую часть: x² − 5x + 6 = 0.
Парабола y = x² − 5x + 6 пересекает Ox при x = 2 и x = 3.
Ответ: 2; 3.

4. Решение как пересечение двух графиков

Уравнение f(x) = g(x) можно решить, построив в одной системе координат графики y = f(x) и y = g(x). Решениями будут абсциссы их общих точек.

Парабола и прямая
Абсциссы общих точек A и B являются решениями уравнения.
Приближённое чтение корней
По сетке получаем приближённые значения x ≈ −0,4 и x ≈ 2,4.

Пример 5. Уравнение параболы и прямой

Решим x² − 4x + 3 = 2x − 5.
Строим y = x² − 4x + 3 и y = 2x − 5.
Графики пересекаются в точках A(2; −1) и B(4; 3).
Ответ: x = 2 и x = 4.

5. Приближённое нахождение корней

Если точка пересечения не попадает точно на деление координатной сетки, корень считывают приближённо. Чем мельче сетка и точнее построение, тем точнее получается ответ.

Пример 6. Иррациональные корни

Решим x² = 5 с помощью графиков y = x² и y = 5.
Графики пересекаются при x = −5 и x = 5.
По координатной сетке: x ≈ −2,24 и x ≈ 2,24.
Точный ответ: ±5; приближённый ответ: ±2,24.

Пример 7. Уточняем корень по таблице

x −0,5 −0,4 2,4 2,5
y = x² − 2x − 1 0,25 −0,04 −0,04 0,25
Слева знак функции меняется между −0,5 и −0,4, поэтому первый корень лежит в этом промежутке.
Справа знак меняется между 2,4 и 2,5, поэтому второй корень находится между этими числами.
По графику: x₁ ≈ −0,4, x₂ ≈ 2,4. Точно: x = 1 ± 2.

6. Точность графического метода

Графический метод Наглядно показывает количество корней и их примерное расположение, но результат зависит от масштаба и аккуратности построения.
↔
Алгебраический метод Позволяет получить точные корни по формуле, разложению на множители или теореме Виета.
Проверьте масштаб Одинаковая единица длины должна использоваться на обеих осях, если иной масштаб не отмечен отдельно.
Не путайте координаты Решением является абсцисса точки пересечения, а не её ордината.
Проверяйте подстановкой Подставьте найденные значения x в исходное уравнение, особенно если корни считывались приближённо.
По рисунку нельзя безосновательно записывать слишком много знаков после запятой. Если сетка имеет шаг 0,1, ответ с точностью до 0,001 график обычно не подтверждает.

7. Самопроверка

Задание 1. Парабола пересекает ось Ox в точках (−3; 0) и (4; 0). Назовите корни соответствующего квадратного уравнения.

Показать ответ
Корнями являются абсциссы точек пересечения.

Ответ: −3; 4.

Задание 2. Сколько действительных корней имеет уравнение, если парабола касается оси Ox своей вершиной?

Показать ответ
Существует одна точка касания.

Ответ: один корень.

Задание 3. Решите графически уравнение (x − 2)² = 0.

Показать решение
График y = (x − 2)² касается Ox в точке (2; 0).

Ответ: x = 2.

Задание 4. Сколько действительных корней имеет уравнение x² + 1 = 0?

Показать решение
Парабола y = x² + 1 целиком расположена выше Ox.

Ответ: действительных корней нет.

Задание 5. Решите уравнение x² − 7x + 12 = 0, используя точки пересечения параболы с Ox.

Показать решение
x² − 7x + 12 = (x − 3)(x − 4). Парабола пересекает Ox при x = 3 и x = 4.

Ответ: 3; 4.

Задание 6. Найдите абсциссы точек пересечения графиков y = x² и y = 4x.

Показать решение
x² = 4x.
x² − 4x = 0.
x(x − 4) = 0.

Ответ: 0; 4.

Задание 7. Найдите абсциссы пересечения графиков y = x² − 3 и y = 1.

Показать решение
x² − 3 = 1.
x² = 4.

Ответ: −2; 2.

Задание 8. Решите уравнение x² = 3x + 4 как задачу о пересечении двух графиков.

Показать решение
Строим y = x² и y = 3x + 4. Их общие точки имеют абсциссы −1 и 4.

Ответ: −1; 4.

Задание 9. По графику уравнения x² = 2 корни получены с точностью до десятых. Запишите приближённый ответ.

Показать ответ
2 ≈ 1,4.

Ответ: x ≈ −1,4 и x ≈ 1,4.

Задание 10. Почему по графику с шагом сетки 1 нельзя уверенно записать корень x = 2,137?

Показать ответ
Такая сетка не позволяет различать тысячные доли. Графический ответ должен соответствовать точности построения.

Ответ: указанная точность не подтверждается графиком.

8. Графический метод за минуту

Приведите к удобному виду Используйте одну параболу y = ax² + bx + c или два графика y = f(x) и y = g(x).
Найдите общие точки Для уравнения с нулём ищите пересечения параболы с Ox.
Читайте абсциссы Решениями являются x-координаты, а не значения y.
Учитывайте точность При необходимости запишите приближённый ответ и проверьте его подстановкой.
ax² + bx + c = 0:
два пересечения с Ox — два корня;
одно касание — один корень;
пересечений нет — действительных корней нет.
