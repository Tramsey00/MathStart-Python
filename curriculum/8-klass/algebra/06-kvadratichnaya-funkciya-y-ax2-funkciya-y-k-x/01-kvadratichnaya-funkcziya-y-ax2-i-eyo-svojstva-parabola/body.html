Общий вид функции

Функция y = ax² называется квадратичной функцией частного вида. Число a — коэффициент при x². Оно не должно быть равно нулю.

y = ax²,   a ≠ 0 Графиком любой такой функции является парабола с вершиной в начале координат.
a > 0 Ветви направлены вверх Функция имеет наименьшее значение, равное нулю.
a < 0 Ветви направлены вниз Функция имеет наибольшее значение, равное нулю.
|a| Определяет форму параболы Чем больше модуль коэффициента, тем уже выглядит парабола.
При a = 0 получится функция y = 0 — ось Ox, а не парабола. Поэтому в определении обязательно указывают a ≠ 0.

1. Как знак коэффициента a меняет график

a > 0 Парабола открыта вверх Все значения функции неотрицательны: y ≥ 0.
a < 0 Парабола открыта вниз Все значения функции неположительны: y ≤ 0.
Положительные значения a
Все ветви направлены вверх. При увеличении |a| парабола становится уже.
Отрицательные значения a
Все ветви направлены вниз. Графики симметричны соответствующим положительным параболам относительно Ox.

Пример 1. Определяем направление ветвей

Для y = 4x² коэффициент a = 4 > 0.
Ветви параболы направлены вверх.
Для y = −3x² коэффициент a = −3 < 0.
Ветви параболы направлены вниз.

2. Как модуль коэффициента a меняет ширину параболы

|a| > 1 Парабола уже При одинаковом x значение |y| больше, чем у y = x².
|a| = 1 Базовая форма Получаются графики y = x² или y = −x².
0 < |a| < 1 Парабола шире При одинаковом x значение |y| меньше, чем у y = x².

Пример 2. Сравниваем значения при одном аргументе

При x = 2:
y = 0,5x² ⇒ y = 0,5 · 4 = 2.
y = x² ⇒ y = 4.
y = 2x² ⇒ y = 8.
Чем больше |a|, тем дальше точка графика находится от оси Ox при том же x ≠ 0.

3. Построение параболы по таблице значений

Для построения выбирают несколько значений x, вычисляют соответствующие значения y и используют симметрию относительно оси Oy.

Пример 3. Таблица значений для y = −2x²

x −2 −1 0 1 2
y = −2x² −8 −2 0 −2 −8
При x = −2: y = −2 · (−2)² = −8.
При x = 1: y = −2 · 1² = −2.
Получаем точки (−2; −8), (−1; −2), (0; 0), (1; −2), (2; −8).
1 Отметьте вершину Для y = ax² это всегда точка O(0; 0).
2 Проведите ось симметрии Ею является ось Oy, то есть x = 0.
3 Поставьте пары точек Точки с аргументами x и −x имеют одинаковые ординаты.
4 Соедините плавно Учитывайте знак a и требуемую ширину параболы.

4. Общие свойства функции y = ax²

Область определения D(f) = R при любом a ≠ 0.
Вершина O(0; 0) — единственная точка пересечения с обеими осями.
Ось симметрии Ось Oy, потому что f(−x) = a(−x)² = ax² = f(x).
Чётность Функция y = ax² является чётной при любом a ≠ 0.
Нуль функции Единственный нуль — x = 0.
Знак функции При a > 0 функция положительна для x ≠ 0; при a < 0 — отрицательна.

Пример 4. Принадлежность точки графику

Проверим точку A(−2; 12) для функции y = 3x².
3 · (−2)² = 3 · 4 = 12.
Точка A принадлежит графику.
Для точки B(2; −12) равенство не выполняется.
Точка B не принадлежит графику y = 3x².

5. Возрастание, убывание и экстремум

Если a > 0 Функция убывает на (−∞; 0] и возрастает на [0; +∞). Наименьшее значение равно 0.
Если a < 0 Функция возрастает на (−∞; 0] и убывает на [0; +∞). Наибольшее значение равно 0.

Пример 5. Наименьшее значение на промежутке

Найдём наименьшее значение y = 2x² на [−3; 1].
Промежуток содержит x = 0.
y(0) = 0.
Наименьшее значение равно 0.

Пример 6. Наибольшее значение функции с a < 0

Для функции y = −5x² на всей числовой прямой:
y ≤ 0.
При x = 0 значение y = 0.
Наибольшее значение равно 0.

6. Как найти коэффициент a по точке графика

Если точка (x₀; y₀) с x₀ ≠ 0 принадлежит графику y = ax², её координаты можно подставить в формулу и найти a.

y₀ = ax₀²

a = y0 x02 .

Пример 7. Восстанавливаем формулу функции

Условие График функции y = ax² проходит через точку M(2; −12). Найдите a.
−12 = a · 2².
−12 = 4a.
a = −3.
Ответ: y = −3x².

7. Самопроверка

Задание 1. Куда направлены ветви параболы y = 7x²?

Показать ответ
a = 7 > 0.

Ответ: вверх.

Задание 2. Куда направлены ветви параболы y = −0,4x²?

Показать ответ
a = −0,4 < 0.

Ответ: вниз.

Задание 3. Какая парабола уже: y = 3x² или y = 0,3x²?

Показать ответ
|3| > |0,3|.

Ответ: y = 3x².

Задание 4. Найдите значение функции y = −2x² при x = −3.

Показать решение
y = −2 · (−3)² = −2 · 9 = −18.

Ответ: −18.

Задание 5. Принадлежит ли точка A(2; 20) графику y = 5x²?

Показать решение
5 · 2² = 20.

Ответ: да, принадлежит.

Задание 6. Укажите множество значений функции y = −4x².

Показать ответ
a < 0, поэтому все значения неположительны.

Ответ: (−∞; 0].

Задание 7. На каком промежутке функция y = 2x² возрастает?

Показать ответ
При a > 0 функция возрастает справа от вершины.

Ответ: [0; +∞).

Задание 8. На каком промежутке функция y = −3x² возрастает?

Показать ответ
При a < 0 функция возрастает слева от вершины.

Ответ: (−∞; 0].

Задание 9. График y = ax² проходит через точку (3; 18). Найдите a.

Показать решение
18 = a · 3².
18 = 9a.
a = 2.

Ответ: 2.

Задание 10. Найдите наибольшее значение функции y = −2x² на промежутке [−4; 3].

Показать решение
Промежуток содержит x = 0. Для функции с a < 0 вершина даёт наибольшее значение.

y(0) = 0.

Ответ: 0.

8. Паспорт коэффициента a

Знак a Определяет направление ветвей параболы.
Модуль |a| Определяет, будет парабола уже или шире базовой.
Вершина и ось Для y = ax² вершина O(0; 0), ось симметрии — Oy.
Экстремум При a > 0 есть минимум 0, при a < 0 — максимум 0.
Быстрая проверка графика:
a > 0 — ветви вверх;
a < 0 — ветви вниз;
|a| > 1 — парабола уже;
0 < |a| < 1 — парабола шире.
