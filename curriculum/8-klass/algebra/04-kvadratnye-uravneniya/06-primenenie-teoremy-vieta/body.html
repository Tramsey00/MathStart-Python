Теорема Виета для квадратного уравнения

Пусть квадратное уравнение ax² + bx + c = 0 имеет корни x₁ и x₂. Тогда сумма и произведение корней выражаются через коэффициенты уравнения.

x₁ + x₂ = − ba ,    x₁x₂ = ca Формулы применяются к корням квадратного уравнения ax² + bx + c = 0.
x₁ + x₂ = −b/a Сумма корней Нужно взять второй коэффициент с противоположным знаком и разделить на старший коэффициент.
x₁x₂ = c/a Произведение корней Свободный член делят на старший коэффициент, не изменяя его знак.

1. Теорема Виета для приведённого уравнения

Для приведённого квадратного уравнения x² + px + q = 0 старший коэффициент равен единице, поэтому формулы становятся проще.

x² + px + q = 0

x₁ + x₂ = −p,
x₁x₂ = q.

Пример 1. Находим сумму и произведение, не решая уравнение

x² − 9x + 14 = 0.
p = −9, q = 14.
x₁ + x₂ = −(−9) = 9.
x₁x₂ = 14.
Ответ: сумма корней 9, произведение 14.
Теорема Виета позволяет узнать сумму и произведение корней, даже если сами корни не требуется находить.

2. Подбор целых корней

Для приведённого уравнения нужно найти два числа, сумма которых равна −p, а произведение равно q. Особенно удобно применять этот способ, когда корни целые.

1 Посмотрите на q Выпишите пары целых множителей свободного члена.
2 Определите знаки Произведение подсказывает, одинаковы знаки или различны.
3 Проверьте сумму Подходящая пара должна давать значение −p.
4 Запишите корни При необходимости проверьте их подстановкой.

Пример 2. Положительное произведение

Решить x² − 7x + 12 = 0.
1 и 12 Сумма равна 13 — не подходит.
2 и 6 Сумма равна 8 — не подходит.
3 и 4 Сумма равна 7 — подходит.
x₁ + x₂ = 7, x₁x₂ = 12.
Подходящая пара: 3 и 4.
Ответ: 3; 4.

Пример 3. Отрицательное произведение

x² + x − 12 = 0.
x₁ + x₂ = −1, x₁x₂ = −12.
Корни имеют разные знаки.
3 + (−4) = −1, 3 · (−4) = −12.
Ответ: −4; 3.

3. Теорема Виета для неприведённого уравнения

Если a ≠ 1, можно сразу использовать общие формулы или сначала разделить уравнение на a и получить приведённый вид.

Пример 4. Сумма и произведение дробных корней

Дано уравнение 2x² − 5x − 3 = 0.
a = 2, b = −5, c = −3.
x₁ + x₂ = − −52 = 52 .
x₁x₂ = −32 .
Корни: 3 и − 12 .
Проверка: 3 − 12 = 52 , а 3 · (− 12 ) = − 32 .

4. Обратная теорема Виета

Если два числа имеют сумму −p и произведение q, то эти числа являются корнями уравнения x² + px + q = 0. Это утверждение называют обратной теоремой Виета.

Даны корни x₁ и x₂ Найдите их сумму S = x₁ + x₂ и произведение P = x₁x₂.
→
Составьте уравнение x² − Sx + P = 0.

Пример 5. Составление уравнения по корням

Даны корни x₁ = −2, x₂ = 5.
S = −2 + 5 = 3.
P = (−2) · 5 = −10.
x² − Sx + P = 0.
x² − 3x − 10 = 0.
Ответ: x² − 3x − 10 = 0.

Пример 6. Уравнение с дробным корнем

Корни: 12 и 3.
S = 72 , P = 32 .
x² − 72 x + 32 = 0.
Умножим всё уравнение на 2: 2x² − 7x + 3 = 0.
Ответ: 2x² − 7x + 3 = 0.

5. Как найти второй корень

Если один корень известен, второй можно найти по сумме или произведению корней, не решая уравнение заново.

x₂ = − ba − x₁

или

x₂ = c ax1 , если x₁ ≠ 0.

Пример 7. Один корень известен

Условие Один из корней уравнения 3x² − 11x + 6 = 0 равен 3. Найдите второй корень.
x₁ + x₂ = 113 .
3 + x₂ = 113 .
x₂ = 23 .
Ответ: 23 .

6. Где теорема Виета особенно полезна

Задача Как помогает теорема Виета
Найти сумму или произведение корней Не нужно вычислять сами корни.
Подобрать целые корни Достаточно проверить пары множителей свободного члена.
Найти второй корень Используют известную сумму или произведение.
Составить уравнение по корням Применяют формулу x² − Sx + P = 0.
Проверить найденные корни Сравнивают их сумму и произведение с коэффициентами.
Теорема Виета не заменяет формулу корней во всех случаях. Если подходящая пара чисел не находится быстро, используйте дискриминант.

7. Самопроверка

Задание 1. Не решая уравнение x² − 11x + 24 = 0, найдите сумму и произведение его корней.

Показать ответ
x₁ + x₂ = 11, x₁x₂ = 24.

Ответ: 11 и 24.

Задание 2. Не решая уравнение 3x² + 7x − 2 = 0, найдите сумму и произведение корней.

Показать ответ
x₁ + x₂ = −7/3, x₁x₂ = −2/3.

Ответ: − 73 и − 23 .

Задание 3. Решите по теореме Виета: x² − 8x + 15 = 0.

Показать решение
Нужно найти два числа с суммой 8 и произведением 15.

Это числа 3 и 5.

Ответ: 3; 5.

Задание 4. Решите по теореме Виета: x² + 2x − 35 = 0.

Показать решение
Сумма корней равна −2, произведение равно −35.

Подходят числа 5 и −7.

Ответ: −7; 5.

Задание 5. Составьте приведённое квадратное уравнение, корни которого равны 4 и −6.

Показать решение
S = 4 + (−6) = −2.
P = 4 · (−6) = −24.

x² − Sx + P = 0.
x² + 2x − 24 = 0.

Ответ: x² + 2x − 24 = 0.

Задание 6. Составьте квадратное уравнение с целыми коэффициентами, корни которого равны 13 и 2.

Показать решение
S = 7/3, P = 2/3.

x² − (7/3)x + 2/3 = 0.
Умножим на 3:

Ответ: 3x² − 7x + 2 = 0.

Задание 7. Один корень уравнения 2x² − 9x + 4 = 0 равен 4. Найдите второй корень.

Показать решение
x₁ + x₂ = 9/2.

4 + x₂ = 9/2.
x₂ = 1/2.

Ответ: 12 .

Задание 8. При каком значении m корни уравнения x² − 10x + m = 0 имеют произведение 21?

Показать решение
Для приведённого уравнения произведение корней равно свободному члену.

m = 21.

Ответ: 21.

Задание 9. При каком значении p сумма корней уравнения x² + px − 18 = 0 равна 3?

Показать решение
x₁ + x₂ = −p.

−p = 3, поэтому p = −3.

Ответ: −3.

Задание 10. Корни уравнения имеют сумму −5 и произведение 6. Найдите корни и составьте уравнение.

Показать решение
Два числа с суммой −5 и произведением 6 — это −2 и −3.

Уравнение: x² − (−5)x + 6 = 0.

Ответ: корни −3 и −2; уравнение x² + 5x + 6 = 0.

8. Четыре задачи, которые решает теорема Виета

Найти сумму и произведение Используйте коэффициенты, не вычисляя сами корни.
Подобрать целые корни Проверяйте пары множителей свободного члена.
Найти неизвестный корень Вычтите известный корень из суммы или разделите произведение.
Составить уравнение По сумме S и произведению P запишите x² − Sx + P = 0.
Для ax² + bx + c = 0:
x₁ + x₂ = −b/a,
x₁x₂ = c/a.

Для уравнения по корням:
x² − (x₁ + x₂)x + x₁x₂ = 0.

В следующей теме научимся решать иррациональные уравнения, которые после изоляции квадратного корня и возведения в квадрат сводятся к квадратному уравнению.
