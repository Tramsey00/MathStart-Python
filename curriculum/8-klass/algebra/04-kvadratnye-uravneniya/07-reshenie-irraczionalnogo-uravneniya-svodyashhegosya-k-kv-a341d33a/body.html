Решение иррационального уравнения, сводящегося к квадратному

Научимся решать уравнения с переменной под знаком квадратного корня: определять допустимые значения, изолировать радикал, правильно возводить обе части в квадрат, решать полученное квадратное уравнение и исключать посторонние корни.

Что называют иррациональным уравнением

Иррациональным называют уравнение, в котором переменная находится под знаком корня. В этой теме рассматриваются уравнения с арифметическим квадратным корнем.

f(x) = g(x) Левая часть всегда неотрицательна, поэтому для корня уравнения обязательно g(x) ≥ 0.
f(x) = g(x) Один изолированный корень После возведения в квадрат часто получается квадратное уравнение.
f(x) = g(x) Два равных радикала При допустимых подкоренных выражениях можно сравнить их содержимое.
f(x) + g(x) = a Два корня в одной части Обычно требуется изоляция одного радикала и два последовательных возведения в квадрат.

1. Общий алгоритм решения

1 Найдите допустимые значения Каждое подкоренное выражение должно быть неотрицательным.
2 Изолируйте один корень В одной части оставьте радикал, остальные слагаемые перенесите.
3 Проверьте знак второй части Она должна быть неотрицательной, потому что равна арифметическому корню.
4 Возведите обе части в квадрат Решите полученное рациональное или квадратное уравнение.
5 Проверьте каждый корень Подставьте значения именно в исходное уравнение.
Возведение в квадрат может добавить посторонние корни. Поэтому проверка в исходном уравнении является обязательной частью решения.

2. Уравнение вида √f(x) = g(x)

Исходное уравнение f(x) = g(x).
⇒
После возведения в квадрат f(x) = [g(x)]², но дополнительно нужно учитывать условие g(x) ≥ 0.

Пример 1. Один допустимый корень

Решить x+5 = x − 1.
Правая часть должна быть неотрицательной: x − 1 ≥ 0, поэтому x ≥ 1.
Возводим обе части в квадрат: x + 5 = (x − 1)².
x² − 3x − 4 = 0.
(x − 4)(x + 1) = 0.
x = 4 или x = −1.
Условию x ≥ 1 соответствует только x = 4.
Проверка: 9 = 3, а 4 − 1 = 3.
Ответ: 4.

Пример 2. Посторонний отрицательный корень

3x+4 = x.
Так как корень равен x, необходимо x ≥ 0.
3x + 4 = x².
x² − 3x − 4 = 0.
x = 4 или x = −1.
x = −1 не подходит, потому что правая часть исходного уравнения отрицательна.
Ответ: 4.

3. Сначала изолируем квадратный корень

Если рядом с корнем есть числа или выражения, радикал сначала оставляют в одной части уравнения. После этого проверяют знак второй части.

Пример 3. Квадратное уравнение с иррациональными корнями

Решить 2x−1 + 1 = x.
Изолируем корень: 2x−1 = x − 1.
Необходимо x − 1 ≥ 0, то есть x ≥ 1.
2x − 1 = (x − 1)².
x² − 4x + 2 = 0.
x = 2 ± 2 .
Число 2 − 2 меньше 1 и не подходит.
Ответ: 2 + 2 .

4. Равенство двух квадратных корней

Если оба радикала определены, равенство арифметических квадратных корней равносильно равенству подкоренных выражений.

f(x) = g(x)

⇔ f(x) = g(x), при f(x) ≥ 0 и g(x) ≥ 0.

Пример 4. Подкоренные выражения линейные

2x+3 = x+8 .
ОДЗ: 2x + 3 ≥ 0 и x + 8 ≥ 0.
2x + 3 = x + 8.
x = 5.
Значение x = 5 принадлежит ОДЗ.
Ответ: 5.

Пример 5. Удобная замена t = √(x + 1)

2 x+1 = x + 1.
Пусть t = x+1 , тогда t ≥ 0 и x + 1 = t².
2t = t².
t(t − 2) = 0.
t = 0 или t = 2.
x + 1 = 0 ⇒ x = −1.
x + 1 = 4 ⇒ x = 3.
Ответ: −1; 3.

5. Почему возникают посторонние корни

Равные числа имеют равные квадраты, но из равенства квадратов не всегда следует равенство исходных чисел. Например, 3² = (−3)², хотя 3 ≠ −3.

До возведения в квадрат Арифметический корень всегда неотрицателен.
После возведения в квадрат Информация о знаке второй части может исчезнуть.
После решения Каждый кандидат обязательно подставляют в исходное уравнение.

Пример 6. Корень квадратного уравнения не является корнем исходного

x+1 = x − 3.
Необходимо x ≥ 3.
x + 1 = (x − 3)².
x² − 7x + 8 = 0.
x = 7±17 2 .
Меньшее значение меньше 3 и не подходит.
Ответ: 7+17 2 .

6. Уравнение с двумя квадратными корнями

Если в уравнении два радикала, после первого возведения в квадрат обычно остаётся один корень. Его снова изолируют и только затем возводят обе части в квадрат второй раз.

Изолируйте сумму корней Запишите исходное уравнение и найдите ОДЗ.
Возведите в квадрат первый раз Раскройте квадрат суммы и оставьте один радикал.
Изолируйте оставшийся корень Проверьте неотрицательность второй части.
Возведите в квадрат второй раз Решите уравнение и проверьте все найденные значения.

Пример 7. Два последовательных возведения в квадрат

Решить x+4 + x−1 = 5.
ОДЗ: x ≥ 1.
Возведём обе части в квадрат: 2x + 3 + 2 (x+4) (x−1) = 25.
(x+4) (x−1) = 11 − x.
Отсюда дополнительно x ≤ 11.
Возводим в квадрат второй раз: (x + 4)(x − 1) = (11 − x)².
x² + 3x − 4 = x² − 22x + 121.
25x = 125, поэтому x = 5.
Проверка: 9 + 4 = 3 + 2 = 5.
Ответ: 5.

7. Самопроверка

Задание 1. Решите: x+2 = x.

Показать решение
Необходимо x ≥ 0.

x + 2 = x².
x² − x − 2 = 0.
(x − 2)(x + 1) = 0.

Подходит только x = 2.

Ответ: 2.

Задание 2. Решите: 2x+3 = x + 1.

Показать решение
Необходимо x + 1 ≥ 0.

2x + 3 = (x + 1)².
x² − 2 = 0.
x = ± 2 .

Значение − 2 не подходит, потому что x + 1 < 0.

Ответ: 2 .

Задание 3. Решите: 5x−1 = x + 1.

Показать решение
5x − 1 = (x + 1)².
x² − 3x + 2 = 0.
(x − 1)(x − 2) = 0.

Оба значения подходят.

Ответ: 1; 2.

Задание 4. Решите: x+7 = 3 − x.

Показать решение
Необходимо −7 ≤ x ≤ 3.

x + 7 = (3 − x)².
x² − 7x + 2 = 0.

x = 7±41 2 .

Условию x ≤ 3 соответствует только меньшее значение.

Ответ: 7−41 2 .

Задание 5. Решите: 3x+10 = 5x−2 .

Показать решение
При допустимых подкоренных выражениях:

3x + 10 = 5x − 2.
2x = 12.
x = 6.

Ответ: 6.

Задание 6. Решите: x+1 + 1 = x.

Показать решение
Изолируем корень: √(x + 1) = x − 1, поэтому x ≥ 1.

x + 1 = (x − 1)².
x² − 3x = 0.
x = 0 или x = 3.

Подходит только x = 3.

Ответ: 3.

Задание 7. Решите: x+4 − x = 2.

Показать решение
ОДЗ: x ≥ 0.

√(x + 4) = √x + 2.
После возведения в квадрат: x + 4 = x + 4√x + 4.
√x = 0.
x = 0.

Ответ: 0.

Задание 8. Решите: x+9 + x = 5.

Показать решение
ОДЗ: x ≥ 0.

После первого возведения в квадрат: √(x(x + 9)) = 8 − x.

После второго возведения: x(x + 9) = (8 − x)².
25x = 64.
x = 64/25.

Проверка подтверждает равенство.

Ответ: 6425 .

Задание 9. Решите: 3 x−1 = x + 1.

Показать решение
ОДЗ: x ≥ 1.

9(x − 1) = (x + 1)².
x² − 7x + 10 = 0.
(x − 2)(x − 5) = 0.

Оба корня подходят.

Ответ: 2; 5.

Задание 10. Решите: x+6 = x − 2.

Показать решение
Необходимо x ≥ 2.

x + 6 = (x − 2)².
x² − 5x − 2 = 0.

x = 5±33 2 .

Условию x ≥ 2 соответствует только большее значение.

Ответ: 5+33 2 .

8. Контроль перед окончательным ответом

Корни определены? Все подкоренные выражения неотрицательны.
Радикал изолирован? Перед возведением в квадрат в выбранной части находится один корень.
Вторая часть неотрицательна? Отрицательное выражение не может равняться арифметическому корню.
Выполнена проверка? Каждый найденный кандидат подставлен в исходное уравнение.
Надёжный маршрут:
ОДЗ → изоляция корня → условие неотрицательности → возведение в квадрат → решение квадратного уравнения → обязательная проверка.
