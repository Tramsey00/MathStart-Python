Не каждое уравнение удобно решать одинаково

Любое квадратное уравнение можно привести к виду ax² + bx + c = 0, где a ≠ 0. После этого выбирают способ решения. Универсальным является способ через дискриминант, но некоторые уравнения быстрее решаются разложением на множители или выделением полного квадрата.

D Через дискриминант Универсальный способ для полного квадратного уравнения.
( )( ) Разложением на множители Удобен, когда трёхчлен легко представить произведением.
(x − m)² Выделением полного квадрата Позволяет свести уравнение к виду (x − m)² = n.

1. Дискриминант квадратного уравнения

Для уравнения ax² + bx + c = 0 вычисляют число, которое называется дискриминантом.

D = b² − 4ac Знак дискриминанта определяет количество действительных корней.
D > 0 Два различных корня Корень из D положителен, поэтому формулы дают два разных значения.
D = 0 Один корень Два корня совпадают. Иногда говорят: один корень кратности два.
D < 0 Действительных корней нет Арифметический квадратный корень из отрицательного числа в R не существует.
При D > 0: x1 = −b−D 2a , x2 = −b+D 2a .
При D = 0: x = −b 2a .

2. Алгоритм решения через дискриминант

1 Запишите стандартный вид Слева ax² + bx + c, справа нуль.
2 Найдите a, b и c Обязательно учитывайте знаки коэффициентов.
3 Вычислите D Подставьте коэффициенты в D = b² − 4ac.
4 Определите число корней Сравните дискриминант с нулём.
5 Найдите и проверьте корни Используйте формулу и при необходимости выполните подстановку.

Пример 1. Два различных корня

Решить 2x² − 7x + 3 = 0.
a = 2, b = −7, c = 3.
D = (−7)² − 4 · 2 · 3 = 49 − 24 = 25.
D > 0, поэтому уравнение имеет два корня.
x1 = 7−5 4 = 12 .
x2 = 7+5 4 = 3 .
Ответ: 12; 3.

Пример 2. Дискриминант равен нулю

x² − 6x + 9 = 0.
D = (−6)² − 4 · 1 · 9 = 36 − 36 = 0.
x = 62 = 3 .
Ответ: 3.

Пример 3. Отрицательный дискриминант

3x² + 2x + 4 = 0.
D = 2² − 4 · 3 · 4 = 4 − 48 = −44.
D < 0.
Ответ: действительных корней нет.

3. Решение разложением на множители

Если левую часть можно представить произведением, используют свойство нулевого произведения: если uv = 0, то u = 0 или v = 0.

a(x − x₁)(x − x₂) = 0

⇔ x = x₁ или x = x₂.

Пример 4. Разложение квадратного трёхчлена

x² − 5x + 6 = 0.
x² − 5x + 6 = (x − 2)(x − 3).
(x − 2)(x − 3) = 0.
x − 2 = 0 или x − 3 = 0.
Ответ: 2; 3.
ax² + bx = 0 Вынесите x за скобки x(ax + b) = 0. Этот способ был разобран для неполных уравнений.
u² − v² = 0 Используйте разность квадратов (u − v)(u + v) = 0. Например, x² − 16 = 0.
Разложение на множители удобно только тогда, когда разложение видно или легко находится. Если это не так, надёжнее использовать дискриминант.

4. Решение выделением полного квадрата

Способ основан на формуле квадрата суммы или разности. Квадратный трёхчлен преобразуют так, чтобы получить уравнение вида (x − m)² = n.

Оставьте x² и x Свободный член перенесите в правую часть.
Добавьте квадрат половины коэффициента Одно и то же число добавляют в обе части.
Сверните квадрат Используйте формулу (x − m)².
Извлеките квадратный корень Не забудьте два противоположных значения.

Пример 5. Выделяем полный квадрат

Решить x² − 8x + 7 = 0.
x² − 8x = −7.
Добавим в обе части 16: x² − 8x + 16 = 9.
(x − 4)² = 9.
x − 4 = −3 или x − 4 = 3.
x = 1 или x = 7.
Ответ: 1; 7.
При переходе от (x − 4)² = 9 нельзя писать только x − 4 = 3. Квадрат числа 3 и квадрат числа −3 равны 9.

5. Как выбрать удобный способ

Вид уравнения Удобный способ Почему
ax² + bx + c = 0 без очевидного разложения Дискриминант Формула работает для любого квадратного уравнения.
ax² + bx = 0 Вынесение x за скобки Сразу получается нулевое произведение.
x² − m² = 0 Разность квадратов Получается (x − m)(x + m) = 0.
Трёхчлен легко раскладывается Разложение на множители Решение получается без вычисления дискриминанта.
Коэффициент при x² равен 1, b — чётное число Выделение полного квадрата Половину коэффициента при x удобно возвести в квадрат.

Пример 6. Один пример — два способа

Решить x² − 7x + 12 = 0.
Через множители (x − 3)(x − 4) = 0 Получаем x = 3 или x = 4.
Через дискриминант D = 49 − 48 = 1 Формула корней также даёт x = 3 и x = 4.

6. Проверка найденных корней

Корень уравнения — значение переменной, при котором левая и правая части равны. Поэтому любой найденный корень можно проверить прямой подстановкой в исходное уравнение.

Проверим x = 3 для уравнения 2x² − 7x + 3 = 0.
2 · 3² − 7 · 3 + 3 = 18 − 21 + 3 = 0.
Значит, x = 3 действительно является корнем.
Типичная ошибка Как избежать
В D подставляют b без его знака. Сначала отдельно выпишите a, b и c.
Забывают квадрат у b. Записывайте формулу D = b² − 4ac полностью.
В знаменателе пишут только 2. Знаменатель формулы корней равен 2a.
При D = 0 ищут два разных корня. Оба значения совпадают: x = −b/(2a).
При извлечении корня из квадрата теряют один знак. Из u² = n при n > 0 следует u = ±√n.

7. Самопроверка

Задание 1. Найдите дискриминант уравнения x² − 5x + 4 = 0.

Показать решение
a = 1, b = −5, c = 4.

D = (−5)² − 4 · 1 · 4 = 25 − 16 = 9.

Ответ: 9.

Задание 2. Сколько действительных корней имеет уравнение 2x² + 3x + 5 = 0?

Показать решение
D = 3² − 4 · 2 · 5 = 9 − 40 = −31.

D < 0, поэтому действительных корней нет.

Ответ: 0.

Задание 3. Решите уравнение x² − 9x + 20 = 0 через дискриминант.

Показать решение
D = (−9)² − 4 · 1 · 20 = 81 − 80 = 1.

x₁ = (9 − 1)/2 = 4, x₂ = (9 + 1)/2 = 5.

Ответ: 4; 5.

Задание 4. Решите уравнение 4x² − 12x + 9 = 0.

Показать решение
D = (−12)² − 4 · 4 · 9 = 144 − 144 = 0.

x = 12/(2 · 4) = 3/2.

Ответ: 32.

Задание 5. Решите разложением на множители: x² − 10x + 21 = 0.

Показать решение
x² − 10x + 21 = (x − 3)(x − 7).

(x − 3)(x − 7) = 0.

Ответ: 3; 7.

Задание 6. Решите уравнение x² − 25 = 0 наиболее коротким способом.

Показать решение
Используем разность квадратов:

(x − 5)(x + 5) = 0.

Ответ: −5; 5.

Задание 7. Решите выделением полного квадрата: x² − 4x − 5 = 0.

Показать решение
x² − 4x = 5.
x² − 4x + 4 = 9.
(x − 2)² = 9.
x − 2 = −3 или x − 2 = 3.

Ответ: −1; 5.

Задание 8. Решите уравнение 3x² + x − 2 = 0.

Показать решение
D = 1² − 4 · 3 · (−2) = 1 + 24 = 25.

x₁ = (−1 − 5)/6 = −1, x₂ = (−1 + 5)/6 = 2/3.

Ответ: −1; 23.

Задание 9. При каком значении m уравнение x² − 6x + m = 0 имеет один действительный корень?

Показать решение
Один корень получается при D = 0.

D = (−6)² − 4 · 1 · m = 36 − 4m.
36 − 4m = 0, поэтому m = 9.

Ответ: 9.

Задание 10. Решите уравнение 6x² − 13x + 6 = 0 и проверьте меньший корень подстановкой.

Показать решение
D = (−13)² − 4 · 6 · 6 = 169 − 144 = 25.

x₁ = (13 − 5)/12 = 2/3, x₂ = (13 + 5)/12 = 3/2.

Проверка x = 2/3:
6 · (2/3)² − 13 · (2/3) + 6 = 8/3 − 26/3 + 18/3 = 0.

Ответ: 23; 32.

8. Быстрый выбор способа

Есть общий множитель? Вынесите его за скобки и примените свойство нулевого произведения.
Видна разность квадратов? Сразу разложите выражение на два сопряжённых множителя.
Трёхчлен легко раскладывается? Используйте множители. Это обычно короче формулы.
Простой способ не виден? Применяйте дискриминант: он работает для любого квадратного уравнения.
Универсальный маршрут:
стандартный вид → коэффициенты a, b, c → дискриминант D → количество корней → формула корней → проверка.

В следующей теме научимся решать рациональные уравнения, которые после введения новой переменной или преобразований сводятся к квадратному уравнению.
