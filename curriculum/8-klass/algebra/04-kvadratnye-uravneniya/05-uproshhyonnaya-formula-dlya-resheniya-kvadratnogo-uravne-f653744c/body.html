Упрощённая формула для решения квадратного уравнения

Разберём сокращённую формулу корней для уравнений с чётным вторым коэффициентом, научимся вычислять D₁, определять количество корней и решать такие уравнения быстрее, не работая с лишними множителями 2 и 4.

Когда можно использовать упрощённую формулу

Если второй коэффициент b является чётным числом, его удобно представить в виде b = 2k. Тогда квадратное уравнение записывается как ax² + 2kx + c = 0.

D₁ = k² − ac Здесь k — половина второго коэффициента: k = b/2.
Для уравнения ax² + 2kx + c = 0:

x1,2 = −k ± D1 a .

1. Как получается упрощённая формула

1 Начинаем с обычного дискриминанта D = b² − 4ac.
2 Подставляем b = 2k D = (2k)² − 4ac.
3 Выносим общий множитель D = 4(k² − ac) = 4D₁.
4 Сокращаем формулу корней √D = 2√D₁, поэтому общий множитель 2 сокращается.
x1,2 = −2k ± 4D1 2a .
x1,2 = −2k ± 2D1 2a .
После сокращения на 2: x1,2 = −k ± D1 a .

2. Количество корней по знаку D₁

D₁ > 0 Два различных корня Используют два знака: минус и плюс перед √D₁.
D₁ = 0 Один корень Формула упрощается до x = −k/a.
D₁ < 0 Действительных корней нет Квадратный корень из отрицательного числа в R не существует.
Знак D₁ совпадает со знаком обычного дискриминанта, потому что D = 4D₁, а число 4 положительно.

3. Алгоритм решения

1 Приведите к стандартному виду Запишите ax² + bx + c = 0.
2 Проверьте b Убедитесь, что второй коэффициент чётный.
3 Найдите k Разделите b на 2: k = b/2.
4 Вычислите D₁ Используйте D₁ = k² − ac.
5 Найдите корни В знаменателе упрощённой формулы находится a, а не 2a.

Пример 1. Два корня

Решить 3x² − 10x + 3 = 0.
a = 3, b = −10, c = 3.
b = 2k, поэтому k = −5.
D₁ = (−5)² − 3 · 3 = 25 − 9 = 16.
x1 = 5−4 3 = 13 .
x2 = 5+4 3 = 3 .
Ответ: 13; 3.

Пример 2. Один корень

2x² + 4x + 2 = 0.
k = 2.
D₁ = 2² − 2 · 2 = 0.
x = −k/a = −2/2 = −1.
Ответ: −1.

Пример 3. Действительных корней нет

5x² + 6x + 5 = 0.
k = 3.
D₁ = 3² − 5 · 5 = 9 − 25 = −16.
Ответ: действительных корней нет.

4. Отрицательный старший коэффициент

Упрощённая формула работает и при a < 0. Нужно только внимательно сохранить знак a в знаменателе.

Пример 4. Знаменатель формулы отрицателен

Решить −2x² + 8x − 6 = 0.
a = −2, b = 8, c = −6, k = 4.
D₁ = 4² − (−2) · (−6) = 16 − 12 = 4.
x1 = −4−2 −2 = 3 .
x2 = −4+2 −2 = 1 .
Ответ: 1; 3.

5. Обычная и упрощённая формулы

Обычная формула D = b² − 4ac,

x₁,₂ = (−b ± √D)/(2a).

Подходит для любого квадратного уравнения.
Упрощённая формула b = 2k,

D₁ = k² − ac,

x₁,₂ = (−k ± √D₁)/a.

Пример 5. Сравним количество вычислений

Уравнение 2x² − 12x + 10 = 0.
По обычной формуле: D = 144 − 80 = 64.
По упрощённой формуле: k = −6, D₁ = 36 − 20 = 16.
Во втором случае числа меньше: √16 = 4 вместо √64 = 8, а знаменатель равен 2 вместо 4.
Корни в обоих случаях одинаковы: 1 и 5.
Упрощённая формула не является новым способом решения. Это сокращённая запись обычной формулы для случая, когда второй коэффициент чётный.

6. Типичные ошибки

Ошибка Почему неверно Как правильно
Берут k = b k является половиной второго коэффициента. k = b/2
Записывают D₁ = k² − 4ac Множитель 4 уже учтён при переходе от D к D₁. D₁ = k² − ac
В знаменателе пишут 2a В упрощённой формуле общий множитель 2 сокращён. Знаменатель равен a
Используют формулу при нечётном b Тогда k = b/2 не является целым и упрощения обычно не получается. Применить обычный дискриминант
Теряют знак k Если b отрицателен, то k также отрицателен. Выписать a, b, c и k отдельно

7. Самопроверка

Задание 1. Найдите k и D₁ для уравнения 2x² − 8x + 3 = 0.

Показать решение
b = −8, поэтому k = −4.

D₁ = (−4)² − 2 · 3 = 16 − 6 = 10.

Ответ: k = −4, D₁ = 10.

Задание 2. Решите уравнение x² − 6x + 5 = 0 по упрощённой формуле.

Показать решение
k = −3.
D₁ = 9 − 5 = 4.

x₁ = 3 − 2 = 1, x₂ = 3 + 2 = 5.

Ответ: 1; 5.

Задание 3. Решите уравнение 3x² + 12x + 9 = 0.

Показать решение
k = 6.
D₁ = 36 − 27 = 9.

x₁ = (−6 − 3)/3 = −3, x₂ = (−6 + 3)/3 = −1.

Ответ: −3; −1.

Задание 4. Решите уравнение 4x² − 4x + 1 = 0.

Показать решение
k = −2.
D₁ = 4 − 4 = 0.

x = −k/a = 2/4 = 1/2.

Ответ: 12 .

Задание 5. Сколько действительных корней имеет уравнение 2x² + 4x + 7 = 0?

Показать решение
k = 2.
D₁ = 4 − 14 = −10.

D₁ < 0.

Ответ: действительных корней нет.

Задание 6. Решите уравнение −3x² + 12x − 9 = 0.

Показать решение
a = −3, k = 6, c = −9.
D₁ = 36 − 27 = 9.

x₁ = (−6 − 3)/(−3) = 3, x₂ = (−6 + 3)/(−3) = 1.

Ответ: 1; 3.

Задание 7. Решите уравнение 5x² − 20x + 15 = 0.

Показать решение
k = −10.
D₁ = 100 − 75 = 25.

x₁ = (10 − 5)/5 = 1, x₂ = (10 + 5)/5 = 3.

Ответ: 1; 3.

Задание 8. Можно ли удобно применить упрощённую формулу к уравнению 2x² − 7x + 3 = 0?

Показать ответ
Второй коэффициент b = −7 нечётный. Формально k = −7/2, но вычисления не упрощаются.

Ответ: удобнее применить обычную формулу через D.

Задание 9. При каком значении m уравнение x² + 8x + m = 0 имеет один действительный корень?

Показать решение
k = 4. Один корень получается при D₁ = 0.

4² − m = 0.
m = 16.

Ответ: 16.

Задание 10. Решите уравнение 6x² − 14x + 4 = 0 и сократите дробные корни.

Показать решение
k = −7.
D₁ = 49 − 24 = 25.

x₁ = (7 − 5)/6 = 2/6 = 1/3,
x₂ = (7 + 5)/6 = 12/6 = 2.

Ответ: 13 ; 2.

8. Когда сокращённая формула действительно удобна

b — чётное число Половина коэффициента k находится без дробей.
Числа в D слишком большие Вычисление D₁ уменьшает квадраты и произведения.
Нужно решить устно быстрее В формуле меньше множителей 2 и 4.
b — нечётное число Обычно проще сразу использовать обычный дискриминант.
Запомните три строки:
b = 2k;
D₁ = k² − ac;
x₁,₂ = (−k ± √D₁)/a.

В следующей теме разберём теорему Виета: научимся находить сумму и произведение корней, подбирать корни без вычисления дискриминанта и составлять квадратное уравнение по заданным корням.
