Определение квадратного уравнения

Квадратным называют уравнение, которое после раскрытия скобок, переноса всех слагаемых в одну часть и приведения подобных можно записать в стандартном виде:

ax² + bx + c = 0 a, b и c — действительные числа, причём a ≠ 0.
Условие a ≠ 0 обязательно. Если a = 0, слагаемое ax² исчезает, и уравнение становится линейным или числовым, но уже не квадратным.

1. Коэффициенты квадратного уравнения

a Старший коэффициент Коэффициент при x². Он всегда отличен от нуля.
b Второй коэффициент Коэффициент при x. Он может быть равен нулю.
c Свободный член Слагаемое без переменной. Оно также может быть равно нулю.

Пример 1. Определяем коэффициенты

3x² − 7x + 2 = 0.
a = 3, b = −7, c = 2.

Пример 2. Не теряем нулевой коэффициент

5x² − 20 = 0 можно записать как 5x² + 0x − 20 = 0.
a = 5, b = 0, c = −20.
Знак является частью коэффициента. В уравнении −2x² + 9x − 4 = 0 старший коэффициент равен −2, а не 2.

2. Приведение уравнения к стандартному виду

Квадратное уравнение не всегда сразу записано в виде ax² + bx + c = 0. Перед определением коэффициентов его нужно преобразовать.

1 Раскройте скобки Используйте распределительное свойство умножения.
2 Перенесите всё в одну часть В правой части должен остаться нуль.
3 Приведите подобные Соберите отдельно x², x и свободные члены.
4 Расположите по степеням Сначала x², затем x, затем число.

Пример 3. Приведение к стандартному виду

Дано уравнение 2x(x − 3) + 5 = x² − 4x.
2x² − 6x + 5 = x² − 4x.
2x² − 6x + 5 − x² + 4x = 0.
x² − 2x + 5 = 0.
a = 1, b = −2, c = 5.

3. Полные и неполные квадратные уравнения

ax² + bx + c = 0 Полное квадратное уравнение Все три коэффициента a, b и c отличны от нуля. Пример: 2x² − 5x + 3 = 0.
ax² + bx = 0 или ax² + c = 0 Неполное квадратное уравнение Второй коэффициент b, свободный член c или оба одновременно равны нулю.
ax² = 0 b = 0 и c = 0 Единственный корень: x = 0.
ax² + bx = 0 c = 0 Выносят x за скобки: x(ax + b) = 0.
ax² + c = 0 b = 0 Выражают x² и сравнивают полученное число с нулём.

4. Решение неполных уравнений

Пример 4. Уравнение ax² = 0

7x² = 0.
x² = 0.
x = 0.

Пример 5. Уравнение ax² + bx = 0

3x² − 12x = 0.
3x(x − 4) = 0.
3x = 0 или x − 4 = 0.
Ответ: 0; 4.

Пример 6. Уравнение ax² + c = 0

2x² − 18 = 0.
2x² = 18, поэтому x² = 9.
x = −3 или x = 3.
Ответ: −3; 3.

Пример 7. Неполное уравнение без действительных корней

5x² + 20 = 0.
x² = −4.
Квадрат действительного числа не может быть отрицательным.
Ответ: действительных корней нет.

5. Приведённые и неприведённые уравнения

x² + px + q = 0 Приведённое уравнение Старший коэффициент равен единице: a = 1. Пример: x² − 8x + 12 = 0.
ax² + bx + c = 0, a ≠ 1 Неприведённое уравнение Старший коэффициент не равен единице. Пример: 3x² + 2x − 5 = 0.

Любое квадратное уравнение можно сделать приведённым, разделив обе его части на ненулевой коэффициент a.

4x² − 12x + 8 = 0.
Делим обе части на 4:
x² − 3x + 2 = 0.
Деление на старший коэффициент не меняет корни уравнения, потому что a ≠ 0.

6. Что не является квадратным уравнением

Уравнение Квадратное? Почему
3x² − 2x + 1 = 0 Да Наибольшая степень переменной равна 2, a = 3 ≠ 0.
0x² + 5x − 1 = 0 Нет Слагаемое с x² отсутствует; это линейное уравнение.
x³ − 4x = 0 Нет Наибольшая степень равна 3.
1 x + x = 2 Не в исходном виде Переменная находится в знаменателе; сначала требуется преобразование с учётом ОДЗ.

7. Самопроверка

Задание 1. Назовите коэффициенты уравнения 6x² − 5x + 9 = 0.

Показать ответ
Ответ: a = 6, b = −5, c = 9.

Задание 2. Назовите коэффициенты уравнения −x² + 7 = 0.

Показать ответ
Запишем: −x² + 0x + 7 = 0.

Ответ: a = −1, b = 0, c = 7.

Задание 3. Приведите к стандартному виду: 3x(x + 2) = x² + 8.

Показать решение
3x² + 6x = x² + 8.
2x² + 6x − 8 = 0.

Ответ: 2x² + 6x − 8 = 0.

Задание 4. Определите вид уравнения 2x² − 7x + 3 = 0: полное или неполное, приведённое или неприведённое.

Показать ответ
Все коэффициенты отличны от нуля, поэтому уравнение полное. Старший коэффициент равен 2, поэтому уравнение неприведённое.

Ответ: полное неприведённое.

Задание 5. Определите вид уравнения x² − 16 = 0.

Показать ответ
b = 0, поэтому уравнение неполное. a = 1, поэтому оно приведённое.

Ответ: неполное приведённое.

Задание 6. Решите уравнение 8x² = 0.

Показать решение
x² = 0.

Ответ: x = 0.

Задание 7. Решите уравнение 5x² + 15x = 0.

Показать решение
5x(x + 3) = 0.
x = 0 или x = −3.

Ответ: −3; 0.

Задание 8. Решите уравнение 3x² − 27 = 0.

Показать решение
3x² = 27, поэтому x² = 9.
x = −3 или x = 3.

Ответ: −3; 3.

Задание 9. Решите уравнение 4x² + 36 = 0.

Показать решение
x² = −9. Квадрат действительного числа не может быть отрицательным.

Ответ: действительных корней нет.

Задание 10. Сделайте уравнение 5x² − 20x + 15 = 0 приведённым.

Показать решение
Разделим обе части на 5:

x² − 4x + 3 = 0.

Ответ: x² − 4x + 3 = 0.

8. Определи вид уравнения за четыре шага

1. Приведи к стандартному виду Все слагаемые должны находиться слева, справа — нуль.
2. Проверь старший коэффициент Если a = 0, уравнение не является квадратным.
3. Посмотри на b и c Оба ненулевые — полное; хотя бы один равен нулю — неполное.
4. Сравни a с единицей a = 1 — приведённое; a ≠ 1 — неприведённое.
Квадратное уравнение: ax² + bx + c = 0, a ≠ 0.
Полное: b ≠ 0 и c ≠ 0.
Неполное: b = 0 или c = 0.
Приведённое: a = 1.
