Базовые свойства квадратных корней

Разберём основные равенства для арифметического квадратного корня: квадрат корня, корень из квадрата, корень из произведения и дроби. Научимся обязательно учитывать условия применения каждого свойства и отличать верные преобразования от внешне похожих ошибок.

Четыре опорных свойства

Все дальнейшие преобразования выражений с квадратными корнями строятся на нескольких базовых равенствах. Важно запоминать не только формулу, но и условия, при которых она верна.

( a )² = a Квадрат арифметического корня Свойство применяется при a ≥ 0.
a2 = |a| Корень из квадрата Равен модулю числа a при любом действительном a.
a·b = a · b Корень из произведения Свойство верно при a ≥ 0 и b ≥ 0.
ab = a b Корень из дроби Необходимо a ≥ 0 и b > 0.

1. Квадрат арифметического квадратного корня

Если a ≥ 0, то

( a )² = a.

По определению a — это неотрицательное число, квадрат которого равен a. Поэтому возведение арифметического корня в квадрат возвращает исходное подкоренное число.

Пример 1. Знак перед корнем имеет значение

( 13 )² = 13.
(− 7 )² = 7.
−( 7 )² = −7.
В выражении (− 7 )² знак минус входит в основание степени. В записи −( 7 )² минус остаётся перед результатом.

2. Корень из квадрата числа

Для любого действительного a:

a2 = |a|.

Квадрат числа a не зависит от его знака, а арифметический квадратный корень всегда неотрицателен. Поэтому результатом является модуль, а не просто число a.

Пример 2. Отрицательное число под квадратом

(−9) 2 = 81 = 9.
|−9| = 9.
Следовательно, (−9) 2 = |−9|.
a > 0 |a| = a, поэтому a2 = a.
a = 0 02 = 0.
a < 0 |a| = −a, поэтому a2 = −a.

3. Квадратный корень из произведения

Если a ≥ 0 и b ≥ 0, то

a·b = a · b .
1 Проверяем знак Оба корня неотрицательны, поэтому их произведение также неотрицательно.
2 Проверяем квадрат ( a · b )² = a · b.

Пример 3. Вычисление корня из произведения

4·25 = 4 · 25 = 2 · 5 = 10.
Разделить один корень a·b → a · b .
⇔
Объединить произведение корней a · b → a·b .

4. Квадратный корень из дроби

Если a ≥ 0 и b > 0, то

ab = a b .

Знаменатель должен быть строго положительным. При b = 0 дробь не определена, а при b < 0 подкоренная дробь не удовлетворяет условиям свойства в школьном курсе действительных чисел.

Пример 4. Корень из числовой дроби

81121 = 911 .
Действительно: 81 = 9, 121 = 11.
Свойство работает и в обратную сторону: частное двух арифметических корней можно объединить под одним знаком корня, если выполнены условия a ≥ 0 и b > 0.

5. Несколько свойств в одном вычислении

В одном выражении свойства часто применяются последовательно. Сначала определите структуру: квадрат, произведение или дробь, затем выполните преобразования по шагам.

Пример 5. Последовательное применение свойств

Вычислить 0.25·144 + 49100 .
0.25·144 = 0.25 · 144 = 0,5 · 12 = 6.
49100 = 710 = 0,7.
6 + 0,7 = 6,7.
Ответ: 6,7.
Для нескольких неотрицательных множителей:

a·b·c = a · b · c.

6. Свойства, которых нет

Корень распределяется по произведению и положительной дроби, но в общем случае не распределяется по сумме или разности.

Пример 6. Проверяем предполагаемое равенство

Неверно 9+16 = 9 + 16.
Проверка Левая часть равна 25 = 5, а правая часть равна 3 + 4 = 7.
Запись Оценка Причина
a+b = a + b В общем случае неверно Свойства корня из суммы нет.
a−b = a − b В общем случае неверно Свойства корня из разности нет.
a2 = a Не всегда Правильно: a2 = |a|.

7. Самопроверка

Задание 1. Вычислите: ( 17 )².

Показать решение
По свойству квадрата арифметического корня:

( 17 )² = 17.

Ответ: 17.

Задание 2. Вычислите: (−12) 2 .

Показать решение
Корень из квадрата равен модулю основания:

(−12) 2 = |−12| = 12.

Ответ: 12.

Задание 3. Вычислите: 9·16 .

Показать решение
9·16 = 9 · 16 = 3 · 4 = 12.

Ответ: 12.

Задание 4. Вычислите: 4981 .

Показать решение
4981 = 79 .

Ответ: 79 .

Задание 5. Вычислите: 0.36·25 .

Показать решение
0.36 = 0,6, 25 = 5.

0,6 · 5 = 3.

Ответ: 3.

Задание 6. Вычислите: (− 11 )².

Показать решение
Минус входит в основание квадрата:

(− 11 )² = ( 11 )² = 11.

Ответ: 11.

Задание 7. Упростите: a2 , если a < 0.

Показать решение
a2 = |a|. При a < 0 модуль равен −a.

Ответ: −a.

Задание 8. Упростите: 4·b2 .

Показать решение
4·b2 = 4 · b2 = 2|b|.

Ответ: 2|b|.

Задание 9. Ученик записал: 4+5 = 4 + 5. Найдите ошибку.

Показать решение
Квадратный корень не распределяется по сумме.

Левая часть: 9 = 3.
Правая часть: 2 + 5, что не равно 3.

Ответ: использовано несуществующее свойство корня из суммы.

Задание 10. Вычислите: ( 18 )² + 25·4 − 819 .

Показать решение
( 18 )² = 18.

25·4 = 5 · 2 = 10.

819 = 9 = 3.

18 + 10 − 3 = 25.

Ответ: 25.

8. Как выбрать нужное свойство

Сначала посмотрите не на числа, а на устройство выражения. Вид записи подсказывает подходящее свойство.

Корень возводят в квадрат Используйте ( a )² = a при a ≥ 0.
Под корнем стоит квадрат Используйте a2 = |a|.
Под корнем произведение Разделяйте корень только при неотрицательных множителях.
Под корнем дробь Числитель должен быть неотрицательным, знаменатель — положительным.
Всегда выполняйте три проверки:
1. Как устроено выражение?
2. Выполнены ли условия свойства?
3. Не заменили ли вы произведение суммой или разностью?

В следующей теме применим эти свойства для вынесения множителя из-под знака корня, внесения множителя под корень, упрощения подобных радикалов и других преобразований иррациональных выражений.
