2. Свойства базовой функции y = √x

Область определения D(f) = [0; +∞), потому что арифметический квадратный корень в действительных числах существует только при x ≥ 0.
Множество значений E(f) = [0; +∞), поскольку значение арифметического корня всегда неотрицательно.
Нуль функции Единственный нуль — x = 0: 0 = 0.
Знак функции При x = 0 значение равно нулю, а при x > 0 функция положительна.
Монотонность Функция возрастает на всей области определения: большему x соответствует больший корень.
Наименьшее значение ymin = 0 при x = 0. Наибольшего значения нет.
Функция не является ни чётной, ни нечётной: её область определения не симметрична относительно нуля.

3. Связь с функцией y = x²

Возведение в квадрат и извлечение арифметического квадратного корня являются обратными действиями для неотрицательных чисел. Поэтому графики y = x² при x ≥ 0 и y = x симметричны относительно прямой y = x.

y = x², x ≥ 0 Точка (a; a²) принадлежит правой ветви параболы.
⇔
y = √x После перестановки координат получается точка (a²; a).

Пример 1. Переход между симметричными точками

Точка (3; 9) лежит на графике y = x².
После перестановки координат получаем точку (9; 3).
Она лежит на графике y = x, потому что 9 = 3.

4. Как коэффициенты k и a меняют график

Интерактивная модель использует функцию y = k x + a. Коэффициент k меняет направление и вертикальный масштаб, а число a сдвигает график вдоль оси Oy.

Условие Что происходит с графиком Множество значений
k > 0 График возрастает и начинается в точке (0; a). [a; +∞)
k < 0 График отражается относительно оси Ox и убывает. (−∞; a]
k = 0 Получается горизонтальный луч y = a при x ≥ 0. {a}
a > 0 График сдвигается вверх на a единиц. Начальная ордината увеличивается на a.
a < 0 График сдвигается вниз на |a| единиц. Начальная ордината уменьшается.

Пример 2. Функция y = 2√x − 1

Начальная точка: (0; −1).
При x = 1: y = 2 · 1 − 1 = 1.
При x = 4: y = 2 · 2 − 1 = 3.
Функция возрастает, D(f) = [0; +∞), E(f) = [−1; +∞).

Пример 3. Функция y = −√x + 3

Начальная точка: (0; 3).
Отрицательный коэффициент отражает график относительно оси Ox.
Функция убывает, D(f) = [0; +∞), E(f) = (−∞; 3].

5. Как читать график функции

По графику можно определять значения функции, находить аргументы по заданному значению y, проверять принадлежность точек и сравнивать значения функции.

Пример 4. Значение функции

Для функции y = x найдём f(25).
f(25) = 25 = 5.
Точка (25; 5) принадлежит графику.

Пример 5. Поиск аргумента

Условие При каком x значение функции y = x равно 6?
x = 6.
x = 6² = 36.
Ответ: 36.

Пример 6. Сравнение значений

Сравним f(7) и f(11).
7 < 11, а функция возрастает.
7 < 11.

6. Типичные ошибки

Ошибка Почему неверно Как правильно
График строят при x < 0 Арифметический корень из отрицательного x не определён в R. D(f) = [0; +∞)
График продолжают ниже оси Ox Значение √x неотрицательно. E(f) = [0; +∞)
Записывают √x = ±y Знак √ задаёт только неотрицательное значение. y = √x ≥ 0
Считают функцию чётной Область определения не симметрична относительно нуля. Функция не является ни чётной, ни нечётной.
Соединяют точки отрезками с изломами График является плавной кривой. Точки соединяют плавно.

7. Самопроверка

Задание 1. Найдите область определения функции y = x.

Показать ответ
Подкоренное выражение должно быть неотрицательным: x ≥ 0.

Ответ: [0; +∞).

Задание 2. Найдите множество значений функции y = x.

Показать ответ
Арифметический квадратный корень всегда неотрицателен и может принимать сколь угодно большие значения.

Ответ: [0; +∞).

Задание 3. Вычислите f(81), если f(x) = x.

Показать решение
f(81) = 81 = 9.

Ответ: 9.

Задание 4. При каком x значение функции y = √x равно 7?

Показать решение
x = 7, поэтому x = 49.

Ответ: 49.

Задание 5. Принадлежит ли точка A(16; 4) графику y = √x?

Показать решение
16 = 4.

Ответ: да, принадлежит.

Задание 6. Принадлежит ли точка B(9; −3) графику y = √x?

Показать решение
9 = 3, а не −3.

Ответ: нет, не принадлежит.

Задание 7. Сравните f(13) и f(15), если f(x) = √x.

Показать решение
Функция возрастает, а 13 < 15.

Ответ: 13 < 15.

Задание 8. Укажите начальную точку графика функции y = −2√x + 4.

Показать решение
При x = 0: y = −2 · 0 + 4 = 4.

Ответ: (0; 4).

Задание 9. Возрастает или убывает функция y = −√x + 2?

Показать решение
Коэффициент перед корнем отрицателен, поэтому базовый возрастающий график отражён относительно оси Ox.

Ответ: функция убывает.

Задание 10. Найдите множество значений функции y = 3√x − 5.

Показать решение
Коэффициент 3 положителен. Наименьшее значение достигается при x = 0: y = −5.

Ответ: [−5; +∞).

8. График за 30 секунд: четыре проверки

1. Проверь x Для базовой функции допустимы только x ≥ 0.
2. Найди начало У y = k√x + a график начинается в точке (0; a).
3. Посмотри на k При k > 0 функция возрастает, при k < 0 — убывает.
4. Запиши значения При k > 0: y ≥ a; при k < 0: y ≤ a.
Для y = √x:
D(f) = [0; +∞);
E(f) = [0; +∞);
график начинается в точке (0; 0) и возрастает.
