Главная идея модуля

Модуль действительного числа показывает не направление, а расстояние от соответствующей точки координатной прямой до начала отсчёта. Поэтому модуль не может быть отрицательным.

a
Модуль числа a — это расстояние от точки A(a) до начала отсчёта O(0).

1. Определение модуля

Значение модуля зависит от знака числа. Положительное число и нуль внутри модуля не меняются, а отрицательное число заменяется противоположным.

x = { x, если x ≥ 0; −x, если x < 0.
x > 0 x = x. Например, 7 = 7.
x = 0 0 = 0.
x < 0 x = −x. Например, −7 = 7.

Пример 1. Модули рациональных чисел

12 = 12.
−3,8 = 3,8.
− 5 9 = 5 9 .

2. Модуль иррационального выражения

Правило определения модуля одинаково для рациональных и иррациональных чисел. Сначала нужно определить знак выражения.

Пример 2. Положительный квадратный корень

Арифметический квадратный корень неотрицателен:
7 = 7.

Пример 3. Выражение под модулем отрицательно

Вычислить 2 − 5 .
2² = 4, а 5 > 4, поэтому 5 > 2.
Следовательно, 2 − 5 < 0.
2 − 5 = 5 − 2.
Нельзя просто удалить знаки модуля. Сначала определите знак всего выражения внутри них.

3. Основные свойства модуля

Свойство Смысл
a ≥ 0 Расстояние не бывает отрицательным.
a = 0 ⇔ a = 0 Нулевое расстояние получается только в начале отсчёта.
−a = a Противоположные числа одинаково удалены от нуля.
ab = a · b Модуль произведения равен произведению модулей.
a b = a b , b ≠ 0 Модуль частного равен частному модулей.
Для любого действительного x:

x = x2 .

Пример 4. Почему корень из квадрата равен модулю

При x = −6:
(−6)2 = 36 = 6.
И одновременно −6 = 6.
Запись x2 = x неверна при x < 0.

4. Расстояние между двумя точками

Если точки A(a) и B(b) расположены на координатной прямой, расстояние между ними равно модулю разности их координат.

a − b
AB = a − b = b − a.

Пример 5. Расстояние между рациональными точками

Дано A(−4), B(3). Найти AB.
AB = −4 − 3 = −7 = 7.
Ответ: 7.

Пример 6. Расстояние с иррациональной координатой

Дано A(1), B( 5 ). Найти AB.
5 > 1, поэтому:
AB = 1 − 5 = 5 − 1.
Ответ: 5 − 1.

5. Простейшие уравнения с модулем

Уравнение с модулем можно понимать как задачу о расстоянии от точки x до начала отсчёта.

Уравнение Геометрический смысл Решение
x = a, a > 0 Точка x удалена от нуля на a единиц. x = −a или x = a
x = 0 Расстояние до нуля равно нулю. x = 0
x = a, a < 0 Расстояние не может быть отрицательным. Корней нет
x = 5 ⇔ x = −5 или x = 5.
x = −2 — корней нет.

6. Типичные ошибки

Ошибка Почему неверно Правильная мысль
x всегда равно x При x < 0 модуль меняет знак. x = −x при x < 0
Модуль может быть отрицательным Модуль — расстояние. x ≥ 0
x2 = x При отрицательном x правая часть отрицательна. x2 = x
Расстояние AB = a − b Разность может получиться отрицательной. AB = a − b
Знак модуля нельзя раскрывать без информации о знаке выражения внутри.

7. Самопроверка

Задание 1. Вычислите −14.

Показать решение
Число −14 отрицательно, поэтому модуль заменяет его противоположным.

Ответ: 14.

Задание 2. Вычислите 11 .

Показать решение
Арифметический квадратный корень неотрицателен.

Ответ: 11.

Задание 3. Вычислите 3 − 10 .

Показать решение
3² = 9, а 10 > 9, поэтому 10 > 3. Выражение внутри модуля отрицательно.

Ответ: 10 − 3.

Задание 4. Найдите расстояние между точками A(−6) и B(2).

Показать решение
AB = −6 − 2 = −8 = 8.

Ответ: 8.

Задание 5. Найдите расстояние между точками A(−3) и B(0).

Показать решение
Расстояние от точки до нуля равно модулю её координаты:

−3 = 3.

Ответ: 3.

Задание 6. Решите уравнение x = 7.

Показать решение
От нуля на расстоянии 7 находятся две точки.

Ответ: x = −7 или x = 7.

Задание 7. Решите уравнение x = −4.

Показать решение
Модуль не может быть отрицательным.

Ответ: корней нет.

Задание 8. Упростите a2 при a < 0.

Показать решение
a2 = a. При a < 0 модуль равен −a.

Ответ: −a.

Задание 9. Сравните −2,5 и 2.

Показать решение
−2,5 = 2,5, а 2 = 2.

Ответ: −2,5 > 2.

Задание 10. Найдите все действительные числа, удалённые от нуля на 3,2 единицы.

Показать решение
Условие записывается уравнением x = 3,2.

Ответ: −3,2 и 3,2.

8. Модуль без путаницы: три ориентира

1. Сначала найди знак Если выражение неотрицательно, знаки модуля можно убрать. Если отрицательно — нужно заменить выражение противоположным.
2. Помни про расстояние a — расстояние от A(a) до нуля, а a − b — расстояние между A(a) и B(b).
3. Проверяй знак ответа Значение модуля не может быть отрицательным. Поэтому уравнение x = a не имеет корней при a < 0.
x ≥ 0;
−a = a;
x2 = x;
расстояние между A(a) и B(b) равно a − b.
