Решение рациональных уравнений

Научимся решать уравнения с алгебраическими дробями: определять область допустимых значений, находить общий знаменатель, освобождаться от дробей, решать полученное уравнение и обязательно проверять найденные корни.

Что называют рациональным уравнением

Рациональным называют уравнение, обе части которого являются рациональными выражениями. В школьных задачах чаще всего встречаются дробно-рациональные уравнения: переменная содержится в одном или нескольких знаменателях.

Целое рациональное уравнение

Переменная не находится в знаменателе: 3x − 7 = 2x + 5.

Дробно-рациональное уравнение

Переменная находится в знаменателе: 2/(x − 1) = 3/(x + 2).

Главная задача

Заменить исходное уравнение более простым, не потеряв допустимые корни и не приняв запрещённое значение.

Главная проверка

Каждый найденный корень должен принадлежать ОДЗ исходного уравнения.

1. Область допустимых значений

До любых преобразований нужно определить, при каких значениях переменной все знаменатели исходного уравнения отличны от нуля.

ОДЗ рационального уравнения: все значения переменной, при которых каждый исходный знаменатель имеет смысл и не равен нулю.
Знаменатели Условия ОДЗ
x − 4 x − 4 ≠ 0 x ≠ 4
x и x + 3 x ≠ 0, x + 3 ≠ 0 x ≠ 0, x ≠ −3
x² − 9 (x − 3)(x + 3) ≠ 0 x ≠ 3, x ≠ −3
ОДЗ находят по исходной записи. Даже если знаменатель позже сократится, его нули всё равно остаются запрещёнными.

2. Основной алгоритм решения

Порядок решения дробно-рационального уравнения:

1. Разложите знаменатели на множители, если это необходимо.
2. Выпишите ОДЗ.
3. Найдите общий знаменатель.
4. Умножьте обе части уравнения на общий знаменатель.
5. Решите полученное целое уравнение.
6. Исключите значения, не входящие в ОДЗ.
7. Запишите ответ.

Умножение обеих частей на общий знаменатель позволяет убрать дроби, но такое преобразование выполняется только при значениях из ОДЗ. Поэтому проверка найденных корней обязательна.

Корень входит в ОДЗ Подставляем его в исходное уравнение или принимаем после проверки преобразований.
Корень не входит в ОДЗ Это посторонний корень. Его исключают из ответа.
Допустимых корней нет В ответе записывают: корней нет.

3. Уравнения с одним знаменателем

Пример 1. Дробь равна числу

Условие Решить уравнение: 3x + 1 x − 2 = 4.
Решение.
ОДЗ: x ≠ 2.
Умножим обе части на x − 2:

3x + 1 = 4(x − 2).
3x + 1 = 4x − 8,
x = 9.
Число 9 входит в ОДЗ.
Ответ: 9.

Пример 2. Сумма дроби и числа

Условие Решить: 5 x + 1 + 2 = 3.
Решение.
ОДЗ: x ≠ −1.
5 x + 1 = 1.
5 = x + 1,
x = 4.
Ответ: 4.

4. Уравнения с разными знаменателями

Пример 3. Две дроби

Условие Решить: 2 x − 1 = 3 x + 2 .
Решение.
ОДЗ: x ≠ 1, x ≠ −2.
Общий знаменатель: (x − 1)(x + 2).
После умножения обеих частей на общий знаменатель:

2(x + 2) = 3(x − 1).
2x + 4 = 3x − 3,
x = 7.
7 входит в ОДЗ.
Ответ: 7.

Пример 4. Три дроби

Условие Решить: 1 x + 2 x + 1 = 3x + 1 x(x + 1) .
Решение.
ОДЗ: x ≠ 0, x ≠ −1.
Общий знаменатель: x(x + 1).
(x + 1) + 2x = 3x + 1.
3x + 1 = 3x + 1.
Получено верное равенство. Значит, уравнение выполняется при всех значениях из ОДЗ.
Ответ: x ≠ 0, x ≠ −1.

5. Посторонние корни

Посторонним называют значение, которое появилось после преобразований, но не является корнем исходного уравнения. В дробно-рациональных уравнениях чаще всего это нуль одного из исходных знаменателей.

Пример 5. Единственный найденный корень запрещён

Условие Решить: x + 2 x − 1 = 3 x − 1 .
Решение.
ОДЗ: x ≠ 1.
После умножения на x − 1:

x + 2 = 3,
x = 1.
Число 1 не входит в ОДЗ, поэтому оно не является корнем.
Ответ: корней нет.

Пример 6. Один корень допустим, другой исключается

Условие Решить: x2 − 4 x − 2 = 5.
Решение.
ОДЗ: x ≠ 2.
x2 − 4 = 5(x − 2).
x2 − 5x + 6 = 0,
(x − 2)(x − 3) = 0.
x = 2 или x = 3.
x = 2 не входит в ОДЗ; x = 3 допустим.
Ответ: 3.
Нельзя сначала сократить дробь на x − 2 и забыть ограничение x ≠ 2. Упрощённое выражение x + 2 равно исходной дроби только при x ≠ 2.

6. Особые результаты после освобождения от дробей

Полученное равенство Вывод Ответ
0 = 0 или 5x + 1 = 5x + 1 Равенство верно при всех допустимых x. Все значения из ОДЗ
0 = 7 или 3 = −2 Получено неверное числовое равенство. Корней нет
Линейное или квадратное уравнение Решаем его обычным способом. Только корни из ОДЗ
Если после преобразований получилось тождество, это не означает, что подходят абсолютно все числа. Запрещённые значения из ОДЗ по-прежнему исключаются.

7. Самопроверка

Задание 1. Решите: 2x + 3 x − 1 = 5.

Показать решение
ОДЗ: x ≠ 1.

2x + 3 = 5(x − 1),
2x + 3 = 5x − 5,
3x = 8,
x = 8 3 .

Найденное значение входит в ОДЗ.

Ответ: 8 3 .

Задание 2. Решите: 7 x + 2 = 1.

Показать решение
ОДЗ: x ≠ −2.

7 = x + 2,
x = 5.

Ответ: 5.

Задание 3. Решите: 3 x − 2 = 2 x + 1 .

Показать решение
ОДЗ: x ≠ 2, x ≠ −1.

3(x + 1) = 2(x − 2),
3x + 3 = 2x − 4,
x = −7.

Ответ: −7.

Задание 4. Решите: 1 x + 1 x + 2 = 3 x + 2 .

Показать решение
ОДЗ: x ≠ 0, x ≠ −2.

Умножим уравнение на x(x + 2):

x + 2 + x = 3x,
2x + 2 = 3x,
x = 2.

Ответ: 2.

Задание 5. Решите: x + 4 x − 3 = 7 x − 3 .

Показать решение
ОДЗ: x ≠ 3.

x + 4 = 7,
x = 3.

Число 3 не входит в ОДЗ.

Ответ: корней нет.

Задание 6. Решите: x2 − 9 x − 3 = 6.

Показать решение
ОДЗ: x ≠ 3.

x² − 9 = 6(x − 3),
x² − 6x + 9 = 0,
(x − 3)² = 0,
x = 3.

Найденное значение не входит в ОДЗ.

Ответ: корней нет.

Задание 7. Решите: x2 − 1 x − 1 = 4.

Показать решение
ОДЗ: x ≠ 1.

x² − 1 = 4(x − 1),
x² − 4x + 3 = 0,
(x − 1)(x − 3) = 0.

x = 1 или x = 3. Значение x = 1 запрещено.

Ответ: 3.

Задание 8. Решите: 2 x − 1 x − 1 = x − 2 x(x − 1) .

Показать решение
ОДЗ: x ≠ 0, x ≠ 1.

После умножения на x(x − 1):

2(x − 1) − x = x − 2.

2x − 2 − x = x − 2,
x − 2 = x − 2.

Получено тождество.

Ответ: все x, кроме 0 и 1.

Задание 9. Решите: 1 x − 2 − 1 x − 2 = 5.

Показать решение
ОДЗ: x ≠ 2.

Левая часть равна нулю:

0 = 5.

Получено неверное равенство.

Ответ: корней нет.

Задание 10. Ученик решил уравнение x2 − 4 x − 2 = 5 и записал два корня: 2 и 3. Найдите ошибку.

Показать решение
В исходном уравнении x ≠ 2, потому что при x = 2 знаменатель равен нулю.

После освобождения от знаменателя действительно получаются значения 2 и 3, но число 2 является посторонним корнем.

Ответ: единственный корень — 3.

8. Как легко запомнить: маршрут от дробей к ответу

Не пытайтесь сразу «убрать знаменатели». Сначала пройдите весь маршрут по порядку — тогда запрещённое значение не попадёт в ответ.

1 Разложить Представьте сложные знаменатели в виде произведений.
2 Записать ОДЗ Исключите все нули исходных знаменателей.
3 Найти общий знаменатель Он должен делиться на каждый знаменатель уравнения.
4 Убрать дроби Умножьте обе части на общий знаменатель.
5 Решить Решите полученное целое уравнение обычным способом.
6 Отсеять Удалите корни, которые не входят в исходное ОДЗ.

Следующая тема открывает раздел «Действительные числа»: повторим натуральные, целые и рациональные числа и установим связь между соответствующими числовыми множествами.
