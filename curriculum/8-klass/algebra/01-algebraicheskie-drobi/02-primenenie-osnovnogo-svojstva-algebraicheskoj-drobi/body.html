Что пригодится перед изучением темы

Основное свойство алгебраической дроби опирается на свойства обыкновенных дробей и разложение многочленов на множители. Особенно важно различать множители и отдельные слагаемые.

Разложение на множители

x2 − 9 = (x − 3)(x + 3), а 6a2 + 12a = 6a(a + 2).

Общий множитель

Сокращать можно только одинаковые множители числителя и знаменателя, а не отдельные части суммы или разности.

Допустимые значения

Знаменатель исходной дроби не должен быть равен нулю. Эти ограничения сохраняются и после упрощения.

Деление на ноль запрещено

Множитель, на который делят числитель и знаменатель, обязательно должен быть отличен от нуля.

1. Основное свойство алгебраической дроби

Значение дроби не изменяется, если её числитель и знаменатель одновременно умножить или разделить на одно и то же выражение, не равное нулю.

При B ≠ 0 и C ≠ 0 выполняется:

AB = A · CB · C.

Если числитель и знаменатель содержат общий ненулевой множитель C, то:

A · CB · C = AB.
Преобразование Что происходит Для чего применяется
Умножение числителя и знаменателя на C Появляется дополнительный множитель Приведение к нужному знаменателю
Деление числителя и знаменателя на C Общий множитель исчезает Сокращение дроби
Одновременная перемена знаков Числитель и знаменатель умножаются на −1 Удобная запись выражения

2. Почему значение дроби не меняется

Умножение числителя и знаменателя на C равносильно умножению всей дроби на дробь CC. При C ≠ 0 эта дробь равна 1, а умножение на 1 не изменяет значение выражения.

AB · CC = A · CB · C, потому что CC = 1.
Числовая аналогия 35 = 3 · 45 · 4 = 1220. Обе дроби обозначают одно и то же число.
Если C = 0, дробь CC не имеет смысла. Поэтому условие C ≠ 0 является обязательным.

3. Как привести дробь к нужному знаменателю

Сначала нужно выяснить, на какой множитель следует умножить исходный знаменатель, чтобы получить требуемый. Затем на этот же множитель умножают числитель.

Порядок действий:

1. Разложите новый и исходный знаменатели на множители.
2. Найдите недостающий множитель.
3. Умножьте на него и числитель, и знаменатель.
4. Проверьте, что недостающий множитель не равен нулю.

Пример 1. Числовой дополнительный множитель

Условие Привести дробь 5a3b к знаменателю 12b.
Решение.
Чтобы из 3b получить 12b, нужно умножить на 4.
5a3b = 5a · 43b · 4 = 20a12b.
Ответ: 20a12b, b ≠ 0.

Пример 2. Дополнительный множитель с переменной

Условие Привести дробь x + 1x − 2 к знаменателю x2 − 4.
Решение.
x2 − 4 = (x − 2)(x + 2).
Недостающий множитель — x + 2.
x + 1x − 2 = (x + 1)(x + 2)(x − 2)(x + 2) = (x + 1)(x + 2)x2 − 4.
Преобразование верно при x ≠ 2 и x ≠ −2.

4. Сокращение алгебраической дроби

Сократить алгебраическую дробь — значит разделить её числитель и знаменатель на общий ненулевой множитель. Для этого числитель и знаменатель сначала представляют в виде произведений.

Алгоритм сокращения:

1. Найдите ОДЗ исходной дроби.
2. Разложите числитель и знаменатель на множители.
3. Найдите одинаковые множители.
4. Сократите только общие множители.
5. Сохраните ограничения исходной дроби.

Пример 3. Сокращение одночленов

Условие Сократить дробь 15a2b20ab2.
Решение.
Исходный знаменатель не равен нулю при a ≠ 0 и b ≠ 0.
15a2b = 5ab · 3a, 20ab2 = 5ab · 4b.
5ab · 3a5ab · 4b = 3a4b.
Ответ: 3a4b, a ≠ 0, b ≠ 0.

Пример 4. Использование разности квадратов

Условие Сократить дробь x2 − 25x − 5.
Решение.
ОДЗ: x ≠ 5.
x2 − 25 = (x − 5)(x + 5).
(x − 5)(x + 5)x − 5 = x + 5.
Ответ: x + 5, где x ≠ 5.

Пример 5. Разложение числителя и знаменателя

Условие Сократить дробь m2 + 3mm2 − 9.
Решение.
ОДЗ: m ≠ 3 и m ≠ −3.
m2 + 3m = m(m + 3).
m2 − 9 = (m − 3)(m + 3).
m(m + 3)(m − 3)(m + 3) = mm − 3.
Ответ: mm − 3, m ≠ 3, m ≠ −3.

5. Знаки в алгебраической дроби

Если одновременно изменить знаки числителя и знаменателя, значение дроби не изменится. Это соответствует умножению обеих частей дроби на −1.

AB = −A−B.
−AB = A−B = − AB.
Пример 6 Так как 3 − x = −(x − 3), то при x ≠ 3:

3 − xx − 3 = −(x − 3)x − 3 = −1.

6. Что сокращать нельзя

Сокращение возможно только тогда, когда весь числитель и весь знаменатель представлены произведениями. Слагаемые внутри суммы или разности сокращать нельзя.

Запись Оценка Объяснение
x(x + 4)x(x − 1) = x + 4x − 1 Верно при x ≠ 0 и x ≠ 1 x является общим множителем числителя и знаменателя.
x + 4x + 7 = 47 Неверно x входит в суммы и не является множителем всего числителя и знаменателя.
x + 5x = 1 + 5x Верно при x ≠ 0 Числитель разделён на знаменатель по частям, сокращения слагаемых нет.
После сокращения внешний вид выражения может стать проще, но ограничения исходной дроби не исчезают. Например, x(x − 4)x = x − 4 только при x ≠ 0.

7. Самопроверка

Задание 1. Умножьте числитель и знаменатель дроби 2a3b на 5x. Считайте, что x ≠ 0.

Показать решение
Умножаем и числитель, и знаменатель на 5x:

2a · 5x3b · 5x = 10ax15bx.

Ответ: 10ax15bx.

Задание 2. Приведите дробь 3x − 2 к знаменателю 4x − 8.

Показать решение
4x − 8 = 4(x − 2), поэтому дополнительный множитель равен 4:

3x − 2 = 124x − 8.

Ответ: 124x − 8, x ≠ 2.

Задание 3. Сократите дробь 18a2b24ab2.

Показать решение
ОДЗ: a ≠ 0, b ≠ 0. Общий множитель числителя и знаменателя — 6ab:

18a2b24ab2 = 3a4b.

Ответ: 3a4b, a ≠ 0, b ≠ 0.

Задание 4. Сократите дробь x2 − 36x − 6.

Показать решение
ОДЗ: x ≠ 6. Разложим разность квадратов:
x2 − 36 = (x − 6)(x + 6).

(x − 6)(x + 6)x − 6 = x + 6.

Ответ: x + 6, x ≠ 6.

Задание 5. Сократите дробь m2 − 4mm2 − 16.

Показать решение
ОДЗ: m ≠ 4 и m ≠ −4.
m2 − 4m = m(m − 4),
m2 − 16 = (m − 4)(m + 4).

m(m − 4)(m − 4)(m + 4) = mm + 4.

Ответ: mm + 4, m ≠ 4, m ≠ −4.

Задание 6. Упростите дробь 7 − aa − 7.

Показать решение
7 − a = −(a − 7), поэтому при a ≠ 7:

7 − aa − 7 = −(a − 7)a − 7 = −1.

Ответ: −1, a ≠ 7.

Задание 7. Ученик записал: x + 5x = 5. Объясните ошибку и запишите верное преобразование.

Показать решение
x в числителе является слагаемым, а не множителем всего выражения x + 5. Поэтому сокращать его нельзя.

Верно:

x + 5x = xx + 5x = 1 + 5x, x ≠ 0.

Ответ: сокращение слагаемых выполнено неверно.

Задание 8. Упростите выражение y2 + 3yy и укажите ограничение.

Показать решение
ОДЗ: y ≠ 0. Вынесем y в числителе за скобки:

y(y + 3)y = y + 3.

Ответ: y + 3, y ≠ 0.

Задание 9. Приведите дробь a + 1a − 1 к знаменателю a2 − 1.

Показать решение
a2 − 1 = (a − 1)(a + 1), поэтому дополнительный множитель — a + 1:

a + 1a − 1 = (a + 1)2a2 − 1.

Для такого преобразования a ≠ 1 и a ≠ −1.

Ответ: (a + 1)2a2 − 1.

Задание 10. Сократите дробь 2x2 + 4xx2 − 4.

Показать решение
ОДЗ: x ≠ 2 и x ≠ −2.
2x2 + 4x = 2x(x + 2),
x2 − 4 = (x − 2)(x + 2).

2x(x + 2)(x − 2)(x + 2) = 2xx − 2.

Ответ: 2xx − 2, x ≠ 2, x ≠ −2.

8. Итог

Основное свойство: числитель и знаменатель можно одновременно умножить или разделить на один и тот же ненулевой множитель.

При сокращении: сначала разложите числитель и знаменатель на множители, затем уберите только одинаковые множители.

При приведении к знаменателю: найдите недостающий множитель и умножьте на него обе части дроби.

После упрощения: обязательно сохраните все ограничения, полученные из знаменателя исходной дроби.
