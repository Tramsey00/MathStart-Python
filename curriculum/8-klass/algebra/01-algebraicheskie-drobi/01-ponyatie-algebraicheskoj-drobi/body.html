Что нужно знать перед темой

Алгебраическая дробь объединяет знакомые понятия: многочлены, деление и дробную черту. Перед изучением темы полезно вспомнить, как подставлять число вместо переменной и почему делить на ноль нельзя.

  • Многочлен состоит из одночленов, соединённых знаками сложения и вычитания.
  • Дробная черта обозначает деление числителя на знаменатель.
  • Значение выражения находят подстановкой числовых значений переменных.
  • Если при подстановке знаменатель обращается в ноль, выражение не имеет смысла.

1. Что называют алгебраической дробью

В обычной дроби числитель и знаменатель являются числами. В алгебраической дроби на их месте могут находиться числа, переменные, одночлены или многочлены.

Алгебраическая дробь — это выражение вида AB, где A и B — многочлены. При вычислении значения дроби знаменатель B обязательно должен быть отличен от нуля.
A(x)B(x)
A(x) — числитель дроби.
B(x) — знаменатель дроби.
Главное условие: B(x) ≠ 0.

Переменная в знаменателе

5x − 2 — алгебраическая дробь. Её знаменатель зависит от x.

Многочлены сверху и снизу

a2 + 3a − 12a + 5 — алгебраическая дробь с многочленами.

Число тоже является многочленом

m − 47 — алгебраическая дробь с постоянным знаменателем.

Многочлен можно записать дробью

p2 − 3 = p2 − 31.

2. Почему знаменатель не может быть равен нулю

Дробь обозначает деление. Например, 123 = 4, потому что 3 · 4 = 12. При делении на ноль такого единственного результата получить нельзя, поэтому дробь со знаменателем 0 не имеет смысла.

В алгебраической дроби ограничение накладывает именно знаменатель: он не должен обращаться в ноль. Числитель при этом может быть равен нулю.
Рассмотрим дробь x − 2x + 5.
При x = 2 числитель равен 0, а знаменатель равен 7: 07 = 0. Значение допустимо.
При x = −5 знаменатель равен 0. Дробь не имеет смысла.
Нельзя автоматически запрещать значение x = 0. Запрещают только те значения, которые обращают в ноль конкретный знаменатель данной дроби.

3. Допустимые значения переменных

Допустимыми значениями переменных называют такие значения, при которых выражение имеет смысл. Их множество часто называют областью допустимых значений, сокращённо — ОДЗ.

Чтобы найти ограничения для алгебраической дроби:

1. Выделите знаменатель.
2. Найдите значения, при которых знаменатель равен нулю.
3. Исключите найденные значения.
4. Остальные значения являются допустимыми.

Пример 1. Линейный знаменатель

Условие Найти допустимые значения x для дроби 3x + 1x − 4.
Решение.
Знаменатель не должен быть равен нулю:
x − 4 ≠ 0.
Знаменатель обращается в ноль при x = 4.
Ответ: допустимы все значения x, кроме x = 4.

Пример 2. Знаменатель раскладывается на множители

Условие Найти допустимые значения a для дроби a + 2a2 − 9.
Решение.
Знаменатель должен быть отличен от нуля:
a2 − 9 ≠ 0.
Разложим разность квадратов:
a2 − 9 = (a − 3)(a + 3).
Произведение равно нулю при a = 3 или a = −3.
Ответ: a ≠ 3 и a ≠ −3.

Пример 3. Знаменатель никогда не равен нулю

Условие Найти допустимые значения m для дроби m − 1m2 + 4.
Решение.
Для любого числового значения m выполняется m2 ≥ 0.
Значит, m2 + 4 ≥ 4, поэтому знаменатель не обращается в ноль.
Ответ: допустимы все значения m.

4. Как найти значение алгебраической дроби

Если значение переменной допустимо, его подставляют одновременно во все места, где встречается эта переменная, затем отдельно вычисляют числитель и знаменатель.

Порядок вычисления:

1. Проверьте, не обращает ли данное значение знаменатель в ноль.
2. Подставьте значение переменной.
3. Вычислите числитель и знаменатель.
4. Выполните деление или оставьте ответ в виде дроби.

Пример 4. Подстановка одного значения

Условие Найти значение дроби 2x + 3x − 1 при x = 4.
Решение.
Проверяем знаменатель: 4 − 1 = 3 ≠ 0.
Подставляем x = 4:
2 · 4 + 34 − 1 = 113.
Ответ: 113.

Пример 5. Дробь с двумя переменными

Условие Найти значение дроби a + ba − b при a = 5 и b = 2.
Решение.
Проверяем знаменатель: 5 − 2 = 3 ≠ 0.
5 + 25 − 2 = 73.
Ответ: 73.

5. Что важно не перепутать

Ситуация Можно или нельзя Почему
Числитель равен нулю, знаменатель не равен нулю Можно Значение дроби равно нулю
Знаменатель равен нулю Нельзя Деление на ноль не определено
Переменная равна нулю, но знаменатель не обращается в ноль Можно Само значение переменной 0 не запрещено
Знаменатель является ненулевым числом Можно при любых значениях переменных Постоянный знаменатель не может обратиться в ноль
Ограничения всегда определяют по исходному знаменателю. Даже если в следующей теме дробь удастся упростить, запрещённые значения исходного выражения нужно сохранить.

6. Самопроверка

Задание 1. Назовите числитель и знаменатель дроби 3x − 52x + 7.

Показать решение
Выражение над дробной чертой является числителем, а выражение под чертой — знаменателем.

Ответ: числитель 3x − 5, знаменатель 2x + 7.

Задание 2. Является ли выражение 4m − 1m2 + 3 алгебраической дробью?

Показать решение
Числитель 4m − 1 и знаменатель m2 + 3 являются многочленами. Следовательно, выражение имеет вид алгебраической дроби.

Ответ: да.

Задание 3. Найдите значение x, при котором дробь 5x + 7 не имеет смысла.

Показать решение
Приравниваем знаменатель к нулю:
x + 7 = 0,
x = −7.

Ответ: x = −7.

Задание 4. Найдите допустимые значения a для дроби 2a − 1a2 − 25.

Показать решение
Знаменатель не должен быть равен нулю:
a2 − 25 ≠ 0.
a2 − 25 = (a − 5)(a + 5).
Знаменатель равен нулю при a = 5 или a = −5.

Ответ: a ≠ 5 и a ≠ −5.

Задание 5. Допустимо ли значение x = 2 для дроби x + 1x2 − 4?

Показать решение
Подставим x = 2 в знаменатель:
22 − 4 = 4 − 4 = 0.
Знаменатель обращается в ноль, поэтому значение недопустимо.

Ответ: нет.

Задание 6. Найдите значение дроби 3x − 2x + 1 при x = 3.

Показать решение
Знаменатель: 3 + 1 = 4 ≠ 0.
Подставляем x = 3:
3 · 3 − 23 + 1 = 74.

Ответ: 74.

Задание 7. Найдите значение дроби a + ba − b при a = 5 и b = 2.

Показать решение
Знаменатель: 5 − 2 = 3 ≠ 0.
5 + 25 − 2 = 73.

Ответ: 73.

Задание 8. Допустимо ли значение x = 4 для дроби x − 4x + 2? Чему равно значение дроби?

Показать решение
При x = 4 знаменатель равен 4 + 2 = 6, то есть не равен нулю.
Числитель равен 4 − 4 = 0.
06 = 0.

Ответ: значение допустимо, дробь равна 0.

Задание 9. Найдите допустимые значения m для дроби m + 6m(m − 3).

Показать решение
Знаменатель m(m − 3) равен нулю, если хотя бы один множитель равен нулю:
m = 0 или m − 3 = 0.
Во втором случае m = 3.

Ответ: m ≠ 0 и m ≠ 3.

Задание 10. Запишите алгебраическую дробь, числитель которой равен x2 − 9, а знаменатель равен x − 3. Укажите допустимые значения x.

Показать решение
Составляем дробь:
x2 − 9x − 3.
Знаменатель не должен быть равен нулю:
x − 3 ≠ 0, поэтому x ≠ 3.

Ответ: x2 − 9x − 3, x ≠ 3.

7. Краткая опора по теме

Алгебраическая дробь: AB, где A и B — многочлены.

Основное ограничение: B ≠ 0.

Чтобы найти недопустимые значения: приравняйте знаменатель к нулю и исключите найденные корни.

Важно: нулевой числитель допустим, если знаменатель не равен нулю.
