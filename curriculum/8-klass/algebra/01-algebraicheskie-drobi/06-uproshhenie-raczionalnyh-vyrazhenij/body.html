Упрощение рациональных выражений

Объединим все изученные действия с алгебраическими дробями: научимся выбирать правильный порядок преобразований, находить ОДЗ, приводить дроби к общему знаменателю, сокращать множители и получать наиболее простую форму рационального выражения.

Что значит упростить выражение

Упростить рациональное выражение — значит заменить его равным выражением, которое содержит меньше действий, имеет более короткую запись или удобнее для дальнейших вычислений. При этом обязательно сохраняются ограничения, заданные исходными знаменателями.

Разложить

Представить многочлены в виде произведения, используя общий множитель и формулы сокращённого умножения.

Привести

Найти общий знаменатель и правильно умножить каждый числитель на дополнительный множитель.

Выполнить действия

Соблюдать порядок действий: сначала скобки, затем умножение и деление, после этого сложение и вычитание.

Сократить

Сокращать только одинаковые множители числителя и знаменателя, а не отдельные слагаемые.

1. Рациональное выражение и его ОДЗ

Рациональным называют выражение, составленное из чисел и переменных с помощью сложения, вычитания, умножения, деления и возведения в целую неотрицательную степень. Если в выражении есть деление на выражение с переменной, нужно определить допустимые значения переменной.

Главное ограничение: ни один знаменатель исходного выражения не должен быть равен нулю.

ОДЗ записывают до начала сокращений. Значения, запрещённые исходным выражением, нельзя возвращать после его упрощения.
Знаменатель Условие Ограничение
x − 4 x − 4 ≠ 0 x ≠ 4
x(x + 3) x(x + 3) ≠ 0 x ≠ 0, x ≠ −3
x² − 9 (x − 3)(x + 3) ≠ 0 x ≠ 3, x ≠ −3
Если выражение делят на дробь, то эта дробь должна быть не только определена, но и не равна нулю. Поэтому дополнительно проверяют её числитель.

2. Универсальный порядок упрощения

ОДЗ → Разложение → Скобки → Умножение и деление → Сложение и вычитание → Сокращение
Алгоритм:

1. Выпишите ограничения всех исходных знаменателей.
2. Разложите числители и знаменатели на множители.
3. Выполните действия в скобках.
4. Деление замените умножением на обратную дробь.
5. До перемножения сократите одинаковые множители.
6. Для сложения и вычитания найдите общий знаменатель.
7. Приведите подобные слагаемые и снова проверьте возможность сокращения.
Не обязательно раскрывать все скобки. Если выражения уже представлены в виде множителей, такая запись часто удобнее для сокращения.

3. Умножение и сокращение в сложном выражении

Пример 1. Полное сокращение произведения

Условие Упростить: x2 − 4 x2 + 4x + 4 · x + 2 x − 2 .
Решение.
ОДЗ: x ≠ −2, x ≠ 2.
x2 − 4 = (x − 2)(x + 2),
x2 + 4x + 4 = (x + 2)2.
(x − 2)(x + 2) (x + 2)2 · x + 2 x − 2 = 1.
Ответ: 1, x ≠ −2, x ≠ 2.

Пример 2. Скобки перед умножением

Условие Упростить: ( m m + 1 + 1 m + 1 ) · m2 − 1 m − 1 .
Решение.
ОДЗ: m ≠ −1, m ≠ 1.
m + 1 m + 1 · (m − 1)(m + 1) m − 1 = 1 · (m + 1).
Ответ: m + 1, m ≠ −1, m ≠ 1.

4. Сложение и вычитание нескольких дробей

Пример 3. Общий знаменатель и приведение подобных

Условие Упростить: 3 x − 1 + 2 x + 1 − 5x − 1 x2 − 1 .
Решение.
ОДЗ: x ≠ 1, x ≠ −1.
x2 − 1 = (x − 1)(x + 1).
3(x + 1) + 2(x − 1) − (5x − 1) (x − 1)(x + 1) .
3x + 3 + 2x − 2 − 5x + 1 = 2.
Ответ: 2 x2 − 1 , x ≠ ±1.

Пример 4. Знаменатель исчез после сокращения

Условие Упростить: a2 − 4a + 4 a − 2 − 3a − 6 a − 2 .
Решение.
ОДЗ: a ≠ 2.
a2 − 4a + 4 − (3a − 6) a − 2 = a2 − 7a + 10 a − 2 .
a2 − 7a + 10 = (a − 5)(a − 2).
(a − 5)(a − 2) a − 2 = a − 5.
Ответ: a − 5, a ≠ 2.

5. Деление и сложные дроби

Пример 5. Деление на алгебраическую дробь

Условие Упростить: ( a a − 3 − 3 a − 3 ) : a + 2 a − 3 .
Решение.
ОДЗ: a ≠ 3. Делитель не должен быть равен нулю, поэтому a ≠ −2.
a − 3 a − 3 : a + 2 a − 3 = 1 · a − 3 a + 2 .
Ответ: a − 3 a + 2 , a ≠ 3, a ≠ −2.

Пример 6. Дробь, в числителе и знаменателе которой стоят дроби

Условие Упростить: 1 x + 1 y 1 x − 1 y .
Решение. ОДЗ: x ≠ 0, y ≠ 0, x ≠ y.
В числителе: 1 x + 1 y = x + y xy .
В знаменателе: 1 x − 1 y = y − x xy .
x + y xy : y − x xy = x + y y − x .
Ответ: x + y y − x , x ≠ 0, y ≠ 0, x ≠ y.

6. Типичные ошибки при упрощении

Ошибка Почему неверно Как правильно
x + 4 x = 4 Сокращены отдельные слагаемые. x + 4 x = 1 + 4 x
ОДЗ записано после сокращения Исчезнувший знаменатель может скрыть запрещённое значение. Сначала выписать ограничения исходной записи.
При делении перевёрнуты обе дроби Обратной заменяют только вторую дробь. A B : C D = A B · D C
Все скобки сразу раскрыты Теряются множители, удобные для сокращения. Сначала проверить, можно ли сохранить разложение.
Хорошее упрощение — не обязательно самое длинное решение. Цель состоит в том, чтобы выполнять только необходимые преобразования.

7. Самопроверка

Задание 1. Упростите: x2 − 25 x2 + 10x + 25 · x + 5 x − 5 .

Показать решение
ОДЗ: x ≠ −5, x ≠ 5.

x² − 25 = (x − 5)(x + 5), а x² + 10x + 25 = (x + 5)².

После сокращения всех одинаковых множителей получаем 1.

Ответ: 1, x ≠ −5, x ≠ 5.

Задание 2. Упростите: 4 a − 2 − a + 2 a − 2 .

Показать решение
ОДЗ: a ≠ 2.

4 − (a + 2) a − 2 = 2 − a a − 2 = −(a − 2) a − 2 = −1.

Ответ: −1, a ≠ 2.

Задание 3. Упростите: 2x + 3x + 1 − 5x + 2 x(x + 1) .

Показать решение
ОДЗ: x ≠ 0, x ≠ −1.

Общий знаменатель: x(x + 1).

Числитель: 2(x + 1) + 3x − (5x + 2) = 2x + 2 + 3x − 5x − 2 = 0.

Ответ: 0, x ≠ 0, x ≠ −1.

Задание 4. Упростите: ( bb − 4 − 4b − 4 ) : b + 1b − 4.

Показать решение
ОДЗ: b ≠ 4, b ≠ −1.

Выражение в скобках равно 1. Поэтому:

1 : b + 1b − 4 = b − 4b + 1.

Ответ: b − 4b + 1, b ≠ 4, b ≠ −1.

Задание 5. Упростите: m2 − 9 m2 − 6m + 9 · m − 3 m + 3 .

Показать решение
ОДЗ: m ≠ 3, m ≠ −3.

m² − 9 = (m − 3)(m + 3), m² − 6m + 9 = (m − 3)².

После сокращения получаем 1.

Ответ: 1, m ≠ 3, m ≠ −3.

Задание 6. Упростите: ( x + 1x − 1 − 2x − 1 ) · x − 1x + 1.

Показать решение
ОДЗ: x ≠ 1, x ≠ −1.

В скобках: x − 1x − 1 = 1.

Следовательно, результат равен x − 1x + 1.

Ответ: x − 1x + 1, x ≠ 1, x ≠ −1.

Задание 7. Упростите сложную дробь: 2x 4x2 .

Показать решение
ОДЗ: x ≠ 0.

2x : 4x2 = 2x · x24 = x2.

Ответ: x2, x ≠ 0.

Задание 8. Ученик записал: x2 + 4xx2 = x + 4. Найдите ошибку и упростите выражение правильно.

Показать решение
Нельзя сокращать отдельное слагаемое x² в сумме. Сначала нужно вынести общий множитель:

x(x + 4)x2 = x + 4x, x ≠ 0.

Ответ: x + 4x, x ≠ 0.

Задание 9. После сокращения выражения x2 − 9x − 3 получилось x + 3. Можно ли подставить x = 3 в исходное выражение?

Показать решение
Нет. В исходном выражении знаменатель x − 3 обращается в ноль при x = 3.

Равенство x2 − 9x − 3 = x + 3 выполняется только при x ≠ 3.

Ответ: нельзя; x = 3 не входит в ОДЗ.

Задание 10. Упростите: ( aa + 2 + 2a + 2 ) · a2 − 4a − 2.

Показать решение
ОДЗ: a ≠ −2, a ≠ 2.

Первая скобка равна 1, а a² − 4 = (a − 2)(a + 2).

1 · (a − 2)(a + 2)a − 2 = a + 2.

Ответ: a + 2, a ≠ −2, a ≠ 2.

8. Быстрый чек-ап: выражение действительно упрощено?

Перед тем как записать ответ, пройдите пять коротких проверок.

1
ОДЗ записано Все нули исходных знаменателей исключены до выполнения сокращений.
2
Порядок действий соблюдён Сначала выполнены действия в скобках, затем умножение и деление, после них — сложение и вычитание.
3
Сокращены только множители Перед сокращением числитель и знаменатель представлены в виде произведений.
4
Результат не усложнён заново Лишние скобки раскрыты только там, где это действительно сделало запись короче.
5
Ограничения сохранены в ответе Даже исчезнувшие после сокращения знаменатели продолжают задавать запрещённые значения.
