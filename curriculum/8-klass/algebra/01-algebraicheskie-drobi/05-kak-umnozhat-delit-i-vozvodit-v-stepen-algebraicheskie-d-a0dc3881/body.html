Как умножать, делить и возводить в степень алгебраические дроби

Разберём правила умножения и деления алгебраических дробей, научимся заранее сокращать множители, правильно переворачивать делитель и возводить в степень числитель и знаменатель.

Что важно помнить

При умножении и делении алгебраических дробей общий знаменатель искать не нужно. Главная задача — разложить выражения на множители, правильно применить правило действия и сократить только общие множители.

Разложение на множители

Используйте вынесение общего множителя, формулы сокращённого умножения и группировку.

Сокращаются множители

Нельзя сокращать отдельные слагаемые внутри суммы или разности. Сначала выражение нужно представить в виде произведения.

Делитель не равен нулю

При делении необходимо проверить не только знаменатели, но и числитель второй дроби.

Ограничения сохраняются

После сокращения исходные недопустимые значения переменных не становятся допустимыми.

1. Умножение алгебраических дробей

Чтобы умножить две алгебраические дроби, нужно перемножить их числители и отдельно перемножить знаменатели.

При B ≠ 0 и D ≠ 0:

AB · CD = A · CB · D.
Шаг Действие
1 Запишите ОДЗ по знаменателям исходных дробей.
2 Разложите числители и знаменатели на множители.
3 Сократите одинаковые множители в числителе и знаменателе.
4 Перемножьте оставшиеся множители или оставьте ответ в удобном виде.

Пример 1. Умножение с сокращением

Условие Упростить: 6a25b · 10b29a.
Решение.
ОДЗ: a ≠ 0, b ≠ 0.
6a2 · 10b25b · 9a.
Сократим числа и одинаковые буквенные множители:
6 · 10 · a2 · b25 · 9 · a · b = 4ab3.
Ответ: 4ab3, a ≠ 0, b ≠ 0.

Пример 2. Сначала разложение на множители

Условие Упростить: x2 − 9x2 − x − 6 · x − 2x + 3.
Решение.
ОДЗ: x2 − x − 6 ≠ 0 и x + 3 ≠ 0.
x2 − x − 6 = (x − 3)(x + 2), поэтому x ≠ 3, x ≠ −2, x ≠ −3.
x2 − 9 = (x − 3)(x + 3).
(x − 3)(x + 3)(x − 3)(x + 2) · x − 2x + 3 = x − 2x + 2.
Ответ: x − 2x + 2, x ≠ 3, x ≠ −2, x ≠ −3.

2. Предварительное сокращение

Часто удобнее не перемножать многочлены сразу, а сначала представить их в виде произведений и сократить общие множители. Это делает вычисления короче и уменьшает вероятность ошибки.

Удобный порядок: разложение на множители → сокращение → умножение оставшихся множителей.
Преобразование Оценка Причина
(x − 2)(x + 5)(x − 2)(x + 1) = x + 5x + 1 Верно Сокращён общий множитель x − 2.
x + 5x + 1 = 51 Неверно Слагаемые x нельзя сокращать.
3x(x − 4)6(x − 4) = x2 Верно Сокращены множители 3 и x − 4.
Сокращение означает деление числителя и знаменателя на один и тот же ненулевой множитель. Поэтому сокращать можно только множители, а не части суммы или разности.

3. Деление алгебраических дробей

Чтобы разделить одну алгебраическую дробь на другую, нужно первую дробь оставить без изменения, знак деления заменить умножением, а вторую дробь заменить обратной.

При B ≠ 0, C ≠ 0 и D ≠ 0:

AB : CD = AB · DC = A · DB · C.

Пример 3. Деление двух дробей

Условие Упростить: 8x215y : 4x5y2.
Решение.
ОДЗ: x ≠ 0, y ≠ 0.
8x215y · 5y24x = 2xy3.
Ответ: 2xy3, x ≠ 0, y ≠ 0.

Пример 4. Деление с разложением многочленов

Условие Упростить: a2 − 4a2 − 5a + 6 : a + 2a − 3.
Решение.
Из знаменателей: a ≠ 2, a ≠ 3.
Делитель не должен быть равен нулю, поэтому a + 2 ≠ 0, то есть a ≠ −2.
a2 − 4 = (a − 2)(a + 2), a2 − 5a + 6 = (a − 2)(a − 3).
(a − 2)(a + 2)(a − 2)(a − 3) · a − 3a + 2 = 1.
Ответ: 1, a ≠ −2, a ≠ 2, a ≠ 3.

4. Почему при делении появляются дополнительные ограничения

Знаменатели обеих исходных дробей должны быть ненулевыми. Кроме того, вся вторая дробь является делителем, поэтому она сама не должна быть равна нулю.

Дробь CD равна нулю тогда и только тогда, когда C = 0 и D ≠ 0.
Следовательно, при делении на эту дробь необходимо требовать C ≠ 0.
Источник ограничения Условие
Знаменатель первой дроби B ≠ 0
Знаменатель второй дроби D ≠ 0
Числитель второй дроби C ≠ 0, потому что делитель не может быть нулём
Числитель первой дроби может быть равен нулю: ноль разрешено делить на ненулевое число. Запрещено только деление на ноль.

5. Возведение алгебраической дроби в степень

При возведении алгебраической дроби в натуральную степень в эту степень возводятся и числитель, и знаменатель.

При B ≠ 0 и натуральном n:

( AB )n = AnBn.

Пример 5. Степень дроби с одночленами

Условие Возвести в степень: ( −2a23b )3.
Решение.
ОДЗ: b ≠ 0.
( −2a23b )3 = (−2)3 · (a2)333 · b3 = −8a627b3.
Ответ: −8a627b3, b ≠ 0.
Основание Степень Знак результата
Отрицательная дробь Чётная Положительный
Отрицательная дробь Нечётная Отрицательный
Положительная дробь Любая натуральная Положительный
Если рассматривается нулевая степень, то ненулевая алгебраическая дробь в степени 0 равна 1. При этом и числитель, и знаменатель исходной дроби должны быть ненулевыми.

6. Несколько действий в одном выражении

В выражениях с умножением, делением и степенями сначала выполняют возведение в степень, затем заменяют деление умножением на обратную дробь, раскладывают выражения на множители и сокращают.

Пример 6. Степень, деление и сокращение

Условие Упростить: ( xx − 1 )2 : x2x2 − 1.
Решение.
Из знаменателей: x ≠ 1, x ≠ −1.
Делитель не равен нулю, поэтому x ≠ 0.
( xx − 1 )2 · x2 − 1x2 = x2(x − 1)2 · (x − 1)(x + 1)x2.
После сокращения: x + 1x − 1.
Ответ: x + 1x − 1, x ≠ −1, x ≠ 0, x ≠ 1.
Порядок проверки: сначала ОДЗ → затем степени → замена деления умножением → разложение на множители → сокращение → окончательная запись ответа.

7. Самопроверка

Задание 1. Упростите: 3a4b · 8b29a.

Показать решение
ОДЗ: a ≠ 0, b ≠ 0.

3a · 8b24b · 9a = 2b3.

Ответ: 2b3, a ≠ 0, b ≠ 0.

Задание 2. Упростите: x2 − 4x2 + 3x + 2 · x + 1x − 2.

Показать решение
ОДЗ: x ≠ −1, x ≠ −2, x ≠ 2.

x2 − 4 = (x − 2)(x + 2), x2 + 3x + 2 = (x + 1)(x + 2).

(x − 2)(x + 2)(x + 1)(x + 2) · x + 1x − 2 = 1.

Ответ: 1, x ≠ −2, x ≠ −1, x ≠ 2.

Задание 3. Выполните деление: 5m26n : 10m9n2.

Показать решение
ОДЗ: m ≠ 0, n ≠ 0.

5m26n · 9n210m = 3mn4.

Ответ: 3mn4, m ≠ 0, n ≠ 0.

Задание 4. Упростите: a2 − 9a2 − 6a + 9 : a + 3a − 3.

Показать решение
Из знаменателей: a ≠ 3. Делитель не равен нулю, поэтому a ≠ −3.

a2 − 9 = (a − 3)(a + 3), a2 − 6a + 9 = (a − 3)2.

(a − 3)(a + 3)(a − 3)2 · a − 3a + 3 = 1.

Ответ: 1, a ≠ −3, a ≠ 3.

Задание 5. Возведите в степень: ( −3x2y2 )2.

Показать решение
ОДЗ: y ≠ 0.

( −3x2y2 )2 = 9x24y4.

Ответ: 9x24y4, y ≠ 0.

Задание 6. Возведите в степень: ( 2a2b5c )3.

Показать решение
ОДЗ: c ≠ 0.

( 2a2b5c )3 = 8a6b3125c3.

Ответ: 8a6b3125c3, c ≠ 0.

Задание 7. Упростите: x2 − 1x2 − 2x + 1 · x − 1x + 1.

Показать решение
ОДЗ: x ≠ 1, x ≠ −1.

x2 − 1 = (x − 1)(x + 1), x2 − 2x + 1 = (x − 1)2.

(x − 1)(x + 1)(x − 1)2 · x − 1x + 1 = 1.

Ответ: 1, x ≠ −1, x ≠ 1.

Задание 8. Упростите: p2 − 4pp2 − 16 : pp + 4.

Показать решение
Из знаменателей: p ≠ −4, p ≠ 4. Делитель не равен нулю, поэтому p ≠ 0.

p2 − 4p = p(p − 4), p2 − 16 = (p − 4)(p + 4).

p(p − 4)(p − 4)(p + 4) · p + 4p = 1.

Ответ: 1, p ≠ −4, p ≠ 0, p ≠ 4.

Задание 9. Упростите: ( mm + 2 )2 : m2m2 − 4.

Показать решение
ОДЗ: m ≠ −2, m ≠ 2, m ≠ 0.

m2(m + 2)2 · (m − 2)(m + 2)m2 = m − 2m + 2.

Ответ: m − 2m + 2, m ≠ −2, m ≠ 0, m ≠ 2.

Задание 10. Ученик записал:

x + 3x · xx + 5 = 35.

Найдите ошибку и запишите правильный результат.

Показать решение
Ученик неверно сократил слагаемые x внутри выражений x + 3 и x + 5. Сокращать можно только общий множитель x:

(x + 3) · xx · (x + 5) = x + 3x + 5.

ОДЗ: x ≠ 0, x ≠ −5.

Ответ: x + 3x + 5, x ≠ 0, x ≠ −5.

8. Итог

Выберите действие и проверьте себя по короткой памятке.

Умножение Перемножьте числители и знаменатели. До вычислений разложите выражения на множители и выполните сокращение.
Деление Замените деление умножением и переверните только вторую дробь. Проверьте, что делитель не равен нулю.
Степень Возведите в степень весь числитель и весь знаменатель. Учитывайте чётность степени и знак дроби.
Сокращение Сокращайте только одинаковые множители. Слагаемые внутри суммы или разности сокращать нельзя.
ОДЗ Исключите нули исходных знаменателей, а при делении — также нули числителя второй дроби.
Финальная проверка Убедитесь, что результат сокращён, знаки расставлены верно, а все исходные ограничения сохранены.

В следующей теме объединим изученные действия и научимся упрощать рациональные выражения, содержащие несколько алгебраических дробей.
