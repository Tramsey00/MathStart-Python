Как складывать и вычитать алгебраические дроби с разными знаменателями

Научимся находить общий знаменатель, определять дополнительные множители, правильно преобразовывать числители и упрощать результат. Отдельно разберём дроби с одночленами, многочленами и знаменателями, которые сначала нужно разложить на множители.

Что нужно вспомнить

Дроби с разными знаменателями нельзя сразу объединить в одну дробь. Сначала их нужно привести к общему знаменателю — так же, как обычные числовые дроби.

Разложение на множители

Многочлены в знаменателях часто требуется разложить по формулам сокращённого умножения или вынесением общего множителя.

Наименьший общий знаменатель

Он должен делиться на каждый исходный знаменатель и по возможности не содержать лишних множителей.

Дополнительный множитель

Это выражение, на которое нужно умножить числитель и знаменатель дроби, чтобы получить выбранный общий знаменатель.

ОДЗ

Каждый исходный знаменатель должен быть отличен от нуля. Все найденные ограничения сохраняются после дальнейшего упрощения.

1. Зачем нужен общий знаменатель

Знаменатель показывает, на какие части разделено целое. Пока части имеют разный размер, их числители нельзя складывать или вычитать. Поэтому дроби сначала преобразуют так, чтобы знаменатели стали одинаковыми.

При B ≠ 0 и D ≠ 0:

AB + CD = AD + BCBD,

AB − CD = AD − BCBD.

Произведение BD всегда является общим знаменателем, но не всегда наименьшим. Если знаменатели имеют общие множители, удобнее выбрать более простой общий знаменатель.

Складывать или вычитать знаменатели нельзя. Сначала знаменатели делают одинаковыми, а затем выполняют действие только с числителями.

2. Как найти наименьший общий знаменатель

Сначала каждый знаменатель представляют в виде произведения. Затем в общий знаменатель включают все необходимые множители в наибольших встречающихся степенях.

Знаменатели Общий знаменатель Почему
2x и 3x 6x НОК чисел 2 и 3 равен 6, множитель x нужен один раз.
a и a2 a2 Берём наибольшую степень переменной.
x − 1 и x + 1 (x − 1)(x + 1) Множители различны, поэтому нужны оба.
x − 2 и x2 − 4 (x − 2)(x + 2) x2 − 4 = (x − 2)(x + 2) уже содержит первый знаменатель.
Дополнительный множитель находят делением общего знаменателя на знаменатель конкретной дроби.

Если общий знаменатель равен 6x, то для знаменателя 2x дополнительный множитель равен 3, а для знаменателя 3x — 2.

3. Полный алгоритм

Чтобы сложить или вычесть алгебраические дроби с разными знаменателями:

1. Запишите ОДЗ исходного выражения.
2. Разложите знаменатели на множители.
3. Найдите наименьший общий знаменатель.
4. Определите дополнительный множитель для каждой дроби.
5. Умножьте каждый числитель на его дополнительный множитель.
6. Объедините дроби и выполните действие в числителе.
7. Раскройте скобки и приведите подобные слагаемые.
8. Разложите результат на множители и сократите дробь, если возможно.
9. Сохраните все ограничения исходного выражения.
Дополнительный множитель умножает весь числитель. Если числитель состоит из нескольких слагаемых, его обязательно заключают в скобки.

4. Дроби с одночленами в знаменателях

Пример 1. Общий буквенный множитель

Условие Выполнить сложение: 32x + 53x.
Решение.
ОДЗ: x ≠ 0.
Наименьший общий знаменатель: 6x.
Для первой дроби дополнительный множитель 3, для второй — 2.
3 · 36x + 5 · 26x = 9 + 106x = 196x.
Ответ: 196x, x ≠ 0.

Пример 2. Разные степени переменной

Условие Выполнить вычитание: 4a − 3a2.
Решение.
ОДЗ: a ≠ 0.
Общий знаменатель: a2.
Первую дробь домножаем на aa.
4aa2 − 3a2 = 4a − 3a2.
Ответ: 4a − 3a2, a ≠ 0.

5. Дроби с многочленами в знаменателях

Пример 3. Два различных линейных множителя

Условие Упростить: 2x − 1 + 3x + 1.
Решение.
ОДЗ: x ≠ 1, x ≠ −1.
Общий знаменатель: (x − 1)(x + 1).
2(x + 1) + 3(x − 1)(x − 1)(x + 1) = 2x + 2 + 3x − 3x2 − 1 = 5x − 1x2 − 1.
Ответ: 5x − 1x2 − 1, x ≠ ±1.

Пример 4. Один знаменатель входит в другой

Условие Упростить: xx − 2 − 4x2 − 4.
Решение.
ОДЗ: x ≠ 2, x ≠ −2.
x2 − 4 = (x − 2)(x + 2).
Общий знаменатель: (x − 2)(x + 2). Первую дробь домножаем на x + 2.
x(x + 2) − 4(x − 2)(x + 2) = x2 + 2x − 4x2 − 4.
Сокращение невозможно.
Ответ: x2 + 2x − 4x2 − 4, x ≠ ±2.

Пример 5. После сложения дробь сокращается

Условие Упростить: x + 1x2 − 1 + 2x − 1.
Решение.
ОДЗ: x ≠ 1, x ≠ −1.
x2 − 1 = (x − 1)(x + 1).
x + 1 + 2(x + 1)(x − 1)(x + 1) = 3(x + 1)(x − 1)(x + 1) = 3x − 1.
Ответ: 3x − 1, x ≠ ±1.
После сокращения ограничение x ≠ −1 не исчезает: оно было получено из исходного знаменателя x2 − 1.

6. Несколько дробей и типичные ошибки

Пример 6. Три дроби в одном выражении

Условие Упростить: 1x − 2 − 2xx2 − 4 + 3x + 2.
Решение.
ОДЗ: x ≠ 2, x ≠ −2.
Общий знаменатель: (x − 2)(x + 2).
(x + 2) − 2x + 3(x − 2)(x − 2)(x + 2) = x + 2 − 2x + 3x − 6(x − 2)(x + 2).
2x − 4(x − 2)(x + 2) = 2(x − 2)(x − 2)(x + 2) = 2x + 2.
Ответ: 2x + 2, x ≠ ±2.
Ошибка Почему неверно Как правильно
Сложить знаменатели Дроби остаются разбитыми на части разного размера. Сначала привести к одному знаменателю.
Домножить только знаменатель Значение дроби изменится. Домножать одновременно числитель и знаменатель.
Не поставить скобки Дополнительный множитель относится ко всему числителю. Писать, например, 3(a − 2), а не 3a − 2.
Потерять ОДЗ после сокращения Исходная дробь всё равно не определена при запрещённом значении. Сохранять ограничения исходных знаменателей.

7. Самопроверка

Задание 1. Выполните сложение: 12x + 34x.

Показать решение
ОДЗ: x ≠ 0. Общий знаменатель: 4x.

24x + 34x = 54x.

Ответ: 54x, x ≠ 0.

Задание 2. Выполните вычитание: 53a − 29a.

Показать решение
ОДЗ: a ≠ 0. Общий знаменатель: 9a.

15 − 29a = 139a.

Ответ: 139a, a ≠ 0.

Задание 3. Выполните сложение: 4b + 1b2.

Показать решение
ОДЗ: b ≠ 0. Общий знаменатель: b2.

4b + 1b2.

Ответ: 4b + 1b2, b ≠ 0.

Задание 4. Упростите: 2x − 3 + 1x + 3.

Показать решение
ОДЗ: x ≠ 3, x ≠ −3.

2(x + 3) + (x − 3)(x − 3)(x + 3) = 3x + 3x2 − 9 = 3(x + 1)x2 − 9.

Ответ: 3(x + 1)x2 − 9, x ≠ ±3.

Задание 5. Упростите: 3y − 2 − 2y + 2.

Показать решение
ОДЗ: y ≠ 2, y ≠ −2.

3(y + 2) − 2(y − 2)(y − 2)(y + 2) = 3y + 6 − 2y + 4y2 − 4 = y + 10y2 − 4.

Ответ: y + 10y2 − 4, y ≠ ±2.

Задание 6. Упростите: xx + 1 + 1x2 − 1.

Показать решение
ОДЗ: x ≠ 1, x ≠ −1.

x2 − 1 = (x − 1)(x + 1).

x(x − 1) + 1(x − 1)(x + 1) = x2 − x + 1x2 − 1.

Ответ: x2 − x + 1x2 − 1, x ≠ ±1.

Задание 7. Упростите: a + 2a2 − 4 + 1a − 2.

Показать решение
ОДЗ: a ≠ 2, a ≠ −2.

a2 − 4 = (a − 2)(a + 2).

a + 2 + (a + 2)(a − 2)(a + 2) = 2(a + 2)(a − 2)(a + 2) = 2a − 2.

Ответ: 2a − 2, a ≠ ±2.

Задание 8. Упростите: 4m − 5 + 15 − m.

Показать решение
ОДЗ: m ≠ 5. Так как 5 − m = −(m − 5), то:

15 − m = − 1m − 5.

4 − 1m − 5 = 3m − 5.

Ответ: 3m − 5, m ≠ 5.

Задание 9. Упростите: 1x − 1 − 2x2 − 1 + 1x + 1.

Показать решение
ОДЗ: x ≠ 1, x ≠ −1.

Общий знаменатель: (x − 1)(x + 1).

(x + 1) − 2 + (x − 1)(x − 1)(x + 1) = 2x − 2(x − 1)(x + 1) = 2x + 1.

Ответ: 2x + 1, x ≠ ±1.

Задание 10. Ученик записал:

2x + 3x + 1 = 52x + 1.

Объясните ошибку и запишите правильный результат.

Показать решение
Знаменатели нельзя складывать. ОДЗ: x ≠ 0, x ≠ −1.

Общий знаменатель: x(x + 1).

2(x + 1) + 3xx(x + 1) = 2x + 2 + 3xx(x + 1) = 5x + 2x(x + 1).

Ответ: 5x + 2x(x + 1), x ≠ 0, x ≠ −1.

8. Итог

Первый шаг: разложите знаменатели на множители и запишите ОДЗ.

Общий знаменатель: включите в него все необходимые множители в наибольших встречающихся степенях.

Дополнительные множители: умножайте на них весь числитель, используя скобки.

После приведения: выполните действие с числителями, упростите результат и сократите общие множители.

ОДЗ: ограничения исходных знаменателей сохраняются даже после сокращения.

В следующей теме разберём умножение, деление и возведение алгебраических дробей в степень, а также предварительное сокращение множителей.
