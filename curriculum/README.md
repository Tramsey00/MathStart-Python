# Исходники уроков

**Начните с [указателя по классам и темам](INDEX.md).** Здесь находятся все 263 урока, включая прежние версии и версии 2.0.

Структура: `класс / предмет / раздел / урок`. Полные названия и адреса указаны в `lesson.json`.

- `body.html` — материал, формулы, рисунки и разметка интерактивных блоков; обязательный файл.
- `lesson.json` — метаданные и сведения о происхождении.
- `page.css` — необязательные стили, которые нужны только этому уроку.
- `page.js` — необязательный скрипт собственного интерактива темы.

Пустые `page.css` и `page.js` не нужны и не создаются при экспорте. Отсутствие такого файла означает отсутствие дополнительного ресурса: удаление файла с последующей публикацией также убирает его код из опубликованной страницы. `body.html` удалять нельзя.

Общее оформление хранится в `static/mathstart/`. Все уроки используют одну тему на основе «Свойства степенных функций и их графики 2.0»: основной стиль `lesson.css`, общие математические элементы, учебные компоненты, диаграммы и содержание. Формат исходника не создаёт отдельную тему оформления. Карточки, примеры, таблицы, заголовки и самопроверку нельзя заново оформлять в локальном `page.css`.

В `page.css` остаются только особенности, например размеры конкретного рисунка или расположение элементов своего интерактива. Сам SVG с координатами и подписями находится в `body.html`. Скрипты отдельных уроков вынесены в `page.js`, а график степенных функций 2.0 подключает общий ресурс из `static/mathstart/js/widgets/`. Общие карточки используют `ms-card`, сетки — `ms-card-grid`; число колонок и смысловые цвета задаются общими модификаторами, описанными в [справочнике стилей](../docs/lesson-theme.md).

Исторические CSS-файлы с хешами из `legacy/`, а также прежние `lesson-base.css` и `lesson-legacy.css` больше не используются. Не возвращайте ссылки на них или копии старой темы при редактировании.

Формат `component_html` используется для трёх подробных уроков 10 класса; `themed_html` — для остальных 260 тем. Содержание старых уроков пересобирается из заголовков разделов при публикации. Добавляя раздел, укажите его уникальный `id`. Подробности: [общий стиль](../docs/lesson-theme.md).

Публикация: `python manage.py publish_lessons --slug АДРЕС`. Предварительная проверка: добавьте `--dry-run`. Сравнение всех файлов с базой: `python manage.py check_lesson_sources --all`.

Читайте [инструкцию](../docs/editing-lessons.md) и [архитектуру](../docs/architecture.md). Прежние генераторы в `content/lessons/` сохранены для истории; актуальная редактура ведётся здесь.
