# Исходники уроков MathStart

Каталог `curriculum/` является источником истины для всех учебных тем MathStart.

В нём находится 263 урока, сгруппированных по классу, предмету и разделу.

Для навигации используйте [`INDEX.md`](INDEX.md).

## Структура

Исходники организованы по схеме:

```text
curriculum/
└── класс/
    └── предмет/
        └── раздел/
            └── урок/
                ├── lesson.json
                ├── body.html
                ├── page.css
                └── page.js
```

`page.css` и `page.js` являются необязательными.

## Файлы урока

| Файл | Назначение |
| --- | --- |
| `lesson.json` | Метаданные страницы и формат исходника. |
| `body.html` | Основное содержимое урока: текст, формулы, таблицы, задания, SVG и разметка интерактивов. |
| `page.css` | CSS, специфичный только для конкретного урока. |
| `page.js` | JavaScript, специфичный только для конкретного урока. |

`lesson.json` и `body.html` обязательны.

Если локальные стили или JavaScript не нужны, `page.css` и `page.js` создавать не следует.

Удаление `page.css` или `page.js` с последующей публикацией очищает соответствующее поле опубликованной страницы.

## `lesson.json`

Файл имеет следующую структуру:

```json
{
  "schema_version": 2,
  "format": "themed_html",
  "page": {
    "slug": "...",
    "page_type": "topic",
    "grade": "...",
    "subject": "...",
    "section": "...",
    "title": "...",
    "order": 1,
    "seo_title": "",
    "seo_description": "",
    "is_published": true
  }
}
```

Основное HTML-содержимое, локальный CSS и JavaScript хранятся отдельными файлами и при чтении исходника добавляются к snapshot страницы.

## Форматы исходников

`themed_html` используется для уроков с готовой учебной HTML-разметкой.

`component_html` используется для уроков, часть структуры которых собирается через общие компоненты MathStart.

`html` используется для HTML, который не требует дополнительной сборки renderer'ом.

Формат определяет способ подготовки HTML перед публикацией, но не создаёт отдельную систему оформления страницы.

## Идентичность урока

Для существующего опубликованного урока следующие поля считаются идентификационными:

```text
slug
page_type
grade
subject
section
```

Обычная публикация не используется для переноса существующей темы на другой адрес или в другой раздел.

Название, порядок, SEO, статус публикации и содержимое страницы изменяются через исходники урока.

## Публикация

Проверка одной темы без записи:

```powershell
python manage.py publish_lessons --slug SLUG --dry-run
```

Публикация:

```powershell
python manage.py publish_lessons --slug SLUG
```

Публикация всего каталога:

```powershell
python manage.py publish_lessons --all
```

Если страницы с указанным `slug` ещё нет в базе, публикация может создать новый `ContentPage`, если соответствующие класс, предмет и раздел существуют в каталоге.

Для уже существующего управляемого урока действует контроль конфликтов: изменения базы, не соответствующие последней принятой публикации или текущему исходнику, не перезаписываются автоматически.

## Проверка

Проверить одну тему:

```powershell
python manage.py check_lesson_sources --slug SLUG
```

Проверить весь каталог:

```powershell
python manage.py check_lesson_sources --all
```

Обновить человекочитаемый указатель:

```powershell
python manage.py index_lessons
```

## Общие стили

Основные стили и повторно используемый JavaScript находятся в `static/mathstart/`.

Локальный `page.css` должен содержать только оформление, специфичное для конкретной темы: например, размеры отдельной схемы, расположение подписей или компоновку собственного интерактива.

Общие карточки, таблицы, задания, примеры, математические элементы и типографика не должны дублироваться в локальных стилях.

Подробнее:

[`../docs/lesson-theme.md`](../docs/lesson-theme.md)

## Сохранение содержимого

Файлы `body.html`, `page.css` и `page.js` публикуются и сравниваются без автоматической нормализации содержимого.

Настройки `.gitattributes` сохраняют их байтовое представление, поэтому не следует выполнять массовое изменение окончаний строк или форматирование этих файлов без необходимости.
