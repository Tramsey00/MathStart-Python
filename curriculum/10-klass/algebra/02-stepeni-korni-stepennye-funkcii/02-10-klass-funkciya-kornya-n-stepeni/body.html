Функция корня n-й степени

Исследуем y = ⁿ√x для чётного и нечётного n: область определения, значения, монотонность и симметрию. Построим графики по точным опорным точкам и разберём их переносы.

1. От определения к функции

В функции y = ⁿ√x каждому допустимому x соответствует одно значение корня. Показатель n фиксирован и является натуральным числом не меньше 2. Меняется аргумент x, а не показатель n.

D(f) — область определения, то есть допустимые x. E(f) — область значений, то есть все получающиеся y. Их нельзя смешивать с видимым фрагментом графика.

2. Чётный корень: y = ²ᵏ√x

СвойствоОписание
D(f) и E(f)[0; +∞) и [0; +∞)
Нуль и знакf(0) = 0; при x > 0 значение положительно
МонотонностьВозрастает на [0; +∞)
ЧётностьНи чётная, ни нечётная: область определения не симметрична относительно 0
Экстремальные значенияНаименьшее 0 при x = 0; наибольшего нет

Для построения четвёртого корня удобно задать y, затем вычислить x = y⁴: получаем точки (0; 0), (1; 1), (16; 2). График не имеет отрицательной ветви.

3. Нечётный корень: y = ²ᵏ⁺¹√x

СвойствоОписание
D(f) и E(f)ℝ и ℝ
Нуль и знакНуль при x = 0; знак y совпадает со знаком x
МонотонностьВозрастает на всей ℝ
ЧётностьНечётная: f(−x) = −f(x)
Симметрия и ограниченияСимметрия относительно начала координат; наибольшего и наименьшего значений нет
Функция возрастает и при отрицательных x. Например, −27 < −8, поэтому ∛(−27) = −3 < −2 = ∛(−8).

4. Сравнение корней и связь со степенью

Для одинакового показателя n: a < b ⇒ ⁿ√a < ⁿ√b, если оба корня определены.
Пример 1. Сравнение⁴√70 < 3, потому что 70 < 3⁴ = 81. А ⁵√(−40) < −2, поскольку −40 < (−2)⁵ = −32.

Графики y = xⁿ и y = ⁿ√x связаны обменом координат. Для нечётного n функция xⁿ обратима на ℝ. Для чётного n сначала ограничивают её на x ≥ 0: на всей ℝ одному положительному значению xⁿ соответствуют два противоположных x.

5. Область определения сложного выражения

Пример 2. Сумма корнейДля y = √(x − 1) + ⁴√(5 − x) нужны одновременно x − 1 ≥ 0 и 5 − x ≥ 0. Пересечение даёт D(f) = [1; 5].
Пример 3. Квадратный трёхчленДля y = ⁴√(9 − x²) нужно x² ≤ 9. Значит, D(f) = [−3; 3]. Подкоренное выражение принимает значения от 0 до 9, поэтому E(f) = [0; √3], так как ⁴√9 = √3.
Пример 4. Нечётный корень в знаменателеДля y = 1 / ∛(x − 4) исключаем только x = 4: знаменатель не должен равняться нулю. Область определения — (−∞; 4) ∪ (4; +∞).

6. Перенос графика

y = ⁿ√(x − a) + b: график y = ⁿ√x переносится на a по горизонтали и на b по вертикали. При a > 0 — вправо, при b > 0 — вверх. Точка (0; 0) переходит в (a; b).
Пример 5. Чётный корень со сдвигомy = √(x − 2) + 1. Сдвигаем график вправо на 2 и вверх на 1. Точки (0; 0), (1; 1), (4; 2) переходят в (2; 1), (3; 2), (6; 3). D = [2; +∞), E = [1; +∞).
Пример 6. Нечётный корень со сдвигомy = ∛(x + 3) − 2 — перенос влево на 3 и вниз на 2. D = E = ℝ; функция возрастает на ℝ, но после такого переноса уже не является нечётной.

7. Пересечения и простые неравенства

Пример 7. Пересечение с прямойДля y = √x и y = x − 2 решаем √x = x − 2. Нужно x ≥ 2. Тогда x = (x − 2)² ⇒ x² − 5x + 4 = 0 ⇒ x = 1 или x = 4. Подходит только 4. Точка пересечения (4; 2).
Пример 8. Прочитать неравенство⁴√(x + 1) ≤ 2. Сначала x + 1 ≥ 0, затем благодаря возрастанию корня x + 1 ≤ 16. Получаем −1 ≤ x ≤ 15.
Для определения числа пересечений рисунок помогает выдвинуть предположение. Точные координаты находят из уравнения и проверяют в исходных формулах.

Проверьте себя

Сначала решите задания самостоятельно. Затем откройте решения и сравните не только ответ, но и условия применения формул.

Задание 1. Укажите D и E функции y = ⁶√x.

Показать решение 1

D = [0; +∞), E = [0; +∞): показатель чётный.

Задание 2. Найдите f(−32), если f(x) = ⁵√x. Является ли f нечётной?

Показать решение 2

f(−32) = −2; функция нечётная, поскольку определена на ℝ и ⁵√(−x) = −⁵√x.

Задание 3. Сравните ⁴√13 и ⁴√17.

Показать решение 3

13 < 17, функция возрастает. Поэтому ⁴√13 < ⁴√17.

Задание 4. Найдите область определения y = √(x + 2) + ⁴√(4 − x).

Показать решение 4

x ≥ −2 и x ≤ 4. Пересечение: [−2; 4].

Задание 5. Найдите D и E функции y = √(x − 3) − 2.

Показать решение 5

Перенос вправо на 3, вниз на 2. D = [3; +∞), E = [−2; +∞). Начальная точка (3; −2).

Задание 6. Найдите область определения y = 1 / ∛(2x − 6).

Показать решение 6

2x − 6 ≠ 0, значит x ≠ 3. Нечётный корень допускает отрицательные подкоренные значения.

Задание 7. Найдите точку пересечения y = ∛x и y = −2.

Показать решение 7

∛x = −2 ⇒ x = −8. (−8; −2).

Задание 8. Решите ⁴√(x − 2) < 3.

Показать решение 8

ОДЗ: x ≥ 2. Из возрастания: x − 2 < 81, то есть x < 83. Ответ: [2; 83). Левая граница включена: ⁴√0 < 3.

Что нужно запомнить

Чётный корень определён на [0; +∞), нечётный — на ℝ. Обе функции возрастают на своей области определения. Для переносов следите за знаком внутри скобок. ОДЗ суммы — пересечение ограничений, а нули знаменателя всегда исключаются.
