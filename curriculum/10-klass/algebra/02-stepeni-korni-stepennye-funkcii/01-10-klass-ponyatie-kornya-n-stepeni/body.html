Понятие корня n-й степени из действительного числа

1. Что означает корень n-й степени

Пусть n — натуральное число, n ≥ 2. Корнем n-й степени из действительного числа a называют такое действительное число b, что bⁿ = a. Число n — показатель корня, a — подкоренное число.

Запись ⁿ√a обозначает определённое значение: при чётном n выбирают неотрицательный корень, при нечётном n корень единственный и имеет тот же знак, что a.
Пример 1. Проверяем определением⁴√81 = 3, поскольку 3⁴ = 81 и 3 ≥ 0. А ⁵√(−32) = −2, поскольку (−2)⁵ = −32. Показатель квадратного корня обычно не пишут: √a = ²√a.
В записи ⁿ√(A) скобки показывают всё подкоренное выражение. Например, ∛(x + 1) и ∛x + 1 — разные выражения.

2. Чётный показатель

Любая чётная степень действительного числа неотрицательна: b²ᵏ ≥ 0. Поэтому действительного корня чётной степени из отрицательного числа нет. Из положительного числа выбирают неотрицательное значение радикала.

Подкоренное число aЗначение ²ᵏ√aПример

Арифметический корень чётной степени всегда неотрицателен. Знак ± не является частью значения радикала.

3. Нечётный показатель

Функция b ↦ b²ᵏ⁺¹ возрастает на всей числовой прямой и принимает все действительные значения. Поэтому для любого a существует ровно один действительный корень нечётной степени.

∛(−125) = −5; ⁵√243 = 3; ⁷√0 = 0.
Для нечётного n: ⁿ√(−a) = −ⁿ√a.
Пример 2. Дроби и десятичные числа∛(−0,064) = −0,4, потому что (−0,4)³ = −0,064. А ⁴√(16/81) = 2/3, потому что (2/3)⁴ = 16/81 и 2/3 > 0.

Пример 4. Степенное уравнение(x − 1)⁴ = 16 ⇒ x − 1 = ±2 ⇒ x = −1 или x = 3. Обе подстановки дают 16.

5. Корень из степени и модуль

Для любого действительного a: ²ᵏ√(a²ᵏ) = |a|. Для нечётного n: ⁿ√(aⁿ) = a. А равенство (ⁿ√a)ⁿ = a верно там, где сам корень определён.
Пример 5. Переменная без ограничения на знак⁴√((x − 3)⁴) = |x − 3|. При x ≥ 3 это x − 3; при x < 3 это 3 − x. Например, при x = 1 корень равен 2, а выражение x − 3 равно −2.
Формула ⁴√(x⁴) = x требует условия x ≥ 0. Если оно не дано, ответ |x|.

6. Область допустимых значений

Область допустимых значений (ОДЗ) — все значения переменной, при которых исходное выражение имеет смысл. Для каждого чётного корня требуем неотрицательное подкоренное выражение; для знаменателя — ненулевое значение.

Пример 6. Корень в знаменателеДля 1 / ⁴√(2x − 6) нужно 2x − 6 > 0: равенство нулю запрещено знаменателем. Получаем x > 3.
Пример 7. Нечётный корень и дробьВ выражении 1 / ∛(x + 2) сам корень определён для всех x, но знаменатель обращается в нуль при x = −2. Поэтому x ≠ −2.

7. Простейшие уравнения с радикалом

При чётном n уравнение ⁿ√A = B равносильно A = Bⁿ вместе с условием B ≥ 0, если выражения A и B определены. При нечётном n ограничение B ≥ 0 не нужно.
Пример 8. Чётный корень⁴√(3x + 1) = 2 ⇒ 3x + 1 = 16 ⇒ x = 5. Подстановка даёт ⁴√16 = 2. А уравнение ⁴√(3x + 1) = −2 сразу не имеет решений.
Пример 9. Постороннее решение√(x + 2) = x. Правая часть должна быть неотрицательной, значит x ≥ 0. После возведения в квадрат: x + 2 = x² ⇒ (x − 2)(x + 1) = 0. Из кандидатов 2 и −1 подходит только 2. При −1 слева 1, справа −1.

Проверьте себя

Сначала решите задания самостоятельно. Затем откройте решения и сравните не только ответ, но и условия применения формул.

Задание 1. Вычислите ⁴√256 и ⁵√(−243).

Показать решение 1

4 и −3: 4⁴ = 256, (−3)⁵ = −243.

Задание 2. Вычислите ∛(−0,008) + ⁴√0,0016.

Показать решение 2

−0,2 + 0,2 = 0. Проверка: (−0,2)³ = −0,008 и 0,2⁴ = 0,0016.

Задание 3. Решите x⁶ = 64.

Показать решение 3

6 — чётный показатель, 64 > 0. Поэтому x = ±2.

Задание 4. Решите x⁴ = −81.

Показать решение 4

Действительных решений нет: четвёртая степень неотрицательна.

Задание 5. Упростите ⁶√((a + 2)⁶), если a < −2.

Показать решение 5

⁶√((a + 2)⁶) = |a + 2|. По условию a + 2 < 0, поэтому ответ −a − 2.

Задание 6. Найдите ОДЗ выражения 1 / ⁴√(5 − x).

Показать решение 6

Нужно 5 − x > 0. Ответ: x < 5.

Задание 7. Решите ∛(2x + 3) = −3.

Показать решение 7

2x + 3 = −27, 2x = −30, x = −15. Проверка: ∛(−27) = −3.

Задание 8. Решите √(2x + 3) = x.

Показать решение 8

x ≥ 0. Возводим в квадрат: x² − 2x − 3 = 0, (x − 3)(x + 1) = 0. Из 3 и −1 подходит только x = 3: √9 = 3.

Что нужно запомнить

Сначала определите чётность n. Чётный корень требует неотрицательного подкоренного выражения и сам неотрицателен; нечётный существует для любого действительного числа. Не путайте значение корня и все решения xⁿ = a. В корне из чётной степени сохраняйте модуль.
