1. Как выбрать первый шаг

Радикал — запись корня. Выражения с радикалами часто упрощаются теми же приёмами, что и многочлены: разложением на множители, группировкой и сокращением дробей.

Что видно в выраженииЧто попробовать
Полная степень под корнемВынести множитель
Сумма нескольких корнейУпростить каждый корень и собрать подобные
Сумма и разность одинаковых выраженийРазность квадратов
Корень в знаменателеУмножить на подходящий множитель или сопряжённое
√x и x в одной дробиВвести t = √x
Сначала ОДЗ, затем преобразования, затем проверка знаков и исключённых значений. Сокращать можно только общий множитель всего числителя и знаменателя.

2. Вынесение и внесение множителя

Пример 1. Выделить полную степень√200 = √(100 · 2) = 10√2; ∛(−432) = ∛(−216 · 2) = −6∛2.
Для b ≥ 0: √(a²b) = |a|√b. При a ≥ 0 можно внести множитель: a√b = √(a²b). При a < 0: a√b = −√(a²b).
Пример 2. Не потерять знак−3√5 = −√45, а не √45. Для кубического корня можно внести и отрицательный множитель целиком: −2∛3 = ∛(−24).
Пример 3. БуквыПри x < 0 и y ≥ 0: √(9x²y) = 3|x|√y = −3x√y. Условия обеспечивают существование всех корней.

3. Подобные радикалы и группировка

Подобными становятся слагаемые с одинаковым показателем и одинаковым подкоренным выражением. Коэффициенты складывают, общий радикал сохраняют.

Пример 4. Упростить сумму
√72 − 2√8 + √18
= 6√2 − 4√2 + 3√2
= 5√2.
Пример 5. Две группы√12 + √20 − √27 + 2√45 = 2√3 + 2√5 − 3√3 + 6√5 = 8√5 − √3.
√a + √b в общем случае не равно √(a + b). Например, √9 + √16 = 7, тогда как √25 = 5.

4. Формулы сокращённого умножения

(u − v)(u + v) = u² − v²;
(u ± v)² = u² ± 2uv + v².
Пример 6. Произведение сопряжённых(2√3 − √5)(2√3 + √5) = 12 − 5 = 7.
Пример 7. Квадрат суммы(√7 + 2)² = 7 + 4√7 + 4 = 11 + 4√7. Среднее слагаемое 2 · √7 · 2 нельзя пропускать.
Пример 8. Выделение полного квадрата√(7 − 4√3) = √((2 − √3)²) = |2 − √3|. Так как 2 > √3, ответ 2 − √3. Чтобы узнать квадрат разности, проверяем 4 + 3 = 7 и 2 · 2 · √3 = 4√3.

5. Освобождение знаменателя от корня

Умножаем числитель и знаменатель на одно и то же ненулевое выражение. Значение дроби сохраняется, а в знаменателе получается число или выражение без радикала.

Пример 9. Один квадратный корень5/√3 = (5√3)/(√3 · √3) = 5√3/3.
Пример 10. Сумма в знаменателе1/(√5 + 2) = (√5 − 2)/((√5 + 2)(√5 − 2)) = (√5 − 2)/(5 − 4) = √5 − 2.
Пример 11. Кубический корень1/∛2 = ∛4/(∛2 · ∛4) = ∛4/2. Выбираем множитель так, чтобы под корнем получилось 2³.
Для буквенного знаменателя сначала проверьте ненулевое значение множителя. Например, домножение на √x − 1 не разрешено при x = 1, хотя дробь 1/(√x + 1) там определена.

6. Сокращение дробей и сохранение ОДЗ

Пример 12. Разность квадратовУпростим (x − 9)/(√x − 3). ОДЗ: x ≥ 0, x ≠ 9. Числитель x − 9 = (√x − 3)(√x + 3). Сократив ненулевой множитель, получаем √x + 3 при x ≥ 0, x ≠ 9.

Упрощённая формула может существовать в большем числе точек, чем исходная. Это не отменяет запрет x = 9: в исходной дроби при этом нулевой знаменатель.

Пример 13. Замена переменнойДля (x − 3√x + 2)/(√x − 1) ОДЗ: x ≥ 0, x ≠ 1. Положим t = √x ≥ 0: (t² − 3t + 2)/(t − 1) = (t − 1)(t − 2)/(t − 1) = t − 2. Ответ: √x − 2 при x ≥ 0, x ≠ 1.

7. Несколько приёмов в одном выражении

Пример 14. Разность дробей
1/(√3 − 1) − 1/(√3 + 1)
= ((√3 + 1) − (√3 − 1)) / ((√3 − 1)(√3 + 1))
= 2/(3 − 1) = 1.
Можно было отдельно рационализировать каждую дробь, но общий знаменатель даёт более короткое решение.
Пример 15. Корень и модуль√((√5 − 3)²) + √((√5 + 3)²) = |√5 − 3| + |√5 + 3|. Так как √5 < 3, получаем (3 − √5) + (√5 + 3) = 6.

После упрощения полезно подставить одно допустимое значение переменной и сравнить обе записи. Такая проверка помогает заметить потерянный знак, но не заменяет доказательство тождества.

Что нужно запомнить

Выделяйте полные степени, собирайте подобные радикалы, используйте формулы сокращённого умножения. При рационализации выбирайте ненулевой множитель. После сокращения дробей обязательно сохраняйте исключённые значения переменной.
