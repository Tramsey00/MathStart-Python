1. Условия перед преобразованием

Ниже m и n — натуральные показатели корней, не меньше 2. Все формулы для произвольной чётности безопасно применять к неотрицательным подкоренным числам. Если показатель нечётный, некоторые свойства допускают и отрицательные числа.

Преобразование должно сохранять значение при каждом допустимом значении переменной. Сначала запишите ОДЗ, затем применяйте формулы.
Из существования корня из произведения не следует существование корня из каждого множителя: √((−2)(−8)) = 4, но √(−2) · √(−8) в ℝ не определено.

2. Корень из произведения

При a ≥ 0, b ≥ 0: ⁿ√(ab) = ⁿ√a · ⁿ√b. При нечётном n допускаются любые действительные a и b.

Почему это верно? Произведение корней в степени n даёт ab. Для чётного n оба множителя неотрицательны, значит произведение — именно арифметический корень.

Пример 1. Сгруппировать множители⁴√8 · ⁴√2 = ⁴√16 = 2. А ∛(−4) · ∛2 = ∛(−8) = −2.
Пример 2. Вынести полный куб∛54 = ∛(27 · 2) = 3∛2. Полный квадрат 9 здесь не подходит для извлечения целого кубического корня.

3. Корень из частного

При a ≥ 0, b > 0: ⁿ√(a/b) = ⁿ√a / ⁿ√b. При нечётном n достаточно a ∈ ℝ и b ≠ 0.
Пример 3. Удобное деление⁴√243 / ⁴√3 = ⁴√81 = 3. Отдельно приближённо вычислять корни не нужно.
Пример 4. Отрицательные числа∛(−54) / ∛2 = ∛(−27) = −3. Нечётность показателя позволяет сохранить отрицательный знак.

4. Корень из корня

При a ≥ 0: ᵐ√(ⁿ√a) = ᵐⁿ√a. Если m и n оба нечётны, формула верна также при a < 0.
Пример 5. Показатели перемножаются√(∛64) = ⁶√64 = 2. Проверка: ∛64 = 4 и √4 = 2.
При извлечении корня из корня показатели умножают, а не складывают. √(∛a) = ⁶√a при a ≥ 0, а не ⁵√a.

5. Степень корня и корень из степени

Если ⁿ√a определён, то для натурального k: (ⁿ√a)ᵏ = ⁿ√(aᵏ). В частности, (ⁿ√a)ⁿ = a. При этом ²ᵏ√(a²ᵏ) = |a|, а ²ᵏ⁺¹√(a²ᵏ⁺¹) = a.
Пример 6. Вычисление(∛5)⁶ = ((∛5)³)² = 5² = 25.
Пример 7. Буквенное выражение⁴√(16x⁸) = 2 · ⁴√((x²)⁴) = 2|x²| = 2x² при любом действительном x. Здесь модуль можно убрать, потому что x² ≥ 0.
Обратное чтение формулы может расширить ОДЗ: √(a²) существует при всех a, но (√a)² — только при a ≥ 0. Сохраняйте исходные ограничения.

6. Общий показатель корней

При a ≥ 0 и натуральном k: ⁿ√a = ⁿᵏ√(aᵏ). Это позволяет привести корни к общему показателю, обычно к НОК исходных показателей.
Пример 8. Умножить корни с разными показателями√2 · ∛2 = ⁶√(2³) · ⁶√(2²) = ⁶√32. Общий показатель — НОК(2, 3) = 6.
Пример 9. Сравнить без округления⁴√5 = ¹²√125, а ∛3 = ¹²√81. Поэтому ⁴√5 > ∛3.
Для отрицательного a нельзя бездумно удваивать показатель: ∛(−8) = −2, но ⁶√((−8)²) = 2. Знак изменился.

7. Сочетание свойств и замена переменной

Пример 10. Переменная под чётным корнемУпростим √(x²(x − 1)). Исходная ОДЗ: x = 0 или x ≥ 1. На x ≥ 1 можно записать |x|√(x − 1) = x√(x − 1). Но при x = 0 исходное выражение равно 0, а √(x − 1) не существует. Ответ: 0 при x = 0; x√(x − 1) при x ≥ 1.
Пример 11. Уравнение с заменой⁴√x + √x = 6. Положим t = ⁴√x ≥ 0, тогда √x = t². Получаем t² + t − 6 = 0, то есть (t + 3)(t − 2) = 0. Подходит t = 2, откуда x = 16. Проверка: 2 + 4 = 6.

Замена полезна, когда одни радикалы выражаются через степени других. После решения обязательно возвращайтесь к исходной переменной.

Что нужно запомнить

Произведение и частное объединяют корни с одинаковым показателем; вложенные корни перемножают показатели. При общем показателе возводите подкоренное число в соответствующую степень. Проверяйте знаки и ОДЗ, особенно при переходе от корня произведения к произведению корней.
