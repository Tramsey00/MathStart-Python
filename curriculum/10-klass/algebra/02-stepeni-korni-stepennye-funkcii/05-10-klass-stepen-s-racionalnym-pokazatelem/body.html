1. Зачем нужен дробный показатель

Квадрат числа 9¹ᐟ² должен равняться 9. Поэтому естественно связать показатель 1/2 с квадратным корнем, показатель 1/3 — с кубическим, а показатель m/n — с корнем n-й степени и возведением в степень m.

Для a > 0, целого m и натурального n ≥ 2: am/n = ⁿ√(aᵐ) = (ⁿ√a)ᵐ. Знаменатель показателя задаёт степень корня, числитель — степень числа.
Пример 1. Два равносильных порядка272/3 = (∛27)² = 3² = 9. Можно сначала получить 27², но извлечь корень до возведения в квадрат проще.

Дроби 1/2 и 2/4 задают одно и то же число, поэтому при a > 0 степени a1/2 и a2/4 равны. Перед вычислением показатель удобно сократить.

2. Основание и школьное соглашение

Здесь используем то же соглашение, что и в школьных материалах ЯКласс: степень с нецелым рациональным показателем определяем для положительного основания. Для положительного показателя дополнительно полагаем 0ʳ = 0.

Показатель rДопустимое основание
r — положительное целоеЛюбое действительное a
r = 0 или отрицательное целоеa ≠ 0
r — положительное нецелое рациональноеa ≥ 0
r — отрицательное нецелое рациональноеa > 0
Не подменяйте без условия ∛(x²) выражением x2/3: первый корень существует и при отрицательных x, а дробную степень в принятом здесь соглашении рассматриваем при x ≥ 0. Сам нечётный корень из отрицательного числа существует: ∛(−8) = −2.

3. Нулевой и отрицательный показатели

При a > 0: a⁰ = 1; a⁻ʳ = 1/aʳ.
16−3/4 = 1/(⁴√16)³ = 1/2³ = 1/8.
Пример 2. Дробное основание(4/9)−1/2 = 1/√(4/9) = 1/(2/3) = 3/2.
Минус в показателе не делает ответ отрицательным. При положительном основании любая рациональная степень положительна. Записи 0⁰ и 0⁻ʳ при r > 0 не определены.

4. Основные свойства

При a > 0, b > 0 и рациональных r, s действуют знакомые правила. Условия на основания позволяют применять их без отдельных случаев для знаков.

ОперацияФормулаПример
Произведение одинаковых основанийaʳ · aˢ = aʳ⁺ˢa1/3 · a2/3 = a
Частное одинаковых основанийaʳ / aˢ = aʳ⁻ˢa5/4 / a1/4 = a
Степень степени(aʳ)ˢ = aʳˢ(a2/3)3/4 = a1/2
Степень произведения(ab)ʳ = aʳbʳ(4a)1/2 = 2a1/2
Степень частного(a/b)ʳ = aʳ/bʳ(a/9)1/2 = a1/2/3
Пример 3. Сложение показателейa5/6 · a1/3 / a1/2 = a5/6+2/6−3/6 = a2/3 при a > 0.
В сумме aʳ + aˢ эти правила не применяются. Складывать показатели можно при умножении степеней одного основания.

5. Десятичные показатели и общее основание

Пример 4. Перевести показатель в дробь320,4 = 322/5 = (⁵√32)² = 2² = 4. Здесь 0,4 = 4/10 = 2/5.
Пример 5. Привести к одному основанию91,25 / 30,5 = (3²)1,25 / 30,5 = 32,5−0,5 = 9.
Пример 6. Числовой и буквенный множители(16b)1,5 · b0,7 / b2,2 = 161,5 · b1,5+0,7−2,2 = 64 · b⁰ = 64 при b > 0. Значение не зависит от положительного b.

6. Переход между корнями и степенями

Пример 7. Общая форма записиПри x > 0: √x · ∛(x²) / ⁶√x = x1/2+2/3−1/6 = x3/6+4/6−1/6 = x. Условие x > 0 учитывает и чётные корни, и знаменатель.
Пример 8. Разность квадратов(a1/3 − 2)(a1/3 + 2) = a2/3 − 4 при a ≥ 0. Это та же формула (u − v)(u + v) = u² − v².

Выбирайте запись, которая упрощает действие: степени удобны для произведений и частных, радикалы — для выделения полной степени и работы с сопряжёнными выражениями.

7. Сравнение и простое уравнение

При a > 1 большему показателю соответствует большая степень. При 0 < a < 1 — меньшая. Для a = 1 все степени равны 1.
Пример 9. Основание меньше единицы(1/4)1/2 = 1/2, а (1/4)3/2 = 1/8. Хотя 1/2 < 3/2, первая степень больше.
Пример 10. Решить x3/2 = 8По определению x ≥ 0. Положим t = √x ≥ 0. Тогда t³ = 8, t = 2 и x = 4. Проверка: (√4)³ = 8.

Если возводите обе части равенства в степень, проверяйте, сохраняется ли равносильность. Область допустимых значений нужно записать до этого действия.

Что нужно запомнить

Для положительного основания am/n = (ⁿ√a)ᵐ. Отрицательный показатель даёт обратную величину. В произведении показатели складывают, в частном вычитают, в степени степени перемножают. Для нецелых показателей соблюдайте принятое ограничение на основание.
