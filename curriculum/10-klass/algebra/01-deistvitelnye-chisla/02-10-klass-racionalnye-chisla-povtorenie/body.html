Рациональные числа. Повторение

Свяжем обыкновенные дроби с конечными и периодическими десятичными записями. Повторим вычисления, сравнение, нахождение середины отрезка и точные преобразования периодических дробей.

1. Что значит «рациональное число»

Рациональное число представляется дробью m/n, где m ∈ ℤ, n ∈ ℕ. Множество рациональных чисел обозначают ℚ.

Целые числа тоже рациональны: −7 = −7/1, а 0 = 0/1. Разные дроби могут задавать одно число: 2/3 = 4/6 = 10/15. Чтобы получить несократимую дробь, делят числитель и знаменатель на их НОД.

Пример 1. Сократить дробь−84/126 = −(84 : 42)/(126 : 42) = −2/3. Знак минус можно поставить перед дробью или в числителе.

2. Какая десятичная запись получится

Деление числителя на знаменатель либо заканчивается, либо даёт повторяющуюся группу цифр — период. Запись 0,(27) означает 0,272727…; запись 0,1(6) означает 0,16666….

В несократимой дроби десятичная запись конечна тогда и только тогда, когда знаменатель имеет только простые множители 2 и 5 (или равен 1). В остальных случаях запись бесконечная периодическая.
ДробьЗнаменательДесятичная запись
7/4040 = 2³ · 50,175
5/1212 = 2² · 30,41(6)
2/11110,(18)

Почему обязательно возникает период? При делении на n возможны лишь остатки 0, 1, …, n − 1. Нулевой остаток завершает деление, а повтор ненулевого остатка запускает повтор тех же цифр.

Перед проверкой знаменателя сократите дробь: 6/15 = 2/5 = 0,4, хотя исходный знаменатель делится на 3.

3. Из периодической дроби в обыкновенную

Пример 2. Чистый период
x = 0,(27); 100x = 27,(27);
100x − x = 27; 99x = 27;
x = 27/99 = 3/11.
Умножили на 100, поскольку в периоде две цифры. Бесконечные одинаковые хвосты при вычитании исчезают.
Пример 3. Есть цифра до периода
x = 0,2(7); 10x = 2,(7); 100x = 27,(7);
100x − 10x = 25; 90x = 25;
x = 5/18.
Обе записи сдвинули так, чтобы повторяющиеся хвосты начинались сразу после запятой.
Равенство 0,(9) = 1 — точное. Если x = 0,(9), то 10x − x = 9, откуда x = 1. Число может иметь две десятичные записи.

4. Действия с дробями

a/b + c/d = (ad + bc)/(bd);
a/b · c/d = ac/(bd);
(a/b) : (c/d) = ad/(bc), если c ≠ 0.
Во всех формулах b ≠ 0 и d ≠ 0.

При сложении удобно выбирать наименьший общий знаменатель. При умножении можно сократить множители числителя и знаменателя до вычислений. Деление заменяют умножением на обратную дробь.

Пример 4. Несколько действий
(5/6 − 3/4) : (−1/8)
= (10/12 − 9/12) · (−8)
= (1/12) · (−8) = −2/3.

5. Сравнение и середина отрезка

Для дробей с положительными знаменателями сравнивают перекрёстные произведения. Например, 5/8 < 7/11, поскольку 55 < 56. Среди отрицательных чисел больше то, у которого меньше модуль: −5/8 > −7/11.

Число, равноудалённое от различных a и b на числовой прямой, равно (a + b)/2. Если a < b, эта середина строго между ними.
Пример 5. Найти серединуДля a = −2/3 и b = 5/6 получаем (−2/3 + 5/6)/2 = (1/6)/2 = 1/12. Расстояния до концов равны 3/4.

Между любыми двумя различными рациональными числами есть рациональное число — их середина. Повторяя этот приём, получаем бесконечно много рациональных чисел в любом непустом интервале.

6. Дроби и целые показатели степени

При a ≠ 0: a⁰ = 1 и a⁻ⁿ = 1/aⁿ, где n ∈ ℕ. Отрицательный показатель означает переход к обратному числу, а не отрицательный результат.
Пример 6. Знак и обратная дробь(−2/3)⁻² = (−3/2)² = 9/4. Чётная степень отрицательного основания положительна. При нечётном показателе знак остаётся отрицательным.
−2² = −4, но (−2)² = 4. В первой записи степень относится только к 2, во второй — ко всему числу −2. Нуль нельзя возводить в нулевую или отрицательную степень в используемых школьных правилах.

7. Точные вычисления с периодом

Пример 7. Корень из периодической дробиВычислим √(0,(4)). Сначала 0,(4) = 4/9, затем √(4/9) = 2/3. Замена на 0,444 даёт только приближение и меняет условие.
Пример 8. УравнениеРешим x + 0,1(6) = 0,75. Здесь 0,1(6) = 1/6 и 0,75 = 3/4. Значит, x = 3/4 − 1/6 = 7/12. Проверка: 7/12 + 2/12 = 9/12 = 3/4.

Сначала переходите к точным дробям, затем выполняйте действия. Округление используйте только тогда, когда в задаче требуется приближённый ответ.

Проверьте себя

Сначала решите задания самостоятельно. Затем откройте решения и сравните не только ответ, но и условия применения формул.

Задание 1. Какие из чисел −8; 0; 0,(13); √49 рациональны?

Показать решение 1

Все четыре: −8/1; 0/1; 13/99; √49 = 7.

Задание 2. Какие дроби имеют конечную десятичную запись: 9/24; 7/30; 11/125?

Показать решение 2

9/24 = 3/8 = 0,375; 11/125 = 0,088. Первая и третья. Дробь 7/30 несократима, знаменатель содержит 3.

Задание 3. Переведите 0,(36) в обыкновенную дробь.

Показать решение 3

100x − x = 36, откуда x = 36/99 = 4/11.

Задание 4. Переведите 0,3(6) в обыкновенную дробь.

Показать решение 4

100x = 36,(6), 10x = 3,(6). Значит, 90x = 33 и x = 11/30.

Задание 5. Вычислите (7/12 − 1/3) : (−3/8).

Показать решение 5

7/12 − 4/12 = 1/4. Далее (1/4) · (−8/3) = −2/3.

Задание 6. Найдите число, равноудалённое от −3/4 и 5/6.

Показать решение 6

(−3/4 + 5/6)/2 = (1/12)/2 = 1/24.

Задание 7. Вычислите (−3/5)⁻².

Показать решение 7

(−5/3)² = 25/9. Минус в показателе переворачивает дробь, а чётная степень делает результат положительным.

Задание 8. Вычислите √(0,(1)) + 0,(6).

Показать решение 8

√(1/9) + 2/3 = 1/3 + 2/3 = 1.

Что нужно запомнить

Рациональное число — дробь целого числа и натурального. Его десятичная запись конечная или периодическая. Периодические дроби переводите в обыкновенные до вычислений; не заменяйте точные числа округлениями.
