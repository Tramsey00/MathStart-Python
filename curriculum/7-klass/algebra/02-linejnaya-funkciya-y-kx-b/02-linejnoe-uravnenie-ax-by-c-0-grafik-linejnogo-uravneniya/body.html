Что нужно знать перед темой

В предыдущей теме мы научились строить точки на координатной плоскости. Теперь будем рассматривать сразу множество точек, координаты которых связаны одним уравнением.

  • Координаты точки записывают в порядке (x; y).
  • Первое число называют абсциссой, второе — ординатой.
  • Для проверки точки её координаты подставляют вместо x и y.
  • Прямую можно построить по двум различным точкам.
  • При переносе слагаемого в другую часть его знак меняется.
  • Деление на ноль невозможно.
Одно решение уравнения с двумя переменными — это не отдельное число, а упорядоченная пара чисел (x; y).

1. Линейное уравнение с двумя переменными

Линейным уравнением с двумя переменными называют уравнение, которое можно записать в виде:

ax + by + c = 0,

где x и y — переменные, a, b и c — заданные числа, причём коэффициенты a и b не могут одновременно равняться нулю.

Коэффициент a

Число, которое умножается на переменную x.

Коэффициент b

Число, которое умножается на переменную y.

Число c

Свободный член, не содержащий переменных.

Переменные x и y

Их значения образуют решение уравнения.

В уравнении 3x − 2y + 7 = 0:
a = 3,   b = −2,   c = 7.

2. Решение уравнения с двумя переменными

Решением уравнения с двумя переменными называют пару значений (x; y), которая после подстановки превращает уравнение в верное числовое равенство.

Пример 1. Проверим пару чисел

Условие Является ли пара (1; 2) решением уравнения 2x + y − 4 = 0?
Проверка.
Подставим x = 1 и y = 2:
2 · 1 + 2 − 4 = 2 + 2 − 4 = 0.
Получили верное равенство 0 = 0.
Пара (1; 2) является решением.

Пример 2. Пара не является решением

Проверить пару (0; 0) для уравнения 2x + y − 4 = 0.
2 · 0 + 0 − 4 = −4.
Получили неверное равенство −4 = 0.
Пара (0; 0) не является решением.

3. Что называют графиком уравнения

Каждому решению (x; y) соответствует точка координатной плоскости. Все точки, координаты которых являются решениями уравнения, образуют его график.

Графиком линейного уравнения ax + by + c = 0 является прямая, если a и b не равны нулю одновременно.

Решения уравнения 2x + y − 4 = 0

Точки A(0; 4), C(1; 2) и B(2; 0) соответствуют решениям уравнения. Точка D(0; 0) не является решением, поэтому она не лежит на прямой.

4. Почему для построения достаточно двух точек

Через две различные точки можно провести единственную прямую. Поэтому для построения графика линейного уравнения достаточно найти две различные пары решений.

Если b ≠ 0, выбирайте два разных значения x и вычисляйте y. Если b = 0, то a ≠ 0: найдите x = −c/a и выберите два разных значения y. Получится вертикальная прямая, все точки которой имеют одну абсциссу.

Алгоритм построения при b ≠ 0:
1. Выберите удобное значение x.
2. Вычислите соответствующее значение y.
3. Получите первую точку.
4. Выберите другое значение x.
5. Вычислите второе значение y.
6. Отметьте обе точки и проведите через них прямую.
Для проверки полезно найти третью пару решений. Соответствующая точка должна лежать на построенной прямой.

5. Построение графика по таблице

Пример 3. Построим график 2x + y − 4 = 0

Выразим переменную y:

2x + y − 4 = 0;
y = 4 − 2x.

Выберем несколько удобных значений x.

x Вычисление y y Точка
0 y = 4 − 2 · 0 4 (0; 4)
1 y = 4 − 2 · 1 2 (1; 2)
2 y = 4 − 2 · 2 0 (2; 0)

Для построения достаточно точек (0; 4) и (2; 0). Точка (1; 2) используется для проверки.

6. Построение по точкам пересечения с осями

Часто удобнее всего найти точки, в которых прямая пересекает координатные оси.

Пересечение с осью Ox

На оси Ox ордината равна нулю, поэтому подставляют y = 0.

Пересечение с осью Oy

На оси Oy абсцисса равна нулю, поэтому подставляют x = 0.

Пример 4. Уравнение x + 2y − 6 = 0

Пересечение с Ox:
y = 0;
x + 2 · 0 − 6 = 0;
x = 6.
Получаем точку A(6; 0).
Пересечение с Oy:
x = 0;
0 + 2y − 6 = 0;
2y = 6;
y = 3.
Получаем точку B(0; 3).

График проходит через точки A(6; 0) и B(0; 3).

Если обе найденные точки совпали с началом координат, нужно выбрать ещё одно ненулевое значение x или y.

7. Переход к виду y = kx + b

Если коэффициент при y не равен нулю, из уравнения ax + by + c = 0 можно выразить y.

Преобразование общего уравнения

После преобразования получаем линейную функцию y = kx + b, где коэффициент при x равен − a b , а свободный член равен − c b .

Пример 5. Преобразуем уравнение

Преобразовать уравнение 3x − 2y − 6 = 0 к виду y = kx + b.
3x − 2y − 6 = 0;
−2y = −3x + 6;
y = 3 2 x − 3.
Ответ: y = 3 2 x − 3.

8. Особые случаи

Некоторые линейные уравнения задают горизонтальные или вертикальные прямые.

Горизонтальная и вертикальная прямые

Условие Вид уравнения График
a = 0, b ≠ 0 by + c = 0 Горизонтальная прямая y = −c : b
b = 0, a ≠ 0 ax + c = 0 Вертикальная прямая x = −c : a
c = 0 ax + by = 0 Прямая проходит через O(0; 0)
Вертикальную прямую x = число нельзя записать в виде y = kx + b, потому что одному значению x соответствует множество значений y.

9. Как найти одну координату по другой

Пример 6. Известна абсцисса

Найти y, если точка принадлежит графику 3x + 2y − 12 = 0 и x = 2.
Подставим x = 2:
3 · 2 + 2y − 12 = 0.
6 + 2y − 12 = 0.
2y − 6 = 0.
2y = 6.
y = 3.
Ответ: точка (2; 3).

Пример 7. Известна ордината

Найти x, если точка принадлежит графику 4x − y + 1 = 0 и y = 5.
4x − 5 + 1 = 0.
4x − 4 = 0.
4x = 4.
x = 1.
Ответ: точка (1; 5).

10. Частые ошибки при построении

Перепутан порядок координат

В точке (x; y) сначала записывается абсцисса, а затем ордината.

Найдена только одна точка

Одной точки недостаточно для определения положения прямой.

Не выполнена проверка

Координаты контрольной точки нужно подставить в исходное уравнение.

Потерян знак минус

Особенно внимательно нужно переносить слагаемые и делить на отрицательный коэффициент.

11. Задания для самопроверки

Сначала выполните вычисления самостоятельно, а затем раскройте решение.

Задание 1. Назовите коэффициенты a, b и c в уравнении 5x − 3y + 8 = 0.

Показать решение
Сравним с видом ax + by + c = 0.

Коэффициент при x равен 5.
Коэффициент при y равен −3.
Свободный член равен 8.

Ответ: a = 5, b = −3, c = 8.

Задание 2. Является ли пара (2; 1) решением уравнения 3x + 2y − 8 = 0?

Показать решение
Подставим x = 2, y = 1:

3 · 2 + 2 · 1 − 8 = 6 + 2 − 8 = 0.

Получили верное равенство.

Ответ: да.

Задание 3. Является ли точка A(−1; 4) точкой графика x + y − 3 = 0?

Показать решение
Подставим координаты:

−1 + 4 − 3 = 0.

Получили 0 = 0.

Ответ: да, точка принадлежит графику.

Задание 4. Найдите y, если x = 3 и 2x + y − 10 = 0.

Показать решение
2 · 3 + y − 10 = 0.

6 + y − 10 = 0.

y − 4 = 0.

y = 4.

Ответ: 4.

Задание 5. Найдите x, если y = −2 и 3x − 2y − 10 = 0.

Показать решение
3x − 2 · (−2) − 10 = 0.

3x + 4 − 10 = 0.

3x − 6 = 0.

3x = 6.

x = 2.

Ответ: 2.

Задание 6. Найдите точки пересечения графика x + y − 5 = 0 с координатными осями.

Показать решение
На оси Ox: y = 0.
x + 0 − 5 = 0, поэтому x = 5.
Первая точка: (5; 0).

На оси Oy: x = 0.
0 + y − 5 = 0, поэтому y = 5.
Вторая точка: (0; 5).

Ответ: (5; 0) и (0; 5).

Задание 7. Заполните таблицу для уравнения y = 6 − 2x:
x = 0; 1; 3.

Показать решение
При x = 0:
y = 6 − 2 · 0 = 6.

При x = 1:
y = 6 − 2 · 1 = 4.

При x = 3:
y = 6 − 2 · 3 = 0.

Ответ: (0; 6), (1; 4), (3; 0).

Задание 8. Преобразуйте уравнение 2x + 4y − 8 = 0 к виду y = kx + b.

Показать решение
2x + 4y − 8 = 0.

4y = −2x + 8.

Разделим обе части на 4:

y = − 1 2 x + 2.

Ответ: y = − 1 2 x + 2.

Задание 9. Какой график задаёт уравнение 2y − 6 = 0?

Показать решение
2y − 6 = 0.

2y = 6.

y = 3.

Это горизонтальная прямая, параллельная оси Ox.

Ответ: прямая y = 3.

Задание 10. Какой график задаёт уравнение 4x + 8 = 0?

Показать решение
4x + 8 = 0.

4x = −8.

x = −2.

Это вертикальная прямая, параллельная оси Oy.

Ответ: прямая x = −2.

Задание 11. Из точек A(0; 4), B(1; 1), C(2; 0) выберите точки, принадлежащие графику 2x + y − 4 = 0.

Показать решение
Проверим A(0; 4):
2 · 0 + 4 − 4 = 0. Точка A принадлежит.

Проверим B(1; 1):
2 · 1 + 1 − 4 = −1. Точка B не принадлежит.

Проверим C(2; 0):
2 · 2 + 0 − 4 = 0. Точка C принадлежит.

Ответ: A и C.

Задание 12. Найдите значение c, если точка M(2; −1) принадлежит графику уравнения 3x + 2y + c = 0.

Показать решение
Подставим x = 2 и y = −1:

3 · 2 + 2 · (−1) + c = 0.

6 − 2 + c = 0.

4 + c = 0.

c = −4.

Ответ: c = −4.

Задание 13. Рассмотрите рисунок. Какие из отмеченных точек являются решениями уравнения x + y − 2 = 0? Назовите точки пересечения графика с осями Ox и Oy.

График уравнения x + y − 2 = 0

Показать решение
Точки A(0; 2), C(1; 1) и B(2; 0) расположены на изображённой прямой.

Проверим подстановкой:

A(0; 2):
0 + 2 − 2 = 0.

C(1; 1):
1 + 1 − 2 = 0.

B(2; 0):
2 + 0 − 2 = 0.

Для точки D(−1; 0):
−1 + 0 − 2 = −3.

Поэтому точка D не принадлежит графику.

График пересекает ось Oy в точке A(0; 2), а ось Ox — в точке B(2; 0).

Ответ: решениями являются точки A, B и C; точки пересечения с осями — A(0; 2) и B(2; 0).

12. Что можно узнать об уравнении до построения

Некоторые свойства графика видны уже по записи уравнения.

Если коэффициент при y не равен нулю, можно выразить y и получить привычный вид y = kx + b.

Если в уравнении отсутствует x, график будет горизонтальной прямой.

Если в уравнении отсутствует y, график будет вертикальной прямой.

Если свободный член равен нулю, точка O(0; 0) является решением, поэтому прямая проходит через начало координат.

Если найдены две различные пары решений, положение прямой уже определено.
Перед построением подберите такие значения x или y, при которых вычисления получаются простыми. Это уменьшает количество дробей и упрощает проверку.
