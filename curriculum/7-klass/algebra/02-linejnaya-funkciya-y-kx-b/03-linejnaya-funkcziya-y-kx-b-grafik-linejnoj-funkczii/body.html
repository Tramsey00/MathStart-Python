Что нужно знать перед темой

Линейная функция объединяет алгебраическую формулу и её графическое изображение. Перед началом полезно повторить работу с выражениями, таблицами и координатной плоскостью.

  • Координаты точки записывают в порядке (x; y).
  • Значение выражения находят подстановкой числа вместо переменной.
  • Через две различные точки можно провести единственную прямую.
  • Точка принадлежит графику, если её координаты удовлетворяют формуле.
  • На оси Oy абсцисса любой точки равна нулю.
  • На оси Ox ордината любой точки равна нулю.
В формуле y = kx + b коэффициентами являются k и b. Буква x обозначает независимую переменную, а значение y зависит от x.

1. Что называют функцией

Функция — это зависимость, при которой каждому допустимому значению переменной x соответствует единственное значение переменной y.

x — независимая переменная, или аргумент функции.

y — зависимая переменная, или значение функции.

Формула функции показывает, какие действия нужно выполнить со значением x, чтобы получить соответствующее значение y.

Пример 1. Найдём значение функции

Условие Функция задана формулой y = 3x − 2. Найти значение y при x = 4.
Решение.
Подставим x = 4:
y = 3 · 4 − 2 = 12 − 2 = 10.
Ответ: 10.

Пример 2. Найдём аргумент по значению функции

Функция задана формулой y = 2x + 5. При каком x значение функции равно 13?
Подставим y = 13:
13 = 2x + 5.
2x = 8.
x = 4.
Ответ: 4.

2. Линейная функция

Линейной называют функцию, которую можно задать формулой:

y = kx + b,

где k и b — заданные числа, x — аргумент, y — значение функции.

Коэффициент k

Определяет направление и крутизну наклона прямой.

Коэффициент b

Показывает ординату точки пересечения графика с осью Oy.

Аргумент x

Значение, которое выбирают или получают из условия задачи.

Значение y

Результат вычисления по формуле при выбранном x.

В функции y = −2x + 5:
k = −2,   b = 5.

3. График линейной функции

Графиком функции называют множество всех точек координатной плоскости, координаты которых удовлетворяют её формуле.

График линейной функции y = kx + b — прямая. Для её построения достаточно найти две различные точки.

Пример 3. Построим график y = 2x − 1

Выберем несколько значений x и вычислим соответствующие значения y.

x Вычисление y Точка
−1 y = 2 · (−1) − 1 −3 A(−1; −3)
0 y = 2 · 0 − 1 −1 B(0; −1)
2 y = 2 · 2 − 1 3 C(2; 3)

Для построения достаточно двух точек, например A и C. Точку B удобно использовать для проверки.

4. Интерактивная лаборатория y = kx + b

Перемещайте ползунки. Коэффициент k меняет наклон прямой, а коэффициент b сдвигает её вверх или вниз. На графике отмечаются точки пересечения прямой с осями Oy и Ox.

Интерактивная модель

Исследуйте график самостоятельно

y = x
график функции точка (0; b) пересечение с осью Ox
Коэффициент k 1
−3 0 3
Коэффициент b 0
−6 0 6
Поведение возрастает
Пересечение Oy (0; 0)
Пересечение Ox (0; 0)

Наблюдение: при изменении k прямая поворачивается, а при изменении b перемещается параллельно самой себе. Координаты пересечений с осями автоматически пересчитываются.

5. Как коэффициент k влияет на график

Знак коэффициента k показывает, как изменяется y при движении по оси x слева направо.

Три основных случая

Значение k Поведение графика Пример
k > 0 Функция возрастает y = 2x − 1
k < 0 Функция убывает y = −3x + 4
k = 0 Значение y постоянно y = 5

6. Как коэффициент b влияет на график

Подставим x = 0 в формулу y = kx + b:

y = k · 0 + b;
y = b.
График функции y = kx + b пересекает ось Oy в точке (0; b).

Изменение b сдвигает прямую параллельно

7. Алгоритм построения графика

Шаг 1. Выберите два удобных значения x.

Шаг 2. Для каждого значения вычислите y.

Шаг 3. Запишите полученные пары (x; y).

Шаг 4. Отметьте точки на координатной плоскости.

Шаг 5. Проведите через точки прямую.

Шаг 6. Проверьте построение по третьей точке.

Пример 4. Построим график y = −3x + 6

x y = −3x + 6 Точка
0 y = 6 A(0; 6)
2 y = 0 B(2; 0)

Точки выбраны так, чтобы вычисления были простыми и прямая пересекала обе координатные оси в целочисленных точках.

8. Принадлежность точки графику

Чтобы проверить, лежит ли точка на графике, её координаты подставляют в формулу функции.

Пример 5. Проверим точку

Принадлежит ли точка A(3; 7) графику функции y = 2x + 1?
Подставим x = 3 и y = 7:
7 = 2 · 3 + 1.
7 = 7.
Точка принадлежит графику.

Пример 6. Точка не принадлежит графику

Проверить точку B(2; 6) для функции y = 2x + 1.
При x = 2 по формуле получаем:
y = 2 · 2 + 1 = 5.
Ордината точки B равна 6, а не 5.
Точка B не принадлежит графику.

9. Точки пересечения с координатными осями

Пересечение с Oy

Подставьте x = 0. Получится точка (0; b).

Пересечение с Ox

Подставьте y = 0 и решите уравнение kx + b = 0.

Пример 7. Найдём обе точки

Найти точки пересечения графика y = 2x − 8 с осями.
С осью Oy:
x = 0, поэтому y = −8.
Получаем точку (0; −8).
С осью Ox:
0 = 2x − 8.
2x = 8.
x = 4.
Точка пересечения с Ox: (4; 0).

10. Линейная функция как модель ситуации

Формула y = kx + b часто описывает величину, которая состоит из постоянной части и части, изменяющейся пропорционально x.

b — начальное или постоянное значение.

kx — изменяющаяся часть.

Пример 8. Стоимость поездки

Посадка в такси стоит 120 рублей, а каждый километр — 18 рублей. Составить функцию стоимости поездки на x километров.
Постоянная часть равна 120 рублям.
Стоимость x километров равна 18x рублей.
Функция: y = 18x + 120.

11. Задания для самопроверки

Выполняйте вычисления последовательно и проверяйте каждую найденную точку подстановкой в исходную формулу.

Задание 1. Назовите k и b в функции y = −3x + 5.

Показать решение
Коэффициент при x равен −3, свободный член равен 5.

Ответ: k = −3, b = 5.

Задание 2. Найдите значение функции y = 4x − 7 при x = 3.

Показать решение
y = 4 · 3 − 7 = 12 − 7 = 5.

Ответ: 5.

Задание 3. Заполните таблицу для функции y = 2x − 3 при x = −1, 0 и 2.

Показать решение
При x = −1: y = 2 · (−1) − 3 = −5.

При x = 0: y = −3.

При x = 2: y = 4 − 3 = 1.

Ответ: (−1; −5), (0; −3), (2; 1).

Задание 4. Принадлежит ли точка A(2; 1) графику y = 3x − 5?

Показать решение
При x = 2:
y = 3 · 2 − 5 = 6 − 5 = 1.

Полученное значение совпадает с ординатой точки.

Ответ: да.

Задание 5. Принадлежит ли точка B(−1; 4) графику y = −2x + 1?

Показать решение
При x = −1:
y = −2 · (−1) + 1 = 2 + 1 = 3.

Ордината точки равна 4, поэтому точка не принадлежит графику.

Ответ: нет.

Задание 6. Найдите b, если график y = 2x + b проходит через точку A(3; 4).

Показать решение
Подставим x = 3 и y = 4:

4 = 2 · 3 + b.

4 = 6 + b.

b = −2.

Ответ: b = −2.

Задание 7. Найдите k, если график y = kx + 1 проходит через точку B(2; 7).

Показать решение
7 = 2k + 1.

2k = 6.

k = 3.

Ответ: k = 3.

Задание 8. Найдите точку пересечения графика y = −4x + 6 с осью Oy.

Показать решение
На оси Oy значение x равно нулю.

y = −4 · 0 + 6 = 6.

Ответ: (0; 6).

Задание 9. Найдите точку пересечения графика y = 2x − 8 с осью Ox.

Показать решение
На оси Ox значение y равно нулю.

0 = 2x − 8.

x = 4.

Ответ: (4; 0).

Задание 10. Определите, возрастает или убывает функция y = −0,5x + 3.

Показать решение
Коэффициент k = −0,5 отрицателен.

Поэтому функция убывает.

Ответ: убывает.

Задание 11. По таблице определите формулу линейной функции.

x −1 0 1
y 4 2 0
Показать решение
При x = 0 значение y равно 2, поэтому b = 2.

При увеличении x на 1 значение y уменьшается на 2, поэтому k = −2.

Ответ: y = −2x + 2.

Задание 12. По рисунку определите формулу графика. Известно, что коэффициент k и свободный член b являются целыми числами.

Определите k и b

Показать решение
Точка A(0; 2) лежит на оси Oy, поэтому b = 2.

Подставим точку B(2; 0) в y = kx + 2:

0 = 2k + 2.

2k = −2.

k = −1.

Ответ: y = −x + 2.

Задание 13. Стоимость услуги описывается функцией y = 25x + 80, где x — количество часов. Объясните смысл коэффициентов 25 и 80 и найдите стоимость за 4 часа.

Показать решение
Число 25 показывает стоимость одного часа.

Число 80 — постоянная часть оплаты.

При x = 4:
y = 25 · 4 + 80 = 100 + 80 = 180.

Ответ: 25 рублей за час, 80 рублей — постоянная часть; всего 180 рублей.

12. Экспресс-анализ формулы y = kx + b

Перед построением графика можно быстро получить несколько важных сведений непосредственно из формулы.

Посмотрите на k. Положительное значение означает возрастание, отрицательное — убывание, нулевое — горизонтальную прямую.

Посмотрите на b. График пересекает ось Oy в точке (0; b).

Найдите вторую точку. Выберите удобное значение x и вычислите y либо найдите пересечение с Ox.

Проверьте себя. Подставьте координаты третьей точки в формулу.
Интерактивный график полезно использовать не для угадывания ответа, а для проверки вывода: сначала предскажите изменение прямой по формуле, затем переместите ползунок и сравните результат.
