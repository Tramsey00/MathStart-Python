Решение систем линейных уравнений методом подстановки

Научимся выражать одну переменную через другую, выполнять подстановку, получать уравнение с одной переменной и находить обе координаты решения. Разберём простые системы, системы со скобками и случаи с дробными ответами.

Что нужно знать перед темой

Метод подстановки превращает систему из двух уравнений с двумя переменными в обычное линейное уравнение с одной переменной.

  • Уметь выражать одну переменную через другую.
  • Правильно переносить слагаемые из одной части уравнения в другую.
  • Раскрывать скобки по распределительному закону.
  • Приводить подобные слагаемые.
  • Решать линейные уравнения с одной переменной.
  • Проверять найденную пару в обоих уравнениях системы.
Подстановка означает замену переменной равным ей выражением. Например, если y = 7 − x, то во втором уравнении вместо y можно записать 7 − x.

1. Идея метода подстановки

Пусть из одного уравнения удалось выразить y через x. Тогда в другом уравнении переменную y заменяют полученным выражением. После такой замены остаётся только одна переменная.

Как система превращается в одно уравнение

2. Алгоритм метода подстановки

Шаг 1. Выразите одну переменную через другую из одного уравнения.

Шаг 2. Подставьте полученное выражение вместо этой переменной во второе уравнение.

Шаг 3. Решите получившееся уравнение с одной переменной.

Шаг 4. Подставьте найденное значение в выражение из первого шага и найдите вторую переменную.

Шаг 5. Запишите ответ парой (x; y) и выполните проверку.

Пять последовательных действий

3. Как выбрать переменную для выражения

Теоретически можно выразить любую переменную из любого уравнения, если коэффициент при ней не равен нулю. На практике выбирают вариант, который даёт более короткие вычисления.

Коэффициент равен 1

Из уравнения x + 2y = 7 удобнее выразить x: x = 7 − 2y.

Коэффициент равен −1

Из уравнения 3x − y = 5 удобно выразить y: y = 3x − 5.

Переменная уже выражена

Если записано y = 4x + 1, первый шаг уже выполнен.

Избегайте лишних дробей

Сначала ищите переменную с коэффициентом 1 или −1.

Выбираем наиболее удобную строку

4. Пример: переменная уже выражена

Решить систему
{
y = 3x − 5,
2x + y = 15.
Переменная y уже выражена. Подставим 3x − 5 вместо y во второе уравнение:
2x + (3x − 5) = 15.
5x − 5 = 15.
5x = 20.
x = 4.
Найдём y:
y = 3 · 4 − 5 = 12 − 5 = 7.
Ответ: (4; 7).
Скобки вокруг выражения при подстановке помогают не потерять знаки, особенно если выражение начинается с минуса.

5. Пример: сначала выразим переменную

Решить систему
{
x + y = 7,
2x − y = 2.
Из первого уравнения выразим y:
y = 7 − x.
Подставим 7 − x вместо y во второе уравнение:
2x − (7 − x) = 2.
Раскроем скобки:
2x − 7 + x = 2.
3x = 9.
x = 3.
y = 7 − 3 = 4.
Ответ: (3; 4).

6. Пример со скобками

Решить систему
{
2(x + y) = 14,
y = x − 1.
Подставим x − 1 вместо y в первое уравнение:
2(x + x − 1) = 14.
2(2x − 1) = 14.
4x − 2 = 14.
4x = 16.
x = 4.
y = 4 − 1 = 3.
Ответ: (4; 3).

7. Пример с дробным ответом

Решить систему
{
3x + 2y = 12,
x − y = 1.
Из второго уравнения выразим x:
x = y + 1.
Подставим в первое уравнение:
3(y + 1) + 2y = 12.
3y + 3 + 2y = 12.
5y = 9.
y = 9 5 .
x = y + 1 = 9 5 + 5 5 = 14 5 .
Ответ: ( 14 5 ; 9 5 ).
Дробный ответ не означает ошибку. Если вычисления выполнены правильно, система может иметь решение с дробными координатами.

8. Что может получиться после подстановки

После упрощения обычно получается уравнение с одним числовым ответом. Но иногда переменная исчезает полностью.

Обычное уравнение

Например, 3x = 9. Система имеет одно решение.

Неверное равенство

Например, 0 = 5. Система не имеет решений.

Верное равенство

Например, 0 = 0. Уравнения задают одну и ту же прямую.

Обязательный вывод

Нельзя писать значение переменной, если после упрощения она исчезла.

Пример: решений нет

{
y = 2x + 1,
y = 2x − 4.
Приравняем выражения:
2x + 1 = 2x − 4.
1 = −4 — неверное равенство.
Система не имеет решений.

Пример: бесконечно много решений

{
y = 3x − 2,
2y = 6x − 4.
Подставим y = 3x − 2 во второе уравнение:
2(3x − 2) = 6x − 4.
6x − 4 = 6x − 4 — верно при любом x.
Система имеет бесконечно много решений.

9. Проверка найденной пары

После решения подставьте найденные значения в исходные уравнения, а не только в преобразованные записи.

Проверка завершает решение

10. Ошибки, которые меняют ответ

Нет скобок при подстановке

В выражении 2x − (7 − x) скобки обязательны: минус меняет знаки внутри.

Подстановка в ту же строку

Выражение из одного уравнения нужно подставить в другое уравнение.

Найдена только одна переменная

После нахождения x необходимо вычислить y и записать пару.

Перепутан порядок ответа

Даже если сначала найден y, ответ всё равно записывают как (x; y).

При переносе выражения через знак равенства меняются знаки слагаемых, а при подстановке отрицательного выражения особенно важно использовать скобки.

11. Задания для самопроверки

Сначала выберите удобную переменную, затем выполняйте шаги алгоритма.

Задание 1. Из уравнения x + 3y = 10 выразите x.

Показать решение
Перенесём 3y в правую часть:

Ответ: x = 10 − 3y.

Задание 2. Из уравнения 4x − y = 9 выразите y.

Показать решение
−y = 9 − 4x.

Умножим обе части на −1:

Ответ: y = 4x − 9.

Задание 3. Решите систему методом подстановки.

{
y = 2x + 1,
x + y = 10.
Показать решение
x + (2x + 1) = 10.

3x + 1 = 10.

3x = 9, x = 3.

y = 2 · 3 + 1 = 7.

Ответ: (3; 7).

Задание 4. Решите систему методом подстановки.

{
x − y = 4,
2x + y = 11.
Показать решение
Из первого уравнения: x = y + 4.

2(y + 4) + y = 11.

3y + 8 = 11.

y = 1.

x = 1 + 4 = 5.

Ответ: (5; 1).

Задание 5. Решите систему.

{
3x + y = 8,
y = 2 − x.
Показать решение
3x + (2 − x) = 8.

2x + 2 = 8.

x = 3.

y = 2 − 3 = −1.

Ответ: (3; −1).

Задание 6. Решите систему.

{
2(x + y) = 18,
y = x + 1.
Показать решение
2(x + x + 1) = 18.

2(2x + 1) = 18.

4x + 2 = 18.

x = 4.

y = 5.

Ответ: (4; 5).

Задание 7. Решите систему.

{
x + 2y = 1,
x = 5 − y.
Показать решение
(5 − y) + 2y = 1.

5 + y = 1.

y = −4.

x = 5 − (−4) = 9.

Ответ: (9; −4).

Задание 8. Решите систему.

{
2x + 3y = 4,
x − y = 2.
Показать решение
Из второго уравнения x = y + 2.

2(y + 2) + 3y = 4.

5y + 4 = 4.

y = 0.

x = 2.

Ответ: (2; 0).

Задание 9. Решите систему с дробным ответом.

{
2x + y = 5,
x − y = 1.
Показать решение
Из второго уравнения x = y + 1.

2(y + 1) + y = 5.

3y = 3.

y = 1, x = 2.

В этой системе ответ оказался целым.

Ответ: (2; 1).

Задание 10. Определите количество решений системы.

{
y = 4x + 2,
y = 4x − 5.
Показать решение
Приравняем выражения:

4x + 2 = 4x − 5.

2 = −5 — неверное равенство.

Ответ: решений нет.

Задание 11. Определите количество решений системы.

{
y = 2x − 3,
3y = 6x − 9.
Показать решение
Подставим y = 2x − 3:

3(2x − 3) = 6x − 9.

6x − 9 = 6x − 9 — верно при любом x.

Ответ: бесконечно много решений.

Задание 12. Найдите ошибку: из y = 6 − x и 3x − y = 2 записали 3x − 6 − x = 2.

Показать решение
Выражение 6 − x подставляется вместо y целиком:

3x − (6 − x) = 2.

После раскрытия скобок получается 3x − 6 + x = 2.

Ошибка: не поставлены скобки и потерян знак плюс перед x.

Задание 13. Решите систему и выполните проверку.

{
x + y = 8,
3x − 2y = 4.
Показать решение
Из первого уравнения y = 8 − x.

3x − 2(8 − x) = 4.

3x − 16 + 2x = 4.

5x = 20, x = 4.

y = 8 − 4 = 4.

Проверка:
4 + 4 = 8;
3 · 4 − 2 · 4 = 12 − 8 = 4.

Ответ: (4; 4).

12. Как сделать решение короче и надёжнее

Ищите коэффициент 1 или −1 Такая переменная выражается без дробей и лишних преобразований.
Ставьте скобки Заменяемое выражение должно восприниматься как единое целое.
Возвращайтесь к простой формуле Вторую переменную удобнее находить по уже выраженной зависимости.
Метод подстановки особенно удобен, когда одна переменная уже выражена или легко выражается из уравнения. В следующей теме рассмотрим метод сложения, который часто быстрее работает при противоположных коэффициентах.
