Решение систем линейных уравнений методом сложения

Научимся складывать и вычитать уравнения системы так, чтобы одна переменная исчезла. Разберём системы с готовыми противоположными коэффициентами, умножение одного или обоих уравнений и особые случаи, когда решений нет или их бесконечно много.

Что нужно знать перед темой

Метод сложения основан на почленном сложении или вычитании двух уравнений. Перед началом полезно повторить действия с отрицательными числами и равносильные преобразования уравнений.

  • Складывать коэффициенты при одинаковых переменных.
  • Вычитать одно уравнение из другого почленно.
  • Умножать обе части уравнения на одно и то же ненулевое число.
  • Раскрывать скобки и приводить подобные слагаемые.
  • Решать линейные уравнения с одной переменной.
  • Проверять найденную пару в исходной системе.
Главная цель метода — получить противоположные коэффициенты при одной переменной. Тогда при сложении эта переменная уничтожится: 3y + (−3y) = 0.

1. Идея метода сложения

Если сложить левые части двух верных равенств и отдельно сложить правые части, получится новое верное равенство. Коэффициенты при одинаковых переменных складываются.

Противоположные слагаемые взаимно уничтожаются

Если коэффициенты при одной переменной противоположны, уравнения складывают. Если коэффициенты одинаковы, удобно вычесть одно уравнение из другого.

2. Алгоритм метода сложения

Шаг 1. Выберите переменную, которую удобнее исключить.

Шаг 2. При необходимости умножьте одно или оба уравнения на подходящие числа, чтобы получить противоположные коэффициенты.

Шаг 3. Сложите уравнения почленно. Если коэффициенты одинаковы, можно вычесть уравнения.

Шаг 4. Решите полученное уравнение с одной переменной.

Шаг 5. Подставьте найденное значение в любое исходное уравнение и найдите вторую переменную.

Шаг 6. Запишите ответ парой (x; y) и выполните проверку.

Последовательность действий

3. Коэффициенты уже противоположны

Решить систему
{
x + y = 7,
x − y = 1.
Коэффициенты при y равны 1 и −1. Сложим уравнения:
(x + y) + (x − y) = 7 + 1.
2x = 8.
x = 4.
Подставим x = 4 в первое уравнение:
4 + y = 7.
y = 3.
Ответ: (4; 3).

4. Когда удобнее вычитать уравнения

Если коэффициенты при выбранной переменной одинаковы, можно вычесть второе уравнение из первого. Тогда одинаковые слагаемые исчезнут.

Решить систему
{
4x + 3y = 18,
x + 3y = 9.
Коэффициенты при y одинаковы. Вычтем второе уравнение из первого:
(4x + 3y) − (x + 3y) = 18 − 9.
3x = 9.
x = 3.
Подставим в x + 3y = 9:
3 + 3y = 9.
3y = 6, поэтому y = 2.
Ответ: (3; 2).
При вычитании скобки обязательны: знак минус должен изменить знаки всех слагаемых вычитаемого уравнения.

5. Умножаем одно уравнение

Решить систему
{
x + 2y = 8,
3x − y = 3.

Коэффициенты при y равны 2 и −1. Умножим второе уравнение на 2, чтобы получить −2y.

Умножение всей строки системы

{
x + 2y = 8,
6x − 2y = 6.
Складываем:
7x = 14.
x = 2.
2 + 2y = 8.
2y = 6, y = 3.
Ответ: (2; 3).

6. Умножаем оба уравнения

Решить систему
{
2x + 3y = 7,
3x − 2y = 4.

Для исключения y нужно получить коэффициенты 6 и −6. Умножим первое уравнение на 2, а второе — на 3.

{
4x + 6y = 14,
9x − 6y = 12.
Сложим уравнения:
13x = 26.
x = 2.
Подставим в первое исходное уравнение:
2 · 2 + 3y = 7.
4 + 3y = 7.
y = 1.
Ответ: (2; 1).
Умножая уравнение на число, нужно умножить каждый член обеих частей, включая свободный член.

7. Как выбрать переменную для исключения

Уже есть противоположные коэффициенты

Сразу складывайте уравнения.

Коэффициенты одинаковы

Вычитайте одно уравнение из другого.

Один коэффициент кратен другому

Обычно достаточно умножить только одно уравнение.

Оба коэффициента неудобны

Найдите их наименьшее общее кратное и умножьте обе строки.

Сложить или вычесть?

8. Особые случаи после сложения

Иногда после исключения переменной исчезают обе переменные. Тогда нужно оценить получившееся числовое равенство.

Система не имеет решений

{
2x + y = 5,
−2x − y = 1.
Сложим уравнения:
0x + 0y = 6.
0 = 6 — неверное равенство.
Система не имеет решений.

Система имеет бесконечно много решений

{
2x + y = 5,
−4x − 2y = −10.
Умножим первое уравнение на 2:
4x + 2y = 10.
Сложим со вторым:
0 = 0 — верное равенство.
Система имеет бесконечно много решений.

9. Проверка найденной пары

Проверка особенно важна после умножения уравнений и действий с отрицательными коэффициентами.

Подставьте найденные значения x и y в оба исходных уравнения. Если обе строки превращаются в верные равенства, решение найдено верно.
Проверим решение (2; 3) системы x + 2y = 8 и 3x − y = 3.
Первое уравнение:
2 + 2 · 3 = 2 + 6 = 8.
Второе уравнение:
3 · 2 − 3 = 6 − 3 = 3.
Оба равенства верны.

10. Ошибки, которые нельзя допускать

Умножена не вся строка

При умножении уравнения изменяются все коэффициенты и свободный член.

Неправильное вычитание

Знак минус перед скобкой меняет знаки всех членов второго уравнения.

Переменная не исчезла

Значит, коэффициенты подготовлены неверно или выбрано не то действие.

Найдена только одна координата

После первого ответа нужно обязательно найти вторую переменную.

Перед почленным сложением полезно записывать подобные члены строго друг под другом: x под x, y под y, числа под числами.

11. Задания для самопроверки

В каждом задании сначала решите, какую переменную удобнее исключить.

Задание 1. Какие слагаемые исчезнут при сложении уравнений 2x + 5y = 9 и 3x − 5y = 6?

Показать решение
Коэффициенты при y противоположны: 5y + (−5y) = 0.

Ответ: слагаемые 5y и −5y.

Задание 2. На какое число нужно умножить уравнение 3x − y = 4, чтобы коэффициент при y стал равен −4?

Показать решение
Коэффициент −1 нужно умножить на 4.

Получится 12x − 4y = 16.

Ответ: на 4.

Задание 3. Решите систему.

{
x + y = 9,
x − y = 3.
Показать решение
Складываем:

2x = 12, x = 6.

6 + y = 9, y = 3.

Ответ: (6; 3).

Задание 4. Решите систему.

{
3x + 2y = 13,
3x − 2y = 5.
Показать решение
Складываем:

6x = 18, x = 3.

3 · 3 + 2y = 13.

2y = 4, y = 2.

Ответ: (3; 2).

Задание 5. Решите систему вычитанием.

{
5x + 4y = 23,
2x + 4y = 14.
Показать решение
Вычтем второе уравнение из первого:

3x = 9, x = 3.

2 · 3 + 4y = 14.

4y = 8, y = 2.

Ответ: (3; 2).

Задание 6. Решите систему, предварительно умножив одно уравнение.

{
x + 3y = 11,
2x − y = 1.
Показать решение
Умножим второе уравнение на 3:

6x − 3y = 3.

Сложим с первым:

7x = 14, x = 2.

2 + 3y = 11, y = 3.

Ответ: (2; 3).

Задание 7. Решите систему.

{
2x + y = 4,
3x − 2y = 5.
Показать решение
Умножим первое уравнение на 2:

4x + 2y = 8.

Сложим:

7x = 13, поэтому x = 13 7 .

Из 2x + y = 4:

y = 4 − 26 7 = 2 7 .

Ответ: ( 13 7 ; 2 7 ).

Задание 8. Решите систему, умножив оба уравнения.

{
2x + 3y = 12,
5x − 2y = 11.
Показать решение
Умножим первое уравнение на 2:
4x + 6y = 24.

Умножим второе уравнение на 3:
15x − 6y = 33.

Складываем:
19x = 57, x = 3.

2 · 3 + 3y = 12.
3y = 6, y = 2.

Ответ: (3; 2).

Задание 9. Определите количество решений системы.

{
3x + y = 7,
−3x − y = 2.
Показать решение
Сложим уравнения:

0 = 9 — неверное равенство.

Ответ: решений нет.

Задание 10. Определите количество решений системы.

{
x − 2y = 4,
−2x + 4y = −8.
Показать решение
Умножим первое уравнение на 2:

2x − 4y = 8.

Сложим со вторым:

0 = 0 — верное равенство.

Задание 11. Найдите ошибку: уравнение 2x − 3y = 5 умножили на −2 и получили −4x − 6y = −10.

Показать решение
При умножении −3y на −2 получается +6y.

Правильная строка:
−4x + 6y = −10.

Ошибка допущена в знаке коэффициента при y.

Задание 12. Решите систему и выполните проверку.

{
4x + 3y = 17,
2x − 3y = 1.
Показать решение
Складываем:

6x = 18, x = 3.

2 · 3 − 3y = 1.

−3y = −5, y = 5 3 .

Проверка:
4 · 3 + 3 · 5 3 = 12 + 5 = 17;
2 · 3 − 3 · 5 3 = 6 − 5 = 1.

Ответ: (3; 5 3 ).

Задание 13. Каким способом удобнее решить систему: подстановкой или сложением? Объясните выбор.

{
7x + 4y = 20,
3x − 4y = 0.
Показать решение
Удобнее метод сложения: коэффициенты при y уже противоположны.

После сложения сразу получаем 10x = 20.

Ответ: метод сложения.

12. Как выбрать рациональный ход решения

Сравните коэффициенты Сначала ищите одинаковые, противоположные или кратные числа.
Избегайте больших множителей Исключайте ту переменную, для которой числа подготавливаются проще.
Контролируйте знаки При умножении и вычитании проверяйте каждый член отдельно.
Метод сложения особенно эффективен, когда коэффициенты при одной переменной уже противоположны или легко становятся противоположными после умножения уравнений.
