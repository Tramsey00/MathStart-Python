Понятие системы линейных уравнений с двумя переменными

Узнаем, что называют системой уравнений и её решением, научимся проверять пары чисел и понимать графический смысл системы. Разберём, почему система может иметь одно решение, не иметь решений или иметь бесконечно много решений.

Что нужно знать перед темой

Система объединяет два уравнения, которые должны выполняться одновременно. Поэтому важно уметь проверять принадлежность точки графику и находить общие точки двух прямых.

  • Решение уравнения с двумя переменными записывают парой (x; y).
  • Для проверки пары координаты подставляют вместо x и y.
  • Графиком линейного уравнения с двумя переменными является прямая.
  • Общая точка двух графиков принадлежит обеим прямым.
  • Различные непараллельные прямые пересекаются в одной точке.
  • Параллельные различные прямые не имеют общих точек.
Слово «одновременно» является ключевым: пара должна превращать в верные равенства каждое уравнение системы, а не только одно из них.

1. Что называют системой уравнений

Если требуется найти значения переменных, которые одновременно удовлетворяют нескольким уравнениям, эти уравнения объединяют фигурной скобкой.

Система двух линейных уравнений с двумя переменными — это два линейных уравнения, рассматриваемые совместно.
{
x + y = 5,
2x − y = 1.

Фигурная скобка

Показывает, что уравнения нужно выполнять одновременно.

Две переменные

В школьных задачах обычно требуется найти пару значений x и y.

Каждая строка

Представляет отдельное линейное уравнение с двумя переменными.

Общее условие

Искомая пара должна подходить сразу к обеим строкам.

2. Решение системы

Решением системы называют пару значений (x; y), которая является решением каждого уравнения системы.

Решение записывают в круглых скобках: сначала значение x, затем значение y.

Пример 1. Проверим пару (2; 3)

Является ли пара (2; 3) решением системы?
{
x + y = 5,
2x − y = 1.
Подставим x = 2 и y = 3 в первое уравнение:
2 + 3 = 5 — верно.
Проверим второе уравнение:
2 · 2 − 3 = 4 − 3 = 1 — верно.
Пара (2; 3) является решением системы.

3. Когда пара не является решением

Достаточно получить неверное равенство хотя бы в одной строке, чтобы пара не была решением всей системы.

Пример 2. Проверим пару (1; 4)

{
x + y = 5,
2x − y = 1.
Первое уравнение:
1 + 4 = 5 — верно.
Второе уравнение:
2 · 1 − 4 = −2, а должно получиться 1.
Пара подходит только к первому уравнению и не является решением системы.
Нельзя прекращать проверку после первого верного равенства: необходимо проверить все уравнения системы.

4. Графический смысл системы

Каждому линейному уравнению соответствует прямая. Решение системы — это координаты точки, принадлежащей обоим графикам.

Решить систему графически — значит построить оба графика и найти координаты их общих точек.

Решение системы как общая точка двух прямых

5. Сколько решений может иметь система

Количество решений зависит от взаимного расположения графиков двух уравнений.

Один, ноль или бесконечно много решений

Расположение прямых Общие точки Решения системы
Пересекаются Одна Одно решение
Параллельны и различны Нет Решений нет
Совпадают Бесконечно много Бесконечно много решений

6. Как проверить готовое решение

Алгоритм проверки пары (x; y):

1. Подставьте координаты в первое уравнение.
2. Убедитесь, что получилось верное равенство.
3. Подставьте те же координаты во второе уравнение.
4. Сделайте вывод только после проверки обеих строк.

Одна пара — две обязательные проверки

7. Как записывают ответ

Если система имеет одно решение, ответ обычно записывают парой координат.

Одно решение

Например: (2; 3).

Решений нет

Пишут: система не имеет решений.

Бесконечно много

Пишут: система имеет бесконечно много решений.

Порядок координат

Сначала записывают x, затем y: (x; y).

Записи (2; 3) и (3; 2) обозначают разные пары. Менять координаты местами нельзя.

8. Система как описание одной ситуации

В прикладных задачах два уравнения часто описывают разные условия одной и той же ситуации. Решение системы должно удовлетворять каждому условию.

Пример 3. Две величины и два условия

Сумма двух чисел равна 11, а их разность равна 3. Обозначим первое число через x, второе — через y.
Условие о сумме:
x + y = 11.
Условие о разности:
x − y = 3.
{
x + y = 11,
x − y = 3.

Пока мы только составили систему. Способы её вычислительного решения будут изучены в следующих темах.

9. Задания для самопроверки

В заданиях на проверку обязательно подставляйте пару в каждую строку.

Задание 1. Объясните, что означает фигурная скобка в записи системы.

Показать решение
Фигурная скобка показывает, что уравнения рассматриваются совместно и должны выполняться одновременно.

Ответ: нужно найти общие значения переменных для всех уравнений.

Задание 2. Является ли пара (3; 2) решением системы?

{
x + y = 5,
x − y = 1.
Показать решение
Первое уравнение:
3 + 2 = 5 — верно.

Второе уравнение:
3 − 2 = 1 — верно.

Ответ: да.

Задание 3. Является ли пара (4; 1) решением системы?

{
x + y = 5,
2x + y = 7.
Показать решение
Первое уравнение:
4 + 1 = 5 — верно.

Второе уравнение:
2 · 4 + 1 = 9, а не 7.

Ответ: нет.

Задание 4. Какая из пар является решением системы: (1; 3), (2; 2) или (3; 1)?

{
x + y = 4,
2x − y = 2.
Показать решение
Все три пары удовлетворяют первому уравнению.

Проверим второе:
для (1; 3): 2 · 1 − 3 = −1;
для (2; 2): 2 · 2 − 2 = 2;
для (3; 1): 2 · 3 − 1 = 5.

Ответ: (2; 2).

Задание 5. Известно, что графики двух уравнений пересекаются в точке A(−2; 5). Каково решение системы?

Показать решение
Координаты общей точки являются решением системы.

Ответ: (−2; 5).

Задание 6. Сколько решений имеет система, если её графики являются различными параллельными прямыми?

Показать решение
Различные параллельные прямые не имеют общих точек.

Ответ: система не имеет решений.

Задание 7. Сколько решений имеет система, если графики её уравнений совпадают?

Показать решение
Каждая точка одной прямой принадлежит и другой прямой. Общих точек бесконечно много.

Ответ: бесконечно много решений.

Задание 8. Проверить, является ли пара (0; 4) решением системы.

{
3x + y = 4,
x − 2y = −8.
Показать решение
Первое уравнение:
3 · 0 + 4 = 4 — верно.

Второе уравнение:
0 − 2 · 4 = −8 — верно.

Ответ: да.

Задание 9. Составьте систему по условию: сумма x и y равна 9, а удвоенное x на 1 больше y.

Показать решение
Первое условие:
x + y = 9.

«Удвоенное x на 1 больше y»:
2x = y + 1, или 2x − y = 1.

{
x + y = 9,
2x − y = 1.

Задание 10. Какая ошибка допущена в рассуждении: «Пара (2; 1) подходит к первому уравнению системы, значит она является решением системы»?

Показать решение
Проверено только одно уравнение. Для решения системы пара должна удовлетворять всем её уравнениям.

Ответ: необходимо проверить второе уравнение.

Задание 11. По рисунку определите решение системы и проверьте его подстановкой.

Найдите координаты общей точки

Показать решение
По рисунку общая точка имеет координаты (1; 2).

Проверим y = x + 1:
2 = 1 + 1 — верно.

Проверим y = −x + 3:
2 = −1 + 3 — верно.

Ответ: (1; 2).

Задание 12. Графики двух уравнений совпадают. Может ли система иметь ровно два решения?

Показать решение
Нет. Если прямые совпадают, каждая их точка является общей. Поэтому решений бесконечно много, а не два.

Ответ: не может.

До изучения вычислительных методов важно научиться правильно понимать саму запись системы и смысл ответа.

Ищем одну пару Одни и те же значения x и y подставляются во все уравнения.
Проверяем каждую строку Одного верного равенства недостаточно для решения системы.
