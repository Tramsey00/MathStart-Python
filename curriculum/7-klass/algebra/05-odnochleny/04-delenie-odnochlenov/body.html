Деление одночленов

Научимся делить одночлены, находить частное коэффициентов, вычитать показатели одинаковых переменных, записывать ограничения на делитель и определять, когда результат деления снова является одночленом.

Что нужно знать перед темой

Деление одночленов опирается на деление чисел и свойство степеней с одинаковыми основаниями.

  • Делить на ноль нельзя.
  • Коэффициенты делят как обычные числа.
  • При делении степеней с одинаковыми основаниями показатели вычитают.
  • Переменная без показателя имеет показатель 1.
  • Если показатели одинаковы, частное соответствующих степеней равно 1.
  • Результат нужно привести к стандартному виду.
При делении буквенных выражений всегда учитывайте область допустимых значений: весь одночлен-делитель должен быть отличен от нуля.

1. Как делить одночлены

Чтобы разделить одночлен на одночлен:

1. разделите коэффициенты;
2. разделите степени одинаковых переменных;
3. вычтите показатели степеней делителя из показателей делимого;
4. запишите результат в стандартном виде.

Коэффициенты и переменные делятся отдельно

Пример 1

18x⁷y⁵ : 3x²y³.
18 : 3 = 6.
x⁷ : x² = x⁵.
y⁵ : y³ = y².
Ответ: 6x⁵y².

4. Если показатели степеней одинаковы

При одинаковых показателях соответствующая переменная исчезает из окончательной записи, потому что её степень становится нулевой.

a⁵ : a⁵ = a5−5 = a⁰ = 1, при a ≠ 0.
Упростить: 24x⁶y³ : 8x²y³.
24 : 8 = 3.
x⁶ : x² = x⁴.
y³ : y³ = 1.
Ответ: 3x⁴.
В окончательном ответе множитель 1 не записывают: 3x⁴ · 1 = 3x⁴.

5. Ограничения на переменные

Одночлен-делитель должен быть отличен от нуля. Если делитель содержит произведение переменных, каждая из них должна быть ненулевой.
Делитель Необходимое условие Почему
5x x ≠ 0 При x = 0 делитель равен нулю
−3a²b a ≠ 0, b ≠ 0 Произведение равно нулю, если хотя бы один множитель равен нулю
7m³n⁴ m ≠ 0, n ≠ 0 Весь одночлен должен оставаться ненулевым
12 Дополнительных ограничений нет Число 12 уже не равно нулю
Упростить: 18a⁵b³ : 6a²b.
Делитель 6a²b не должен быть равен нулю:
a ≠ 0, b ≠ 0.
18a⁵b³ : 6a²b = 3a³b².
Ответ: 3a³b² при a ≠ 0 и b ≠ 0.

6. Когда частное является одночленом

В школьном определении одночлена переменные не должны находиться в знаменателе. Поэтому после вычитания показателей не должны появляться отрицательные показатели.

Частное одночленов является одночленом, если показатель каждой переменной в делимом не меньше соответствующего показателя в делителе.

Сравниваем показатели каждой переменной

Пример 4

10a²b⁵ : 5a⁴b².
Для переменной a пришлось бы вычислить 2 − 4.
В результате a оказалось бы в знаменателе.
Такое частное не является одночленом.

7. Деление на числовой одночлен

Если делитель является ненулевым числом, меняется только коэффициент. Буквенная часть сохраняется.

28x⁴y³ : 7 = 4x⁴y³.
−45a⁶b² : (−9) = 5a⁶b².
Деление на число 1 не изменяет одночлен, а деление на −1 меняет только его знак.

8. Дробный коэффициент в результате

Коэффициенты не обязаны делиться нацело. Частное всё равно может быть одночленом с дробным коэффициентом.

Пример 5

5x⁶y³ : 8x²y.
5 : 8 = 5 8 .
x⁶ : x² = x⁴.
y³ : y = y².
Ответ: 5 8 x⁴y².
Дробный коэффициент записывают перед буквенной частью так же, как целый или десятичный коэффициент.

9. Сочетание деления с умножением и степенью

Если выражение содержит степени, умножение и деление, сначала выполняют возведение в степень, затем умножение и деление слева направо.

Пример 6

Упростить: (2a²b)3 : 4a³b².
Сначала возведём одночлен в куб:
(2a²b)3 = 8a⁶b³.
Теперь разделим:
8a⁶b³ : 4a³b² = 2a³b.
Ответ: 2a³b.

Пример 7

Упростить: 18x⁵y³ · 2xy² : 6x²y.
Выполняем умножение и деление слева направо:
18x⁵y³ · 2xy² = 36x⁶y⁵.
36x⁶y⁵ : 6x²y = 6x⁴y⁴.
Ответ: 6x⁴y⁴.

10. Проверка деления умножением

Результат деления можно проверить обратным действием: частное умножают на делитель и получают делимое.

Проверить: 30a⁷b⁵ : 5a²b³ = 6a⁵b².
Умножим частное на делитель:
6a⁵b² · 5a²b³.
6 · 5 = 30.
a⁵ · a² = a⁷.
b² · b³ = b⁵.
Получили 30a⁷b⁵ — исходное делимое.
Деление выполнено верно.

11. Частые ошибки

Показатели сложены

При делении показатели вычитают, а не складывают.

Нарушен порядок вычитания

Из показателя делимого вычитают показатель делителя.

Не записаны ограничения

Переменные из делителя должны быть ненулевыми.

Полученный коэффициент обязательно считают целым

Коэффициент частного может быть дробным.

Удобная проверка: умножьте найденное частное на делитель. Если получилось исходное делимое, вычисление выполнено верно.

12. Задания для самопроверки

Для каждого примера отдельно делите коэффициенты и вычитайте показатели одинаковых переменных.

Задание 1. Разделите: 20x⁷ : 5x².

Показать решение
20 : 5 = 4.

x⁷ : x² = x⁵.

Ответ: 4x⁵, x ≠ 0.

Задание 2. Разделите: −36a⁶b⁴ : 9a²b.

Показать решение
−36 : 9 = −4.

a⁶ : a² = a⁴.

b⁴ : b = b³.

Ответ: −4a⁴b³ при a ≠ 0 и b ≠ 0.

Задание 3. Разделите: −42x⁸y⁵ : (−7x³y²).

Показать решение
−42 : (−7) = 6.

x⁸ : x³ = x⁵.

y⁵ : y² = y³.

Ответ: 6x⁵y³ при x ≠ 0 и y ≠ 0.

Задание 4. Упростите: 15a⁵b³ : 5a⁵b.

Показать решение
15 : 5 = 3.

a⁵ : a⁵ = 1.

b³ : b = b².

Ответ: 3b² при a ≠ 0 и b ≠ 0.

Задание 5. Разделите: 7x⁶y⁴ : 12x²y.

Показать решение
7 : 12 = 7 12 .

x⁶ : x² = x⁴.

y⁴ : y = y³.

Ответ: 7 12 x⁴y³ при x ≠ 0 и y ≠ 0.

Задание 6. Является ли одночленом частное 12a⁷b⁵ : 3a³b²?

Показать решение
Показатели в делимом не меньше показателей в делителе:

7 − 3 = 4;    5 − 2 = 3.

Частное равно 4a⁴b³.

Ответ: да, является.

Задание 7. Является ли одночленом частное 8a²b⁴ : 2a⁵b?

Показать решение
Для переменной a показатель в делимом меньше:

2 − 5 < 0.

Переменная a окажется в знаменателе.

Ответ: частное не является одночленом.

Задание 8. Укажите ограничения для выражения 30x⁶y³ : 5x²y.

Показать решение
Делитель 5x²y должен быть ненулевым.

Для этого x ≠ 0 и y ≠ 0.

Ответ: x ≠ 0, y ≠ 0.

Задание 9. Упростите: (3x²y)3 : 9x³y².

Показать решение
(3x²y)³ = 27x⁶y³.

27x⁶y³ : 9x³y² = 3x³y.

Ответ: 3x³y при x ≠ 0 и y ≠ 0.

Задание 10. Упростите: 12a⁴b² · 5ab³ : 10a²b.

Показать решение
Сначала умножим:

12a⁴b² · 5ab³ = 60a⁵b⁵.

Затем разделим:

60a⁵b⁵ : 10a²b = 6a³b⁴.

Ответ: 6a³b⁴ при a ≠ 0 и b ≠ 0.

Задание 11. Найдите ошибку: 24x⁸ : 6x³ = 4x²⁴.

Показать решение
При делении показатели вычитают:

x⁸ : x³ = x⁵.

Правильный ответ: 4x⁵ при x ≠ 0.

Задание 12. Проверьте умножением равенство 40a⁹b⁶ : 8a⁴b² = 5a⁵b⁴.

Показать решение
Умножим частное на делитель:

5a⁵b⁴ · 8a⁴b² = 40a⁹b⁶.

Получили делимое.

Ответ: равенство верно.

Задание 13. Упростите: (−2a³b²)2 · 9ab³ : 6a²b.

Показать решение
Возведём одночлен в квадрат:

(−2a³b²)² = 4a⁶b⁴.

Умножим:

4a⁶b⁴ · 9ab³ = 36a⁷b⁷.

Разделим:

36a⁷b⁷ : 6a²b = 6a⁵b⁶.

Ответ: 6a⁵b⁶ при a ≠ 0 и b ≠ 0.

13. Как проверить результат

Коэффициент Проверьте знак и частное числовых множителей.
Показатели Из показателя делимого вычитается показатель делителя.
Ограничения Все переменные, входящие в делитель, должны быть ненулевыми.
