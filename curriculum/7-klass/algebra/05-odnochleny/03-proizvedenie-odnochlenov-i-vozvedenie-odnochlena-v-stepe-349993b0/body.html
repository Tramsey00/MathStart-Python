Что нужно знать перед темой

При умножении и возведении одночленов в степень используются свойства умножения чисел и уже изученные свойства степеней.

  • Уметь приводить одночлен к стандартному виду.
  • Перемножать положительные и отрицательные числа.
  • Применять правило am · an = am+n.
  • Применять правило (am)n = amn.
  • Возводить произведение в степень.
  • Помнить, что переменная без показателя имеет показатель 1.
Произведение одночленов снова является одночленом. После выполнения действий результат нужно привести к стандартному виду.

1. Как умножать одночлены

Чтобы перемножить одночлены:

1. перемножьте коэффициенты;
2. перемножьте степени одинаковых переменных;
3. сложите показатели одинаковых оснований;
4. запишите результат в стандартном виде.

Числа умножаются отдельно от букв

Пример 1

5x²y · 3xy⁴.
5 · 3 = 15.
x² · x = x³.
y · y⁴ = y⁵.
Ответ: 15x³y⁵.

2. Алгоритм умножения одночленов

Четыре последовательных действия

Множители можно переставлять и объединять благодаря переместительному и сочетательному свойствам умножения.

3. Знаки при умножении одночленов

Плюс · плюс

Коэффициент результата положительный.

Минус · минус

Коэффициент результата положительный.

Плюс · минус

Коэффициент результата отрицательный.

Минус · плюс

Коэффициент результата отрицательный.

Пример 2

(−2a³b) · (−5ab²).
(−2) · (−5) = 10.
a³ · a = a⁴.
b · b² = b³.
Ответ: 10a⁴b³.

Пример 3

7x²y · (−3xy³) = −21x³y⁴.

4. Умножение трёх и более одночленов

При большем количестве множителей алгоритм не меняется: отдельно перемножают все коэффициенты и отдельно объединяют одинаковые переменные.

Упростить: 2a²b · (−3ab³) · 5a⁴.
Коэффициенты:
2 · (−3) · 5 = −30.
Степени a:
a² · a · a⁴ = a2+1+4 = a⁷.
Степени b:
b · b³ = b⁴.
Ответ: −30a⁷b⁴.

5. Возведение одночлена в натуральную степень

Чтобы возвести одночлен в натуральную степень:

1. возведите коэффициент в эту степень;
2. возведите в эту степень каждый буквенный множитель;
3. при возведении степени в степень перемножьте показатели.

Для одночлена axmyk выполняется:

(axmyk)n = anxmnykn.

Показатель относится ко всему одночлену

Пример 4

(3x²y³)2 = 3²(x²)²(y³)².
= 9x⁴y⁶.
Ответ: 9x⁴y⁶.

6. Знак степени одночлена

Если коэффициент одночлена отрицательный, знак результата зависит от чётности показателя степени.

Чётный показатель

Отрицательный коэффициент превращается в положительный.

Нечётный показатель

Отрицательный коэффициент остаётся отрицательным.

(−3a²)4 = (−3)4(a²)4 = 81a⁸.
(−3a²)3 = (−3)3(a²)3 = −27a⁶.
Скобки обязательны: показатель должен относиться и к знаку минус, и к числовому коэффициенту, и ко всей буквенной части.

7. Сочетание умножения и возведения в степень

Пример 5

Упростить: (2a²b)3 · (−3ab²).
Сначала выполним возведение в степень:
(2a²b)3 = 8a⁶b³.
Затем умножим одночлены:
8a⁶b³ · (−3ab²) = −24a⁷b⁵.
Ответ: −24a⁷b⁵.

Пример 6

Упростить: (−xy²)2 · 4x³y.
(−xy²)2 = x²y⁴.
x²y⁴ · 4x³y = 4x⁵y⁵.
Ответ: 4x⁵y⁵.

8. Представление одночлена в виде квадрата

Одночлен можно представить в виде квадрата другого одночлена, если:

  • его коэффициент является квадратом числа;
  • показатели всех переменных чётные;
  • коэффициент неотрицательный.
Представить 36a⁶b⁴ в виде квадрата одночлена.
36 = 6².
a⁶ = (a³)².
b⁴ = (b²)².
36a⁶b⁴ = (6a³b²)².
Ответ: (6a³b²)².
Одночлен −25x⁴ нельзя представить квадратом действительного одночлена, потому что квадрат не может быть отрицательным.

9. Представление одночлена в виде куба

Для представления одночлена в виде куба:

  • коэффициент должен быть кубом числа;
  • показатели всех переменных должны делиться на 3;
  • коэффициент может быть как положительным, так и отрицательным.
Представить −8x⁹y⁶ в виде куба одночлена.
−8 = (−2)³.
x⁹ = (x³)³.
y⁶ = (y²)³.
−8x⁹y⁶ = (−2x³y²)³.
Ответ: (−2x³y²)³.

10. Частые ошибки

Показатели перемножены при обычном произведении

x² · x³ = x⁵, а не x⁶.

Коэффициент не возведён в степень

(3x)² = 9x², а не 3x².

Показатели сложены в степени степени

(x⁴)³ = x¹², а не x⁷.

Потерян знак отрицательного коэффициента

(−2x)³ = −8x³.

При обычном умножении одночленов показатели одинаковых переменных складываются. При возведении одночлена в степень внутренний и внешний показатели перемножаются.

11. Задания для самопроверки

Записывайте отдельно произведение коэффициентов и действия с каждой переменной.

Задание 1. Перемножьте одночлены: 4x² · 3x⁵.

Показать решение
4 · 3 = 12.

x² · x⁵ = x⁷.

Ответ: 12x⁷.

Задание 2. Перемножьте одночлены: −5a²b · 2ab³.

Показать решение
(−5) · 2 = −10.

a² · a = a³.

b · b³ = b⁴.

Ответ: −10a³b⁴.

Задание 3. Упростите: (−3x²y) · (−4xy⁵).

Показать решение
(−3) · (−4) = 12.

x² · x = x³.

y · y⁵ = y⁶.

Ответ: 12x³y⁶.

Задание 4. Упростите: 2a³ · (−5a²b) · 3b⁴.

Показать решение
2 · (−5) · 3 = −30.

a³ · a² = a⁵.

b · b⁴ = b⁵.

Ответ: −30a⁵b⁵.

Задание 5. Возведите в квадрат одночлен 4x³y².

Показать решение
(4x³y²)² = 4²(x³)²(y²)² = 16x⁶y⁴.

Ответ: 16x⁶y⁴.

Задание 6. Возведите в куб одночлен −2a²b.

Показать решение
(−2a²b)³ = (−2)³(a²)³b³ = −8a⁶b³.

Ответ: −8a⁶b³.

Задание 7. Упростите: (−3x²y³)².

Показать решение
Показатель 2 чётный:

(−3)² = 9;    (x²)² = x⁴;    (y³)² = y⁶.

Ответ: 9x⁴y⁶.

Задание 8. Упростите: (2ab²)³ · 5a²b.

Показать решение
(2ab²)³ = 8a³b⁶.

8a³b⁶ · 5a²b = 40a⁵b⁷.

Ответ: 40a⁵b⁷.

Задание 9. Представьте 49x⁸y⁶ в виде квадрата одночлена.

Показать решение
49 = 7².

x⁸ = (x⁴)².

y⁶ = (y³)².

Ответ: (7x⁴y³)².

Задание 10. Представьте −27a¹²b³ в виде куба одночлена.

Показать решение
−27 = (−3)³.

a¹² = (a⁴)³.

b³ = b³.

Ответ: (−3a⁴b)³.

Задание 11. Можно ли представить −16x⁶ в виде квадрата действительного одночлена?

Показать решение
Квадрат действительного одночлена не может иметь отрицательный коэффициент.

Ответ: нельзя.

Задание 12. Найдите ошибку: (5x³)² = 5x⁶.

Показать решение
Коэффициент 5 также нужно возвести в квадрат:

(5x³)² = 5²(x³)² = 25x⁶.

Ошибка: коэффициент не возведён в степень.

Задание 13. Упростите: (−2x²y)³ · 3xy⁴ · (−x).

Показать решение
Сначала возведём одночлен в куб:

(−2x²y)³ = −8x⁶y³.

Перемножим коэффициенты:

(−8) · 3 · (−1) = 24.

Степени x:
x⁶ · x · x = x⁸.

Степени y:
y³ · y⁴ = y⁷.

Ответ: 24x⁸y⁷.

12. Как проверить преобразование

Коэффициенты Проверьте знак и выполненное действие с числами.
Показатели переменных При произведении складываются, при степени степени перемножаются.
Стандартный вид Каждая переменная должна встречаться в результате только один раз.
При умножении одночленов отдельно контролируйте числа и каждую переменную. При возведении в степень не забывайте возводить коэффициент и умножать показатели степеней.
