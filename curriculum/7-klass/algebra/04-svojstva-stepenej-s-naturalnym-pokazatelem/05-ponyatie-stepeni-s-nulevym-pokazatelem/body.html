Понятие степени с нулевым показателем

Разберём, почему любое ненулевое число в нулевой степени равно единице, зачем обязательно условие a ≠ 0, как применять новое определение совместно со свойствами степеней и какие записи не имеют смысла.

Что нужно знать перед темой

Нулевой показатель вводится так, чтобы уже изученные свойства степеней продолжали работать и не приводили к противоречиям.

  • Степень с натуральным показателем — произведение одинаковых множителей.
  • При делении степеней с одинаковыми основаниями показатели вычитают.
  • Любое ненулевое число, разделённое само на себя, равно 1.
  • Деление на ноль не определено.
  • Скобки показывают, какое число является основанием степени.
  • Возведение в степень выполняется раньше сложения и вычитания.
В этой теме не рассматриваются степени с отрицательными показателями. Они изучаются позднее. Сейчас добавляется только показатель 0.

1. Определение степени с нулевым показателем

Для любого числа a, не равного нулю:

a0 = 1, если a ≠ 0.

Основание может быть положительным, отрицательным, дробным или представлять собой ненулевое выражение. Результат всё равно равен 1.

Положительное основание

70 = 1.

Отрицательное основание

(−5)0 = 1.

Дробное основание

( 3 8 )0 = 1.

Буквенное основание

x0 = 1 при x ≠ 0.

Разные ненулевые основания дают один результат

2. Почему a⁰ равно 1

Рассмотрим частное двух одинаковых степеней с ненулевым основанием.

С одной стороны:
am : am = 1, потому что ненулевое число делится само на себя.
С другой стороны, по свойству деления степеней:
am : am = am−m = a0.
Следовательно:
a0 = 1 при a ≠ 0.

Два способа вычислить одно и то же частное

3. Закономерность при уменьшении показателя

Значение следующей степени с меньшим показателем получается делением предыдущего значения на основание.

34 = 81;
33 = 81 : 3 = 27;
32 = 27 : 3 = 9;
31 = 9 : 3 = 3;
30 = 3 : 3 = 1.

Показатель уменьшается на 1 — значение делится на 3

4. Почему запись 0⁰ не определена

Правило a0 = 1 действует только при a ≠ 0. Для основания 0 применить доказательство нельзя.

Чтобы получить a0, рассматривалось частное am : am.
При a = 0 получается:
0m : 0m = 0 : 0.
Деление 0 : 0 не определено.
Поэтому запись 00 в школьном курсе не имеет определённого значения.

Условие a ≠ 0 нельзя убирать

Записи 03, 08 и другие степени нуля с положительными показателями определены и равны 0. Проблема возникает только в записи 00.

5. Применение определения в вычислениях

Пример 1

120 + 52 = 1 + 25 = 26.

Пример 2

(−7)0 − 30 = 1 − 1 = 0.

Пример 3

4 · 20 + 3 = 4 · 1 + 3 = 7.

Пример 4

( −9 11 )0 = 1.

6. Нулевой показатель в свойствах степеней

После введения нулевого показателя свойства степеней можно применять и в случаях, когда разность показателей равна нулю.

Пример 5

a6 : a6 = a6−6 = a0 = 1, при a ≠ 0.

Пример 6

x3 · x0 = x3+0 = x3, при x ≠ 0.

Пример 7

(a5)0 = 1,
если a5 ≠ 0, то есть a ≠ 0.
При появлении нулевого показателя всегда проверяйте, может ли основание быть равно нулю.

7. Буквенные выражения и ограничения

В числовом примере обычно сразу видно, ненулевое ли основание. В буквенном выражении нужно записывать условие.

x⁰

Равно 1 только при x ≠ 0.

(x − 4)⁰

Равно 1 при x − 4 ≠ 0, то есть при x ≠ 4.

(2a + 6)⁰

Равно 1 при 2a + 6 ≠ 0, то есть при a ≠ −3.

(ab)⁰

Равно 1, если a ≠ 0 и b ≠ 0.

Пример 8 Упростить (x + 2)0.
Основание не должно быть равно нулю:
x + 2 ≠ 0.
x ≠ −2.
При этом условии:
(x + 2)0 = 1.

8. Скобки и порядок действий

Скобки определяют основание степени, поэтому записи могут иметь различные значения.

(−5)⁰

Основание равно −5. Значение равно 1.

−5⁰

Сначала 5⁰ = 1, затем ставится минус: результат −1.

2 + 3⁰

Сначала степень: 2 + 1 = 3.

(2 + 3)⁰

Основание равно 5, поэтому результат 1.

Возведение в степень выполняется раньше знака минус перед степенью, если минус не включён в основание скобками.

9. Что важно не перепутать

Запись Значение Причина
60 1 Основание не равно нулю
06 0 Шесть множителей, равных нулю
00 Не определено Правило a0 = 1 требует a ≠ 0
−40 −1 Минус стоит перед степенью
(−4)0 1 Основание равно −4
Нулевой показатель не означает, что результат равен нулю. Для любого ненулевого основания результат равен единице.

10. Задания для самопроверки

В каждом примере сначала определите основание и проверьте, не равно ли оно нулю.

Задание 1. Вычислите 190.

Показать решение
Основание 19 не равно нулю.

Ответ: 1.

Задание 2. Вычислите (−12)0.

Показать решение
Основание −12 не равно нулю.

Ответ: 1.

Задание 3. Вычислите ( 7 13 )0.

Показать решение
Дробь 7 13 не равна нулю.

Ответ: 1.

Задание 4. Вычислите 80 + 23.

Показать решение
80 = 1, 23 = 8.

1 + 8 = 9.

Ответ: 9.

Задание 5. Вычислите 5 · 30 − 4.

Показать решение
30 = 1.

5 · 1 − 4 = 1.

Ответ: 1.

Задание 6. Сравните 05 и 50.

Показать решение
05 = 0.

50 = 1.

Ответ: 05 < 50.

Задание 7. Вычислите (−6)0 и −60.

Показать решение
(−6)0 = 1.

−60 = −(60) = −1.

Ответ: 1 и −1.

Задание 8. Упростите x7 : x7, x ≠ 0.

Показать решение
x7 : x7 = x7−7 = x0 = 1.

Ответ: 1.

Задание 9. При каких значениях x верно (x − 5)0 = 1?

Показать решение
Основание должно быть ненулевым:

x − 5 ≠ 0.

x ≠ 5.

Ответ: при всех x, кроме x = 5.

Задание 10. При каком значении a выражение (2a + 8)0 не имеет определённого значения?

Показать решение
Основание не должно превращаться в ноль:

2a + 8 = 0.

2a = −8.

a = −4.

Ответ: при a = −4.

Задание 11. Найдите ошибку: 00 = 1, потому что любое число в нулевой степени равно единице.

Показать решение
Правило действует только для ненулевого основания.

В записи 00 основание равно нулю.

Ответ: условие a ≠ 0 не выполнено; запись 00 не определена.

Задание 12. Упростите (a3b2)0. Укажите необходимые ограничения.

Показать решение
Основание a3b2 должно быть ненулевым. Это возможно, если a ≠ 0 и b ≠ 0.

Тогда:

(a3b2)0 = 1.

Ответ: 1 при a ≠ 0 и b ≠ 0.

Задание 13. Вычислите 24 · 54 · 100.

Показать решение
100 = 1.

24 · 54 = (2 · 5)4 = 104.

104 · 1 = 10 000.

Ответ: 10 000.

11. Как рассуждать с нулевым показателем

Найдите основание Определите всё выражение, к которому относится показатель 0.
Проверьте ненулевое условие Если основание не равно нулю, значение степени равно 1.
Соблюдайте порядок действий Сначала вычислите степень, затем выполняйте остальные действия.
Нулевой показатель завершает раздел о степенях и позволяет сохранить формулу деления при равных показателях. Следующий раздел посвящён одночленам и их стандартному виду.
