Разложение на множители способом группировки

Научимся объединять члены многочлена в подходящие группы, выносить общий множитель из каждой группы и получать одинаковую скобку, которую затем можно вынести как общий множитель.

Идея способа группировки

Иногда у всего многочлена нет одного общего множителя, зато его можно разделить на несколько групп. После вынесения множителя из каждой группы должны появиться одинаковые скобки.

исходный многочлен
ax + ay + bx + by

Общего множителя у всех четырёх членов нет. Объединим первые два и последние два слагаемых.

после группировки
(a + b)(x + y)

В каждой группе появилась одинаковая скобка x + y, поэтому её удалось вынести за скобки.

Способ группировки — это разложение многочлена на множители, при котором его члены объединяют в группы, выносят общий множитель из каждой группы, а затем выносят общую скобку.

1. Три действия метода

Составить группы Объедините члены так, чтобы внутри каждой группы можно было вынести общий множитель.
Вынести множители Разложите каждую группу отдельно и внимательно сохраните знаки перед скобками.
Получить общую скобку Если скобки совпали, вынесите их как общий множитель всего выражения.
Если после первого шага одинаковые скобки не появились, попробуйте переставить члены или составить группы по-другому.

2. Подробный разбор основного примера

Разложить на множители: x² + 3x + 2x + 6.
Объединим первые два и последние два члена:
(x² + 3x) + (2x + 6).
Вынесем общий множитель из каждой группы:
x(x + 3) + 2(x + 3).
Общая скобка равна x + 3:
(x + 3)(x + 2).
Ответ: (x + 2)(x + 3).

Одинаковая скобка становится общим множителем

3. Почему скобки должны совпасть

После первого вынесения множителей выражение обычно принимает вид A·C + B·C. Здесь C — одинаковое выражение в двух слагаемых. По распределительному свойству его можно вынести за скобки.

A·C + B·C = C(A + B).
Например:
x(x + 3) + 2(x + 3) = (x + 3)(x + 2).
Если скобки получились разными, разложение ещё не завершено. Нужно проверить знаки, порядок членов и выбранную группировку.

4. Группировка с отрицательными членами

Разложить на множители: 3a² − 6ab + 2ac − 4bc.
Составим две группы:
(3a² − 6ab) + (2ac − 4bc).
Вынесем общий множитель из каждой группы:
3a(a − 2b) + 2c(a − 2b).
Общая скобка a − 2b:
Ответ: (a − 2b)(3a + 2c).
Знак минус внутри общей скобки должен быть одинаковым в обеих группах.

5. Когда приходится выносить минус

Разложить на множители: x² − 3x − 2x + 6.
Сгруппируем члены:
(x² − 3x) + (−2x + 6).
Из первой группы вынесем x, а из второй — число −2:
x(x − 3) − 2(x − 3).
Теперь скобки совпадают:
Ответ: (x − 3)(x − 2).
Иногда отрицательный множитель выносят специально, чтобы получить такую же скобку, как в другой группе.

6. Перестановка членов перед группировкой

Члены многочлена можно переставлять, потому что сложение обладает переместительным свойством. Это часто помогает увидеть подходящие пары.

Разложить на множители: 2a² + ab − 6a − 3b.
Удобно объединить первый член с третьим, а второй — с четвёртым:
(2a² − 6a) + (ab − 3b).
2a(a − 3) + b(a − 3).
Ответ: (a − 3)(2a + b).
неудобно
(2a² + ab) + (−6a − 3b)

После вынесения множителей одинаковые скобки сразу не появляются.

удобно
(2a² − 6a) + (ab − 3b)

В обеих группах получается скобка a − 3.

7. Группировка более чем четырёх членов

Группы не обязаны состоять ровно из двух членов. Главное, чтобы после вынесения множителей возник общий множитель-многочлен.

Разложить на множители: ax + ay + az + bx + by + bz.
Объединим первые три и последние три члена:
(ax + ay + az) + (bx + by + bz).
a(x + y + z) + b(x + y + z).
Ответ: (a + b)(x + y + z).

8. Проверка раскрытием скобок

После разложения перемножьте полученные множители. Если восстановился исходный многочлен, группировка выполнена верно.

Проверить: 2m² + 6m − mn − 3n = (2m − n)(m + 3).
Раскроем скобки:
(2m − n)(m + 3) = 2m² + 6m − mn − 3n.
Получили исходный многочлен.
Разложение выполнено правильно.

9. Применение в уравнениях

Решить уравнение: x² + 5x + 2x + 10 = 0.
Сгруппируем члены:
x(x + 5) + 2(x + 5) = 0.
(x + 5)(x + 2) = 0.
Произведение равно нулю, если хотя бы один множитель равен нулю:
x + 5 = 0   или   x + 2 = 0.
Ответ: −5; −2.

10. Задания для самопроверки

В решении показывайте выбранные группы, вынесенные множители и получившуюся общую скобку.

Задание 1. Разложите на множители: ax + ay + bx + by.

Показать решение
Сгруппируем:

(ax + ay) + (bx + by).

a(x + y) + b(x + y).

Ответ: (a + b)(x + y).

Задание 2. Разложите на множители: x² + 4x + 3x + 12.

Показать решение
(x² + 4x) + (3x + 12) = x(x + 4) + 3(x + 4).

Ответ: (x + 3)(x + 4).

Задание 3. Разложите на множители: 2a² + 6a + ab + 3b.

Показать решение
(2a² + 6a) + (ab + 3b) = 2a(a + 3) + b(a + 3).

Ответ: (2a + b)(a + 3).

Задание 4. Разложите на множители: 5x² − 10x + 3xy − 6y.

Показать решение
(5x² − 10x) + (3xy − 6y) = 5x(x − 2) + 3y(x − 2).

Ответ: (x − 2)(5x + 3y).

Задание 5. Разложите на множители: x² − 7x − 2x + 14.

Показать решение
(x² − 7x) + (−2x + 14) = x(x − 7) − 2(x − 7).

Ответ: (x − 7)(x − 2).

Задание 6. Разложите на множители: 6a² − 9ab + 4ac − 6bc.

Показать решение
(6a² − 9ab) + (4ac − 6bc) = 3a(2a − 3b) + 2c(2a − 3b).

Ответ: (2a − 3b)(3a + 2c).

Задание 7. Переставьте члены и разложите на множители: 3x² + 2xy − 12x − 8y.

Показать решение
Удобная группировка:

(3x² − 12x) + (2xy − 8y).

3x(x − 4) + 2y(x − 4).

Ответ: (x − 4)(3x + 2y).

Задание 8. Разложите на множители: am + an + bm + bn + cm + cn.

Показать решение
(am + an) + (bm + bn) + (cm + cn) = a(m + n) + b(m + n) + c(m + n).

Ответ: (a + b + c)(m + n).

Задание 9. Проверьте раскрытием скобок: 4x² + 12x − xy − 3y = (4x − y)(x + 3).

Показать решение
(4x − y)(x + 3) = 4x² + 12x − xy − 3y.

Получили исходный многочлен.

Равенство верно.

Задание 10. Решите уравнение: x² + 6x + 3x + 18 = 0.

Показать решение
x(x + 6) + 3(x + 6) = 0.

(x + 6)(x + 3) = 0.

Ответ: −6; −3.

Задание 11. Найдите такую группировку и разложите: 2x² + xy − 10x − 5y.

Показать решение
(2x² − 10x) + (xy − 5y) = 2x(x − 5) + y(x − 5).

Ответ: (x − 5)(2x + y).

Задание 12. Разложите на множители: 3a³ + 6a²b − 5ac − 10bc.

Показать решение
(3a³ + 6a²b) + (−5ac − 10bc).

3a²(a + 2b) − 5c(a + 2b).

Ответ: (a + 2b)(3a² − 5c).

Задание 13. Разложите на множители и решите уравнение: 2x² − 8x + 3x − 12 = 0.

Показать решение
Сгруппируем:

(2x² − 8x) + (3x − 12) = 0.

2x(x − 4) + 3(x − 4) = 0.

(x − 4)(2x + 3) = 0.

x = 4   или   x = − 3 2 .

Ответ: 4; − 3 2 .

11. Быстрая самопроверка решения

Все члены использованы Ни один член исходного многочлена не потерян и не записан дважды.
Скобки совпали После вынесения множителей внутри групп получено одно и то же выражение.
Проверка восстановила многочлен После раскрытия итоговых скобок получается исходная запись.
