Разложение на множители с помощью формул сокращённого умножения

Научимся читать знакомые формулы в обратную сторону: узнавать разность квадратов, полные квадраты и суммы или разности кубов, а затем записывать многочлен в виде произведения.

1. Формулы теперь читаем справа налево

Раньше формулы сокращённого умножения помогали раскрывать скобки. Теперь они используются в обратном направлении: по многочлену нужно узнать формулу и восстановить произведение.

Разность квадратов

a² − b² = (a − b)(a + b)

Два квадрата разделены знаком минус.

Квадрат суммы

a² + 2ab + b² = (a + b)²

Средний член равен удвоенному произведению оснований квадратов.

Квадрат разности

a² − 2ab + b² = (a − b)²

Крайние члены положительные, а средний — отрицательный.

Кубы

a³ ± b³ = (a ± b)(a² ∓ ab + b²)

Вторая скобка всегда содержит положительный последний член b².

Перед применением формулы каждый член должен быть записан в стандартном виде.

2. Разность квадратов

Чтобы применить формулу a² − b² = (a − b)(a + b), проверьте два условия: оба члена являются квадратами и между ними стоит знак минус.
Пример 1. Разложить на множители: x² − 49.
49 = 7², поэтому x² − 49 = x² − 7².
x² − 7² = (x − 7)(x + 7).
Ответ: (x − 7)(x + 7).
Пример 2. Разложить на множители: 25a² − 4b².
25a² = (5a)², а 4b² = (2b)².
25a² − 4b² = (5a − 2b)(5a + 2b).
Ответ: (5a − 2b)(5a + 2b).

3. Полный квадрат суммы

Трёхчлен является квадратом суммы, если его крайние члены — квадраты, а средний член равен удвоенному произведению их оснований.

Пример 3. Разложить на множители: x² + 10x + 25.
x² = x², 25 = 5².
Проверим средний член: 2 · x · 5 = 10x.
Все части формулы совпали.
Ответ: (x + 5)².
Пример 4. Разложить на множители: 9m² + 24mn + 16n².
9m² = (3m)², 16n² = (4n)².
2 · 3m · 4n = 24mn.
Ответ: (3m + 4n)².

4. Полный квадрат разности

Для квадрата разности проверка почти такая же, но средний член должен быть отрицательным.

Пример 5. Разложить на множители: y² − 12y + 36.
36 = 6².
−2 · y · 6 = −12y.
Ответ: (y − 6)².
Пример 6. Разложить на множители: 4a² − 20ab + 25b².
4a² = (2a)², 25b² = (5b)².
−2 · 2a · 5b = −20ab.
Ответ: (2a − 5b)².

5. Сумма и разность кубов

a³ + b³ = (a + b)(a² − ab + b²),

a³ − b³ = (a − b)(a² + ab + b²).
Пример 7. Разложить на множители: x³ − 27.
27 = 3³.
x³ − 3³ = (x − 3)(x² + 3x + 9).
Ответ: (x − 3)(x² + 3x + 9).
Пример 8. Разложить на множители: 8a³ + b³.
8a³ = (2a)³.
(2a)³ + b³ = (2a + b)(4a² − 2ab + b²).
Ответ: (2a + b)(4a² − 2ab + b²).

6. Как выбрать формулу

1
Посчитайте количество членов Два члена часто указывают на разность квадратов или сумму/разность кубов; три — на полный квадрат.
2
Представьте крайние члены как степени Найдите основания квадратов или кубов: 16x² = (4x)², 27y³ = (3y)³.
3
Проверьте знак и средний член Для полного квадрата средний член обязан точно равняться ±2ab.
4
Запишите произведение и проверьте Раскройте полученные скобки мысленно или письменно — должен восстановиться исходный многочлен.

7. Формула может быть спрятана в одночленах

Роль a и b в формулах могут выполнять не только отдельные буквы, но и числа, одночлены или более сложные выражения.

Пример 9. Разложить на множители: 36x⁴ − 81y⁶.
36x⁴ = (6x²)², 81y⁶ = (9y³)².
36x⁴ − 81y⁶ = (6x² − 9y³)(6x² + 9y³).
Ответ: (6x² − 9y³)(6x² + 9y³).
Пример 10. Разложить на множители: a⁴ + 6a²b + 9b².
a⁴ = (a²)², 9b² = (3b)².
2 · a² · 3b = 6a²b.
Ответ: (a² + 3b)².

8. Применение в уравнениях

Пример 11. Решить уравнение: x² − 64 = 0.
x² − 64 = (x − 8)(x + 8).
Произведение равно нулю, если один из множителей равен нулю.
x − 8 = 0 или x + 8 = 0.
Ответ: x = 8 или x = −8.
В этой теме формула применяется непосредственно. В следующей записи разберём ситуации, где перед формулой или после неё требуется дополнительный приём.

9. Задания для самопроверки

Задание 1. Разложите на множители: x² − 81.

Показать решение
x² − 81 = x² − 9² = (x − 9)(x + 9).

Ответ: (x − 9)(x + 9).

Задание 2. Разложите на множители: 16a² − 25b².

Показать решение
16a² = (4a)², 25b² = (5b)².

Ответ: (4a − 5b)(4a + 5b).

Задание 3. Разложите на множители: x² + 14x + 49.

Показать решение
49 = 7², а 2 · x · 7 = 14x.

Ответ: (x + 7)².

Задание 4. Разложите на множители: 9m² − 30mn + 25n².

Показать решение
9m² = (3m)², 25n² = (5n)², −2 · 3m · 5n = −30mn.

Ответ: (3m − 5n)².

Задание 5. Разложите на множители: y³ + 8.

Показать решение
8 = 2³.

y³ + 2³ = (y + 2)(y² − 2y + 4).

Ответ: (y + 2)(y² − 2y + 4).

Задание 6. Разложите на множители: 27a³ − b³.

Показать решение
27a³ = (3a)³.

Ответ: (3a − b)(9a² + 3ab + b²).

Задание 7. Является ли трёхчлен x² + 8x + 25 полным квадратом?

Показать решение
Крайние члены имеют основания x и 5, поэтому средний член должен быть 2 · x · 5 = 10x, а не 8x.

Ответ: нет.

Задание 8. Разложите на множители: 4x⁴ + 12x²y + 9y².

Показать решение
4x⁴ = (2x²)², 9y² = (3y)², 2 · 2x² · 3y = 12x²y.

Ответ: (2x² + 3y)².

Задание 9. Решите уравнение: 25x² − 4 = 0.

Показать решение
(5x − 2)(5x + 2) = 0.

5x − 2 = 0 или 5x + 2 = 0.

Ответ: x = 2/5 или x = −2/5.
