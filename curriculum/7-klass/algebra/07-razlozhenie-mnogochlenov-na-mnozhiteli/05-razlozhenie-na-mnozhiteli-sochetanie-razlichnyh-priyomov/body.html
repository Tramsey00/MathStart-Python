Разложение на множители: сочетание различных приёмов

Научимся последовательно применять несколько способов разложения: выносить общий множитель, использовать группировку и формулы сокращённого умножения, а затем проверять, можно ли продолжить преобразование.

1. Почему одного способа бывает недостаточно

После первого преобразования выражение может оказаться разложенным не полностью. Внутри полученных скобок иногда остаётся общий множитель, разность квадратов, полный квадрат или выражение, которое удобно сгруппировать.

Полное разложение часто выполняется в несколько этапов:

первый приём открывает возможность применить следующий.
найти общий множитель проверить формулы попробовать группировку проверить каждый множитель ещё раз

2. С чего начинать разложение

Общий множитель есть во всех членах Сначала вынесите его за скобки. Это обычно самый короткий и надёжный первый шаг.
Видна знакомая формула Проверьте разность квадратов, полный квадрат, сумму или разность кубов.
Члены удобно объединяются Попробуйте переставить их и применить способ группировки.
Практический порядок В большинстве примеров сначала проверяют общий множитель, затем формулы сокращённого умножения, после этого — возможность группировки и повторного разложения полученных множителей.

3. Общий множитель и разность квадратов

Пример 1. Разложить на множители: 3x³ − 12x.
Первый приём
3x³ − 12x = 3x(x² − 4).
Второй приём
x² − 4 = x² − 2² = (x − 2)(x + 2).
Полный ответ
3x(x − 2)(x + 2).
Если остановиться на записи 3x(x² − 4), разложение будет правильным, но не полным: скобка x² − 4 раскладывается дальше.

4. Группировка, затем формула

Пример 2. Разложить на множители: a³ + a² − 4a − 4.
Объединим члены по парам:
(a³ + a²) − (4a + 4).
Вынесем множители из групп:
a²(a + 1) − 4(a + 1).
Вынесем общую скобку:
(a + 1)(a² − 4).
Разложим разность квадратов:
Ответ: (a + 1)(a − 2)(a + 2).

5. Повторное применение одной формулы

Пример 3. Разложить на множители: x⁴ − 16.

Разность квадратов применяется дважды

После каждого шага рассматривайте все полученные множители отдельно.

6. Общий множитель, группировка и разность квадратов

Пример 4. Разложить на множители: 2x³ + 4x² − 18x − 36.
Сначала вынесем общий числовой множитель 2:
2(x³ + 2x² − 9x − 18).
Сгруппируем члены внутри скобок:
2[x²(x + 2) − 9(x + 2)].
Вынесем общую скобку:
2(x + 2)(x² − 9).
Используем разность квадратов:
Ответ: 2(x + 2)(x − 3)(x + 3).

7. Скрытая разность квадратов

Пример 5. Разложить на множители: 9a² − 6ab + b² − 25.
Первые три члена образуют полный квадрат:
9a² − 6ab + b² = (3a − b)².
Получаем:
(3a − b)² − 5².
Применим разность квадратов:
Ответ: (3a − b − 5)(3a − b + 5).
В роли выражений A и B в формуле A² − B² могут выступать не только одночлены, но и целые скобки.

8. Когда разложение можно считать законченным

Нужно продолжать В множителе остался общий множитель, разность квадратов, полный квадрат, сумма или разность кубов либо удобная группировка.
Можно остановиться Каждый множитель уже имеет простой вид и изученными способами дальше не раскладывается.
Проверка полноты Просмотрите каждый множитель отдельно. Полное разложение — это не просто произведение, а произведение, которое уже нельзя дополнительно упростить изученными приёмами.

9. Применение в уравнениях

Решить уравнение: x⁵ − x = 0.
Вынесем общий множитель x:
x(x⁴ − 1) = 0.
Применим разность квадратов:
x(x² − 1)(x² + 1) = 0.
Ещё раз разложим разность квадратов:
x(x − 1)(x + 1)(x² + 1) = 0.
При действительных x множитель x² + 1 не равен нулю.
Ответ: −1; 0; 1.

10. Задания для самопроверки

Задание 1. Разложите на множители: 5x³ − 20x.

Показать решение
Вынесем общий множитель:

5x³ − 20x = 5x(x² − 4).

Применим разность квадратов:

Ответ: 5x(x − 2)(x + 2).

Задание 2. Разложите на множители: a³ − a² − 9a + 9.

Показать решение
Сгруппируем:

a²(a − 1) − 9(a − 1).

= (a − 1)(a² − 9).

Ответ: (a − 1)(a − 3)(a + 3).

Задание 3. Разложите на множители: y⁴ − 81.

Показать решение
y⁴ − 81 = (y² − 9)(y² + 9).

y² − 9 = (y − 3)(y + 3).

Ответ: (y − 3)(y + 3)(y² + 9).

Задание 4. Разложите на множители: 3m³ + 6m² − 12m − 24.

Показать решение
Вынесем 3:

3(m³ + 2m² − 4m − 8).

Сгруппируем:

3[m²(m + 2) − 4(m + 2)].

Ответ: 3(m + 2)(m − 2)(m + 2) = 3(m + 2)²(m − 2).

Задание 5. Разложите на множители: 4x² + 12xy + 9y² − 16.

Показать решение
Первые три члена:

4x² + 12xy + 9y² = (2x + 3y)².

Получаем разность квадратов:

Ответ: (2x + 3y − 4)(2x + 3y + 4).

Задание 6. Разложите на множители: 2a⁵ − 2a.

Показать решение
2a⁵ − 2a = 2a(a⁴ − 1).

= 2a(a² − 1)(a² + 1).

Ответ: 2a(a − 1)(a + 1)(a² + 1).

Задание 7. Разложите на множители: x³ + 3x² − 4x − 12.

Показать решение
Сгруппируем:

x²(x + 3) − 4(x + 3).

= (x + 3)(x² − 4).

Ответ: (x + 3)(x − 2)(x + 2).

Задание 8. Решите уравнение: 2x³ − 18x = 0.

Показать решение
2x(x² − 9) = 0.

2x(x − 3)(x + 3) = 0.

Ответ: −3; 0; 3.

Задание 9. Проверьте, полностью ли разложено выражение: 4x(x² − 25).

Показать решение
Скобка x² − 25 является разностью квадратов.

Полное разложение:

4x(x − 5)(x + 5).

11. Итоговый маршрут решения

общий множитель проверен формулы просмотрены группировка рассмотрена каждый множитель проверен повторно ответ восстановлен раскрытием скобок
Главная привычка Не останавливайтесь сразу после появления первых скобок. Полное разложение требует повторно проверить каждый полученный множитель и только после этого записать окончательный ответ.
