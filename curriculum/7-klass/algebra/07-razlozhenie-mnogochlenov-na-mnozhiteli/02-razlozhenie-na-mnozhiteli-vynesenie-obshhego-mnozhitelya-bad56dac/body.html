Вынесение общего множителя за скобки

Научимся находить общий числовой и буквенный множитель всех членов многочлена, правильно записывать выражение в скобках и проверять полученное разложение обратным умножением.

Идея приёма

Если каждый член многочлена содержит один и тот же множитель, этот множитель можно вынести за скобки.

ab + ac = a(b + c).

Слева общий множитель a повторяется в каждом слагаемом. Справа он записан один раз перед скобками.
То, что остаётся внутри скобок, можно найти делением: каждый член исходного многочлена делится на вынесенный множитель.

1. Как выполнить вынесение общего множителя

Найдите наибольший общий делитель коэффициентов всех членов.
Определите переменные, которые входят в каждый член многочлена.
Для каждой общей переменной выберите наименьший показатель степени.
Запишите найденный общий одночлен перед скобками.
Разделите каждый член многочлена на общий множитель и запишите результаты в скобках.
Чтобы разложение было полным, обычно выносят наибольший общий множитель, а не только любую общую часть.

2. Как найти числовую часть общего множителя

Нужно найти наибольший общий делитель всех коэффициентов.

12x + 18

НОД чисел 12 и 18 равен 6. Поэтому числовая часть общего множителя — 6.

20a² − 30ab + 50a

НОД чисел 20, 30 и 50 равен 10. Значит, из всех членов можно вынести 10.

Пример 1 Разложить на множители: 18x + 24y.
НОД(18; 24) = 6.
18x : 6 = 3x,    24y : 6 = 4y.
Ответ: 6(3x + 4y).

3. Как найти буквенную часть

В общий множитель входят только те переменные, которые присутствуют во всех членах. Их показатели выбираются по наименьшей степени.

Переменная x В x⁵, x³ и x² наименьший показатель равен 2, поэтому выносим x².
Переменная y В y⁴, y² и y³ наименьший показатель равен 2, поэтому выносим y².
Переменная z Если хотя бы в одном члене z отсутствует, выносить z за скобки нельзя.
Пример 2 Разложить на множители: x⁵y⁴ + x³y² − x²y³.
Общая степень x: x².
Общая степень y: y².
Общий множитель: x²y².
x⁵y⁴ : x²y² = x³y²;
x³y² : x²y² = x;
−x²y³ : x²y² = −y.
Ответ: x²y²(x³y² + x − y).

4. Собираем общий одночлен полностью

Пример: 18x⁴y³ − 12x³y⁵ + 6x²y²

5. Почему в скобках иногда появляется 1

Если один из членов многочлена полностью совпадает с вынесенным множителем, после деления остаётся число 1.

Пример 3 Разложить на множители: 8a³ − 12a² + 4a.
Общий множитель равен 4a.
8a³ : 4a = 2a²;
−12a² : 4a = −3a;
4a : 4a = 1.
Ответ: 4a(2a² − 3a + 1).
Единицу нельзя пропускать: без неё после раскрытия скобок исчезнет последний член исходного многочлена.

6. Когда удобно вынести отрицательный множитель

Если первый член многочлена отрицательный, иногда удобно вынести отрицательный общий множитель. Тогда первый член в скобках станет положительным.

Можно вынести 4x

−8x³ + 12x² − 4x = 4x(−2x² + 3x − 1).

Часто удобнее вынести −4x

−8x³ + 12x² − 4x = −4x(2x² − 3x + 1).

При вынесении отрицательного множителя знак каждого члена внутри скобок меняется.

7. Вынесение многочлена как общего множителя

Общим множителем может быть не только одночлен, но и целое выражение, которое повторяется в каждом слагаемом.

Пример 4 Разложить на множители: 5x(x − 2) + 3(x − 2).
В обоих слагаемых повторяется множитель (x − 2).
5x(x − 2) + 3(x − 2) = (x − 2)(5x + 3).
Ответ: (x − 2)(5x + 3).

8. Проверка раскрытием скобок

Проверить разложение:

15x³ − 25x² + 10x = 5x(3x² − 5x + 2).
5x · 3x² = 15x³.
5x · (−5x) = −25x².
5x · 2 = 10x.
Получили исходный многочлен.
Разложение выполнено верно.

9. Применение при решении уравнений

Решить уравнение: 6x² − 18x = 0.
Вынесем общий множитель 6x:
6x(x − 3) = 0.
Произведение равно нулю, если хотя бы один множитель равен нулю:
6x = 0   или   x − 3 = 0.
Ответ: x = 0 или x = 3.

10. Задания для самопроверки

В решении указывайте общий множитель и показывайте деление каждого члена многочлена на него.

Задание 1. Разложите на множители: 12x + 18.

Показать решение
НОД(12; 18) = 6.

12x : 6 = 2x,    18 : 6 = 3.

Ответ: 6(2x + 3).

Задание 2. Разложите на множители: 14a² − 21a.

Показать решение
Общий множитель равен 7a.

14a² : 7a = 2a,    −21a : 7a = −3.

Ответ: 7a(2a − 3).

Задание 3. Разложите на множители: 20x³ + 15x² − 5x.

Показать решение
Общий множитель равен 5x.

Ответ: 5x(4x² + 3x − 1).

Задание 4. Разложите на множители: 18a⁴b³ − 12a³b².

Показать решение
НОД коэффициентов равен 6.

Наименьшие показатели общих переменных: a³ и b².

Общий множитель: 6a³b².

Ответ: 6a³b²(3ab − 2).

Задание 5. Разложите на множители: 8x⁵y² + 12x³y⁴ − 4x²y².

Показать решение
Общий множитель равен 4x²y².

Ответ: 4x²y²(2x³ + 3xy² − 1).

Задание 6. Разложите на множители, вынеся отрицательный множитель: −15x³ + 10x² − 5x.

Показать решение
Удобно вынести −5x.

Ответ: −5x(3x² − 2x + 1).

Задание 7. Найдите наибольший общий множитель членов многочлена 24a⁶b⁴ − 36a⁴b⁵ + 12a³b².

Показать решение
НОД(24; 36; 12) = 12.

Наименьшая степень a равна 3, наименьшая степень b равна 2.

Ответ: 12a³b².

Задание 8. Разложите на множители: 7m(m + 2) − 3(m + 2).

Показать решение
Общий множитель — скобка (m + 2).

Ответ: (m + 2)(7m − 3).

Задание 9. Проверьте раскрытием скобок: 9x²y − 6xy² = 3xy(3x − 2y).

Показать решение
3xy · 3x = 9x²y.

3xy · (−2y) = −6xy².

Получили исходный многочлен.

Разложение верное.

Задание 10. Решите уравнение: 5x² + 20x = 0.

Показать решение
5x(x + 4) = 0.

5x = 0 или x + 4 = 0.

Ответ: x = 0 или x = −4.

Задание 11. Найдите пропущенное выражение: 6x²( ? ) = 18x⁵ − 12x³ + 6x².

Показать решение
Делим каждый член на 6x²:

18x⁵ : 6x² = 3x³;
−12x³ : 6x² = −2x;
6x² : 6x² = 1.

Ответ: 3x³ − 2x + 1.

Задание 12. Исправьте неполное разложение: 18x³ − 12x² = 3x²(6x − 4).

Показать решение
Равенство верно, но общий множитель выбран не наибольший.

Из обоих членов можно вынести 6x².

Полное разложение: 6x²(3x − 2).

Задание 13. Разложите на множители: 30a⁵b³ − 45a³b⁴ + 15a²b².

Показать решение
НОД коэффициентов равен 15.

Наименьшие показатели: a² и b².

Общий множитель равен 15a²b².

После деления членов получаем: 2a³b, −3ab² и 1.

Ответ: 15a²b²(2a³b − 3ab² + 1).

11. Быстрая проверка перед ответом

Коэффициент Вынесен ли наибольший общий делитель всех числовых коэффициентов?
Переменные Взяты ли только общие переменные и их наименьшие показатели?
Скобки Каждый ли член внутри скобок получен делением на общий множитель?
Раскройте скобки: результат должен полностью совпасть с исходным многочленом.
