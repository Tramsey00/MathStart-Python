1. Что именно сокращается в дроби

Сокращаются множители Числитель и знаменатель нужно представить в виде произведений. После этого одинаковый ненулевой множитель можно сократить.
Слагаемые не сокращаются Нельзя вычёркивать отдельные части суммы или разности. Сначала из выражения необходимо получить произведение.
Если A, B и C — выражения, причём B ≠ 0 и C ≠ 0, то:

A · C B · C = A B .

2. Наглядный пример сокращения

Одинаковый множитель находится и в числителе, и в знаменателе

3. Полный алгоритм

Шаг 1. Найдите значения, при которых исходный знаменатель равен нулю.

Шаг 2. Разложите числитель и знаменатель на множители.

Шаг 3. Выделите одинаковые множители.

Шаг 4. Сократите только общий ненулевой множитель.

Шаг 5. Запишите упрощённую дробь и исходные ограничения.
Ограничения определяют до сокращения, потому что исходная дробь не существует при нулевом знаменателе.

4. Вынесение общего множителя

Пример 1. Сократить дробь: 6x² + 12x 6x .
Ограничение: 6x ≠ 0, поэтому x ≠ 0.
Разложим числитель:
6x² + 12x = 6x(x + 2).
Тогда:
6x(x + 2) 6x = x + 2.
Ответ: x + 2, где x ≠ 0.

5. Разность квадратов

Пример 2. Сократить дробь: x² − 25 x − 5 .
Ограничение: x − 5 ≠ 0, значит x ≠ 5.
x² − 25 = (x − 5)(x + 5).
(x − 5)(x + 5) x − 5 = x + 5.
Ответ: x + 5, где x ≠ 5.
Хотя выражение x + 5 определено при x = 5, оно заменяет исходную дробь только при x ≠ 5.

6. Полный квадрат в знаменателе

Пример 3. Сократить дробь: 2x² − 8 x² + 4x + 4 .
Знаменатель: x² + 4x + 4 = (x + 2)².
Поэтому x ≠ −2.
Числитель:
2x² − 8 = 2(x² − 4) = 2(x − 2)(x + 2).
Сократим один множитель x + 2:
2(x − 2)(x + 2) (x + 2)² = 2(x − 2) x + 2 .
Ответ: 2(x − 2) x + 2 , где x ≠ −2.

7. Противоположные множители

Первый множитель
a − b
Обычная разность двух выражений.
Противоположный множитель
b − a = −(a − b)
При перестановке членов разности появляется множитель −1.
a − b b − a = a − b −(a − b) = −1.
Ответ: −1, где a ≠ b.

8. Граница сокращения

Нельзя сокращать части суммы В дроби x + 3 x буква x не является множителем всего числителя. Поэтому сократить x в этой записи нельзя.
Неверно: x + 3 x = 1 + 3.
Верная запись:
x + 3 x = 1 + 3 x , где x ≠ 0.

9. Задания для самопроверки

Задание 1. Сократите: 12x² 4x .

Показать решение
Ограничение: x ≠ 0.

12x² : 4x = 3x.

Ответ: 3x, где x ≠ 0.

Задание 2. Сократите: x² − 16 x − 4 .

Показать решение
x ≠ 4.

x² − 16 = (x − 4)(x + 4).

Ответ: x + 4, где x ≠ 4.

Задание 3. Сократите: a² + 6a + 9 a + 3 .

Показать решение
a ≠ −3.

a² + 6a + 9 = (a + 3)².

Ответ: a + 3, где a ≠ −3.

Задание 4. Сократите: m² − 9 m² + 6m + 9 .

Показать решение
m² + 6m + 9 = (m + 3)², поэтому m ≠ −3.

m² − 9 = (m − 3)(m + 3).

Ответ: m − 3 m + 3 , где m ≠ −3.

Задание 5. Сократите: 3x² − 12 x² + 4x + 4 .

Показать решение
x ≠ −2.

3x² − 12 = 3(x − 2)(x + 2).

x² + 4x + 4 = (x + 2)².

Ответ: 3(x − 2) x + 2 , где x ≠ −2.

Задание 6. Сократите: a − b b − a .

Показать решение
b − a = −(a − b).

Ответ: −1, где a ≠ b.

Задание 7. Можно ли сократить x в дроби x + 5 x ?

Показать решение
Нет. Числитель x + 5 является суммой, а x не является множителем всего числителя.

Ответ: сократить нельзя.

Задание 8. Сократите: y² − 25 y² − 10y + 25 .

Показать решение
y² − 10y + 25 = (y − 5)², поэтому y ≠ 5.

y² − 25 = (y − 5)(y + 5).

Ответ: y + 5 y − 5 , где y ≠ 5.

Задание 9. Сократите: x³ − 4x x² + 4x + 4 .

Показать решение
x ≠ −2.

x³ − 4x = x(x² − 4) = x(x − 2)(x + 2).

x² + 4x + 4 = (x + 2)².

Ответ: x(x − 2) x + 2 , где x ≠ −2.

10. Короткая проверка перед ответом

  • Исходный знаменатель не равен нулю.
  • Числитель и знаменатель разложены полностью.
  • Сокращены одинаковые множители, а не слагаемые.
  • В ответе сохранены все исходные ограничения.
После сокращения дробь становится проще, но запрещённые значения переменной из исходного знаменателя по-прежнему не входят в область допустимых значений.
