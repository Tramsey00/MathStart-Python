Понятие тождества

1. Что называют тождеством

Тождество — это равенство, верное при всех допустимых значениях входящих в него переменных.
Тождественно равные выражения Два выражения называют тождественно равными, если при всех допустимых значениях переменных они принимают одинаковые значения.
Тождественное преобразование Это замена выражения другим выражением, тождественно равным исходному. Значение выражения при этом не меняется.
3(a + 2) = 3a + 6.
Равенство верно при любом значении a, поэтому это тождество.

3. Допустимые значения переменных

При проверке тождества учитывают только те значения, при которых обе части равенства имеют смысл. Такие значения называют допустимыми.

Рассмотрим равенство: x² − 9x − 3 = x + 3.
Исходный знаменатель не должен обращаться в нуль:
x − 3 ≠ 0, поэтому x ≠ 3.
Разложим числитель:
x² − 9 = (x − 3)(x + 3).
При x ≠ 3 общий множитель сокращается, и получается x + 3.
Равенство является тождеством при x ≠ 3.
Значение x = 3 нельзя добавлять после сокращения: исходная дробь при нём не существует.

4. Как доказать тождество

1
Преобразовать левую часть в правую Раскрыть скобки, привести подобные или разложить выражение на множители.
2
Преобразовать обе части к одному выражению Этот способ удобен, когда ни одна сторона сразу не похожа на другую.
3
Показать, что разность частей равна нулю Если левая часть минус правая тождественно равна нулю, равенство доказано.

5. Преобразование одной части

Пример 1. Доказать тождество: 3(a + 2) − 2a = a + 6.
Преобразуем левую часть:
3(a + 2) − 2a = 3a + 6 − 2a.
= a + 6.
Получили правую часть.
Тождество доказано.

6. Преобразование обеих частей

Пример 2. Доказать тождество: (x + 4)² − (x − 4)² = 16x.
Раскроем квадраты в левой части:
x² + 8x + 16 − (x² − 8x + 16).
= x² + 8x + 16 − x² + 8x − 16.
= 16x.
Получили правую часть.
Тождество доказано.

7. Доказательство через разность частей

Пример 3. Доказать тождество: (a − b)² + 4ab = (a + b)².
Вычтем правую часть из левой:
(a − b)² + 4ab − (a + b)².
= a² − 2ab + b² + 4ab − a² − 2ab − b².
= 0.
Разность частей равна нулю, тождество доказано.

8. Как опровергнуть неверное равенство

тождество
(a + b)² = a² + 2ab + b²
Верно при всех значениях a и b.
не тождество
x² = x
Верно только при x = 0 и x = 1.
Чтобы доказать, что равенство не является тождеством, достаточно найти хотя бы одно допустимое значение, при котором части не равны. Например, при x = 2 получаем 2² = 4, но 4 ≠ 2.

9. Подстановка: проверка или доказательство?

Подстановка нескольких чисел помогает обнаружить ошибку, но не доказывает тождество. Переменная может принимать бесконечно много значений, а проверить их все подстановкой невозможно.

Для доказательства используют тождественные преобразования.

Для опровержения достаточно одного контрпримера.

10. Задания для самопроверки

Задание 1. Является ли равенство 5(x + 2) = 5x + 10 тождеством?

Показать решение
Да. После раскрытия скобок левая часть превращается в 5x + 10 при любом x.

Ответ: является.

Задание 2. Является ли равенство x + 4 = 10 тождеством?

Показать решение
Нет. Оно верно только при x = 6, поэтому это уравнение.

Ответ: не является.

Задание 3. Докажите тождество: 2(3a − 1) + a = 7a − 2.

Показать решение
2(3a − 1) + a = 6a − 2 + a = 7a − 2.

Тождество доказано.

Задание 4. Докажите тождество: (x + 2)² − 4x = x² + 4.

Показать решение
(x + 2)² − 4x = x² + 4x + 4 − 4x = x² + 4.

Тождество доказано.

Задание 5. Докажите тождество: (a + b)² − (a − b)² = 4ab.

Показать решение
a² + 2ab + b² − (a² − 2ab + b²) = 4ab.

Тождество доказано.

Задание 6. Опровергните равенство x² + 1 = 2x.

Показать решение
Возьмём x = 0. Левая часть равна 1, правая — 0.

Ответ: равенство не является тождеством.

Задание 7. При каких допустимых значениях верно тождество x² − 4x − 2 = x + 2?

Показать решение
Исходный знаменатель не равен нулю, поэтому x ≠ 2. При этих значениях x² − 4 = (x − 2)(x + 2), и общий множитель сокращается.

Ответ: при x ≠ 2.

Задание 8. Докажите тождество: 3x(x − 2) − x(3x − 7) = x.

Показать решение
3x² − 6x − 3x² + 7x = x.

Тождество доказано.

Задание 9. Является ли проверка при x = 1 и x = 2 достаточным доказательством тождества?

Показать решение
Нет. Совпадение при нескольких значениях не гарантирует равенство при всех допустимых значениях. Нужно выполнить тождественное преобразование.

Ответ: нет.

11. Короткая проверка доказательства

учтены допустимые значения преобразована только одна часть или обе части отдельно каждый переход равносилен предыдущему получены одинаковые выражения
Тождество не подтверждают несколькими удачными подстановками — его доказывают преобразованиями. А чтобы показать, что равенство не является тождеством, достаточно одного подходящего контрпримера.
