Как складывать и вычитать многочлены

Научимся находить сумму и разность многочленов, правильно раскрывать скобки, учитывать знаки каждого члена, объединять подобные слагаемые и проверять результат подстановкой числовых значений.

Что нужно знать перед темой

При сложении и вычитании многочленов основная работа выполняется со знаками и подобными членами.

  • Каждый член многочлена читается вместе со своим знаком.
  • Подобные члены имеют одинаковую буквенную часть.
  • При сложении подобных членов изменяются только коэффициенты.
  • Плюс перед скобками не изменяет знаки внутри.
  • Минус перед скобками меняет знак каждого члена.
  • После раскрытия скобок результат приводят к стандартному виду.
В окончательном ответе не должны оставаться скобки и подобные члены, которые ещё можно объединить.

1. Сумма многочленов

Чтобы сложить многочлены:

1. запишите их сумму;
2. раскройте скобки, не меняя знаков;
3. найдите подобные члены;
4. приведите подобные слагаемые.

Если перед скобками стоит знак «+», скобки можно убрать, сохранив все знаки внутри.

При сложении знаки внутри скобок сохраняются

Пример 1

(5x² − 3x + 4) + (2x² + 6x − 9).
= 5x² − 3x + 4 + 2x² + 6x − 9.
= (5 + 2)x² + (−3 + 6)x + (4 − 9).
Ответ: 7x² + 3x − 5.

2. Разность многочленов

Чтобы вычесть один многочлен из другого:

1. запишите разность в скобках;
2. измените знак каждого члена вычитаемого;
3. уберите скобки;
4. приведите подобные слагаемые.

Минус перед скобками означает умножение каждого члена внутри на число −1.

При вычитании знаки второго многочлена меняются

Пример 2

(8a² − 3a + 1) − (5a² + 2a − 6).
= 8a² − 3a + 1 − 5a² − 2a + 6.
= 3a² − 5a + 7.
Ответ: 3a² − 5a + 7.

3. Зачем нужны скобки

Скобки показывают, какой многочлен вычитается целиком. Без них легко изменить знак только первого члена и получить неверный ответ.

Правильно

A − (b − c + d) = A − b + c − d.

Неправильно

A − (b − c + d) не равно A − b − c + d.

Раскрыть скобки: 7x − (3x² − 4x − 5).
Знаки внутри скобок: +3x², −4x, −5.
После вычитания они становятся: −3x², +4x, +5.
7x − 3x² + 4x + 5.
Ответ: −3x² + 11x + 5.

4. Горизонтальный способ

При горизонтальной записи многочлены последовательно раскрывают, а затем объединяют подобные члены.

Удобный порядок:

1. раскрыть все скобки;
2. переставить подобные члены рядом;
3. выполнить действия с коэффициентами;
4. записать стандартный вид.

Пример 3

(4x³ − 2x + 6) + (x² + 5x − 1) − (3x³ − 2x² + 4).
= 4x³ − 2x + 6 + x² + 5x − 1 − 3x³ + 2x² − 4.
= (4x³ − 3x³) + (x² + 2x²) + (−2x + 5x) + (6 − 1 − 4).
Ответ: x³ + 3x² + 3x + 1.

5. Запись по степеням

Чтобы не пропустить подобные члены, полезно располагать многочлены по убыванию степеней и мысленно сопоставлять одинаковые степени.

Степень Первый многочлен Второй многочлен Сумма коэффициентов
x³ 2x³ −x³ x³
x² Нет члена 4x² 4x²
x −5x 3x −2x
Число 7 −2 5
Отсутствующий член можно мысленно считать членом с коэффициентом 0: например, 2x³ − 5x + 7 содержит 0x².

6. Сложение и вычитание нескольких многочленов

Если выражение содержит несколько скобок, знак перед каждой скобкой применяется только к содержимому этой скобки.

Упростить: (2x² − 3x + 4) − (x² + 5x − 2) + (4x² − x + 1).
Раскроем скобки:
2x² − 3x + 4 − x² − 5x + 2 + 4x² − x + 1.
Члены с x²: 2 − 1 + 4 = 5.
Члены с x: −3 − 5 − 1 = −9.
Свободные члены: 4 + 2 + 1 = 7.
Ответ: 5x² − 9x + 7.

7. Многочлены с несколькими переменными

Правило не меняется: объединяются только члены с полностью совпадающей буквенной частью.

Пример 4

(3a²b − 5ab² + 2b³) + (4a²b + 7ab² − b³).
= (3 + 4)a²b + (−5 + 7)ab² + (2 − 1)b³.
Ответ: 7a²b + 2ab² + b³.

Пример 5

(6x²y − 3xy²) − (2x²y + 5xy²).
= 6x²y − 3xy² − 2x²y − 5xy².
Ответ: 4x²y − 8xy².

8. Нулевой результат и противоположные многочлены

Два многочлена называются противоположными, если сумма их соответствующих членов равна нулю.
P = 3x² − 5x + 7.
Противоположный многочлен:
−P = −3x² + 5x − 7.
P + (−P) = 0.
Чтобы записать многочлен, противоположный данному, нужно изменить знак каждого его члена.

9. Нахождение неизвестного многочлена

Сложение и вычитание многочленов позволяют находить неизвестное слагаемое, уменьшаемое или вычитаемое.

Найти многочлен Q, если Q + (2x² − 3x + 1) = 5x² + x − 4.
Неизвестное слагаемое равно разности суммы и известного слагаемого:
Q = (5x² + x − 4) − (2x² − 3x + 1).
Q = 5x² + x − 4 − 2x² + 3x − 1.
Ответ: Q = 3x² + 4x − 5.

10. Проверка результата подстановкой

Равносильность исходного и упрощённого выражений можно проверить, подставив одно и то же число вместо переменной.

Проверить при x = 2:

(3x² − x + 4) − (x² + 2x − 1) = 2x² − 3x + 5.
Левая часть:
(3 · 2² − 2 + 4) − (2² + 2 · 2 − 1) = 14 − 7 = 7.
Правая часть:
2 · 2² − 3 · 2 + 5 = 8 − 6 + 5 = 7.
Значения совпали.
Совпадение при одном значении не является полным доказательством, но помогает обнаружить вычислительную ошибку.

11. Частые ошибки

Изменён только первый знак

После минуса перед скобками меняется знак каждого члена.

Сложены неподобные члены

x² и x нельзя объединять в один одночлен.

Потерян отсутствующий член

Следите за степенями, которых нет в одном из многочленов.

Ответ не приведён к стандартному виду

После раскрытия скобок нужно объединить все подобные члены.

Различие между плюсом и минусом перед скобками

12. Задания для самопроверки

Сначала раскрывайте скобки отдельной строкой, а уже затем объединяйте подобные члены.

Задание 1. Найдите сумму: (3x² + 5x − 2) + (4x² − 2x + 7).

Показать решение
3x² + 5x − 2 + 4x² − 2x + 7.

(3 + 4)x² + (5 − 2)x + (−2 + 7).

Ответ: 7x² + 3x + 5.

Задание 2. Найдите разность: (8x² − 3x + 1) − (5x² + x − 4).

Показать решение
8x² − 3x + 1 − 5x² − x + 4.

Ответ: 3x² − 4x + 5.

Задание 3. Упростите: (2a²b − 5ab²) + (7a²b + 3ab²).

Показать решение
(2 + 7)a²b + (−5 + 3)ab².

Ответ: 9a²b − 2ab².

Задание 4. Упростите: (6x²y + 4xy²) − (2x²y − 5xy²).

Показать решение
6x²y + 4xy² − 2x²y + 5xy².

Ответ: 4x²y + 9xy².

Задание 5. Раскройте скобки и упростите: 4x² − (x² − 3x + 5).

Показать решение
4x² − x² + 3x − 5.

Ответ: 3x² + 3x − 5.

Задание 6. Упростите: (5x³ − 2x + 1) + (3x² + 4x − 6) − (2x³ − x² + 3).

Показать решение
Раскроем скобки:

5x³ − 2x + 1 + 3x² + 4x − 6 − 2x³ + x² − 3.

Объединим подобные члены:

3x³ + 4x² + 2x − 8.

Ответ: 3x³ + 4x² + 2x − 8.

Задание 7. Запишите многочлен, противоположный 4x³ − 7x² + 2x − 5.

Показать решение
Изменяем знак каждого члена:

Ответ: −4x³ + 7x² − 2x + 5.

Задание 8. Найдите P + Q, если P = 2x² − 5x + 3, Q = −2x² + 8x − 7.

Показать решение
P + Q = 2x² − 5x + 3 − 2x² + 8x − 7.

Члены с x² взаимно уничтожаются.

Ответ: 3x − 4.

Задание 9. Найдите P − Q, если P = 3a² + 2a − 1, Q = a² − 5a + 4.

Показать решение
P − Q = 3a² + 2a − 1 − a² + 5a − 4.

Ответ: 2a² + 7a − 5.

Задание 10. Найдите многочлен Q, если Q + (x² − 4x + 6) = 5x² + x − 2.

Показать решение
Q = (5x² + x − 2) − (x² − 4x + 6).

Q = 5x² + x − 2 − x² + 4x − 6.

Ответ: Q = 4x² + 5x − 8.

Задание 11. Найдите значение выражения (2x² + 3x − 1) − (x² − x + 4) при x = −2.

Показать решение
Сначала упростим:

x² + 4x − 5.

Подставим x = −2:

(−2)² + 4 · (−2) − 5 = 4 − 8 − 5 = −9.

Ответ: −9.

Задание 12. Найдите ошибку: (5x² − 3x + 2) − (2x² + x − 4) = 3x² − 2x − 2.

Показать решение
После минуса перед скобками знаки второго многочлена должны измениться:

5x² − 3x + 2 − 2x² − x + 4.

Правильный ответ: 3x² − 4x + 6.

Задание 13. Упростите: (4x³ − 2x² + 5x − 1) − (x³ + 3x² − 2x + 4) + (2x³ − x² − 6x + 7).

Показать решение
Раскроем скобки:

4x³ − 2x² + 5x − 1 − x³ − 3x² + 2x − 4 + 2x³ − x² − 6x + 7.

Члены с x³: 4 − 1 + 2 = 5.

Члены с x²: −2 − 3 − 1 = −6.

Члены с x: 5 + 2 − 6 = 1.

Свободные члены: −1 − 4 + 7 = 2.

Ответ: 5x³ − 6x² + x + 2.

13. Как проверить ответ

Скобки раскрыты Перед минусом изменены знаки каждого члена второго многочлена.
Подобные члены объединены В результате не осталось членов с одинаковой буквенной частью.
Стандартный вид Члены расположены в удобном порядке по убыванию степеней.
При сложении многочленов знаки внутри скобок сохраняются, а при вычитании — меняются на противоположные. В следующей теме разберём умножение многочлена на одночлен.
