Как умножать многочлен на одночлен

Разберём распределительное свойство умножения, научимся умножать одночлен на каждый член многочлена, правильно работать со знаками, степенями и дробными коэффициентами, а затем приводить результат к стандартному виду.

Что нужно знать перед темой

Умножение многочлена на одночлен объединяет сразу несколько ранее изученных действий.

  • Приведение одночлена к стандартному виду.
  • Умножение коэффициентов с учётом знаков.
  • Сложение показателей одинаковых переменных.
  • Раскрытие скобок.
  • Приведение подобных слагаемых.
  • Запись многочлена в стандартном виде.
Одночлен нужно умножить на каждый член многочлена без исключения. Пропуск одного члена полностью меняет результат.

1. Распределительное свойство умножения

Для любых выражений a, b и c выполняется:

a(b + c) = ab + ac.

Аналогично:

a(b − c) = ab − ac.

Множитель перед скобками распределяется на каждый член суммы или разности внутри скобок.

Одночлен умножается на каждый член многочлена

2. Алгоритм умножения многочлена на одночлен

Шаг 1. Умножьте одночлен на первый член многочлена.

Шаг 2. Повторите действие для каждого следующего члена.

Шаг 3. В каждом произведении перемножьте коэффициенты.

Шаг 4. Сложите показатели одинаковых переменных.

Шаг 5. Приведите результат к стандартному виду.

Пять последовательных шагов

3. Подробный пример

Умножить: −2a²b(3ab² − 4a² + 5b).
Умножим одночлен на первый член:
−2a²b · 3ab² = −6a³b³.
Умножим на второй член:
−2a²b · (−4a²) = 8a⁴b.
Умножим на третий член:
−2a²b · 5b = −10a²b².
Ответ: −6a³b³ + 8a⁴b − 10a²b².
Знак каждого члена результата определяется отдельно.

4. Знаки при раскрытии скобок

Положительный одночлен

Знаки членов внутри скобок сохраняются.

Отрицательный одночлен

Знак каждого произведения становится противоположным знаку члена.

Пример 1

4x(2x² − 3x + 5) = 8x³ − 12x² + 20x.

Пример 2

−4x(2x² − 3x + 5) = −8x³ + 12x² − 20x.

Положительный и отрицательный множители

5. Умножение многочлена с несколькими переменными

Для каждого произведения отдельно объединяют одинаковые переменные.

Пример 3

3a²b(2ab² − 5a³ + 4b³).
3a²b · 2ab² = 6a³b³.
3a²b · (−5a³) = −15a⁵b.
3a²b · 4b³ = 12a²b⁴.
Ответ: 6a³b³ − 15a⁵b + 12a²b⁴.
У каждого полученного одночлена может быть своя степень. В конце члены можно расположить в удобном порядке.

6. Если после раскрытия скобок появляются подобные члены

После умножения результат иногда содержит члены, которые можно объединить с членами, уже находившимися вне скобок.

Упростить: 2x(x² − 3x + 5) + 4x² − 7x.
Раскроем скобки:
2x³ − 6x² + 10x + 4x² − 7x.
Объединим члены с x²:
−6x² + 4x² = −2x².
Объединим члены с x:
10x − 7x = 3x.
Ответ: 2x³ − 2x² + 3x.

7. Дробные коэффициенты

Если коэффициент одночлена является дробью, он умножается на коэффициент каждого члена по обычным правилам работы с дробями.

Пример 4

2 3 x(9x² − 6x + 12).
2 3 x · 9x² = 6x³.
2 3 x · (−6x) = −4x².
2 3 x · 12 = 8x.
Ответ: 6x³ − 4x² + 8x.

8. Умножение на число

Число также является одночленом. При умножении многочлена на число меняются только коэффициенты его членов.

5(2x³ − 4x + 7) = 10x³ − 20x + 35.
−3(x² + 6x − 5) = −3x² − 18x + 15.
При умножении на отрицательное число знак каждого члена меняется.

9. Геометрический смысл распределительного свойства

Площадь большого прямоугольника можно найти как произведение его длины на общую ширину или как сумму площадей частей.

Площадь прямоугольника подтверждает формулу a(b + c) = ab + ac

10. Уравнения с умножением многочлена на одночлен

Решить уравнение: 3x(2x − 5) − 6x² = −30.
Раскроем скобки:
6x² − 15x − 6x² = −30.
Члены 6x² и −6x² уничтожаются:
−15x = −30.
x = 2.
Ответ: 2.
После раскрытия скобок уравнение может заметно упроститься.

11. Проверка результата

Результат можно проверить подстановкой одного и того же значения переменной в исходное и преобразованное выражения.

Проверить при x = 2:

3x(x² − 2x + 5) = 3x³ − 6x² + 15x.
Левая часть:
3 · 2 · (2² − 2 · 2 + 5) = 6 · 5 = 30.
Правая часть:
3 · 2³ − 6 · 2² + 15 · 2 = 24 − 24 + 30 = 30.
Значения совпали.

12. Частые ошибки

Пропущен один член

Одночлен умножается на каждый член внутри скобок.

Неверный знак

Знак каждого произведения определяется отдельно.

Показатели перемножены

При обычном произведении степеней показатели складываются.

Не приведены подобные члены

После раскрытия скобок выражение нужно упростить до конца.

Полезная проверка: число полученных произведений должно совпадать с количеством членов многочлена в скобках.

13. Задания для самопроверки

Выписывайте каждое произведение отдельно, особенно если одночлен или многочлен содержит отрицательные коэффициенты.

Задание 1. Раскройте скобки: 3x(x² + 4x − 5).

Показать решение
3x · x² = 3x³.

3x · 4x = 12x².

3x · (−5) = −15x.

Ответ: 3x³ + 12x² − 15x.

Задание 2. Раскройте скобки: −2a(a² − 3a + 7).

Показать решение
−2a · a² = −2a³.

−2a · (−3a) = 6a².

−2a · 7 = −14a.

Ответ: −2a³ + 6a² − 14a.

Задание 3. Умножьте: 5x²(2x³ − 4x + 1).

Показать решение
5x² · 2x³ = 10x⁵.

5x² · (−4x) = −20x³.

5x² · 1 = 5x².

Ответ: 10x⁵ − 20x³ + 5x².

Задание 4. Умножьте: −3ab(2a² − 5ab + 4b²).

Показать решение
−3ab · 2a² = −6a³b.

−3ab · (−5ab) = 15a²b².

−3ab · 4b² = −12ab³.

Ответ: −6a³b + 15a²b² − 12ab³.

Задание 5. Раскройте скобки: 1 2 x(8x² − 6x + 10).

Показать решение
1 2 x · 8x² = 4x³.

1 2 x · (−6x) = −3x².

1 2 x · 10 = 5x.

Ответ: 4x³ − 3x² + 5x.

Задание 6. Упростите: 4x(x² − 2x + 3) + 5x² − 7x.

Показать решение
Раскроем скобки:

4x³ − 8x² + 12x + 5x² − 7x.

Приведём подобные:

Ответ: 4x³ − 3x² + 5x.

Задание 7. Упростите: −2a(a² + 3a − 4) + 5a² − 6a.

Показать решение
−2a³ − 6a² + 8a + 5a² − 6a.

Ответ: −2a³ − a² + 2a.

Задание 8. Упростите: 3xy(2x² − xy + 4y²).

Показать решение
3xy · 2x² = 6x³y.

3xy · (−xy) = −3x²y².

3xy · 4y² = 12xy³.

Ответ: 6x³y − 3x²y² + 12xy³.

Задание 9. Найдите значение выражения 2x(x² − 3x + 4) при x = −1.

Показать решение
Сначала раскроем скобки:

2x³ − 6x² + 8x.

Подставим x = −1:

2 · (−1)³ − 6 · (−1)² + 8 · (−1) = −2 − 6 − 8 = −16.

Ответ: −16.

Задание 10. Решите уравнение: 2x(3x − 4) − 6x² = −16.

Показать решение
6x² − 8x − 6x² = −16.

−8x = −16.

x = 2.

Ответ: 2.

Задание 11. Найдите ошибку: 3x(x² − 2x + 5) = 3x³ − 6x² + 5.

Показать решение
Одночлен 3x не был умножен на последний член 5.

3x · 5 = 15x.

Правильный ответ: 3x³ − 6x² + 15x.

Задание 12. Найдите значение k, если после раскрытия скобок kx(2x − 3) получается 8x² − 12x.

Показать решение
kx(2x − 3) = 2kx² − 3kx.

Сравним коэффициенты:

2k = 8, откуда k = 4.

Проверка: −3 · 4 = −12.

Ответ: 4.

Задание 13. Упростите: −2x²(3x³ − 4x² + 5x − 6) + 7x⁴ − 3x³ + 12x².

Показать решение
Раскроем скобки:

−6x⁵ + 8x⁴ − 10x³ + 12x² + 7x⁴ − 3x³ + 12x².

Объединим подобные члены:

8x⁴ + 7x⁴ = 15x⁴;
−10x³ − 3x³ = −13x³;
12x² + 12x² = 24x².

Ответ: −6x⁵ + 15x⁴ − 13x³ + 24x².

14. Как проверить раскрытие скобок

Количество произведений Оно должно совпадать с количеством членов в многочлене.
Знаки и коэффициенты Проверьте знак каждого произведения и числовые множители.
Степени и подобные члены Сложите показатели одинаковых переменных и упростите результат.
Умножение многочлена на одночлен основано на распределительном свойстве: множитель применяется к каждому члену в скобках. В следующей теме разберём умножение многочлена на многочлен.
