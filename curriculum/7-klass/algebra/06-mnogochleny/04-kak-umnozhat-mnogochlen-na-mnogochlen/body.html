Как умножать многочлен на многочлен

Разберём, как получить произведение двух многочленов: умножить каждый член первого многочлена на каждый член второго, аккуратно определить знаки, привести полученные одночлены к стандартному виду и объединить подобные слагаемые.

Что нужно знать перед темой

Умножение многочленов основано на распределительном свойстве, которое применяется несколько раз подряд.

  • Уметь умножать одночлен на многочлен.
  • Учитывать знак каждого члена многочлена.
  • Складывать показатели одинаковых переменных.
  • Приводить одночлены к стандартному виду.
  • Находить и объединять подобные слагаемые.
  • Располага́ть члены многочлена по убыванию степеней.
Если первый многочлен содержит m членов, а второй — n членов, до приведения подобных слагаемых получится m · n произведений.

1. Главное правило

Чтобы умножить многочлен на многочлен, нужно:

каждый член первого многочлена умножить на каждый член второго,

затем сложить полученные произведения и привести подобные слагаемые.

Для двучленов правило записывается так:

(a + b)(c + d) = ac + ad + bc + bd.

Каждый член первого двучлена встречается с каждым членом второго

2. Алгоритм умножения многочленов

Шаг 1. Определите количество членов в каждом многочлене.

Шаг 2. Умножьте первый член первого многочлена на все члены второго.

Шаг 3. Повторите действие для остальных членов первого многочлена.

Шаг 4. Приведите каждый полученный одночлен к стандартному виду.

Шаг 5. Объедините подобные слагаемые.

Последовательность действий

3. Умножение двучлена на двучлен

Умножить: (2x + 3)(x − 4).
Умножим 2x на оба члена второго двучлена:
2x · x = 2x²;    2x · (−4) = −8x.
Умножим 3 на оба члена второго двучлена:
3 · x = 3x;    3 · (−4) = −12.
Получаем:
2x² − 8x + 3x − 12.
Приведём подобные слагаемые:
Ответ: 2x² − 5x − 12.
В произведении двух двучленов сначала получается четыре произведения. После приведения подобных членов итоговых членов может стать меньше.

4. Работа со знаками

Знак каждого произведения определяется отдельно. Нельзя заранее менять все знаки только по одному внешнему минусу.

Пример 1

(3x − 2)(2x − 5).
3x · 2x = 6x².
3x · (−5) = −15x.
(−2) · 2x = −4x.
(−2) · (−5) = 10.
Ответ: 6x² − 19x + 10.

Пример 2

(−x + 4)(3x + 2).
−3x² − 2x + 12x + 8.
Ответ: −3x² + 10x + 8.

5. Умножение трёхчлена на двучлен

Умножить: (x² + 2x − 3)(x + 4).
Умножим x² на x + 4:
x³ + 4x².
Умножим 2x на x + 4:
2x² + 8x.
Умножим −3 на x + 4:
−3x − 12.
Сложим все произведения:
x³ + 4x² + 2x² + 8x − 3x − 12.
Ответ: x³ + 6x² + 5x − 12.

6. Табличный способ

При большом количестве членов удобно использовать таблицу: в верхней строке записывают члены одного многочлена, в левом столбце — члены другого, а внутри — произведения.

Таблица для произведения (x + 3)(2x − 5)

Таблица помогает не пропустить произведения, но после её заполнения всё равно нужно привести подобные слагаемые.

7. Многочлены с несколькими переменными

Принцип остаётся тем же: каждый член умножается на каждый, а одинаковые переменные объединяются с помощью свойств степеней.

Пример 3

(2a + b)(3a − 4b).
2a · 3a = 6a².
2a · (−4b) = −8ab.
b · 3a = 3ab.
b · (−4b) = −4b².
−8ab + 3ab = −5ab.
Ответ: 6a² − 5ab − 4b².

Пример 4

(x² + xy + y²)(x − y).
x³ − x²y + x²y − xy² + xy² − y³.
Противоположные члены уничтожаются:
Ответ: x³ − y³.

8. Степень произведения многочленов

Если старшие члены многочленов не исчезают после приведения, степень произведения равна сумме степеней множителей.

Если степень P равна m, а степень Q равна n, то степень произведения P · Q обычно равна m + n.
(2x³ − x + 1)(5x² + 4).
Старшие члены: 2x³ и 5x².
Их произведение: 10x⁵.
Степень результата равна 3 + 2 = 5.
Для определения старшего члена полного произведения часто достаточно перемножить старшие члены исходных многочленов.

9. Геометрическая модель

Площадь прямоугольника со сторонами x + a и x + b можно разбить на четыре части.

Площадь прямоугольника объясняет четыре произведения

10. Уравнения после раскрытия скобок

Решить уравнение: (x + 2)(x − 3) − x² = −10.
Раскроем скобки:
x² − 3x + 2x − 6 − x² = −10.
Приведём подобные:
−x − 6 = −10.
−x = −4.
Ответ: x = 4.

11. Проверка подстановкой

Равенство исходного произведения и полученного многочлена можно проверить при выбранном значении переменной.

Проверить при x = 2:

(x + 3)(2x − 1) = 2x² + 5x − 3.
Левая часть:
(2 + 3)(2 · 2 − 1) = 5 · 3 = 15.
Правая часть:
2 · 2² + 5 · 2 − 3 = 8 + 10 − 3 = 15.
Значения совпали.

12. Задания для самопроверки

Перед приведением подобных слагаемых проверьте, все ли произведения выписаны и верно ли определён их знак.

Задание 1. Умножьте: (x + 2)(x + 5).

Показать решение
x · x = x².

x · 5 = 5x.

2 · x = 2x.

2 · 5 = 10.

Ответ: x² + 7x + 10.

Задание 2. Умножьте: (x − 3)(x + 4).

Показать решение
x² + 4x − 3x − 12.

Ответ: x² + x − 12.

Задание 3. Умножьте: (2x + 1)(3x − 5).

Показать решение
6x² − 10x + 3x − 5.

Ответ: 6x² − 7x − 5.

Задание 4. Умножьте: (4a − 3b)(2a + b).

Показать решение
8a² + 4ab − 6ab − 3b².

Ответ: 8a² − 2ab − 3b².

Задание 5. Умножьте: (x² + 3x + 2)(x − 1).

Показать решение
x³ − x² + 3x² − 3x + 2x − 2.

Ответ: x³ + 2x² − x − 2.

Задание 6. Умножьте: (2x² − x + 4)(x + 3).

Показать решение
2x³ + 6x² − x² − 3x + 4x + 12.

Ответ: 2x³ + 5x² + x + 12.

Задание 7. Упростите: (x + 2)(x − 2) + 4.

Показать решение
(x + 2)(x − 2) = x² − 2x + 2x − 4 = x² − 4.

x² − 4 + 4 = x².

Ответ: x².

Задание 8. Упростите: (2x − 3)(x + 5) − 2x².

Показать решение
2x² + 10x − 3x − 15 − 2x².

Ответ: 7x − 15.

Задание 9. Найдите значение выражения (x − 4)(2x + 3) при x = −1.

Показать решение
Сначала раскроем скобки:

2x² − 5x − 12.

Подставим x = −1:

2 · 1 + 5 − 12 = −5.

Ответ: −5.

Задание 10. Решите уравнение: (x + 1)(x − 4) − x² = −7.

Показать решение
x² − 4x + x − 4 − x² = −7.

−3x − 4 = −7.

−3x = −3.

Ответ: x = 1.

Задание 11. Найдите ошибку: (x + 3)(x − 2) = x² − 6.

Показать решение
Пропущены произведения x · (−2) и 3 · x.

x² − 2x + 3x − 6.

Правильный ответ: x² + x − 6.

Задание 12. Не раскрывая все скобки, определите степень произведения: (3x⁴ − x + 2)(5x³ + 7x² − 1).

Показать решение
Степень первого многочлена равна 4.

Степень второго многочлена равна 3.

Старшие члены дают 15x⁷.

Ответ: степень произведения равна 7.

Задание 13. Упростите: (2x² − 3x + 1)(x − 4) − (2x³ − 11x² + 13x − 4).

Показать решение
Раскроем первые скобки:

2x³ − 8x² − 3x² + 12x + x − 4.

Получаем:

2x³ − 11x² + 13x − 4.

Вычитается тот же многочлен:

Ответ: 0.

13. Соберите способ в одну схему

Распределите множители Каждый член первого многочлена должен встретиться с каждым членом второго.
Соберите произведения Определите знаки, перемножьте коэффициенты и сложите показатели степеней.
Сожмите результат Найдите подобные слагаемые и запишите итоговый многочлен стандартно.
Удобно считать ожидаемое число промежуточных произведений ещё до начала вычислений. Эта простая проверка помогает заметить пропущенный член. Далее изучаются формулы, позволяющие некоторые произведения многочленов раскрывать значительно быстрее.
