Связь с распределительным свойством

Деление многочлена на одночлен является обратным действием по отношению к умножению одночлена на многочлен.

Если c ≠ 0, то:

(ac + bc) : c = ac : c + bc : c = a + b.

То есть общий делитель распределяется по всем членам многочлена.

Делить нужно каждый член многочлена без исключения. Количество полученных частных до упрощения совпадает с количеством членов исходного многочлена.

1. Основное правило

Чтобы разделить многочлен на одночлен:

1. разделите на одночлен каждый член многочлена;
2. выполните деление коэффициентов;
3. вычтите показатели одинаковых переменных;
4. запишите результат в стандартном виде.

Общий делитель применяется к каждому члену

Пример 1

(15x⁴ − 10x³ + 5x²) : 5x².
= 15x⁴ : 5x² − 10x³ : 5x² + 5x² : 5x².
= 3x² − 2x + 1.
Ответ: 3x² − 2x + 1, где x ≠ 0.

2. Как делить отдельные члены

В каждом частном отдельно выполняются действия с коэффициентами и степенями переменных.

Действие Что делать Пример
Коэффициенты Разделить как обычные числа 24 : 6 = 4
Одинаковые переменные Вычесть показатели x⁷ : x³ = x⁴
Одинаковые степени Получить множитель 1 y⁵ : y⁵ = 1
Переменной нет в делителе Переписать её без изменения ab³ : a = b³
Из показателя переменной в делимом вычитают показатель той же переменной в делителе, а не наоборот.

4. Выражения с несколькими переменными

Пример 2

Разделить: (18a⁵b³ − 12a³b⁴ + 6a²b²) : 6a²b².
Первый член: 18a⁵b³ : 6a²b² = 3a³b.
Второй член: −12a³b⁴ : 6a²b² = −2ab².
Третий член: 6a²b² : 6a²b² = 1.
Ответ: 3a³b − 2ab² + 1, где a ≠ 0 и b ≠ 0.
Ограничения записывают для всех переменных, входящих в делитель.

5. Отрицательный делитель

При отрицательном делителе знак каждого частного определяется по обычным правилам деления чисел.

Пример 3

(−24x⁵ + 16x³ − 8x²) : (−8x²).
−24x⁵ : (−8x²) = 3x³.
16x³ : (−8x²) = −2x.
−8x² : (−8x²) = 1.
Ответ: 3x³ − 2x + 1, где x ≠ 0.

6. Дробные коэффициенты

Коэффициент частного может быть дробным. Это не мешает результату оставаться многочленом.

Пример 4

(5x⁴ − 10x³ + 15x²) : 6x².
= 5 6 x² − 5 3 x + 5 2 .
Ответ: 5 6 x² − 5 3 x + 5 2 , где x ≠ 0.

7. Когда частное является многочленом

Частное является многочленом, если после деления каждого члена переменные не оказываются в знаменателе.

Для каждой переменной показатель в каждом члене делимого должен быть не меньше показателя этой переменной в делителе.

Выражение Результат Многочлен?
(x⁵ + x³) : x² x³ + x Да
(x⁴ + x) : x² x² + 1/x Нет
(a³b² + a²b⁴) : ab a²b + ab³ Да
(a² + b²) : ab a/b + b/a Нет
Само деление может быть допустимым при ненулевом делителе, но его результат не всегда является многочленом.

8. Геометрический смысл правила

Если прямоугольник разделён на части с общей высотой a, то деление общей площади на высоту возвращает сумму ширин.

(ab + ac) : a = b + c

9. Проверка обратным действием

Найденное частное можно умножить на делитель. Если получится исходный многочлен, деление выполнено верно.

Проверить:

(20x⁵ − 12x³ + 4x²) : 4x² = 5x³ − 3x + 1.
Умножим частное на делитель:
4x²(5x³ − 3x + 1).
= 20x⁵ − 12x³ + 4x².
Получен исходный многочлен.
Проверка выполнена.

10. Уравнения после деления

Решить уравнение:

(12x³ − 18x²) : 6x = 5, где x ≠ 0.
Разделим каждый член:
2x² − 3x = 5.
2x² − 3x − 5 = 0.
Разложим левую часть:
(2x − 5)(x + 1) = 0.
x = 5 2 или x = −1.
Оба значения не равны нулю.
Ответ: −1; 5 2 .

11. Задания для самопроверки

В каждом задании сначала запишите ограничения, а затем разделите на одночлен каждый член многочлена.

Задание 1. Разделите: (18x⁴ + 12x³ − 6x²) : 6x².

Показать решение
18x⁴ : 6x² = 3x².

12x³ : 6x² = 2x.

−6x² : 6x² = −1.

Ответ: 3x² + 2x − 1, где x ≠ 0.

Задание 2. Разделите: (−24a⁵ + 16a³ − 8a²) : 8a².

Показать решение
Ответ: −3a³ + 2a − 1, где a ≠ 0.

Задание 3. Разделите: (21x⁶y³ − 14x⁴y⁵ + 7x³y²) : 7x³y².

Показать решение
Первый член даёт 3x³y.

Второй член даёт −2xy³.

Третий член даёт 1.

Ответ: 3x³y − 2xy³ + 1, где x ≠ 0 и y ≠ 0.

Задание 4. Разделите: (10x⁵ − 15x³ + 5x²) : (−5x²).

Показать решение
10x⁵ : (−5x²) = −2x³.

−15x³ : (−5x²) = 3x.

5x² : (−5x²) = −1.

Ответ: −2x³ + 3x − 1, где x ≠ 0.

Задание 5. Разделите: (3x⁴ + 6x³ − 9x²) : 4x².

Показать решение
Ответ: 3 4 x² + 3 2 x − 9 4 , где x ≠ 0.

Задание 6. Является ли многочленом частное (x⁶ + x⁴ − x²) : x²?

Показать решение
Частное равно x⁴ + x² − 1.

Переменных в знаменателе нет.

Ответ: да, является.

Задание 7. Является ли многочленом частное (x⁵ + x − 3) : x²?

Показать решение
Член x : x² даёт 1 x , а −3 : x² оставляет переменную в знаменателе.

Ответ: нет, частное не является многочленом.

Задание 8. Укажите ограничения: (12a⁴b³ − 6a²b²) : 3a²b.

Показать решение
Делитель 3a²b должен быть ненулевым.

Ответ: a ≠ 0, b ≠ 0.

Задание 9. Проверьте умножением: (30x⁶ − 18x⁴ + 6x²) : 6x² = 5x⁴ − 3x² + 1.

Показать решение
6x²(5x⁴ − 3x² + 1) = 30x⁶ − 18x⁴ + 6x².

Равенство верно.

Задание 10. Найдите значение частного (8x⁴ − 12x³ + 4x²) : 4x² при x = 3.

Показать решение
Сначала разделим:

2x² − 3x + 1.

При x = 3:

2 · 9 − 9 + 1 = 10.

Ответ: 10.

Задание 11. Найдите пропущенный многочлен: 5x²( ? ) = 20x⁵ − 15x³ + 10x².

Показать решение
Разделим правую часть на 5x²:

20x⁵ : 5x² = 4x³;
−15x³ : 5x² = −3x;
10x² : 5x² = 2.

Ответ: 4x³ − 3x + 2.

Задание 12. Упростите: [(18x⁵ − 12x³) : 6x²] + 2x³ − x.

Показать решение
Деление в скобках:

3x³ − 2x.

Прибавим остальные члены:

3x³ − 2x + 2x³ − x.

Ответ: 5x³ − 3x, где x ≠ 0.

Задание 13. Упростите и проверьте обратным действием: (24a⁶b⁴ − 16a⁴b³ + 8a³b²) : 8a³b².

Показать решение
Выполним деление:

24a⁶b⁴ : 8a³b² = 3a³b²;
−16a⁴b³ : 8a³b² = −2ab;
8a³b² : 8a³b² = 1.

Частное: 3a³b² − 2ab + 1.

Проверка:

8a³b²(3a³b² − 2ab + 1) = 24a⁶b⁴ − 16a⁴b³ + 8a³b².

Ответ: 3a³b² − 2ab + 1, где a ≠ 0 и b ≠ 0.

12. Перед переходом к разложению на множители

Распределите деление Общий одночлен должен разделить каждый член многочлена.
Сравните показатели Из показателя в делимом вычитается показатель в делителе.
Вернитесь умножением Частное, умноженное на делитель, должно дать исходный многочлен.
Деление показывает действие, обратное вынесению общего множителя:

ab + ac = a(b + c)   и   (ab + ac) : a = b + c.

Эта связь станет основой следующего раздела — разложения многочленов на множители.
