Сумма углов треугольника. Внешний угол

Докажем, что сумма углов любого треугольника равна 180°, научимся находить неизвестные углы и разберём важное свойство внешнего угла.

1. Теорема о сумме углов треугольника

Теорема

Сумма углов любого треугольника равна 180°.

Для треугольника ABC это записывают так: ∠A + ∠B + ∠C = 180°. Форма и размеры треугольника значения не имеют.

Доказательство с помощью параллельной прямой

Шаг 1. Дополнительное построение

Через вершину B проведём прямую a, параллельную стороне AC.

Шаг 2. Сравниваем накрест лежащие углы

Секущая AB даёт ∠4 = ∠1, а секущая BC даёт ∠5 = ∠3.

Шаг 3. Используем развёрнутый угол

Углы 4, 2 и 5 вместе образуют развёрнутый угол: ∠4 + ∠2 + ∠5 = 180°.

Шаг 4. Заменяем равные углы

Подставляем ∠4 = ∠1 и ∠5 = ∠3. Получаем ∠1 + ∠2 + ∠3 = 180°.

2. Как находить неизвестный угол

Если известны два угла треугольника, третий находят вычитанием их суммы из 180°.

Неизвестный угол = 180° − сумма двух известных углов.

Пример: два угла равны 48° и 67°

∠A = 180° − ∠B − ∠C ∠B = 180° − ∠A − ∠C ∠C = 180° − ∠A − ∠B

3. Полезные следствия

Не более одного прямого угла

Два прямых угла уже дают 180°, поэтому для третьего угла места не остаётся.

Не более одного тупого угла

Сумма двух тупых углов обязательно превышает 180°.

Не менее двух острых углов

Даже если третий угол прямой или тупой, два остальных обязаны быть острыми.

4. Внешний угол треугольника

Внешним углом треугольника называют угол, смежный с одним из внутренних углов. Чтобы получить внешний угол, одну из сторон треугольника продолжают за вершину.

Внешний угол BCD при вершине C

Свойство

Внешний угол треугольника равен сумме двух внутренних углов, не смежных с ним.

Смежные углы

Внутренний угол при C и внешний угол BCD дают в сумме 180°.

Сумма углов треугольника

В то же время ∠A + ∠B + ∠C = 180°.

Сравниваем равенства

Из обоих равенств следует: ∠BCD = ∠A + ∠B.

Внешний угол больше каждого из двух внутренних углов, не смежных с ним, потому что он равен их сумме.

5. Разобранные примеры

Пример 1. Обычный треугольник

Дано: ∠A = 39°, ∠B = 84°.

Решение: ∠C = 180° − 39° − 84° = 57°.

Ответ: 57°.

Пример 2. Равнобедренный треугольник

Дано: угол при вершине равен 44°.

Решение: сумма двух равных углов при основании равна 180° − 44° = 136°. Каждый из них равен 68°.

Ответ: 68°, 68° и 44°.

Пример 3. Внешний угол

Дано: внешний угол равен 126°, один не смежный внутренний угол равен 51°.

Решение: 126° = 51° + x, поэтому x = 75°.

Ответ: 75°.

Пример 4. Углы заданы отношением

Дано: углы относятся как 3 : 4 : 5.

Решение: 3x + 4x + 5x = 180°, откуда 12x = 180° и x = 15°. Углы равны 45°, 60° и 75°.

Ответ: 45°, 60°, 75°.

6. Задания для самопроверки

Задание 1. В треугольнике два угла равны 46° и 73°. Найдите третий угол.

Показать решение

Третий угол равен 180° − 46° − 73° = 61°.

Задание 2. Углы треугольника относятся как 2 : 3 : 4. Найдите все углы.

Показать решение

Пусть углы равны 2x, 3x и 4x. Тогда 9x = 180°, x = 20°. Углы: 40°, 60° и 80°.

Задание 3. В равнобедренном треугольнике угол при вершине равен 38°. Найдите углы при основании.

Показать решение

Углы при основании равны. Их сумма равна 180° − 38° = 142°, поэтому каждый равен 71°.

Задание 4. В равнобедренном треугольнике внешний угол при вершине равен 124°. Найдите внутренние углы треугольника.

Показать решение

Внутренний угол при вершине равен 180° − 124° = 56°. Два угла при основании равны: (180° − 56°) : 2 = 62°. Ответ: 56°, 62°, 62°.

Задание 5. Внешний угол треугольника равен 137°, а один из не смежных с ним внутренних углов равен 58°. Найдите другой не смежный угол.

Показать решение

По свойству внешнего угла: 137° = 58° + x. Поэтому x = 79°.

Задание 6. Внешний угол при вершине C равен 105°. Внутренний угол A равен 47°. Найдите угол B.

Показать решение

Внешний угол равен сумме двух не смежных внутренних: 105° = 47° + ∠B. Поэтому ∠B = 58°.

Задание 7. Может ли треугольник иметь два тупых угла? Обоснуйте ответ.

Показать решение

Нет. Сумма двух тупых углов уже больше 180°, а сумма всех трёх углов треугольника равна 180°.

Задание 8. Может ли треугольник иметь углы 25°, 65° и 90°? Как называется такой треугольник?

Показать решение

Да, потому что 25° + 65° + 90° = 180°. Это прямоугольный треугольник.

Задание 9. Один угол треугольника в два раза больше второго, а третий равен 60°. Найдите первые два угла.

Показать решение

Пусть меньший угол равен x, тогда второй равен 2x. Получаем x + 2x + 60° = 180°, 3x = 120°, x = 40°. Углы: 40° и 80°.

Задание 10. Докажите, что внешний угол треугольника больше каждого внутреннего угла, не смежного с ним.

Показать решение

Внешний угол равен сумме двух положительных не смежных внутренних углов. Поэтому эта сумма больше каждого из слагаемых по отдельности.

Главные связи темы

Внутренние углы треугольника всегда дают 180°. Внешний угол дополняет смежный внутренний угол до 180° и одновременно равен сумме двух других внутренних углов. Эти два факта позволяют решать большинство задач темы.
