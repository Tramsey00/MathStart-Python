1. Смежные углы

Два угла называют смежными, если у них одна сторона общая, а две другие стороны являются противоположными лучами.

Смежные углы образуют развёрнутый угол

Почему сумма равна 180°

Лучи OA и OC — противоположные, поэтому ∠AOC является развёрнутым.

Луч OB делит развёрнутый угол на две части: ∠AOB и ∠BOC.

Следовательно, ∠AOB + ∠BOC = 180°.

2. Вертикальные углы

Два угла называют вертикальными, если стороны одного угла являются продолжениями сторон другого.

Углы при пересечении двух прямых

Доказательство равенства вертикальных углов

Углы 1 и 2 смежные, поэтому ∠1 + ∠2 = 180°.

Углы 3 и 2 также смежные, поэтому ∠3 + ∠2 = 180°.

Следовательно, ∠1 = 180° − ∠2 и ∠3 = 180° − ∠2.

Значит, ∠1 = ∠3. Аналогично ∠2 = ∠4.

3. Перпендикулярные прямые

Две пересекающиеся прямые называют перпендикулярными, если они образуют четыре прямых угла. Запись: a ⊥ b.

Перпендикулярные прямые образуют четыре угла по 90°

Достаточно одного прямого угла

Если при пересечении прямых один угол равен 90°, то вертикальный ему тоже равен 90°, а смежные углы равны 180° − 90° = 90°.

Перпендикулярность симметрична

Если a ⊥ b, то и b ⊥ a.

Две прямые к одной прямой

Если a ⊥ c и b ⊥ c, то прямые a и b не пересекаются, то есть параллельны.

Угол между прямыми

За угол между пересекающимися прямыми принимают меньший из образованных углов.

4. Как решать задачи на пересечение прямых

1
Найдите вертикальный угол

Он равен данному углу.

2
Найдите смежный угол

Вычтите данный угол из 180°.

3
Проверьте четыре угла

Вертикальные углы должны совпадать, а каждая смежная пара — давать 180°.

Пример Один из углов при пересечении прямых равен 64°. Вертикальный ему угол также равен 64°. Каждый из двух смежных углов равен 180° − 64° = 116°.

5. Задания для самопроверки

Задание 1. Один из смежных углов равен 68°. Найдите второй.

Показать решение

Сумма смежных углов равна 180°.

180° − 68° = 112°.

Ответ: 112°.

Задание 2. Смежные углы равны. Найдите каждый из них.

Показать решение

Пусть каждый угол равен x. Тогда x + x = 180°, 2x = 180°, x = 90°.

Ответ: по 90°.

Задание 3. Один из вертикальных углов равен 47°. Найдите противоположный ему угол.

Показать решение

Вертикальные углы равны.

Ответ: 47°.

Задание 4. При пересечении двух прямых один из углов равен 131°. Найдите остальные три угла.

Показать решение

Вертикальный ему угол также равен 131°.

Два смежных угла равны 180° − 131° = 49°.

Ответ: 131°, 49°, 49°.

Задание 5. Смежные углы относятся как 2 : 7. Найдите эти углы.

Показать решение

Пусть углы равны 2x и 7x.

2x + 7x = 180°, 9x = 180°, x = 20°.

Углы: 40° и 140°.

Ответ: 40° и 140°.

Задание 6. Прямые a и b перпендикулярны. Чему равен каждый из четырёх углов при их пересечении?

Показать решение

Перпендикулярные прямые образуют четыре прямых угла.

Ответ: 90°.

Задание 7. Угол между пересекающимися прямыми равен 90°. Как называются эти прямые?

Показать решение

Прямые, образующие прямой угол, называются перпендикулярными.

Ответ: перпендикулярные.

Задание 8. При пересечении двух прямых вертикальные углы обозначены 5x − 12° и 3x + 26°. Найдите все четыре угла.

Показать решение

Вертикальные углы равны:

5x − 12 = 3x + 26.

2x = 38, x = 19.

Вертикальные углы: 5 · 19 − 12 = 83°.

Смежные с ними углы: 180° − 83° = 97°.

Ответ: 83°, 97°, 83°, 97°.

Коротко о главном

В задачах на пересечение прямых сначала определяйте, какие углы смежные, а какие вертикальные. Это сразу подсказывает, нужно ли складывать углы до 180° или приравнивать их. Если же прямые перпендикулярны, каждый образованный угол равен 90°.

Смежные углы Их сумма равна 180°, потому что вместе они образуют развёрнутый угол.
Вертикальные углы Они расположены друг напротив друга и всегда имеют одинаковую градусную меру.
Перпендикулярные прямые При пересечении таких прямых получаются четыре прямых угла по 90°.
