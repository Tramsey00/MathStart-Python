1. Обход каждого ребра ровно один раз

Во многих задачах требуется пройти по всем дорогам, линиям или участкам сети, не повторяя ни один из них. На языке графов нужно построить особую цепь, содержащую все рёбра.

Эйлеров путь проходит по каждому ребру графа ровно один раз. Если он заканчивается в той же вершине, где начался, такой путь называют эйлеровым циклом.

Эйлеров граф — связный граф, в котором существует эйлеров цикл.

2. Как степени вершин предсказывают обход

В промежуточную вершину мы входим по одному ребру и выходим по другому. Использованные рёбра образуют пары, поэтому степень такой вершины должна быть чётной.

Все степени чётные

В связном графе существует эйлеров цикл. Начать можно в любой вершине.

Ровно две нечётные

Существует открытый эйлеров путь: он начинается в одной нечётной вершине и заканчивается в другой.

Нечётных больше двух

Пройти все рёбра ровно один раз невозможно.

Проверяем связность

Все рёбра должны принадлежать одной связной части графа.

Вершины в эйлеровом обходе могут повторяться. Запрещено повторять именно рёбра.

3. Ориентированные графы

Ориентированный граф — граф, у каждого ребра которого указано направление. Направленное ребро часто называют дугой и изображают стрелкой.

Такие графы используют для односторонних дорог, переходов между страницами, последовательности действий и перевозок, где направление имеет смысл.

В ориентированном графе направление ребра обязательно

Неориентированное ребро AB

Связь действует в обе стороны: из A в B и из B в A.

Дуга A → B

Переход разрешён из A в B. Обратное направление возможно только при наличии отдельной стрелки B → A.

4. Входящие и исходящие дуги

Для вершины ориентированного графа отдельно считают стрелки, которые входят в неё, и стрелки, которые выходят из неё.

Входящая степень

Количество дуг, направленных к данной вершине.

Исходящая степень

Количество дуг, направленных из данной вершины.

Направленный путь

Последовательность дуг, по которым можно двигаться только по стрелкам.

5. Задания для самопроверки

Задание 1. Что называют эйлеровым циклом?

Показать решение

Это замкнутый обход, который проходит по каждому ребру графа ровно один раз и возвращается в начальную вершину.

Задание 2. Связный граф имеет степени вершин 2, 4, 2, 2. Является ли он эйлеровым?

Показать решение

Да. Все степени чётные, поэтому в связном графе существует эйлеров цикл.

Задание 3. В связном графе ровно две нечётные вершины A и D. Где должен начинаться и заканчиваться эйлеров путь?

Показать решение

Он должен начаться в одной нечётной вершине и закончиться в другой: из A в D или из D в A.

Задание 4. Можно ли пройти каждое ребро ровно один раз, если в связном графе четыре нечётные вершины?

Показать решение

Нет. Для открытого эйлерова пути допустимы ровно две нечётные вершины, а для цикла — ни одной.

Задание 5. Для графа на рисунке запишите эйлеров цикл, начинающийся в A.

Показать решение

Один из вариантов: A–B–C–D–E–C–A.

Задание 6. В ориентированном графе есть стрелки A → B и B → C. Можно ли пройти из C в A по этим двум дугам?

Показать решение

Нет. Направления стрелок ведут из A в B и из B в C, а обратный проход не разрешён.

Задание 7. У вершины P три входящие и две исходящие дуги. Назовите её входящую и исходящую степени.

Показать решение

Входящая степень равна 3, исходящая — 2.

Задание 8. Почему при проверке эйлерова обхода нельзя считать только вершины?

Показать решение

Условие относится к рёбрам: каждое ребро должно быть пройдено ровно один раз. Вершины при этом могут встречаться несколько раз.

Карта понятий раздела

Вершины и рёбра

Описывают объекты и связи между ними.

Степень вершины

Показывает число подходящих рёбер и помогает считать рёбра графа.

Путь, цепь, цикл

Описывают движение по рёбрам и замкнутые маршруты.

Эйлеров обход

Использует каждое ребро ровно один раз; направление стрелок в ориентированном графе учитывать обязательно.
